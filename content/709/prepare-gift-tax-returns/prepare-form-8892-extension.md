# Prepare Form 8892 extension for gift tax return

Use Form 8892 to request an automatic 6-month extension of time to file Form 709, when the taxpayer's not filing Form 4868 with individual income tax return or to make a payment of gift tax.

To prepare Form 8892 extension:

- Go to **Organizer**, **Extensions**.
- On the **8892 Extension Information** tab, select the applicable print option.
- Indicate if the taxpayer's filed Form 4868 and is required to file Form 8892-V (payment voucher).
- Indicate if you wish to have Part III information printed when not required.
- Indicate if you wish to de-select the **If you are applying for an automatic 6-month extension... in Part II**.
- Indicate if you wish to suppress the carry of the extension payment for Form 709, Page 1.
- And lastly, if necessary, enter override amounts for gift tax paid and GST tax paid.
