# Prepare Form 4868 extension for gift tax return

Use Form 4868 if applying for an extension of time to file with the taxpayer's individual income tax return.

To prepare Form 4868 extension:

- Go to **Organizer**, **Extensions**.
- Select **4868 Extension Information**.
- Select either:

  - send extension correspondence to preparer
  - print Automatic extension under Reg. 1.6081-4
- If applicable, complete the section for a taxpayer who's out of the country; otherwise, skip to the next step.

  - If applicable, select to print Taxpayer Abroad at the top of Form 4868.
  - Indicate if the taxpayer's abroad and is a U.S. citizen or resident.
  - If applicable, select to print this statement: State Regarding Extension of Time to File Pursuant to Regulation Section 1.6081-5(a).
- Enter the spouse's first and last name and SSN.
- If needed, enter overrides for total tax liability and total payments.
- And lastly, enter the fiscal year dates.
