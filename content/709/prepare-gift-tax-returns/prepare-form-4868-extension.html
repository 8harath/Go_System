Prepare Form 4868 extension for gift tax return

Use Form 4868 if applying for an extension of time to file with the taxpayer's individual income tax return.
To prepare Form 4868 extension:
  1. Go to
    Organizer
    ,
    Extensions
    .
  2. Select
    4868 Extension Information
    .
  3. Select either:
    1. send extension correspondence to preparer
    2. print Automatic extension under Reg. 1.6081-4
  4. If applicable, complete the section for a taxpayer who's out of the country; otherwise, skip to the next step.
    1. If applicable, select to print Taxpayer Abroad at the top of Form 4868.
    2. Indicate if the taxpayer's abroad and is a U.S. citizen or resident.
    3. If applicable, select to print this statement: State Regarding Extension of Time to File Pursuant to Regulation Section 1.6081-5(a).
  5. Enter the spouse's first and last name and SSN.
  6. If needed, enter overrides for total tax liability and total payments.
  7. And lastly, enter the fiscal year dates.
