E-file Alabama and New York consolidated returns

Submit consolidated 1065 and 1120 returns for Alabama and New York by e-filing the top-level return together with all member returns.
Alabama and New York require you to e-file 1065 and 1120 business returns separately for each member of a consolidated group. So when a lower-member return in either state is part of a consolidated return, you'll need to qualify and submit both the top-level and each lower-member return separately.
We've included a search feature unique to these 2 states to help you complete this process. To e-file either Alabama or New York, select
Returns Processing
,
E-file
, then
Select Returns
.

Consol display option

  1. For
    Select Returns/Extension
     options, select
    Consol Display
     for the
    Display Type
    .
  2. Mark the
    States/Cities ready to send
     checkbox, then select the state and return e-file type from the dropdown.
  3. Review the results, which show the top returns and member returns for the type you selected.
  4. Select the link for the top return to submit it along with the lower members.
  5. Mark the
    Select
     checkbox for the return, then select
    Submit for E-file
     to complete the e-file submission process.
  6. The system submits the top return and all members of the selected return to the taxing authority.

Regular display option

  1. For
    Select Returns/Extension
     options, select
    Regular Display
     for the
    Display Type
    .
  2. Mark the
    States/Cities ready to send
     checkbox, then select the state and return e-file type from the dropdown.
    note
    The system grays out all checkboxes for consolidated returns and makes them unavailable to submit for e-file. A message displays prompting you to submit this return with the entire consolidated group.
  3. Select the link on the subsidiary return ID.
  4. Mark the checkbox for the return to submit for e-file.

Alabama or New York links

If the system grays out an Alabama or New York consolidated return on the
Initial Returns
 screen, you need to select the
Alabama
 or
New York
 link. You'll get a list of qualified states, and you can submit the Alabama or New York parent, subsidiary, and consolidated returns as well.
  1. On the
    Initial Returns
     screen, review and mark the
    Select
     checkbox next to the following:
    • Each jurisdiction that's part of your Alabama or New York consolidated group.
    • All Alabama or New York consolidated group members.
  2. Select
    Submit For E-file
     to submit all the state returns you selected on this screen.
  3. Alternatively, you can select the jurisdiction's link to submit the returns if you prefer.
important

Select All

Returns
