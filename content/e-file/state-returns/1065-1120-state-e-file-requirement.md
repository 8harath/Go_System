# E-file Alabama and New York consolidated returns

Submit consolidated 1065 and 1120 returns for Alabama and New York by e-filing the top-level return together with all member returns.

Alabama and New York require you to e-file 1065 and 1120 business returns separately for each member of a consolidated group. So when a lower-member return in either state is part of a consolidated return, you'll need to qualify and submit both the top-level and each lower-member return separately.

We've included a search feature unique to these 2 states to help you complete this process. To e-file either Alabama or New York, select **Returns Processing**, **E-file**, then **Select Returns**.

## Consol display option

- For **Select Returns/Extension** options, select **Consol Display** for the **Display Type**.
- Mark the **States/Cities ready to send** checkbox, then select the state and return e-file type from the dropdown.
- Review the results, which show the top returns and member returns for the type you selected.
- Select the link for the top return to submit it along with the lower members.
- Mark the **Select** checkbox for the return, then select **Submit for E-file** to complete the e-file submission process.
- The system submits the top return and all members of the selected return to the taxing authority.

## Regular display option

- For **Select Returns/Extension** options, select **Regular Display** for the **Display Type**.
- Mark the **States/Cities ready to send** checkbox, then select the state and return e-file type from the dropdown.

  note

  The system grays out all checkboxes for consolidated returns and makes them unavailable to submit for e-file. A message displays prompting you to submit this return with the entire consolidated group.
- Select the link on the subsidiary return ID.
- Mark the checkbox for the return to submit for e-file.

## Single Alabama or New York forms

If you select the **Regular Display** option, you can submit single returns from the 

Initial Returns

 screen. Select the link or mark the checkbox in the **Selected** column.

## Regular display with all states option

When you select **All States/Cities E-file**, the results on the 

Returns

 screen display all qualified states and cities for all entity types.

You can submit single company returns with single Alabama or New York the same way as other single company jurisdictions. Mark the **All** checkbox or the **Select** checkbox, or select the link for the single company states.

## Considerations for other states

For consolidation companies with states other than Alabama or New York, you can submit an e-file from 2 locations:

- The 

  Returns

   screen
- The **Alabama** or **New York** links

**Returns screen**

On this screen, the system shows all qualified states and makes them available for you to submit for e-file except for Alabama and New York.

* Mark the **Select** option next to the states.
* Select **Submit For E-File**.
* You can submit all states other than the 2 mandatory states to their respective jurisdictions from the 

  Initial Returns

   screen.

## Alabama or New York links

If the system grays out an Alabama or New York consolidated return on the 

Initial Returns

 screen, you need to select the **Alabama** or **New York** link. You'll get a list of qualified states, and you can submit the Alabama or New York parent, subsidiary, and consolidated returns as well.

- On the 

  Initial Returns

   screen, review and mark the **Select** checkbox next to the following:


  * Each jurisdiction that's part of your Alabama or New York consolidated group.
  * All Alabama or New York consolidated group members.
- Select **Submit For E-file** to submit all the state returns you selected on this screen.
- Alternatively, you can select the jurisdiction's link to submit the returns if you prefer.

important

Access consolidated New York and Alabama from the Alabama or New York links to e-file the parent, subsidiary, and consolidated returns. If you select **Select All** on the initial 

Returns

 screen, the system won't submit the Alabama and New York consolidations.
