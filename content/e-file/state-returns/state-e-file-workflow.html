State e-file workflow

Track your state return through each step of the electronic filing process, from transmission to final acknowledgment.
Understanding the state e-file workflow helps you track where your return is in the submission process. All state returns follow this path:
  1. Thomson Reuters transmits your return (including any state returns) to the IRS.
  2. The IRS e-file system runs validation checks. If the return passes validation, the IRS sends it to the state. If the return fails validation, the IRS rejects it.
  3. The state retrieves your return from the IRS e-file system and sends a receipt confirmation.
  4. The state processes your return and sends an acknowledgment (accepted or rejected) back to the IRS e-file system.
  5. The system retrieves the acknowledgment and makes it available to you in the
    E-file Status Report
    .
