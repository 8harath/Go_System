## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 calendar days |


|

**E-Filing mandate** | No mandate for e-filing returns. The state mandates electronic payments for estimated tax payments over $50,000 and extension payments over $5,000. |


|

**Accepts state-only filings** | Yes - Attach the federal XML created for this State (Default) - Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared |


|

**Return types accepted** | Resident  Non-Resident  5227  Amended  Extension |


|

**Return types not accepted** | Part-year resident  Estimated payments |


|

**Accepts return with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Direct debit  Online e-payment  Check |


|

**Signature requirements** | Form M-8453F.  PIN not allowed as signature. |


|

**Supports PDF attachments** | Yes |
