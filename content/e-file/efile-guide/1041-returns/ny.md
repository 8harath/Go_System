# 1041 New York electronic filing information

## State contact information

If you have specific questions about what you can e-file or about rejections you received, contact the state for more information.

**NYS Department of Taxation and Finance**

[www.tax.ny.gov](http://www.tax.ny.gov)

**Phone**: 518-457-6387

## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 7 days |


|

**E-filing mandate** | Yes, if you prepare 10 or more returns or e-file one or more returns using software. |


|

**Accepts state-only filings** | Yes, attach the federal XML created for this site. Only federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident  Non-resident  Amended  Estimate payments  Extension |


|

**Return types not accepted** | Char 500Withholding  Bankruptcy estates with no balance due  Charitable remainder trusts with no balance due |


|

**Accepts return with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Check by mail |


|

**Signature requirements** | ERO retains TR-579.2 and TR-579.3  PIN not allowed as signature |


|

**Supports PDF attachments** | Yes |


|

**Special considerations** | If a return includes a form that is not supported by New York for electronic filing, the entire return must be paper filed. |
