State electronic filing details

E-filing information
Details
Grace period
No grace period, must be filed by due date.
E-filing mandate
Beginning with the first return due on or after January 1, 2019, all fiduciary income taxpayers must file forms and make payments electronically. If you are unable to file and pay electronically, you may request a waiver.
Accepts state-only filings
Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared
