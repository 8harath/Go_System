## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 calendar days from the due date of the return to resubmit rejected returns. |


|

**E-Filing mandate** | None |


|

**Accepts state-only filings** | Yes - Attach the federal XML created for this State (Default) - Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident  Part-year resident  Non-resident  Amended |


|

**Return types not accepted** | Estimate payments  Extension  5227 |


|

**Accepts return with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit  Online e-payment, via Georgia Tax Center  Check |


|

**Signature requirements** | GA Form 8453F is a signature form. It summarizes the agreement between the taxpayer and the tax preparer. It is for the taxpayer’s records and must be retained for a period of 3 years.  PIN is not allowed as signature. |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | We support the same number of years the IRS supports as long as you have been approved to e-file that return. |
