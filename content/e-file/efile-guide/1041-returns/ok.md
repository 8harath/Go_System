# 1041 Oklahoma electronic filing information

## State contact information

If you have specific questions about what you can e-file or about rejections you received, contact the state for more information.

**Oklahoma Tax Commission - Communications Division**

[www.tax.ok.gov](http://www.tax.ok.gov)

|

**Accepted forms of payment** | Direct debit (EFW)  Credit card via website (with fee)  Electronic funds transfer (EFT)  Check by mail |
