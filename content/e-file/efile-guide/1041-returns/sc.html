E-filing information
Details
Grace period
5 days
E-Filing mandate
E-file is mandated if the tax preparer filed 100+ returns in the previous tax year. A $50/return fee is charged on any mandated return that is not e-filed. Where electronic means are not available to file the return, but the 2D barcode is available, the preparer must use the 2D barcode.
Accepts state-only filings
Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared
