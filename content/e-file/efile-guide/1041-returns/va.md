## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | No grace period, must be filed by due date. |


|

**E-filing mandate** | Beginning with the first return due on or after January 1, 2019, all fiduciary income taxpayers must file forms and make payments electronically. If you are unable to file and pay electronically, you may request a waiver. |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared |


|

**Return types accepted** | Unrelated Business Income Tax Return  Resident  Amended  Estimated Payments (with return)  Extensions |


|

**Return types not accepted** | Annual Information Return |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT) |


|

**Signature requirements** | Form VA-8453C or VA-8879C retained by ERO for 3 years.. Pin accepted as signature. |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | N/A |
