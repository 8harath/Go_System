## State electronic filing details

|

E-filing information | Details |

|

**Grace period** | 5 calendar days. If the fifth day falls on a weekend or holiday, then the next business day will be the final day to retransmit and considered timely. |


|

**E-Filing mandate** | None  FTB Pub. 1346X - Fiduciary returns do not fall under the individual e-file mandate at this time. |


|

**Accepts state-only filings** | Yes - Attach the federal XML created for this State (Default) - Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared |


|

**Return types accepted** | Resident  Non-resident  Amended  Estimates  Extension |


|

**Return types not accepted** | Part-year resident  5227 |


|

**Accepts return with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of balance payment** | Direct debit  Check  ePayment |


|

**Signature requirements** | Yes - FTB 8879-FID. PIN allowed as signature. |


|

**Supports PDF attachments** | Yes |
