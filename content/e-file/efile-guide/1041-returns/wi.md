# 1041 Wisconsin electronic filing information

## State contact information

If you have specific questions about what you can e-file or about rejections you received, contact the state for more information.

## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 days |


|

**E-Filing mandate** | Must e-file if preparing 50 or more returns |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared |


|

**Return types accepted** | Resident  Non-resident  Amended  Estimate payments  Withholding |


|

**Return types not accepted** | Extension  Agency return  Grantor return  Schedule CC |


|

**Accepts return with these conditions** | Refund/credit  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit  Check |


|

**Signature requirements** | Pin allowed as signature. |


|

**Supports PDF attachments** | Yes |


|

**Special considerations** | You cannot make Form PW-1 payments by check if filing electronically; you must use EFW. |
