# 1041 South Carolina electronic filing information

## State contact information

If you have specific questions about what you can e-file or about rejections you received, contact the state for more information.

**South Carolina Department of Revenue - Fiduciary Tax**

<https://dor.sc.gov/tax/fiduciary>

**Email:** [Fiduciaries@dor.sc.gov](mailto:Fiduciaries@dor.sc.gov)

**Phone:** 803-898-5791

## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 days |


|

**E-Filing mandate** | E-file is mandated if the tax preparer filed 100+ returns in the previous tax year. A $50/return fee is charged on any mandated return that is not e-filed. Where electronic means are not available to file the return, but the 2D barcode is available, the preparer must use the 2D barcode. |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared |


|

**Return types accepted** | Resident  Non-resident  Amended |


|

**Return types not accepted** | Estimate payments  Extension  Withholding |


|

**Accepts return with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit  Check |


|

**Signature requirements** | No signature form. PIN accepted as signature |


|

**Supports PDF attachments** | Yes |
