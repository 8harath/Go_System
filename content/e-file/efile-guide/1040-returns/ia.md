|

E-filing information | Details |

**Grace period** | 10 calendar days |

**E-filing mandate** | None |

|

**Return types accepted** | Resident  Part-year resident  Nonresident  Estimate payments (except for married filing separate combined returns) |

|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Check  Online ePayment |


|

**Signature requirements** | ERO retains IA-8453\_F for 3 years. PIN is allowed as signature for federal/state only. PIN is not allowed for state only. |


|

**Driver's license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|
