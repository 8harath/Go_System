## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 7 days |


|

**E-filing mandate** | Yes, if:    * You file more than 11 original tax returns (not amended) tax returns during any calendar year; * You prepared at least 10 original tax returns during the previous calendar year; and * OH Dept of Taxation hasn’t granted you an exclusion (yearly).   Opt-out / Waiver: Form IT Waiver is mailed with paper return. |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident  Nonresident  Part-year  Amended  Forms IT10  SD100  Estimate payments |


|

**Return types not accepted** | Extension  Combined / Consolidated |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Credit card |


|

**Signature requirements** | Acceptance of perjury statement is considered to be signature.  PIN allowed as signature: No |


|

**Drivers license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and 2 prior tax years |


|

**Special considerations** | N/A |
