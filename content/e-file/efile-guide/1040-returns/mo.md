## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 calendar days |


|

**E-filing mandate** | No |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Amended (beginning with 2022 returns)  Resident  Nonresident  Part-year |


|

**Return types not accepted** | Estimate Payments  Extension |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Electronic funds withdrawal (EFW)  Electronic funds transfer (EFT)  Credit card  Check |


|

**Signature requirements** | ERO retains signed Form MO-8453 for 3 years, or signing Federal 8879 satisfies state requirements. PIN is allowed as signature. |


|

**Drivers license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | None. |
