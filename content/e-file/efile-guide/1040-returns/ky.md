## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 calendar days |


|

**E-filing mandate** | You must e-file if you are preparing more than 10 returns (following the IRS). File Form 8948-K to opt out. |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident  Part-year resident  Nonresident  Amended  Estimate payments  Extension  Louisville/Jefferson County |


|

**Return types not accepted** | Lexington/Fayette County  Occupational License Fee return (Form OL-S) |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes, when you are filing Form 725 or resident Form 740. No, when are you filing non-resident or part-year resident Form 740-NP. |


|

**Accepted forms of payment** | Direct debit (EFW)  Credit card  Online ePayment |


|

**Signature requirements** | ERO retains 8879-K for 3 years, or completes federal Form 8879. |


|

**Drivers license requirements** | Optional for state return. Required for Louisville. |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | See KY-1345 Handbook for Electronic filers. |
