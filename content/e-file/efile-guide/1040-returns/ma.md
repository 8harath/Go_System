## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 business days |


|

**E-filing mandate** | Yes, if preparing more than 10 returns. Extension requests are mandated when the payment is $5,000 or more. Contact Massachusetts DOR if you need to file a waiver. |


|

**Accepts state-only filings** | Yes |


|

**Return types accepted** | Resident  Nonresident  Part-year  Amended  Estimate Payments  Extension (when payment is included) |


|

**Return types not accepted** | LLC Annual report |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Credit card |


|

**Signature requirements** | ERO retains signed Form M-8453 for 3 years |


|

**Signature requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | See M-1345 Handbook for Electronic Filers for more information. |
