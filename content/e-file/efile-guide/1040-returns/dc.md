## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | DC has no published perfection period, please contact DC if you need information regarding your specific return. |


|

**E-filing mandate** | No |


|

**Accepts state-only filings** | Yes - Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident  Part-year resident  Amended  Estimate Payments  Extension |


|

**Return types not accepted** | Nonresident |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Check  Direct debit (EFW)  Electronic funds transfer (EFT) |


|

**Signature requirements** | ERO retains D-40E for 3 years. PIN is not allowed as signature. |


|

**Driver's license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | See DC-1345 Handbook for Electronic Filers for more information. |
