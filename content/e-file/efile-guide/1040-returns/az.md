## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 calendar days |


|

**E-filing mandate** | No |


|

**Accepts state-only filings** | You must file a federal return with, or prior to filing, the AZ return. |


|

**Return types accepted** | Resident  Part-year resident  Nonresident  Extension  Property Tax Credit (with return) |


|

**Return types not accepted** | Amended  Estimate payments |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Credit card  Online ePayment |


|

**Signature requirements** | ERO retains AZ-8879 for 4 years |


|

**Driver's license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | Arizona does not accept amended returns for any tax year. |
