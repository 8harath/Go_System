## State electronic filing details

|

E-filing | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 days |


|

**E-filing mandate** | Yes, if filing more than 25 returns.  ERO retains Form RPD-41338 |


|

**Accepts state-only filings** | Yes |


|

**Return types accepted** | Resident  Nonresident  Part-year |


|

**Return types not accepted** | Amended  Estimate Payments  Extension |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (checking account only)  Electronic funds transfer (EFT)  Credit card |


|

**Signature requirements** | ERO retains PIT-8453 for 3 years. Mail Form PIT-8453 to Taxation and Revenue Department if paper documentation is required to be submitted.  PIN not allowed as signature. |


|

**Drivers license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | See Federal/State Electronic Filing Handbook |
