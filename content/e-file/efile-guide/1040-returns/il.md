## State electronic filing details

|  |  |
| --- | --- |
|

**Grace period** | 5 business days |


|

**E-filing mandate** | You must e-file if you are preparing more than 10 returns (follows IRS electronic filing mandate). |


|

**Accepts state-only filings** | Yes, attach the federal XML created for this state (default). Only federal e-file validation errors need to be cleared. E-file Reject Diagnostics don't need to be cleared. |


|

**Return types accepted** | Resident  Part-year resident  Nonresident  Estimate payments  Amended |


|

**Return types not accepted** | Extension |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Check  Online ePayment |


|

**Signature requirements** | ERO retains IL-8453 for 3 years. PIN is not allowed as signature. |


|

**Driver's license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | N/A |
