## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 days |


|

**E-filing mandate** | Preparers must e-file if more than 100 returns were filed in the prior tax year. A checkmark box on Form 502/505 authorizes the paid preparer not to e-file. |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident  Nonresident  Part-year  Amended  Estimate Payments (separate e-file for each payment)  Extension |


|

**Return types not accepted** | N/A |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes (up to 3 accounts) |


|

**Accepted forms of payment** | Direct debit (EFW) (Not for amended returns)  Electronic funds transfer (EFT)  Credit card |


|

**Signature requirements** | ERO retains signed EL-101 for 3 years. PIN is not allowed. |


|

**Drivers license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | See E-File Handbook for additional information. |
