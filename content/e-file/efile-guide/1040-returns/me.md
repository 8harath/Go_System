## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | Rejected returns must be resubmitted within 24 hours of the due date. |


|

**E-filing mandate** | Preparers must e-file if you are preparing more than 10 returns. |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident  Part-year resident  Nonresident  Amended  Estimate payments |


|

**Return types not accepted** | Extension |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Online ePayment |


|

**Signature requirements** | Maine considers the act of e-filing a signature. The signature process used for the federal return is accepted for the state signature requirement. No signature is required for State-Only returns. No signature document should be mailed to the state. |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | See Publication IIT-ELF, Maine Handbook for Electronic filers |
