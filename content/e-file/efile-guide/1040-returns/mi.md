## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | State doesn't have a perfection date |


|

**E-filing mandate** | Yes, if preparing 11 or more returns. |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident  Nonresident  Part-year  Amended  MI-1040CR series |


|

**Return types not accepted** | Estimate Payments  Extensions  Superseded |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Credit card  Check |


|

**Signature requirements** | Accepts federal PIN as signature when filing federal and state together. For state-only, provide "shared secrets" to use a state PIN, or complete Form MI-8453. If used, ERO retains MI-8453 for 6 years. |


|

**Drivers license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | See Michigan Tax Preparer Handbook for Electronic Filing information. |
