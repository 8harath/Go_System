## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | Resubmit a return within 24 hours of receipt or rejection |


|

**E-filing mandate** | Yes, if you are preparing more than 100 returns. |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident  Nonresident  Part-year  RI-1065 (SMLLC & Sole Proprietorship)  BUS-V  Amended  Extension |


|

**Return types not accepted** | Estimate Payments  Property tax relief claim |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  note EFW payments for extensions are supported starting with TY2024.  Electronic funds transfer (EFT)  To pay online visit [https://tax.ri.gov/online-services/make-payment-online](https://taxportal.ri.gov/).  Credit card  note EFW payments for Single Member LLC are supported starting with TY2024.  SMLLC payments can also be paid online, by credit card or by using Form BUS-V.  To pay with a credit card online visit [tax.ri.gov/online-services/make-payment-online/credit-card-payments](https://tax.ri.gov/online-services/make-payment-online/credit-card-payments) |


|

**Signature requirements** | None.  Completing federal signature requirements satisfies state requirements.  PIN allowed as signature: No |


|

**Drivers license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | None |
