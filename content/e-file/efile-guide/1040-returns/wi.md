**E-filing mandate** | You must e-file if preparing 50 or more returns. |

**Return types accepted** | Resident  Non-Resident  Part Year Resident  Amended  Estimate Payments  Amended |


|

|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Check  Direct debit (EFW)  ePayment |


|

**Signature requirements** | The act of e-filing is considered to be signature. PIN is not allowed as signature. |


|

**Driver's license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | See Publication 115 Handbook for Federal/State Electronic Filing for more information. |
