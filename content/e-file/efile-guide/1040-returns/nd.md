## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 days |


|

**E-filing mandate** | No |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident  Nonresident  Part-year  Estimate Payments  Amended |


|

**Return types not accepted** | Extension |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Credit card  ePayment |


|

**Signature requirements** | None  The IRS obtains the taxpayer’s signature by requiring the taxpayer to select a PIN (federal Form 8879). North Dakota recognizes the federal PIN as the signature for the North Dakota return. If the return must be submitted as an unlinked (state only) return, a self-selected PIN may be used. |


|

**Drivers license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | N/A |
