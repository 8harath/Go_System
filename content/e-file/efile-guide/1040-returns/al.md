## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 10 calendar days |


|

**E-filing mandate** | You'll need to e-file if you're preparing 11 or more returns. Mail Form EOO with paper return to opt out. |


|

**Accepts state-only filings** | Yes, for nonresident returns only. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared |


|

**Return types accepted** | Resident  Part-year resident  Nonresident  Estimate Payments  Extensions |


|

**Return types not accepted** | Amended |


|

**Accepts returns with these conditions** | Refund  Zero balance (except extensions)  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Check  Credit card |


|

**Signature requirements** | ERO retains AL-8453 for 3 years. PIN is not allowed as signature. |


|

**Drivers license requirements** | Alabama  **requires**  a drivers license or state ID for both the taxpayer and spouse when you file electronically. |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | * If you need to e-file the Alabama return separately, you must transmit the federal return first. * See Publication 4163 Alabama ERO Handbook |
