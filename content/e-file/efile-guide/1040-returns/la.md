## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 calendar days |


|

**E-filing mandate** | You must e-file at least 90% of returns if you are preparing more than 100 returns. All Nonresident Professional Athlete returns must be e-filed. |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident  Part-year resident  Nonresident  Amended  Extension  Nonresident Professional Athlete (Form IT-540B-NRA) |


|

**Return types not accepted** | Estimate payments |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Credit card  Online ePayment |


|

**Signature requirements** | ERO retains LA-8453 for 3 years. If you are using a PIN to sign, Form LA-8453 is not required. |


|

**Drivers license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | Taxpayers who e-file and are due a federal & state refund and direct deposit the federal refund must also direct deposit the state refund unless the taxpayer lacks a personal checking account. For more information see Handbook for Electronic Filers. |
