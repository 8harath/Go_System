## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | None |


|

**E-filing mandate** | Must e-file if preparing 50 or more returns |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident  Part-year resident  Nonresident  Amended  Extensions  Estimates |


|

**Return types not accepted** | Form 763-S Special Nonresident Claim |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Credit card |


|

**Signature requirements** | ERO retains signed Form VA-8543 or VA-8879 for 3 years. |


|

**Driver's license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | See Handbook for Authorized Tax Preparers and Electronic Return Originators for more information. |
