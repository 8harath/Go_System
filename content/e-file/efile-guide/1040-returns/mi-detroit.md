## City electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | None |


|

**E-filing mandate** | You must e-file if you are preparing more than 10 returns. |


|

**Accepts city-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident  Part-year resident  Nonresident  Amended |


|

**Return types not accepted** | Extension  Estimate |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Direct debit (EFW) |


|

**Signature requirements** | Detroit accepts federal PIN as the signature when you are e-filing with the federal return. If you are e-filing without a federal return, provide "shared secrets" to use PIN. |


|

**Driver's license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current year and prior two years |


|

**Special considerations** | For tax year 2015 and later, Detroit returns are processed by the Michigan Department of Treasury. See Michigan Tax Preparer Handbook for Electronic Filing. |
