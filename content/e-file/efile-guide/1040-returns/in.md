## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 calendar days |


|

**E-filing mandate** | A preparer must e-file resident returns if they're preparing more than 10 returns. |


|

**Accepts state-only filings** | Yes, attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident (IT-40)  Part-year/Nonresident (IT-40PNR)  Reciprocal Nonresident (IT-40RNR)  Amended IT-40, IT-40PNR, IT-40RNR for tax years 2024 and beyond |


|

**Return types not accepted** | Estimate  Extension (IT-9)  Amended IT-40, IT-40PNR, IT-40RNR for tax years 2023 and prior (paper-file only) |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes, original returns only. |


|

**Accepted forms of payment** | Online ePayment  Credit card  Check  Direct Debit (Electronic Funds Withdrawal) for a balance due on original or amended returns, and estimates filed with the original return only. |


|

**Signature requirements** | ERO retains IT-8879 for 4 years from close of tax year. PIN is allowed as signature. |


|

**Driver's license requirements** | Optional |


|

**Supports PDF attachments** | No |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | None |
