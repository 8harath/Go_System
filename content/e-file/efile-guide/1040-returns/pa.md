E-filing information | Details |

**Grace period** | None |


|

**E-filing mandate** | Must e-file if preparing 11+ returns  Opt-out / Waiver: A checkbox on Form PA-40 authorizes the paid preparer not to e-file. |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics don’t have to be cleared. |


|

**Return types accepted** | Resident  Nonresident  Part-year  Amended  Estimate Payments  Extension |


|

**Return types not accepted** | None |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Credit card  note Payments of $15,000 or more are required to be paid using EFW, EFT, or by credit card. To pay using EFT or credit card go to [mypath.pa.gov](http://www.mypath.pa.gov). You may also pay by a credit card by telephone by calling 1-800-272-9829.  EFW and EFT payments can be made from banks located in the U.S. |


|

**Signature requirements** | ERO retains signed PA-8453, PA-8879, or jurat statement for 3 years.  PIN allowed as signature: Yes - Fed/State, No - State only, No - state amended return |


|

**Drivers license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax years supported for e-filing** | Current tax year and 2 prior tax years |


|

**Special considerations** | See Publication REV-993 Handbook for Electronic Filers |
