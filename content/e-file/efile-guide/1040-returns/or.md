## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 30 days |


|

**E-filing mandate** | Yes, if filing more than 10 returns.  ERO retains Declaration to File Tax Return on Paper. |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default) - Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident  Nonresident  Part-year  Amended |


|

**Return types not accepted** | Estimate Payments  Extension |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Credit card |


|

**Signature requirements** | ERO retains Form EF for 3 years. If using a PIN Form EF is not required.  PIN allowed as signature: Yes |


|

**Drivers license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | * Portland Arts tax forms only allow one individual that is 18+ years on an e-filed form. If you're filing a joint return or have dependents that are 18 years or older, you'll need to paper file. * You can use the Filing Status Optimization (FSO) utility to split a MFJ return in order to e-file the Portland Arts forms. * If you e-file the Arts tax forms, you must use electronic funds withdrawal (EFW). |
