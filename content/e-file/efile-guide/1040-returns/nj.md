## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 10 days |


|

**E-filing mandate** | Yes, if filing more than 10 resident returns.  Penalty of $50/return that is not e-filed.  Opt-out / Waiver: ERO retains Form NJ-1040-O |


|

**Accepts state-only filings** | Yes |


|

**Return types accepted** | Resident  Nonresident  Part-year  Amended  Estimate Payments (separate e-file)  Extension  PTR-1 |


|

**Return types not accepted** | N/A |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (required for extensions)  Electronic funds transfer (EFT)  Credit card |


|

**Signature requirements** | Act of e-file is considered signature. NJ-8879 is not required.  PIN allowed as signature: Yes |


|

**Drivers license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Within 3 calendar years |


|

**Special considerations** | If an extension shows a balance due it must be paid by direct debit. See NJ 1040 Handbook for Practitioners |
