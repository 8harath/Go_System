# 1040 federal electronic filing information

## Contact information

If you have specific questions about what you can e-file or about rejections you received, contact the IRS for more information.

**Internal Revenue Service**

**Website**: <https://www.irs.gov/e-file-providers/e-file-for-tax-professionals>

**Phone**: 866-255-0654

**Tax Refund Inquiries**: [Where's My Refund?](https://www.irs.gov/wheres-my-refund)

## Electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 calendar days to e-file, or 10 calendar days to paper file. |


|

**E-filing mandate** | You'll need to e-file if you're preparing 11 or more returns.  Complete Form 8944 with paper return to opt out. |


|

**Return types accepted** | 1040 and 1040-SR resident individual  1040NR, Nonresident  1040-SS, Self Employment  1040X, Amended  Superseded  Extension  Estimate payments (only if made as electronic funds withdrawal payments with tax return or extension) |


|

**Return types not accepted** | Dual Status returns (1040 with 1040NR attachments) |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Electronic funds withdrawal (EFW)  Check  Credit card (if payment is set up through IRS.gov or an approved third-party vendor) |


|

**Signature requirements** | ERO retains 8879 for 3 years. PIN is allowed as signature. |


|

**Drivers license requirements** | The IRS recommends including drivers license information to help prevent identity theft and fraudulent filing. |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | None |
