E-filing mandate
You'll need to e-file if you're preparing 11 or more returns. Mail Form EOO with paper return to opt out.

Yes, for nonresident returns only. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared
