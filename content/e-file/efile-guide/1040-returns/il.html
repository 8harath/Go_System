Grace period
5 business days
E-filing mandate
You must e-file if you are preparing more than 10 returns (follows IRS electronic filing mandate).
Accepts state-only filings
Yes, attach the federal XML created for this state (default). Only federal e-file validation errors need to be cleared. E-file Reject Diagnostics don't need to be cleared.
