## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 10 days |


|

**E-filing mandate** | No |


|

**Accepts state-only filings** | Yes, attach the federal XML created for this state (default). Only federal e-file validation errors need to be cleared. E-file Reject Diagnostics don't need to be cleared. |


|

**Return types accepted** | Resident  Part-year resident  Nonresident  Amended  Estimate |


|

**Return types not accepted** | Extension |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Check  ePayment |


|

**Signature requirements** | Idaho considers the act of e-filing a signature. The signature process used for the federal return is accepted for the state signature requirement. No signature is required for State-Only returns. No signature document should be mailed to the state. PIN is not allowed as signature. |


|

**Driver's license requirements** | Optional |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | See Idaho E-file (MeF) Handbook |
