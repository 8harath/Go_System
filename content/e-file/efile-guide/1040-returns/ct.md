## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 days |


|

**E-filing mandate** | You must e-file if preparing 50 or more returns. |


|

**Accepts state-only filings** | Yes  Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Resident  Part-year resident  Nonresident  Estimate payments (there will be a separate e-file for each estimate payment)  Extension  Amended |


|

**Return types not accepted** | N/A |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Credit card  Check  Online ePayment |


|

**Signature requirements** | Completing federal Form 8879 signature requirements satisfies state requirement |


|

**Driver's license requirements** | Required |


|

**Supports PDF attachments** | No |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years (except for amended returns, which aren't eligible for e-file) |


|

**Special considerations** | See Electronic filing handbook |
