**E-filing mandate** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |

|

**Return types not accepted** | Corporations filing Form 1120-POL, 1120-REIT, or 1120-PC  Withholding  Declaration of Deminimus Activity |

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Electronic funds transfer (C corp only)  Check by mail  myPATH (PA online portal) |


|

**Signature requirements** | ERO retains signed PA-8879C/P/NRC or PA-8453C/P/NRC  PIN is allowed as a signature |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |
