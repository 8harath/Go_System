## State electronic filing details

|

E-filing information | Details |

**Grace period** | 10 days for returns and extensions |


|

**E-filing mandate** | Yes if federal gross receipts are greater than or equal to $1,000,000 |


|

**Accepts state-only filings** | Yes |


|

**Return types accepted** | C Corporation  S Corporation  Consolidated / Combined  Amended  Short year  Extension  Withholding  Pass-through Entity Tax |


|

**Return types not accepted** | Estimates |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic Funds Transfer (EFT)  Check by mail |


|

**Signature requirements** | ERO retains signed 8879(C)-K for 4 years |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|
