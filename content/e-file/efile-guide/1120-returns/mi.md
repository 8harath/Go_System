## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | No |


|

**E-filing mandate** | Yes, all returns. |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared |


|

**Return types accepted** | C Corporation  Amended  Short-year  Unitary  Financial, Insurance |


|

**Return types not accepted** | Estimate Payments  Extension  Composite  S Corporation |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Check by mail  Direct debit (EFW)  Electronic funds transfer (EFT) |


|

**Signature requirements** | Form 4763 (MI-8879), Fed PIN, or Fed 8453 |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years. |


|

**Special considerations** | N/A |
