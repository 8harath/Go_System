# 1120 Ohio Municipal Net Profit electronic filing information

## State contact information

If you have specific questions about what you can e-file or about rejections you received, contact the municipality for more information. Municipal Net Profit tax information is available on the [Ohio Department of Taxation's website](https://www.tax.ohio.gov/MunicipalTax.aspx).

## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 10 days |


|

**E-filing mandate** | All MNP returns and estimates are required to be filed electronically unless a waiver has been granted. |


|

**Accepts city-only filings** | Yes |


|

**Return types accepted** | C Corporation  S Corporation  Amended  Short year  Estimates (filed separate from return) |


|

**Return types not accepted** | Consolidated / Combined  Extension |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Check (with approval from department) |


|

**Signature requirements** | Ohio considers the act of e-filing an authorized signature. |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | N/A |
