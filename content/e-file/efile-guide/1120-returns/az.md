## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 10 days |


|

**E-filing mandate** | Yes |


|

**Accepts state-only filings** | You must file a federal return with, or prior to filing, the AZ return. |


|

**Return types accepted** | C Corporation  S Corporation  Consolidated / Combined |


|

**Return types not accepted** | Estimates  Amended - C Corporation  Corporations filing Form 1120-POL |


|

**Direct deposits of refunds** | No |


|

**Accepted forms of payment** | Direct debit (EFW)  Check  Online ePayment |


|

**Signature requirements** | ERO retains AZ-8879 for 4 years |


|

**Supports PDF attachments** | No |


|

**Tax year(s) supported for e-filing** | Current tax year and 2 prior years |


|

**Special considerations** | Accepts federal extension |
