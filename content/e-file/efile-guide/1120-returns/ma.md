## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|

**Grace period** | 10 days |


|

**E-filing mandate** | Yes. All returns are mandated. See TIR 21-9 |


|

**Accepts state-only filings** | Yes |


|

**Return types accepted** | C Corporation  S Corporation  Consolidated/Combined  Short-year  Amended  Composite  Extension  Estimate Payments (filed with return)  Entity Level Tax  Security Corporation |


|

**Return types not accepted** | Homeowner association returns filed on Form 3M  Annual reports |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT) |


|

**Signature requirements** | ERO retains signed M-8453C for 3 years |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | N/A |
