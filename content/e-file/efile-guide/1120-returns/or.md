## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 10 days |


|

**E-filing mandate** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Accepts state-only filings** | No. Attach the federal XML created for Federal with a status of "Qualified" or "Accepted". |


|

**Return types accepted** | C Corporation  S Corporation  Consolidated/Combined  Amended  Short-year  Composite: Form OC |


|

**Return types not accepted** | Estimate Payments  Extension |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Direct debit (EFW)  Check by mail  ePayment |


|

**Signature requirements** | Signature Date. PIN isn't allowed as a signature. |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | N/A |
