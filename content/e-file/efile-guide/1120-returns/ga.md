## State electronic filing details

|

E-filing information | Details |

|

**Grace period** | 10 days |


|

**E-filing mandate** | Yes, if a corporation is claiming or assigning any 100-level credits on their tax return. |


|

**Accepts state-only filings** | Yes |


|

**Return types accepted** | C Corporation  S Corporation  Consolidated / Combined  Short year  Amended |


|

**Return types not accepted** | Estimates  Extension  Composite |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Check by mail |


|

**Signature requirements** | ERO retains signed GA-8453-C/S for 3 years |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | N/A |
