## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | Follows IRS - 5 days for corporate extension and 10 days for corporate return. |


|

**E-filing mandate** | Yes, if assets exceed $250,000 or has 100 or more Schedule K-1s. |


|

**Accepts state-only filings** | No |


|

**Return types accepted** | C Corporation  S Corporation  Consolidated/Combined  Short-year  Electing Pass-Through Entity Return (part of main return)  Extension |


|

**Return types not accepted** | Amended  Estimate Payments  Composite |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Check by mail |


|

**Signature requirements** | All filers must use PIN. In addition, ERO retains Forms 83-115/84-115 for 3 years. Same requirements for extensions. |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | N/A |
