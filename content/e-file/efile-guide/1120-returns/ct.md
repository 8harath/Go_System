## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 5 days |


|

**E-filing mandate** | All corporate returns and their associated payments other than Form OP-424. |


|

**Accepts state-only filings** | Yes |


|

**Return types accepted** | C Corporation  S Corporation  Consolidated / Combined  Short year  Estimates (filed separate from return)  Extension  Amended C Corporation  Amended S Corporation |


|

**Return types not accepted** | Amended Combined |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Check by mail (only if waiver is granted) |


|

**Signature requirements** | None |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | Connecticut prefers that you use electronic funds withdrawal to make any payments. |
