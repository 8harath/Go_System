## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 10 days |


|

**E-filing mandate** | Yes |


|

**Accepts state-only filings** | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared |


|

**Return types accepted** | C Corporation  S Corporation  Withholding (part of the main return e-file) |


|

**Return types not accepted** | Amended  Consolidated/Combined  Composite  Corporations filing Form 1120-POL or 1120-H  Short-year  Estimate Payments  Extension |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Check by mail |


|

**Signature requirements** | None |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | N/A |
