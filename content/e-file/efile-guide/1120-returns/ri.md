## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 3 days |


|

**E-filing mandate** | Yes, attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics don’t have to be cleared. |


|

**Accepts state-only filings** | Yes, attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Amended  C Corporation  S Corporation  Consolidated/Combined  Short-year  Extension |


|

**Return types not accepted** | Estimate Payments  Composite |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Electronic funds transfer (EFT)  Electronic funds withdrawal (EFW)  Check by mail |


|

**Signature requirements** | No  PIN is not allowed as a signature. |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and 2 prior tax years |
