## State electronic filing details

|

E-filing information | Details |

**Grace period** | 5 days |


|

**E-filing mandate** | Yes, corporations with $1 million in federal gross income and pass-through entities with more than 24 Schedule K-1s must e-file. |


|

**Accepts state-only filings** | Yes |


|

**Return types accepted** | S Corporation  C Corporation  Consolidated/Combined  Short year  PTET (part of main return) |


|

**Return types not accepted** | Extension |


|

**Accepts returns with these conditions** | Zero balance  Balance due  Refunds  Direct Deposit of Refund  Estimates with return  Amended returns  Refund due |


|

**Direct deposit of refunds** | Yes |


|

**Accepted forms of payment** | Check by mail  Direct Debit (EFW)  Pay on INTime (IN Online Portal) |


|

**Signature requirements** | ERO retains signed IT-8879C for tax returns. |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|
