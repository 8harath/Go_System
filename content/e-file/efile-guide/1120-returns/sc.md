## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 10 days |


|

**E-filing mandate** | Yes, preparer-mandated based on number returns |


|

**Accepts state-only filings** | Yes, attach the federal XML created for this State (Default). Only Federal e-file validation errors. |


|

**Return types accepted** | C Corporation  S Corporation  Consolidation/Combined  Short-year  Amended  Extension  Estimate Payments |


|

**Return types not accepted** | Composite  Withholding |


|

**Direct deposit of refunds** | Yes, for electronically filed returns only |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Check by mail |


|

**Signature requirements** | Form SC8453C retained by ERO for 3 years  PIN is not allowed as a signature |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | N/A |
