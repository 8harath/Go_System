E-filing information | Details |

**Grace period** | 10 days for returns, 5 days for extensions |


|

**E-filing mandate** | Yes, if paid $5,000 or more in last state fiscal year (July 1-June 30) |


|

**Accepts state-only filings** | Yes |


|

**Return types accepted** | C Corporation  S Corporation (when subject to federal tax)  Consolidated / Combined  Amended  Short year  Estimates (separate from return)  Extension |


|

**Return types not accepted** | N/A |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Check by mail (return only) |


|

**Signature requirements** | None |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|
