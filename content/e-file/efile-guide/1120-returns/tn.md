## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 10 days |


|

**E-filing mandate** | Yes, attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Accepts state-only filings** | Yes, attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | C Corporation  S Corporation  Combined (Unitary Financial Institutions)  Amended  Short-year  Estimates (separate e-file for each estimate)  Extension |


|

**Return types not accepted** | Composite |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT) |


|

**Signature requirements** | None  PIN not allowed as a signature |


|

**Supports PDF attachments** | Yes, supporting documents of Report of Debts only |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | N/A |
