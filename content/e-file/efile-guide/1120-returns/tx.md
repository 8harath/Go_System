## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 10 days |


|

**E-filing mandate** | No  Opt-out/waiver: Mandate applies to tax preparer that prepares 100 or more returns for a tax period for the same year. |


|

**Accepts state-only filings** | Yes |


|

**Return types accepted** | C Corporation  S Corporation  Consolidated/Combined  Extension |


|

**Return types not accepted** | Amended |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Direct debit (EFW) - Yes, if less than $100,000. If over $100,000 TEXNET is the only option. See https://texnet.cpa.state.tx.us/TXN\_StartPage.asp for more information.  Electronic funds transfer (EFT) - Yes, mandatory if prior year Franchise Tax due was $10,000 or more.  Check by mail |


|

**Signature requirements** | No  PIN not allowed as a signature |


|

**Supports PDF attachments** | No |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | Need Taxpayer's Web-file Number and Total revenue from last filed return. |
