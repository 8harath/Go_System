## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 10 days |


|

**E-filing mandate** | Yes |


|

**Accepts state-only filings** | Yes - Attach the federal XML created for this State (Default) - Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Partnership  Amended  Extensions |


|

**Return types not accepted** | Estimate Payments  Consolidated  Composite  Composite Extension |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Online using Taxpayer Access Point (TAP)  Check by mail |


|

**Signature requirements** | Signed Form 84-115 (MS8453-PTE) retained by ERO for three years and must use PIN for electronic signature |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | 5 day grace period for returns rejected on the extension due date. |
