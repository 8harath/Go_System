## State electronic filing details

E-filing information | Details |


| --- | --- |

| --- | --- |
|

**Grace period** | Rhode Island does not follow the IRS return perfection period. If the electronic return cannot be corrected and retransmitted, the taxpayer must file a paper return. |


|

**E-filing mandate** | Yes |


|

**Accepts state-only filings** | Yes - Attach the federal XML created for this State (Default) - Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared |


|

**Return types accepted** | Partnership  Short-year  Extension  Amended |


|

**Return types not accepted** | Composite  Composite Extension  Consolidated  Estimates |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Check by mail |


|

**Signature requirements** | No |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year only |
