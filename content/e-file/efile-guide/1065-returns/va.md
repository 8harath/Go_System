## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | None. Virginia does not follow the IRS return perfection period. A return must be transmitted and accepted by the due date of the return to be considered timely filed. |


|

**E-filing mandate** | Yes |


|

**Accepts state-only filings** | Yes - Attach the federal XML created for this State (Default) - Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared |


|

**Return types accepted** | Partnership |


|

**Return types not accepted** | Extensions  Consolidated  Composite  Composite Extension  Amended  Estimates |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | N/A |


|

**Signature requirements** | ERO retains Form VA-8453P or VA-8879P for 3 years.  PIN allowed as signature. |


|

**Supports PDF attachments** | No |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |
