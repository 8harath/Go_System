## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |

**Grace period** | 10 calendar days |


|

**E-filing mandate** | Yes |


|

**Accepts state-only filings** | No - Attach the federal XML created for Federal with a status of "Qualified" or "Accepted" |


|

**Return types accepted** | Partnership  Amended  Extension (balance due only) |


|

**Return types not accepted** | Composite  Composite Extension  Consolidated  Estimates |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Check by mail |


|

**Signature requirements** | Signed Form is retained by ERO for 3 years. Enter a SOS ID number or FTB Assigned ID number in the Organizer States California General Information ID Options, or select a reason why the entity does not have a state ID number.  PIN is not allowed as signature. |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |
