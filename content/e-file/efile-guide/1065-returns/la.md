## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 10 calendar days |


|

**E-filing mandate** | LA Administrative Code 61:III.1507 requires e-filing if the total assets of the partnership have an absolute value equal to or greater than $250,000.  LA Revised Statute 47:201.1(F)(4) also requires e-filing of any return containing Schedule 6922. |


|

**Accepts state-only filings** | Yes - Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared. |


|

**Return types accepted** | Partnership  Short year  Amended |


|

**Return types not accepted** | Consolidated  Composite  Composite Extension  Estimates  Extension |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Direct debit (EFW)  Check by mail  ePayment |


|

**Signature requirements** | ERO retains signed R-8453-PE and R-8453-CP for 3 years |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |
