## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 10 business days |


|

**E-filing mandate** | Yes |


|

**Accepts state-only filings** | No - Attach the federal XML created for Federal with a status of "Qualified" or "Accepted". |


|

**Return types accepted** | Composite (PTE-C)  Estimates  Extensions  Partnership  Pass-through Entity Return (EPT) |


|

**Return types not accepted** | Amended  Consolidated  Composite Extension  Estimates  Extension |


|

**Accepts returns with these conditions** | Refund  Zero balance  Balance due |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT) |


|

**Signature requirements** | ERO retains signed Form 8453-PTE (Partnership), 8453-B (Privilege tax), and 8453-PTE (Nonresident composite) for three years.  PIN not allowed as signature. |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years through 9/1. Then current plus one prior year until 12/31. |


|

**Special considerations** | AL allows one partnership return per year for e-file. You must paper file subsequent short year returns or amended returns. |
