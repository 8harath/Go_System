## State electronic filing details

|

E-filing information | Details |


| --- | --- |

|  |  |
| --- | --- |
|

**Grace period** | 7 calendar days for returns (0 for extensions) |


|

**E-filing mandate** | If mandated in previous year, or prepared more than one authorized document for 10 or more different taxpayers. New York eliminated any opt-out or reasonable cause record. |


|

**Accepts state-only filings** | Yes  Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared |


|

**Return types accepted** | CT-13  Estimate Payments (separate from return)  Extension |


|

**Return types not accepted** | Char 500 |


|

**Direct deposit of refunds** | No |


|

**Accepted forms of payment** | Direct debit (EFW)  Electronic funds transfer (EFT)  Check by mail |


|

**Signature requirements** | ERO and taxpayer signs Form TR-579-CT and ERO retains for 3 years. |


|

**Supports PDF attachments** | Yes |


|

**Tax year(s) supported for e-filing** | Current tax year and two prior tax years |


|

**Special considerations** | None |
