R0000-029 e-file error

Error

If the Signature Option 'PIN Number' is selected (the element 'SignatureOption' in the Return Header has a value of 'PIN Number') then the following fields must have a value in the Return Header: 'PractitionerPIN,' 'TaxpayerPIN,' 'Name of the Officer,' 'Title of the Officer,' 'DateSigned,' and 'PINEnteredBy Indicator.'

Cause

Information is missing from Form 8879, Practitioner PIN.

Solution

  1. Go to
    Organizer
    ,
    Federal E-file
    , then
    Signature Authorization
    .
  2. In the
    If Form 8879 - Practitioner PIN is selected
     section, mark a selection for
    PIN entered by
     either
    Officer
     or
    ERO
    .
  3. In the
    PIN Information
     section, enter a 5-digit PIN for either the Officer or ERO.
  4. Go to
    General Information
    ,
    Basic Return Information
    , then
    Return Information
    .
  5. Enter the name, title, and date for the signing officer.
  6. Perform a full recompute, recreate the e-file, then resubmit.
