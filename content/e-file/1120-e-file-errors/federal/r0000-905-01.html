R0000-905-01 e-file error

Error

Electronic Filing Identification Number (EFIN) in the Return Header must be listed in the e-File database and in accepted status. (R0000-905-01).

Cause

The EFIN included in the return is invalid.

Solution

  1. Go to
    Organizer
     then
    Federal E-file
    .
  2. Select
    Enable
    .
  3. Review the
    EFIN
    :
    1. If the
      EFIN
       is wrong, correct it, do a full recompute, recreate the e-file, and resubmit the return.
    2. If the
      EFIN
       is correct, call the IRS e-help Desk at 866.-255-0654 to resolve the rejection.
