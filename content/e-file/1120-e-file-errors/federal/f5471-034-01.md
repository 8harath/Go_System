# F5471-034-01 e-file error

```
Form 5471 (F5471-034-01): If Form 5471, Item B, checkbox "3" is checked, then one or more "Category 3 Filer Statements" must be attached.
```

This happens when Form 5471, item B, checkbox 3 is checked but the Category 3 Filer Statement is not included.

## Solution

- Go to 

  **Organizer****Foreign Information**

  .
- Go to 

  **Foreign Corporation****Foreign Corporation**

  .
- Select **(Company Name),** then **Filer Information**.
- Select **Category 3 Filer Statement**.
- Select **Add new Subscriber** and enter the information.
- Do a full Recompute, then recreate the e-file.

note

If this is part of a consolidated return, you will have to fill out this information down on the Subsidiary level where the 5471 is entered.
