# E-file diagnostic: Form 4626, Form 1120-F Additional Information Questions JJ

```
Form 4626: Form 1120-F Additional Information Question JJ is answered "No". You're required to file Form 4626. The IRS has not issued e-file schema for Form 4626. If you need to file the form before e-file schema is available, the form must be attached as PDF file for inclusion with the e-file submission. To ensure that the title matches the exact IRS requirement, select the predefined title "Form 4626" when adding PDF attachments in the Organizer > Federal E-file > Attachments > Summary.
```

This happens when Additional Questions JJ is answered "No” and Form 4626 isn't attached as a PDF Attachment.

## Solution

- Go to **Organizer**, then the **Federal E-file** folder.
- elect **Attachments**, **PDF Attachments**, **Summary** and then **Attach PDF**.
- Select **Add**.
- For **Attachment Jurisdiction**, select **Federal**.
- Select **Browse for file** and **Done**.
- Select **Upload** and **Done**.
- Select **Compute**, then **Full Recompute**.
- Run a full-recompute and re-create the e-file.

note

You may need to go to **Print**, select **Selected Federal F Corp**, scroll down to **Form 4626**, and select one of the options: **Preview**, **Create to PDF** or **Send to Safesend**. Create a PDF and attach it to the return.
