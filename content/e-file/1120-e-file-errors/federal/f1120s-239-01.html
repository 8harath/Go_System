F1120S-239-01 e-file error

Error

Filer's TIN and Name Control in the Return Header must match data in the e-File database unless Form 1120S, Item H (2), checkbox "Name Change" is checked. (value, rule F1120S-239-01).

Cause

The filer's name or EIN is incorrect on the return.

Solution

  1. Check the name control:
    1. Go to the
      Electronic Filing
       folder.
    2. Select the
      ELF
       screen.
    3. If the
      Name Control: Force
       field is filled, review Publication 4163 to check that it's correct.
  2. Check the EIN:
    1. Select
      General Information
      , then
      Basic Return Information
      .
    2. Make sure the
      EIN
       is correct.
  3. If you corrected either field, do a full recompute, recreate the e-file, and resubmit.
  4. If you're not overriding the name control and the EIN is correct, call the IRS e-help Desk at 866-255-0654 and verify the client's EIN.
