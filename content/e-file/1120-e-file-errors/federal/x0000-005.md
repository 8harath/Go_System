# X0000-005 e-file error

## Error

```
The XML data has failed schema validation.
```

## Cause

This error can occur when the return doesn't conform to the IRS specifications for electronic filing.

## Solution

- Check if there are any reject diagnostics or validation errors.
- Do a full recompute, recreate the e-file, and resubmit the return.
- If you still receive this error, contact Support.
