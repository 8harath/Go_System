F1120-329-01 e-file error

Federal l Form 1120: Rule Number: F1120-329-01 Sch K, line 4a or line 4b has a choice of "Yes" but Sch G is not attached.
This e-file error will show if
Yes
 is selected for line 4a or line 4b but Sch G is not attached.

Solution

  1. At the parent locator, select
    Organizer
    ,
    General Information
    , then
    Questions
    .
  2. If
    Sch K questions 4a or 4b
     are answered
    Yes
    , select
    Yes provide detail
    .
  3. If there is no detail to provide, select
    No
     to this question.
  4. Then fully compute and recreate the e-file.
