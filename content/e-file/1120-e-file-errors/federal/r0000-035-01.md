# R0000-035-01 e-file error

## Error

```
The 'TaxPeriodEndDt' in the Return Header must be less than the Received Date. (value YYYY-MM-DD, rule R0000-035-01).
```

## Cause

The tax year-end date in the rejected return is after the date on which the electronic file was received by the IRS. For example, a fiscal year return with a year-end date of April 30 needs to be received by the IRS after April 30.

## Solution

- Go to **Organizer** then **General Information**.
- Select **Basic Return Information**.
- Check the **Fiscal year ending**:


  - If it's wrong, correct it, do a full recompute, recreate the e-file, and resubmit the return.
  - If it's correct, call the IRS e-help Desk and 866-255-0654 and verify what they have on their record.
