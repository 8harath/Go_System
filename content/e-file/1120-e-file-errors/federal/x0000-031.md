# X0000-031 e-file error

## Error

```
Zip Entry names must conform to the guidelines in Publication 4164.
```

## Cause

A PDF attached to the return has a name or title that doesn't meet e-filing requirements.

## Solution

- Go to **Organizer** then **Federal E-File**.
- Select **Attachments**, **PDF Attachments**, then **Summary**.
- Select **Attach PDF**.
- Check that the names and titles of your PDF attachments meet the following e-file requirements:


  * 23 characters or less.
  * No spaces.
  * No special characters.
- Delete each PDF that you need to change, change the name or title, then reattach it.
