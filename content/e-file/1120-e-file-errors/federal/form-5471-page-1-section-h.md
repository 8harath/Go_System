# E-file diagnostic: Form 5471, Page 1, Section H

```
Form 5471, Page 1, Section H: The Meeting Filing Requirement Statement must be completed for each person entered in Section H
```

## Solution

- Go to the **Organizer** folder and select **Foreign Information**, then **Foreign Corporation****.**
- Select the entity, then **Filer Information**.
- Select **Person**, then **Person on Whose Behalf 5471 is Filed**, then the name.
- On the **Meeting Filing Requirements Statement** tab, do 1 of the following:


  * Mark the **Suppress Meeting Filing Requirements Statement box** checkbox.
  * Enter **Requirements met description**, **Return Name**, **Service Center**, and an address.
- Do a full-recompute and re-create the e-file.
