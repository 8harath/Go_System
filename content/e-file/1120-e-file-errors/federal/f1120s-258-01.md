# F1120S-258-01 e-file error

```
Form 1120S: Rule Number: F1120S-258-01 Schedule K shows an amount for section 179 expense deduction, but Form 4562 is not attached.
```

This happens when Federal 1120-S - US Corporation Inc. Tax Return, Page 3, line 11 section 179 expense deduction has an amount, but Form 4562 is not attached.

## Solution

- Go to the **Organizer**, then to the **Income and Deductions** folder.
- Select **Deductions** and then **Depreciation and Amortization**.
- Select the **Entry Name** folder and access **Form 4562 Information**.
- Select the **4562 Overrides** option and go to the **Federal 4562 Overrides**.
- Then, go to the **Overrides for Other Depreciation, Listed Property, and IRC § 263A Costs** section, enter **NONE** at the **Other depreciation** line.
- Run a full recompute and recreate the e-file.
