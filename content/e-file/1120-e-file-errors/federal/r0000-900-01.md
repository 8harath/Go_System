# R0000-900-01 e-file error

## Error

```
The return type indicated in the return header must match the return type established with the IRS for the EIN.(value, rule R0000-900-01).
```

## Cause

The type of return on file with the IRS doesn't match the EIN included in the electronic file.

## Solution

- Go to **Organizer** then **General Information**.
- Select **Basic Return Information** then **Entity Information**.
- Check the **EIN**:


  - If the **EIN** is wrong, correct it, do a full recompute, recreate the electronic file, and resubmit.
  - If the **EIN** is correct, contact the IRS e-help Desk at 866-255-0654 and verify what they have on their record.
