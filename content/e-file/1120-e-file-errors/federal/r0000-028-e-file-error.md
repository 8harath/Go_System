# R0000-028 e-file error

## Error

Signature Option "Binary Attachment 8453 Signature Document" is selected Binary attachment Description must be "8453 Signature Document".

## Cause

The PDF attachment and its description isn't correct.

## Solution

- Go to **Organizer**, **Federal E-file**, **Attachments**, **PDF Attachments**, and then **Summary**.
- Review the Form 8453 attachment and make sure to use the predefined description '8453 Signature Document' or if Form 8453 isn't attached, select **Attach PDF**.
- Perform a full re-compute, re-create the e-file, then re-submit.
