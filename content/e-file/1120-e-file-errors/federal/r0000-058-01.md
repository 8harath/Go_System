# R0000-058-01 e-file error

## Error

```
An XML document that represents a binary attachment must have a valid reference to an attached file. (value, rule R0000-58-01).
```

note

The value will represent the PDF attachment causing the rejection.

## Cause

The file name of the PDF attachment doesn't meet e-filing requirements.

## Solution

- Go to **Organizer** then **Federal E-File**.
- Select **Attachments**, **PDF Attachments**, then **Summary**.
- Select **Attach PDF**.
- Make sure that the file names of your PDF attachments meet the following e-file requirements:


  - 23 characters or less.
  - No spaces.
  - No special characters.
- If you need to change the file name of a PDF, delete it, make the change, then reattach it.
- Do a full recompute, recreate the e-file, and resubmit the return.
