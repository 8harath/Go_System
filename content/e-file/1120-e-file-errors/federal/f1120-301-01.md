# F1120-301-01 e-file error

You'll get the following error message if the Schedule M-1/M-3 computation setting in General Options doesn't match your Box A4 selection. If Box A4 is over 10 million, then the M-3 needs to be attached.

## Error message

```
Form 1120: Rule Number: F1120-301-01 Box A4 is checked on 1120, Page 1 but Schedule M-3 is not attached.
```

## Solution

Complete these steps to fix the Schedule M-3 issue:

- Go to 

  **Organizer****Balance Sheet/M1-M2-M3**

  .
- Locate the **Schedule M-3** section within **General Options**.
- Check whether the computation is set to M-1 only or M-3.
- Change the configuration to compute Schedule M-1 only if it's under 10 million on Box A4, or M-1 and M-3 if it's over that amount.
- Do a full recompute of the return by selecting 

  **Returns****Recompute**

  .
- Recreate the e-file by going to 

  **E-File****Create E-File**

  .

tip

After changing the schedule computation settings, perform a full recompute and recreate the e-file. Always verify the General Options settings match your filing requirements.
