# F7004-003-03 e-file error

## Error

```
Form 7004, the application for extension can only be filed after the Tax Period End Date ("TaxPeriodEndDate" specified in the "ReturnHeader") and on or before the due date of the return to which the extension applies as specified in the Publication 4164. (value YYYY-MM-DD, rule F7004-003-03).
```

## Cause

You've filed an extension either before the tax year end or after the return due date. For example, on a return with a tax year end of 3/15, you'd receive this rejection if you filed an extension before 3/15 or after 7/15.

tip

There will either be a mistake or override in the dates entered in the client, or the extension can't be filed now.

## Solution

- Check the fiscal year-end date:


  - Go to **Organizer** then **General Information**.
  - Select **Basic Return Information**.
  - Select the **Entity Information** tab
  - Check the **Fiscal year ending** date.


    - If the date is wrong, correct it.
    - If the date is correct, make a note of it.
- Check the extension dates:


  - Go to **Organizer** then **Payments and Extensions**.
  - Select **Automatic Extensions** then **7004 Basic Data**.
  - Check the override dates in the Dates section:


    - If any date is wrong, correct it.
    - If a date is correct, make a note of it.
- Compare the date the extension was filed, the fiscal year-end date, and the extension date:


  - If the extension is too early to file based on the client's tax year end, wait until you can file it.
  - If the extension is late or if the return due date has passed, file the return instead of the extension.
