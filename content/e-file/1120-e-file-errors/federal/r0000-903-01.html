R0000-903-01 e-file error

Error

Taxpayer TIN in the Return Header must not be the same as a TIN of a previously accepted paper return for the return type and tax period indicated in the tax return. (value #########, rule R0000-903-01)

Cause

A return has already been filed and accepted with this TIN.

Solution

  1. Go to
    Organizer
     then
    General Information
    .
  2. Select
    Basic Return Information
     then
    Entity Information
    .
  3. Check the EIN:
    1. If the
      EIN
       is wrong, correct it, do a full recompute, recreate the electronic file, and resubmit.
    2. If the
      EIN
       is correct, contact the IRS e-help Desk at 866-255-0654 and verify what they have on their record.
