# R0000-004-01 e-file error

```
ReturnTypeCd (specified in the Return Header) and the return version (specified by the returnVersion attribute of the Return element) of the return must match the return type and the version supported by the Modernized e-File system.
```

This happens when e-filing a return outside the current tax year or previous 2 tax years. For example, if the new tax year is 2023, then the 2 previous tax years are 2022 and 2021. Anything outside of these years can't be e-filed per the IRS.

## Solution

The only solution is to paper file this return.

note

For future knowledge, IRS e-file server go offline in late December each year for maintenance and then re-open in January. The IRS posts the shutdown date at <https://www.eitc.irs.gov/mef-status>.
