# F1120-112-02 e-file error

```
Form 1120: Rule Number: F1120-112-02 Attachment of Form 2220 is indicated on page 1 but Form 2220 is not attached.
```

This happens when penalty has no value.

## Solution

- Go to **Tax Forms**, then **Federal** and select **2220 - Underpayment of Estimated Tax**.
- Go to **Underpayment of Estimated Tax**, **Page 2**.
- Enter a value or **NONE** in **Line 38**.
- Do a full recompute and recreate the e-file
