# F4626-051 e-file error

```
F4626-051: If Form 4626, 'CtrlGrpTreatedSingleEmplrInd' has a choice of "Yes" indicated, then there must be at least one 'MemCtrlGrpAndFPMGGroupMemGrp' with 'EntityMember59k1DGroupInd' checked having a non-zero value in 'FinancialStmtIncomeLossAmt' and values in 'GroupMemberName', 'GroupMemberEIN'.
```

This happens when group member details are missing for form 4626.

## Solution

- Go to **Organizer**, **Taxes** folder, and select **Alternative Minimum Tax**.
- Ensure that Question A **Is the corporation filing this form a member of a controlled group treated as single employer under section 59(k)(1)(D) and 52?** is marked as **Yes**.
- Go to the **Part V** section, then select **Part V Detail**. Fill out the information.
- Do a full recompute and recreate the e-file.
