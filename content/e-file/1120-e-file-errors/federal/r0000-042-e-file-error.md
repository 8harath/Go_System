# R0000-042 e-file error

```
The period between "Tax Period Beginning Date" and "Tax Period Ending Date " must not be more then twelve months. (Automatic GOTO is not available).
```

This error message appears when the duration between the "Tax Period Beginning Date" and the "Tax Period Ending Date" exceeds twelve months. "Automatic GOTO is not available" indicates that there is no automatic correction or navigation feature to resolve this issue, so users need to manually adjust the dates to fit within the required twelve-month timeframe.

## Solution

note

**Navigation:** In Organizer, select **General Information**, **Basic Return Data**, then **Entity Information**.

In Organizer, select **General Information**, **Return and Print Options**, **Pg 1-6 Options** Tab. Make selection "52-53 week return under Regulation". Do a Full recompute and recreate the e-file.
