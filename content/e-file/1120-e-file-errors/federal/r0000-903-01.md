# R0000-903-01 e-file error

## Error

```
Taxpayer TIN in the Return Header must not be the same as a TIN of a previously accepted paper return for the return type and tax period indicated in the tax return. (value #########, rule R0000-903-01)
```

## Cause

A return has already been filed and accepted with this TIN.

## Solution

- Go to **Organizer** then **General Information**.
- Select **Basic Return Information** then **Entity Information**.
- Check the EIN:


  - If the **EIN** is wrong, correct it, do a full recompute, recreate the electronic file, and resubmit.
  - If the **EIN** is correct, contact the IRS e-help Desk at 866-255-0654 and verify what they have on their record.
