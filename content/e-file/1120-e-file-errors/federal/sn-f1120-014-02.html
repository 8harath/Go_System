SN-F1120-014-02 e-file error

*SN-F1120-014-02: If Schedule N (Form 1120), Line 4b, has a non-zero value, then Form 5471 must be attached to Line 4b.
This happens when Schedule N (Form 1120), Line 4b, has a value but you haven’t attached Form 5471.

Solution 1

  1. In
    Tax forms
    , select
    Federal
    .
  2. Select
    Sch N - Foreign Operations of US Corp
    .
  3. In
    Line 4b
    , if you have entered any number then you need to attach
    Form 5471
     where it transfers to the XML.
  4. Do a full recompute and recreate the e-file.
note
If you have an amount in Line 4b that has been entered indicating that there are 5471s attached when there is not, remove the value from line 4b in member or attach a 5471 (not as PDF). IRS doesn't allow the PDF attachment of Form 5471. It needs to be in XML format.

Solution 2

  1. In Organizer, select
    General Information
    , then
    Questions
    , then
    Schedule N
    .
  2. Review
    Number of Forms 5471 Attached
    . If there is a number in this field, then Form 5471 should be populated in the Organizer.
  3. In Organizer, select
    Foreign Information
    , then
    Foreign Corporation
    , then
    Foreign Corporation
    .
  4. Select
    Add new foreign Corporation
     and enter the required information for the foreign corporation.
  5. Do a full recompute and recreate the e-file.
