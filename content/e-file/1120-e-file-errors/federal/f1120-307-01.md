# F1120-307-01 e-file error

## Error

```
Per Publication 4163, "Filer's TIN and Name Control in the Return Header must match data in the e-File database unless Form 1120, Item E(3), checkbox 'Name Change' is checked." (value, rule F1120-307-01).
```

## Cause

The filer's name or EIN is incorrect on the return.

## Solution

- Check the name control:


  - Go to **Organizer** then **Federal E-file**.
  - Select **Additional Information** then **Business Name Control**.
  - If **Business name control (Override)** is completed, review Publication 4163 to check that it's correct.
- Check the EIN:


  - Go to **General Information** then **Basic Return Information**.
  - Check the **EIN**.
- If you corrected either field, recreate the e-file, and resubmit the return.
- If you're not overriding the name control and the **EIN** is correct, call the IRS e-help Desk at 866-255-0654 and verify the client's **EIN**.
