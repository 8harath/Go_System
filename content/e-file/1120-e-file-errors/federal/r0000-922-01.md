# R0000-922-01 e-file error

## Error

```
Filer's EIN and Name Control in the Return Header must match data in the e-File database, unless "Name Change" or "Name or Address Change" checkbox is checked, if applicable. (value #########, rule R0000-922-01)
```

## Cause

The IRS e-File database has a different EIN and Name Control combination on file.

## Solution

- If the partnership changed its address or name:


  - Go to **Organizer** then **General Information**.
  - Select **Basic Return Information**.
  - Mark the **Address change or Name change** checkbox.
- Check the name control:


  - Go to **Organizer** then **Federal E-file**.
  - Select **Additional Information** then **Business Name Control**.
  - If the **Business name control (Override)** field is completed, review Publication 4163 to check that it's correct.
- Check the **EIN**:


  - Select **General Information** then **Basic Return Information**.
  - Make sure the **EIN** is correct.
- If you corrected either field, recreate and resubmit the e-file.
- If you didn't change the name control and the EIN is correct, call the IRS e-help Desk at 866.255.0654 and verify the client's EIN.
