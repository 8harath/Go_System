F1120F-001-01 e-file error 

1120 Federal Form 1120-F: RuleNumber: F1120F-001-01 If Form 1120-F, checkbox "Schedule M-3 attached" is checked, then Schedule M-3 (Form 1120-F) must be attached.
This happens when Schedule M-3 is required but it is not completed.

Solution 1

  1. In Organizer, select
    General Information
    , then
    Basic Return Information
    .
  2. Select
    Return Information
    and in the Check if section, select
    Schedule M-3 attached
    .
  3. Do a full recompute.

Solution 2

  1. In Organizer, select
    Balance Sheet/M1-M2-M3
    , then
    Schedule M-3
    .
  2. Select
    Schedule M1, M2, M3 Options
     and in the Print Options section, uncheck
    Suppress print of Schedule M-3
  3. Do a full recompute and recreate the e-file.
    note
    Sch M-3 needs to be filled out if total assets are over $10 million.
