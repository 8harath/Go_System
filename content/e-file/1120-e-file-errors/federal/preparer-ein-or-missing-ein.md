# Preparer EIN or Missing EIN e-file error

```
Preparer EIN or Missing EIN: Can either be EIN or missing EIN reason. Only one value allowed.
```

This happens when an EIN is missing from the e-file.

## Solution

- Go to **Organizer**, **General Information**, and then **Paid Preparer/ERO Information**.
- On the **Firm** tab, in the **Firm Information** section, select **ID Type** and enter an EIN. If this was already entered, select **Applied for** and then re-select **EIN**.
- Perform a full recompute, recreate the e-file, then resubmit.
