E-file diagnostic: XML is created but not qualified

Error

XML is created but NOT qualified - Diag need to be cleared.

Cause

This happens when you have qualified a Top consolidation but have diagnostics in member locators or subsidiaries. The Topcon won't show any diagnostics.

Solution

  1. In Organizer, select
    Federal E-File
    , then
    Status
    .
  2. Select
    Consolidation Detail
    .
  3. Review the
    Return Number
     and
    Status
     columns. Identify which subsidiary or member is not qualified.
  4. Go to the unqualified member and read the diagnostics.
  5. Make necessary changes.
  6. Do a Full Recompute at the member level.
  7. Consolidate the Topcon.
  8. Recreate the e-file.
