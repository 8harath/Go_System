# SN-F1120-013-01e-file error

```
SN-F1120-013-01: If Schedule N (Form 1120), Line 1b has a non-zero value, then Form 8858 must be attached to the return.
```

This happens when you are missing the information that needs to be attached as per state requirements for e-filing.

## Solution 1

- Select **Tax Forms**, then **Federal**.
- Go to **Sch N - Foreign Operations of US Corp**, **Line 1a**. Change to **NO** or populate **Line 1b**.
- To make changes, select **Organizer**, **General Information**, then **Questions**.
- Select **Schedule N** and enter the details.
- Do a full recompute.
- Recreate the e-file.

## Solution 2

8858 needs to be entered in the lower levels of the consolidation in **Organizer** and can't be attached as PDFs.

- Go to 

  **Organizer****Foreign Information****Foreign Corporation****Foreign Corporation**

   folder.
- Select **Add new Foreign Corporation** and enter the details.
- Do a full recompute for the member.
- Consolidate the Topcon.
- Recreate the e-file.

## Solution 3

- Select **Organize**, then **Taxes**.
- Select **Alternative Minimum Tax**.
- Go to the **Form 4626 organizer** section.
- Select **Yes** for **Line A**.
- Do a full recompute.
- Recreate the e-file.
