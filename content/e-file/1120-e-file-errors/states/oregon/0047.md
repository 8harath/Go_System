# 0047 e-file error

```
XML Error Checking: Rule Number: *0047 Description: If Consolidated submission with Sch. AP attach with filename 'ORApportionWorkpapers.pdf'. To attach a PDF: Navigation Edit Insert EFile attachments
```

This happens when a PDF Document needs to be attached for a Consolidation submission.

**Solution 1**

- Go to **Tax Forms**, **States**, then select **Oregon**.
- Go to **Form OR 20 Excise Tax Return Page 2**.
- If Question E (1), Consolidated Federal Return is marked, a PDF document named **ORApportionWorkpapers.pdf** must be attached.
- To attach the PDF, go to **Organizer**, then **Oregon**, and open the **E-file** folder.
- Go to **Attachments**, then **Summary**, and select **Attach PDF**.
- Do a full compute and recreate the e-file.

**Solution 2**

If not doing a Consolidated submission, remove the PDF attachment if it is attached.
