0031 e-file error

XML Error CheckingRule Number: *0031Description: If Schedule OR-AP Part 2 line 10(a) is populatedAttach OR Apportioned Net Loss Deduction detail with filename ‘AppNetLossDed.pdf’
This happens when the OR-AP line 10 is populated but the form is not attached as a PDF or incorrectly named.

Solution

  1. In Tax forms, select
    States
    , then
    Oregon
    .
  2. See if OR-AP, Page 4, line 10(a) is populated.
  3. In Organizer, select
    States
    , then
    Oregon
    .
  4. Select
    E-file
    , then
    Attachments
    , then
    Summary
    .
  5. Select
    Attach PDF
    . This opens the
    Electronic Filing Attachments
     window.
  6. Select
    Add
    .
  7. Select the
    Attachment Jurisdiction
    : Oregon.
  8. Select
    Browse for file
    , and find your attachment.
note
The file should have the file name: AppNetLossDed.pdf. There should not be any spaces.

Remove attachment

If line 10(a) is not populated, remove the attachment.
  1. In Organizer, select
    States
    , then
    Oregon
    .
  2. Select
    E-file
    , then
    Attachments
    , then
    Summary
    .
  3. Select
    Attach PDF
    .
  4. Select the file and then
    Delete
    .
