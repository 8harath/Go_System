# MDO\_21CMB00 (C) e-file error

```
Oregon City-Portland – Missing a copy of Oregon form OR-20. Pdf must be attached named FormOR20.pdf.
```

This happens when FormOR20.pdf attachment is missing or incorrectly attached to the Oregon City-Portland return.

## Solution

- In Organizer, go to **Cities**.
- Select **Portland/Multnomah OR E-file**, **Attachments**, then **Summary**.
- Select **Attach PDF**.
- Select **Add**.
- For the Attachment Jurisdiction, select **Oregon**.
- Select **Browse for file**.
- Select **Upload**.
- Go to **Organizer**, **States**, **State E-file**, **Enable/Create Returns**.


  - If filing the **Oregon** return, clear **Enable** for **Oregon City - Portland**.
  - If filing the **Oregon City - Portland** return, clear **Enable** for **Oregon**.
- Do a full recompute and recreate the e-file.

The description and file name should be **FormOR20.pdf**. The Oregon City and the Oregon City METBIT can't be e-filed at the same time. Create 1 return 1st before filing the 2nd return. Once 1 return is created and qualified edit the attachment and re-attach it to the 2nd return.
