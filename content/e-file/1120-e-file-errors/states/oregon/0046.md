# 0046 e-file error

```
Form OR-20/OR-20-INC: Missing federal Form 1120 page 1 consolidated schedules attach items of gross income and deductions by each entity detail with filename 'FF1120p1.pdf'
```

This happens when the FF1120p1.pdf is missing.

## Solution

- Go to **Organizer**, **States**, then the **Hawaii** folder.
- Go to **E-File**, then the **Attachments** folder.
- Select **Summary**, then select the **Attach PDF** button.
- Select **Add**.
- Select Attachment Jurisdiction: **Oregon**.
- Select the **Browse for file** button, then attach PDF named **FF1120p1.pdf** without spaces or special characters.
- Do a full recompute, and recreate the e-file.
