# E-file diagnostic: Electronic Funds Transfer (EFT/Direct Debit)

```
Electronic Funds Transfer (EFT/Direct Debit): Information required for EFT/Direct Debit is missing. Please provide ALL the following information: 1) Select Checking or Savings 2) Routing number 3) Account number 4) Payment amount 5) Requested settlement date 6) Identification number 7) Account Holder name 8) Account Holder Type. Navigate to Organizer/States/Common State/General Information/Bank Information/Direct Debit tab to enter the missing information. (#72)
```

This happens when the direct debit information is missing for the state.

**Solution**

- Go to **Organizer**, **States** folder.
- Go to the **Common State**,**General Information** folder.
- Go to the **Bank Information** folder.
- Go to the **Direct Debit**tab.
- In **Column A**, go to **Oregon**.
- Fill out all Columns **C**, **D**, **F**, **G**, **K** and **L** columns for **Oregon**.
- Do a full recompute and recreate the e-file.
