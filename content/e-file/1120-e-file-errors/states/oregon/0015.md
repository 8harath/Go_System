# 0015 e-file error

```
1120 Oregon XML Error Checking: Rule Number: *0015 Description: If Schedule OR-AP Part 2 line 2 is populated attach Net NBI detail with filename 'IncomeNonBusinessOrLoss.pdf'. To attach a PDF: Navigation Edit Insert EFile attachments
```

This happens when there is a value on OR-AP Part 2 line 2 with no PDF attachment or vice versa.

**Solution**

- Go to **Tax Forms**, **States**, then **Oregon**.
- If **OR-AP** **Pg4**, **Part 2**, **Line 2** has a value, a PDF attachment needs to be attached.
- Go to **Organizer** folder, select **States**, **Oregon**, then **E-file**.
- In **Attachments**, go to **PDF Summary**, then select **ADD**.
- Using the **Attachment Jurisdiction** dropdown, select **Oregon**, **Browse for File**.
- After attaching the file, select **Predefined description** and use **IncomeNonBusinessOrLoss**. Then, select**Upload**.

note

The name of the file needs to be **IncomeNonBusinessOrLoss.pdf**.
