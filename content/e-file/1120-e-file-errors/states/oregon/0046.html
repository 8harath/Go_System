0046 e-file error

Form OR-20/OR-20-INC: Missing federal Form 1120 page 1 consolidated schedules attach items of gross income and deductions by each entity detail with filename 'FF1120p1.pdf'
This happens when the FF1120p1.pdf is missing.

Solution

  1. Go to
    Organizer
    ,
    States
    , then the
    Hawaii
     folder.
  2. Go to
    E-File
    , then the
    Attachments
     folder.
  3. Select
    Summary
    , then select the
    Attach PDF
     button.
  4. Select
    Add
    .
  5. Select Attachment Jurisdiction:
    Oregon
    .
  6. Select the
    Browse for file
     button, then attach PDF named
    FF1120p1.pdf
     without spaces or special characters.
  7. Do a full recompute, and recreate the e-file.
