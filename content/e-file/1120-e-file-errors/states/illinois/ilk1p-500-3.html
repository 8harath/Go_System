ILK1P-500-3 e-file error

Rule Number ILK1P-500-3: SchILK1P Step 1 Line 3 must contain a valid FEIN.
This reject happens when the pass-through entity doesn't have an EIN entered or it's entered incorrectly.

Solution

  1. Go to
    Organizer
     then
    States
     and select
    Illinois
    .
  2. Select
    State Adjustments
    , then
    Pass Through Input
    .
  3. Select
    Schedule K-1-P
    and then the name.
  4. In the
    Step 1 - Identify your partnership or S Corporation
     section, enter a valid EIN in xx-xxxxxxx format.
  5. Do a full recompute, recreate the e-file and resubmit.
