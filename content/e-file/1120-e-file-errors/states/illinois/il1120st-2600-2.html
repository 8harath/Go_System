IL1120ST-2600-2 e-file error

Form IL-1120-ST (Rule IL1120ST-2600-2): If Form IL-1120-ST Step 2, Ordinary Income or Loss, or Equivalent from Federal Schedule K is present, then IRS-1120S must be attached.
This e-file error will show if there is no federal copy attached to the XML.

Solution 1

  1. Within the
    Organizer
    , select
    States
     then
    State E-File
    .
  2. Select
    Enable/Create Returns
    .
  3. On the
    Federal Copy
     tab, select
    Illinois
    .
  4. Make sure that the
    Federal XML
     has been created and qualified.
  5. Do a full recompute and recreate the e-file.

Solution 2

  1. In
    Organizer
    , select
    States
     then
    Common State
    .
  2. Select
    General Information
     then
    Basic Return Information
    .
  3. On the
    Signature Information
     tab, go to column K and enter a
    Signature date
     for the Illinois row.
  4. Do a full recompute and recreate the e-file.

Solution 3

  1. Within the
    Organizer
    , select
    States
     then
    Illinois
    .
  2. Select
    State Adjustments
    , then
    Additions and Subtractions
    .
  3. Go to the
    Subtractions
     section and make sure there isn't a description entered in the
    Other subtractions
     field with no
    Amount
    .
  4. If there is, either add an amount or remove the description.
  5. Do a full recompute and recreate the e-file.
