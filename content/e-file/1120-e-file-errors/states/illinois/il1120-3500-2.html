IL1120-3500-2 e-file error

Form IL-1120 (Rule IL1120-3500-2): If Form IL-1120 Step 2, Federal Taxable Income from U.S. Form 1120, is negative, zero or positive, then IRS-1120 must be attached.
You need to attach IRS Form 1120 to the Illinois 1120 return.

Solution

  1. In
    Organizer
    , go to
    States
     then
    State E-file
    .
  2. Select
    Enable/Create Returns
     and go to the
    Federal Copy
     tab.
  3. In column
    B
    ,
    Federal Copy
     select an option from the drop-down to attach the federal XML.
  4. Make sure the details in Columns G, H, and I are correct to attach the right Federal Copy.
  5. Do a full recompute and re-create the e-file.
note
Illinois only allows electronic filing of the state return when the federal return type is 1120 or 1120S. Illinois also doesn't allow PDF attachments.
