# E-file diagnostic: Illinois Electronic Payment Options

```
Illinois Electronic Payment Options: Taxpayers with annual liability of $20,000 or greater are required to pay using an electronic method.
```

This happens when you are missing information required by the state. If the annual liability is $20,000 or greater, you need to pay using an electronic method.

## Solution

- Go to 

  **Organizer****States****Common State**

  .
- Select **General Information**.
- Select **Bank Information**, then the **Direct Debit** tab.
- In **Column C**, select **EFT** from the dropdown for **Illinois**.
- Do a full recompute and recreate the e-file.
