# IL1120-6300-2 e-file error

```
Form IL-1120 (Rule IL1120-6300-2): If Form IL-1120 Step 1 Line E (unitary) contains an "X", then Form IL-1120 Step 4 Line 27 must equal Sch UB Step 3 Line 27 Col E.
```

This happens when the amount on IL-1120, page 2, step 4 line 27 doesn’t match the amount on the sch UB page 4, Step 3, line 27 column E.

## Solution 1

- In the parent and member returns, go to **Organizer**, **States**, **State and City Activation/Consolidation**, and then **State and City Activation/Consolidation**.
- Ensure all members have Illinois turned on.
- Perform a full recompute and reconsolidate.

## Solution 2

- Go to **Tax Forms**, then select **States**, then **Illinois**, and then **IL-1120-Income and Replacement Tax**.
- Select **IL-1120, Page 2**, **Step 4**, **Line 27**. Make a note of the amount on line 27.
- Review and ensure it equals the amount on **Tax Forms**, **States**, **Illinois**, **Combined Report**, **Sch UB-Combined Apportionment for UBG**.
- Select **Sch UB**, **Combined Apportionment**.
- Select **Sch UB Page 3 - Step 3**.
- On line 27, Column E the combined totals need to match the line 27 noted previously.
- If there are overrides causing the numbers not to match then you need to clear the overrides so they do match.
- Perform a full recompute and recreate the e-file.
