# ILK1P-500-3 e-file error

```
Rule Number ILK1P-500-3: SchILK1P Step 1 Line 3 must contain a valid FEIN.
```

This reject happens when the pass-through entity doesn't have an EIN entered or it's entered incorrectly.

## Solution

- Go to **Organizer** then **States** and select **Illinois**.
- Select **State Adjustments**, then **Pass Through Input**.
- Select **Schedule K-1-P** and then the name.
- In the **Step 1 - Identify your partnership or S Corporation** section, enter a valid EIN in xx-xxxxxxx format.
- Do a full recompute, recreate the e-file and resubmit.
