# IL1120ST-2600-2 e-file error

```
Form IL-1120-ST (Rule IL1120ST-2600-2): If Form IL-1120-ST Step 2, Ordinary Income or Loss, or Equivalent from Federal Schedule K is present, then IRS-1120S must be attached.
```

This e-file error will show if there is no federal copy attached to the XML.

## Solution 1

- Within the **Organizer**, select **States** then **State E-File**.
- Select **Enable/Create Returns**.
- On the **Federal Copy** tab, select **Illinois**.
- Make sure that the **Federal XML** has been created and qualified.
- Do a full recompute and recreate the e-file.

## Solution 2

- In **Organizer**, select **States** then **Common State**.
- Select **General Information** then**Basic Return Information**.
- On the**Signature Information** tab, go to column K and enter a **Signature date** for the Illinois row.
- Do a full recompute and recreate the e-file.

## Solution 3

- Within the **Organizer**, select **States** then **Illinois**.
- Select **State Adjustments**, then **Additions and Subtractions**.
- Go to the 

  Subtractions

   section and make sure there isn't a description entered in the **Other subtractions** field with no **Amount**.
- If there is, either add an amount or remove the description.
- Do a full recompute and recreate the e-file.
