# E-file diagnostic: FormILAuthorization

```
Field 'FormIL1065' is unexpected FormILAuthorization
```

This happens when the e-file authorization checkbox isn't marked.

## Solution

- Go to **Organizer**, **States**, **Illinois**, **E-File** folder.
- Select **Additional Information**, then go to the **Authorization** section.
- Mark the **By checking the box, I agree that I have examined the return, and to the best of my knowledge it is true, correct, and complete** checkbox.
- Do a full recompute and recreate the e-file.
