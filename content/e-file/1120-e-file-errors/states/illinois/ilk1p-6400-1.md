# ILK1P-6400-1 e-file error

```
Schedule K-1-P (Rule ILK1P-6400-1): If Step 4 Line 31 Col A or Col B is not blank, then description is required and vice versa.
```

This happens when Sch K-1-P, Step 4, Line 31, Column A or Column B has an amount but no description, or if Line 31 has a description with no amounts.

## Solution 1

If there is an Overpayment amount:

- Go to 

  **Organizer****States****Illinois**

  .
- Select **State Adjustments**, then **Pass Through Input**.
- Go to 

  **Schedule K-1-P****“NAME”****Step 4 – Share of Business Income (Loss)**

   section.
- If there are amounts in **Column A** or **Column B**, add a description on **Line 31 Other Business Income**.
- Do a full recompute and recreate the e-file.

## Solution 2

If there is no Overpayment amount:

- Go to 

  **Organizer****States****Illinois**

  .
- Select **State Adjustments**, then **Pass Through Input**.
- Go to 

  **Schedule K-1-P****“NAME”****Step 4 – Share of Business Income (Loss)**

   section.
- Remove the description for **Line 31 – Other Business Income**.
- Do a full recompute and recreate the e-file.
