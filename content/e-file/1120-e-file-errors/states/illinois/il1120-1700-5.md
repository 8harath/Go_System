# IL1120-1700-5 e-file error

## Error

```
The federal return as filed with the IRS should be attached. If Illinois requires an IL pro-forma, it will be requested at a later date. (IL1120-1700-5)
```

## Cause

The state sends this alert with every return whether it is accepted or rejected.

## Solution

Disregard this alert. It doesn’t require any further action.
