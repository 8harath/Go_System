# Rule ILHeader-500-2 e-file error

```
IL Return Header (Rule ILHeader-500-2): If IL-Header TaxPeriodEndDate is not between 12/25/21 and 12/25/22, or IL-Header TaxPeriodBeginDt to TaxPeriodEndDt is greater than 53 weeks, you have filed an incorrect schema version.
```

You'll receive this message if the fiscal year end date entered for Form 1120 Illinois doesn't fall within the dates listed on the diagnostic.

## Solution

Per the e-file schema provided by Illinois, the return will need to be filed out of the correct software (locator) version or paper filed.
