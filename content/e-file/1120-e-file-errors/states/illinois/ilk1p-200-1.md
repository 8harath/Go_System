# ILK1P-200-1 e-file error

```
ILK1P-200-1: Either Sch K1P Step 1 Line 1 (partnership) or Sch K1P Step 1 Line 1 (S Corporation) must contain an X. Both cannot be marked.
```

This happens when the business type on the Sch K-1-P is missing.

## Solution

- Go to **Organizer**, **States**.
- Go to **Illinois**, **State Adjustments**.
- Go to **Pass Through Input**, **Schedule K-1-P**.
- Select the **Name** of the pass-through.
- In the **Step 1-Identify Your Partnership or S Corporation** section, select either **Partnership** or **S Corporation** for the **Business type**.
- Run a full recompute, then recreate the e-file.
