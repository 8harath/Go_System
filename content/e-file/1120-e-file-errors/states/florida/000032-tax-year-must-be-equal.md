# 000032 e-file error

```
000032: Tax Year must be equal the Year portion of Tax Period Begin Date CCYY or Tax Period End Date CCYY.
```

This happens when the fiscal year return isn’t in the current year.

**Solution**

- Go to **Organizer**, then to the **General Information** folder.
- Go to **Basic Return Information**.
- Go to the **Entity Information** tab.
- Go to the **DATES** section.
- The **Fiscal year beginning** and **Fiscal year ending** need to be in the current year.
- Do a full recompute and recreate the e-file.
