# STATE-016 e-file error

```
If the Submission Category in the State Submission Manifest has a value of ("CORPEP" or "PARTEP" or "INDEP" or "ESTRSTEP"), then TaxYr in the State Submission Manifest must be the same as processing year.
```

## Solution

Review the return date.

- Go to **Organizer**, **General Information**, and then **Basic Return Information**.
- Review the **Fiscal year ending date**. If the date's too far into the following year, the state requires the estimate to be filed from a current tax year return. If this is the case, consider one of these options:


  - paper file the return,
  - update the current dates, or
  - file the return from the current year product.
