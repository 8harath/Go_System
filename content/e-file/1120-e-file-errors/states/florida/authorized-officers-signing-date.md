# E-file diagnostic: Florida e-file: Authorized officer’s signing date

```
Florida e-file: Authorized officer's signing date, first name, last name, and email are required entries for Florida e-file.
```

This happens when signing the officer’s information is missing.

**Solution**

- Go to **Organizer**, **States**, and **Common State**.
- Go to **General Information**, and select **Basic Return Information**.
- Select the **Signature Authorization** tab.
- On the Florida row, make sure you enter the following information: **First name**, **Last name**, **E-Mail Address**, **Phone number**, and **Signature Date**.
