E-file diagnostic: PDF Attachment Requirement

PDF Attachment Requirement: FormCO411/BA471 Federal Extension box is checked, IRS Form 7004 PDF is missing Go to : Organizer /Vermont/E-file/Attachments/Summary/Attach required pdf and check the box for pdf attached.
This happens when the PDF attachment for Federal Extension Form 7004 PDF is missing.

Solution

  1. Select
    Organizer
    ,
    States
    , then the
    Vermont
     folder.
  2. Select
    E-File
    , then the
    Attachments
     folder.
  3. Select
    Summary
    , then
    Attach PDF
    . This opens the
    Electronic Filing Attachments
     Dialogue.
  4. Select
    Add
    .
  5. Select
    Attachment Jurisdiction: Vermont
    .
  6. Select
    Browse for file
    , then attach the PDF named
    Form7004.pdf
     without spaces or special characters.
  7. Do a full recompute then recreate the e-file.
note
If the PDF
Form7004.pdf
 is already attached, mark the
CO-411 or BA 471, Federal Extension, a PDF of IRS Form 7004 is missing
 checkbox.
