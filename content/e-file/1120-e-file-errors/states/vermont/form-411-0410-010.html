Form 411-0410-010 Form 7004 PDF is missing e-file error

Form 411-0410-010: Federal Extension. Required Copy of IRS Form 7004 PDF is missing.
This happens when CO-411 or BA 471, Federal Extension, is selected and the file name of the missing IRS Form 7004 PDF is incorrect.

Solution

  1. Go to Organizer and select
    States
    Vermont
    E-file
    Attachments
    Summary
    .
  2. If
    CO-411 or BA 471, Federal Extension, a PDF of IRS Form 7004 PDF is missing
     is selected, you'll need to attach Form 7004 as a PDF.
    1. Select
      Attach PDF
      .
    2. Select
      Add
       and select
      Vermont
       for the
      Attachment Jurisdiction
      .
    3. Find for the file and attach it. The name of the file should be
      Form7004.pdf
       with no spaces or special characters.
  3. If you don’t need the checkbox selected, remove it.
  4. Recreate the e-file and submit it again.
note
The name of the file should be
Form7004.pdf
 with no spaces or special characters.
