# Form 411-0410-010 Form 7004 PDF is missing e-file error

```
Form 411-0410-010: Federal Extension. Required Copy of IRS Form 7004 PDF is missing.
```

This happens when CO-411 or BA 471, Federal Extension, is selected and the file name of the missing IRS Form 7004 PDF is incorrect.

## Solution

- Go to Organizer and select 

  **States****Vermont****E-file****Attachments****Summary**

  .
- If **CO-411 or BA 471, Federal Extension, a PDF of IRS Form 7004 PDF is missing** is selected, you'll need to attach Form 7004 as a PDF.


  - Select **Attach PDF**.
  - Select **Add** and select **Vermont** for the **Attachment Jurisdiction**.
  - Find for the file and attach it. The name of the file should be 

    Form7004.pdf

     with no spaces or special characters.
- If you don’t need the checkbox selected, remove it.
- Recreate the e-file and submit it again.

note

The name of the file should be **Form7004.pdf** with no spaces or special characters.
