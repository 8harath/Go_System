# E-file diagnostic: Form 411-0396-010

```
Form 411-0396-010: VT Apportionment percentage is less than 100 percent Form BA402 must be attached.
```

This happens when the BA402 isn't included in the e-file but is required.

## Solution 1

- Select **Organizer**, then the **States** folder.
- Select **Vermont**, then the **General Information** folder.
- Go to the **General Information** section.
- Mark the **Corporation has nexus in Vermont** checkbox.
- Do a full recompute then recreate the e-file.

## Solution 2

- Select **Organizer**, then the **States** folder.
- Select **Vermont**, **E-file**, then the **Forms Included in E-file** folder.
- Mark the **BA402** checkbox.
- Do a full recompute then recreate the e-file.

note

If this is a consolidated return, at least 1 subsidiary must be marked with nexus in Vermont.
