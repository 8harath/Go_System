File number not entered as required by the state

SC-1120, SC-1120/S or SC-1101B: The file number has not been entered as required by the state.

Solution

  1. Go to
    Organizer
    ,
    States
    ,
    Common State
    ,
    General Information
    , and then
    State /City ID Numbers
    .
  2. Enter the file number for South Carolina.
    tip
    If the file number isn't known, you can request it by emailing corptax@sctax.org or calling 803-896-1730.
  3. Perform a full re-compute, re-create the e-file, then re-submit.
