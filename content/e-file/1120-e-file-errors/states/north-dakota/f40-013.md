# F40-013 e-file error

```
For filing methods b1 and c1, the aggregate of all columns line 14 or 16 (SFW) must equal the total factor on lines 14a or 16a (SFW).
```

This happens when the sum of the members’ 1120 North Dakota Form 40, Page 7, line 14 doesn’t equal what is shown on the TopCon's Form 40, Page 7, line 14.

## Solution

- Go to 

  **Tax Forms****States****North Dakota**

  .
- Select **Composite Report**, then **Schedule CR**.
- Select **Detail**, then **40, Page 7**. and check each member’s line 14.
- Update the amounts on each member's locator to ensure that the total sum matches the figure found on TopCon's form 40, Page 7, line 14. To verify this:


  - Go to 

    **Tax Forms****States****North Dakota**

    .
  - Select **Combined Report**, **Schedule CR**, then **40, Page 7, line 14**.
- After making corrections at each member's locator, consolidate the return at TopCon, and recreate the e-file.

note

If there's a difference with the amount, you'll need to file the return on paper.
