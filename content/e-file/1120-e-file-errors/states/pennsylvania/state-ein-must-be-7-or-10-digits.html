E-file diagnostic: State EIN must be 7 or 10 digits

PA e-file: State EIN must be 7 or 10 digits in length. Go to: Organizer\States\Common State\General Information\State /City ID Numbers
This happens when the state ID is missing for the state of Pennsylvania.

Solution

  1. Go to
    Organizer
    States
    Common State
    General Information
    .
  2. Go to the
    State/City ID Number
     section.
  3. Enter an ID number for
    Pennsylvania
    .
    note
    The ID number must be 7 or 10 digits.
  4. Recompute and recreate the e-file.
