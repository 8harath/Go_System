RCT-101 e-file error

Any payment amounts of $1,000 or more must be made electronically. Payments can be scheduled via EFT with this return if filing electronically or can be scheduled online at https://www.etides.state.pa.us.
This informational diagnostic happens when a payment amount is $1,000 or more and must be made electronically.

Solution

This is an informational diagnostic and doesn't have to be cleared to e-file the return.
