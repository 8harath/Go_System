# PA1120-024 e-file error

```
RCT-101 is present and Federal Form 1120, 1120S or 1120F is not present.
```

This happens when the Federal Copy is not attached to the PA return. This is because this is an 1120-RIC Federal return, and that option isn't available for an 1120-RIC.

## Solution

You can't select **Attach the Federal XML created in the Federal Organizer** in Column F since this locator is an 1120-RIC, so follow these steps:

- Go to 

  **Organizer****General information****Basic Return Information**

  .
- Go to the **Entity Information** tab.
- For **Set Return Type**, select **1120 – U.S. Corporation** from the dropdown.
- Go to 

  **Organizer****States**

  .
- Go to **Enable/Create Returns**.
- Go to the **Federal Copy** tab.
- Enter the federal information in Columns F, M, N, and O.
- Do a full recompute and recreate the e-file.

note

The state requires a federal copy, so if you filed the federal return on paper, you'll need to file the state return on paper as well.
