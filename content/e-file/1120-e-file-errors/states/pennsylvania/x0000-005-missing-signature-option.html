X000-005: Missing Signature Option e-file error

This error occurs when you haven't selected a signature option for the state.

Error message

X0000-005: Missing Signature Option: Go to Organizer\States\State E-file\Enable\Return tab. Select a signature option

Solution

  1. Go to
    Organizer
    States
    State E-file
    Enable/Create Returns
    Return
    tab.
  2. In
    Column K
     for Pennsylvania, select a
    signature option
    .
  3. Do a full recompute, then recreate the e-file.
note
This selection is still required even if you're only filing the extension.
