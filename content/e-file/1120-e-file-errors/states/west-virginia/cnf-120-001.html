CNF-120-001 e-file error

If Form WV/CNF-120, Checkbox 3 "Corporation" is checked, then either IRS Form 1120 or IRS Proforma 1120 must be attached. Name the PDF file as "IRS1120.pdf" or "IRS1120.PDF" or "IRSPro1120.pdf" or "IRSPro1120.PDF."
You get this error when the federal e-file isn't attached or is attached and doesn't have an accepted naming convention.

Solution

  1. Go to
    Organizer
    ,
    States
    ,
    West Virginia
    ,
    E-file
    ,
    Attachments
    ,
    Summary
    , and then
    Summary
    .
  2. Select
    Attach PDF
    .
  3. If an attachment with an unaccepted naming convention is attached, remove it, then select
    Add
    . 
  4. Enter the following:
    1. Attachment Jurisdiction
      : Federal
    2. Attach the file.
    3. Select User defined description
      : IRS1120.pdf
  5. Select
    Upload
    , then
    Done
    .
  6. Perform a full re-compute, re-create the e-file, then re-submit.
