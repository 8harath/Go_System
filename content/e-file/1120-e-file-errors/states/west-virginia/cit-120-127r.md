# CIT-120-127R e-file error

```
CIT-120-127R: Apportionment Factor (Column AJ) for each entity must equal the quotient of Entity
WV Sales divided by the Group Everywhere Sales. GOTO is not available). Navigation: Tax Form\ States \ West Virginia \ Combined Report \ Apportionment - Member Information \ Review part 1- Regular Factor for all entities listed.
```

This happens when you have amounts entered in Elimination binder.

## Solution

- Go to **Tax Forms**, **States**, then to the **West Virginia** folder.
- Select Form **CIT-120APT**, then go to **Page 2**.
- Look at the subview on the **Within and Everywhere** apportionment amounts to find the amounts in the eliminations.
- If you have any amounts in the **Elimination Binder**, remove them and adjust the amounts entered in the other member returns.
- To enter the amounts, go to **Organizer**, **States**, and to the **Allocation and Apportionment** folder.
- Go to **Organizer/Overrides**, then select the **West Virginia** folder.
- Select **Payroll and Sales**. Enter the values.
- Do a full recompute, reconsolidate, and recreate the e-file.
