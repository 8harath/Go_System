# OH-MNP10-037 e-file error

## Error

```
The historical credit carryforward amount for the municipal corporation indicated cannot exceed the tax liability regardless of the total carryforward amount available for the current taxable year. Remaining carryforward amounts will be available for use in preceding taxable years. Please correct and retransmit.(OH-MNP10-037)
```

## Cause

The historical Credit Carryforward can't be greater than the Tax Liability. This is an e-file limitation imposed by the state of Ohio.

## Solution

- In the **Tax Forms**, select **Cities**.
- Select **Ohio Generic Cities**, **OH**, then **Ohio MNP**.
- Check the **Consolidated totals** line on Form MNP10, Page 3.


  - If you find an error, fix it. Then recompute, recreate the e-file, and re-submit the return.
  - If the line is correct, contact the jurisdiction for further clarification.
