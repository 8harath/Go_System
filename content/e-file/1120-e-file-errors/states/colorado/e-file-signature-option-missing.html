E-file diagnostic: General Rule 2: The electronic filing signature option is missing.

* General Rule 2: The electronic filing signature option is missing.(Automatic GOTO is not available) Navigation: Organizer\State\States E-file\Enable\Create Returns\Return tab\Signature Option.
This happens when the signature option is not selected in Column K for a Colorado return.

Solution

  1. Go to
    Organizer
    States
    State E-file
    .
  2. Select
    Enable\Create Returns
     and go to the
    Return
     tab.
  3. Make a selection for the
    Signature Option
     in Column K.
  4. Do a full recompute and recreate the e-file.
