# E-file diagnostic: General Rule 3 Return Authorization

```
General Rule 3: Return Authorization - The Business Representative information First Name, Last Name, Title, Signature Date, and Phone number have not been entered. (Automatic GOTO is not available) Navigation: Please enter the information at Organizer\States\Common State\General Information\Basic Return Information\Signature Information tab.
```

This happens when the Business Representative information such name, date, or phone number is missing.

## Solution

- Go to **Organizer**, then the **States** folder.
- Go to the **Common State**, **General Information**, then the **Basic Return Information** folder.
- Go to the **Signature Information** tab.
- Fill in **Columns B**, **D**, **F**, **H** and **L** for **Colorado**.
- Do a full recompute, and recreate the e-file.
