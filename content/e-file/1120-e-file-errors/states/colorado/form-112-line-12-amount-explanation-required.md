# E-file diagnostic: If Form 112, line 12 has amount explanation required

```
If Form 112, line 11 (Other subtractions) has amount then an explanation required to be enter. Navigation: Tax form Form 112 page 2 Line 11 Explain click on View Detail will take you to the organizer field.
```

This happens ff there is an amount in Colorado Form 112, Page 2, Line 11, and the explanation is missing.

## Solution

- In Organizer, select **States**, then **Colorado**.
- Continue to the **State Adjustments**, look for the**Other Subtractions** section.
- Enter the explanation.
- Perform a full recompute and recreate the e-file.
