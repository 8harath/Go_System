# S4-0012 e-file error

```
*S4-0012: Form 1120N Schedule IV, Column III Combined Income line 27 must equal the result of Column I Subtotal line 27 minus Column II Eliminations line 27.
```

This happens when Form 1120N Page 1 has adjustments on any line of this form, if any adjustments exist the return will need to be paper filed. The state schema allows for Combined Subtotal, Elimination, and Combined income Total on Schedule IV but does not include consolidation adjustments.

## Solution 1

- Go to 

  **Tax Forms****States****Nebraska****Form 1120N Pg 1**

  .
- Right click and review all lines for any adjustments that may exist.
- Go to **Consolidated Returns**, **Step 1 – What to Consolidate**.
- Select **Subsidiary Listing Complete**.
- Go to **Step 4 - Review Preconsol Checklist**. Select **Compute subsidiaries with compute pending**, then **Compute all subsidiaries now**.
- Go to **Step 5 – Consolidate!** and select **Consolidate**.
- Recreate the e-file.

## Solution 2

- Go to 

  **Tax Forms****States****Nebraska****Form 1120N Pg 1**

  .
- Right click and review any line for adjustments.
- Review the members and make sure no adjustments exist; everything must be in balance.
- If there are adjustments, go to **States Combined Returns** and select **State Consolidation Steps**.
- Select **Delete Previously transferred state data**.
- Select **Nebraska**.
- Go to 

  **Organizer****Consolidated Returns****Step 1 – What to Consolidate**

  .
- Select **Subsidiary Listing Complete**.
- Go to **Step 4 - Review Preconsol Checklist**. Select **Compute subsidiaries with compute pending**, then **Compute all subsidiaries now**.
- Go to **Step 5 – Consolidate!** and select **Consolidate**.
- Recreate the e-file.
