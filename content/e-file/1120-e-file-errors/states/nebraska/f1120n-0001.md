# F1120N-0001 e-file error

```
Rule F1120N-0001: If filing combined return, must include NE Schedule III and IV.
```

This happens when 1120N, Sch III doesn't have any data.

## Solution

- Go to 

  **Tax Forms****States****Nebraska**

  .
- Select **1120N - Corporate Income Tax Return**, then go to **Page 1120N Sch III**.
- In **Column D** there must be an amount or **NONE**.
- Enter **NONE** for the **Totals** row if you don’t have an amount.
- Follow these steps to enter data.


  - Go to the 

    **Organizer****States****Allocation and Apportionment**

    .
  - Go to 

    **Organizer / Overrides****Nebraska**

    .
  - Select **Sales**, then go to the **Organizer - Nebraska Sales Apportionment** section.
  - Enter the sales apportionment amounts or **NONE**.
- Do a full recompute and recreate the e-file.
