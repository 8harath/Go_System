# NEGeneral-0001 e-file error

## Error

```
A return has already been filed for this Nebraska State Id for this tax period end date.
```

## Cause

The e-file database shows this ID has already been used on an accepted return.

## Solution

- In the **Organizer**, go to **States**.
- Open **Nebraska** and select **General Information**.
- Make sure a valid State ID is entered.


  - If the ID is already correct, contact the state to check the ID number for this return.
  - If you don't have a record of your Nebraska State ID, the taxpayer or representative with a POA on file with the Department can contact the Nebraska Taxpayer’s Assistance office at 800-742-7474.
