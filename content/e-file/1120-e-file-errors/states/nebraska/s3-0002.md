# S3-0002 e-file error

```
GrandTotal_GrTotEstTaxAmt (Column B) must equal the total of all CorpFilingReturn_TotEstTaxAmt, ParentCorp_TotEstAmt, and Subsidiary_TotEstTaxAmt eleements (listed in Column B).
```

This happens when filing a combined Nebraska Form 1120N and consolidation adjustments exist on Form 1120N, Page 1.

## Solution

The state schema doesn't allow consolidation adjustments, so the Nebraska return must be paper filed.

- Go to **Tax Forms**, **States**, then **Nebraska**.
- Select **1120N – Corporate Income Tax Return**, then the **1120N, Pg 2** tab
- Select the drill down arrow ![ ](/content/dam/helpandsupp/en-us/Topics/ONESOURCE-family/images/drill-down.png/_jcr_content/renditions/cq5dam.web.1280.1280.jpeg) on line 25.
- Clear any overrides and use subview to open the subsidiary for which an estimated tax was paid.
- Drill down ![ ](/content/dam/helpandsupp/en-us/Topics/ONESOURCE-family/images/drill-down.png/_jcr_content/renditions/cq5dam.web.1280.1280.jpeg) on the field for **Amount paid**.
- Then Select the **Payments of tax** tab.
- On the line for Nebraska, enter the appropriate amounts for each of the quarters.
- Do a full recompute.
- Close the subsidiary return to go back to the Topcon.
- In Organizer, select **Consolidated returns**.
- Select **Step 5 – Consolidate**, then **Consolidate**.
