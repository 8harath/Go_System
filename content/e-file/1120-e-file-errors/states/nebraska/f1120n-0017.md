# F1120N-0017 e-file error

```
* F1120N-0017: EstTaxPaymentsAmt (line 20) must equal GrandTotal_GrTotEstTaxAmt (Schedule III) if a Schedule III is present
```

This happens when a discrepancy between the estimated tax payments reported on Form 1120N, line 20, and the total estimated tax payments reported on Schedule III. The issue arises when the amounts in these 2 places don’t match, which is required if Schedule III is present.

## Solution 1

- Go to 

  **Tax Forms****States****Nebraska**

  .
- Select **Form 1120N - Corporate Income Tax Return**, then **1120N, Page 1**.
- **Line 20** must be equal to **Form 1120N Sch III, column (A) total**.
- Do a full recompute and recreate the e-file.

## Solution 2

- Go to 

  **Organizer****State Combined Returns**

  .
- Go to **State Consolidation Steps**. Select **6 - Press Delete previously transferred state**, then **Nebraska**.
- Go to 

  **Organizer****Consolidated Returns**

  .
- Go to **Step 1 - What to Consolidate**. In the **Consolidated Return List** section, select **Subsidiary Listing complete**.
- Go to 

  **Organizer****Consolidated Returns****Step 4 - Review Preconsol Checklist****Out of balance and compute pending**

  . Select **Compute all Subsidiaries now**.
- Go to 

  **Organizer****Consolidated Returns****Step 5 – Consolidate**

  . In the **Consolidation** section, select **Consolidate**.
- Do a full recompute and recreate the e-file.
