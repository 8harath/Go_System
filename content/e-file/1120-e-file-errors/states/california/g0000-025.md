# G0000-025 e-file error

## Error

```
The [CAReturnHeaderDocumentId] in the Schedule R-7 must equal a document ID [documentId] from the Parent or Subsidiary CA-ReturnHeader attribute.(G0000-025)
```

## Cause

This reject is typically caused by improper structure.

## Solution

- In **Tax Forms**, go to **States**.
- Select **California**, then **Selected Options**.
- In the **Return Type** tab, right-click on the different California entity types and select **Subview**.
- In the structure, make sure there is 1 parent and 1 elimination.

Next, review to make sure all members have California activated.

- Go to **Organizer**, then select **States**.
- Open the **State and City Activation** folder, then select **State and City Activation**.
- Right-click on the Combined return type for California, then select **Subview**.
- Verify that all members are marked.

Next, check to make sure a member is selected as the key corporation.

- Go to **Organizer**, then select **States**.
- Select **California**, then **Combined Return Information**.
- Open the **Combined Information** screen and review the **Member is the Key Corporationfield in the Schedule R-7 information** section.


  - Right-click the checkbox and select **Subview** to make sure this is marked at the member level.

Lastly, make sure there is a valid ID number entered for California.

- Go to **Organizer**, then select **States**.
- Select **Common States**, then **General Information**.
- Review the State/City ID numbers.
