# F540NR-960 e-file error

## Error

```
If Form 540NR Line 91 [SharedResponsibilityPenalty] is present, then Form 3853 must be attached.
```

## Resolution

- In the **Organizer**, go to **States**.
- Select **California**, then **General Information**.
- Go to Health Care, Health Care, then select the **Shared Responsibility Penalty** tab.
- In the **Full Year Coverage Declaration** section, answer **Yes** or **No**.
- If you answered **No**, drill down on the name and fill out the information to calculate the penalty.
- Do a Full Recompute, recreate the electronic file, and resubmit the return.
