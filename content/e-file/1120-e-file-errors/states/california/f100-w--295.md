# F100(W)-295 e-file error

## Error

```
Rule Number F100(W)-295: If Form 100/100W, Line 33 [Withholding] is present, then either Form 592-B or Form 593 must be attached.
```

## Cause

Form 100/100W, Line 33 [Withholding] is present, but Form 592-B or Form 593 is not attached.

## Solution

- In the **Organizer**, go to **States**.
- Select **California**, then **E-file**.
- Add either Nonresident Withholding (Form 592-B) or Real Estate Withholding (Form 593-B) at the member level.
- Re-compute the member.
- Reconsolidate, then recreate the XML.
