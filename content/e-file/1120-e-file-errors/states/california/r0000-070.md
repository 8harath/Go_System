# R0000-070 e-file error

## Error

```
A federal return must be attached in either XML or PDF format.
```

## Cause

If choosing PDF format, the file must be named Federal Return.pdf and the Attachment Description must be entered as “Federal Return”. This is required except when filing the CA Form 568, CA Form 100X, or when Form 100 [ExemptOrganization] is present.

## Solution

- In the **Organizer**, go to **States**.
- Go to **California**, **E-file**, **Attachments**, then **Summary**.
- Select **Attach PDF**, then select **Add**.
- Select **California** as the Attachment Jurisdiction and select **Add**.
- Select your PDF and select **Open**.
- Within the **Select a Title for this Binary Attachment - Step 1**, enter **Federal Return** and select **Finish**.
- Create the **California e-file in Organizer**, select **States**, **State E-File**, **Enable/Create Returns**, then **Recreate xml**.
