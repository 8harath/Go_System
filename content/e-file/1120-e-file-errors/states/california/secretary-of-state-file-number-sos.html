E-file diagnostic: Secretary of State File Number (SOS)

Secretary of State File Number (SOS): The SOS number must be 12 digits and begin with 19 or 20.
This happens when you haven’t entered a valid Social Security file number (SOS).

Solution

  1. Go to
    Organizer
    ,
    States
    ,
    Common State
    , then the
    General Information
     folder.
  2. Select
    State/City ID Numbers
    , then go to the
    State/City ID Numbers
     section.
  3. In
    Line State/City ID Numbers
    , enter the valid
    SOS
     number. It needs to be 12 digits.
  4. Go to
    Organizer
    ,
    States
    ,
    California
    , then the
    Disregarded Entity
     folder.
  5. Select
    General Information
    , then go to the
    General Information
     section.
  6. In
    Line Secretary of State file number
    , enter the valid
    SOS
     number.
note
  • This is different from the California Corporate number, which is 7 digits.
  • The state of CA requires a SOS number to be on file. The SOS number needs to be 12 digits and begin with 19 or 20.
  • If you don’t have the valid SOS number, then contact the state to obtain a number. California E-Help Desk: (916) 845-0353.
