R0000-057 e-file error

Error

Every PDF file attached must be referenced by the binary attachment XML document that represents it.

Cause

A valid reference to an attached file is missing.

Solution

  1. In the
    Organizer
    , go to
    States
    .
  2. Go to
    California
    ,
    E-file
    ,
    Attachments
    , then
    Summary
    .
  3. Remove the attachments.
  4. Change the file name of each PDF attachment that will be included in the e-file. California doesn't allow any special characters or spaces. The file name must be 23 characters or less.
  5. Attach the PDFs and do a full re-compute.
  6. Recreate the e-file and resubmit.
