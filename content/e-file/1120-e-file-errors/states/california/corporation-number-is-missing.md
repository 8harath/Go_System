# E-file diagnostic: Missing California corporation number

```
General Information: The California corporation number is missing in the parent and/or subsidiary returns.
```

This happens when member returns don't have the corporation number entered.

## Solution

- Go to 

  **Organizer****States****California****General Informationfolder**

  .
- Go to the **General Information** section, in the **Scannable Forms Information** subsection.
- Review the **Corporation Number (7 or 12 digits)** entry for all lower members. Right-click and select **Subview** to see which members don't have this entered. Open each member return needing this entry.
- If you want this line to be blank, you must select a reason from the dropdown in the **Reason the corporation number is not applicable** section.
- Perform a full recompute for each member.
- Reconsolidate at the TopCon level, recreate the e-file, and resubmit.

note

This applies to all the lower members of the consolidation locator that don't have a valid corporation number entered. If you do not have a valid corporation number, then you will have to contact the California E-Help Desk at **(916) 845-0353** to obtain a number.
