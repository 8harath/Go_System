F568-100 e-file error

Error

Form 568 Question J [BusinessActivityCode] must be a valid 6-digit Principal Business Activity (PBA) code per the current Form 568 Booklet. (F568-100)

Cause

California requires a valid Principle business activity code to be included in the return.

Solution

  1. In the
    Organizer
    , go to
    General Information
    .
  2. Select
    Basic Return Information
    .
  3. Enter the proper code in the Principal business code field.
  4. For more information, contact the California Help Desk at (916) 845-0353.
  5. Do a Full Recompute, recreate the electronic file, and resubmit the return.
