# E-file diagnostic: The California e-file extension cannot be submitted unless there is a payment due

```
E-file Extension Payment: The California e-file extension cannot be submitted unless there is a payment due. If no payment is due, an extension is not filed, it is automatic. If submitting payment, all required information must be entered (account type, routing number, account number, date to be debited, amount to be debited, authorization to debit, and daytime phone number). Navigation: Organizer/States/Common State/General Information/ /Bank Information/Extension - Debit tab.
```

This happens when either the bank information is missing for the California extension, or there is no amount due with the California extension.

## Solution

- Go to **Organizer**, then the **States** folder.
- Go to **Common State**, **General Information**, then the **Bank Information** folder.
- Go to the **Extension-Debit** tab.
- Fill out all the payment information.
- Do a full recompute, and recreate the e-file.

note

There must be an amount due with the extension to be able to e-file. If you want to pay by check or EFT, then you will have to paper-file the extension.
