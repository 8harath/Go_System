# F100(W)-225 e-file error

```
1120 California State Adjustments: Rule Number F100(W)-225 Form 100/100W, Line 17 [NetIncomeAfterAdjusts] and Line 18 [NetIncomeState] must be present.
```

This happens when California form 100 Side 2 Lines 17 and 18 are blank.

## Solution

- Go to 

  **Tax Forms****States****California**

  .
- **100-Corporation Franchise Return**, **Side 2**, **Line 17** must be populated.
- Line 17 automatically derives its value from the preceding lines. Line 17 description shows Net income (loss) after state adjustments. Subtract line 16 from Side 1, line 9.

note

If no values are anticipated for Line 16 and Line 9, and input **NONE** at Line 17, then do a full recompute and recreate the e-file.
