# Create estimates 4th quarter XML electronic filing process is completed. Validation is not processed.

```
Create estimates 4th quarter XML electronic filing process is completed. Validation is not processed.
```

## Solution

- In Organizer, go to **States**, **California**, then **e-file**.
- Open **Additional Information**.
- In **e-File Payment Method**, select or switch to **Use Form 8453 BE(PMT)**.
- Recreate Quarter 4.
- Change **e-File Payment Method** back to **None Selected**.
