# F100(W)-105 e-file error

```
Schedule Q: Rule Number F100(W)-105 If Form 100/100W, Question K(1) [SingleInterest] or Question K(3) [SameInterest] is checked "Yes", then Question K(3) [ParentCountry] must be present.
```

This happens when Form 100W Side 3 Schedule Q Questions K1 or K3 are marked yes then Parent Country must be selected.

## Solution 1

- Go to 

  **Tax Forms****States****California**

  .
- Select **100W-Corporation Franchise Return**, **Side 3**.
- If Questions **K1** and **K3** are **yes**, then a country of the ultimate parent must be selected:


  - Go to 

    **Organizer****States****California****General Information**

    .
  - On the 

    General Information

     screen, select a country from the **If yes, enter country of the ultimate parent** dropdown.
- Do a full-recompute and re-create the e-file.

## Solution 2

- Go to 

  **Organizer****General Information****Basic Return Information****Entity Information**

  .
- Go to **Return/Entity Type** and change the **Return type** to **1120-C Corporation**.


  * Remove data entry for **Ownership**.
- Go to 

  **Organizer****States****California****General Information****General Information**

  . Clear the checkboxes and remove the ultimate parent.
- Go to

  **Organizer****General Information****Basic Return Information****Entity Information**

  .
- Go to **Return/Entity Type** and change the **Return type** to back to **1120-S Corporation**.
- Perform a full-recompute and re-create the e-file.
