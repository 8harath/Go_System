# X0000-020 e-file error

## Errors

```
Your State submission does not match the latest published FTB Schema or is not well formed. You must contact your software provider to resolve this error.
```

```
XPath to Error/Return/ReturnHeader/PartnerInformationGrp/SignatureDt (X0000-020)
```

## Cause

The federal return hasn’t been accepted by the IRS.

## Solution

Submit the federal return. Once the federal return has been accepted, recreate and resubmit the California e-file. Alternatively, you can resubmit the California return with a PDF Copy of the Federal return.

- In the **Organizer**, go to **States**.
- Select **State E-file**, then **Enable/Create Returns**.
- In the **Federal Copy** tab, select **Attach federal return as PDF** within Column B for Federal Copy.
- When attaching a PDF copy of the federal return, name the file **Federal Return.pdf** before attaching it and enter **Federal Attachment** for the Attachment Title when attaching it to the California e-file.
