X0000-010 e-file error submission.xml

Your State submission does not match the latest published FTBSchema or is not well formed. You must contact your software providers to resolve this error. Data Value File Name: submission.xml. The returnVersion attribute is invalid - The value 2022v2.0 is invalid according to its datatype String - The Enumeration constraint failed.
This is a known issue to be updated on 1/21/24.

Solution

Update version (on or after 1/21/24), perform a full recompute, and then re-create and re-submit the e-file.
