GAX0000-001 e-file error 

GAX0000Federal or state GA Return Record No NA Form Occurrence No 0 Field Seq No 0 Form No GAX0000 Page No 1 Reject Code GAX0000-001 Path to XML Error Category Schema Validation Rule Number GAX0000-00.
This happens when the Form 1120 Georgia state schema is missing information in the e-file.

Solution 1

  1. In Organizer, select
    States
    , then
    Georgia
    .
  2. General Information
    ,
    Return Date Overrides
     section.
  3. Enter the current tax return dates plus one year on both the beginning and ending date.
  4. In Organizer, select
    States
    , then
    Georgia
    .
  5. Select
    Return Options
    .
  6. In the section Computation Suppression:
    1. If you want to e-file Georgia from the Federal Parent return with Georgia selected as a single entity, you need to select
      Not applicable
       to populate Form 600 Schedule 1.
  7. Perform a full recompute, recreate the e-file, and resubmit the return.

Solution 2

  1. In Organizer, select
    States
    , then
    Common State
    .
  2. Select
    General Information
    , then
    Basic Return Information
    .
  3. Select
    Return Information
    .
  4. In the Final Return Column H, if this is checked on the Common State Row 3, then the net worth return dates on Form 600 will not flow through.
  5. You need to uncheck this on the Common State row so the dates flow to Form 600.
  6. Perform a full recompute, recreate the e-file and resubmit the return.

Solution 3

  1. In Organizer, select
    States
    , then
    Georgia
    .
  2. Select
    General Information
    .
  3. In the Other Information section, enter the Corporation Representative Name, Corporation Representative Telephone Number, and Corporation Representative E-mail.
  4. Perform a full recompute, recreate the e-file, and resubmit the return.
