# E-file diagnostic: Form GA 4562 Attachment

```
Form GA 4562 Attachment: The presence of Form GA 4562 was detected. This form must be attached as a PDF. If PDF is attached, mark the checkbox titled "GA Form 4562" to indicate that PDF has been attached.
```

## Solution

To clear this diagnostic, Form GA 4562 must be attached as a PDF file.

- Print Georgia Form 4562 to a PDF.
- In 

  Organizer

  , go to the 

  Federal E-file

   folder and select **Attachments**.
- Select **PDF Attachments**, then **Summary**.
- Select **Attach PDF**.
- Select **Add**.
- Select **Georgia** as the Attachment Jurisdiction, then **Next**.
- Select your attachment, then **Open**.
- Select **Predefined description** and select **Form 4562 Depreciation**
- Select **Upload**, then **Done**.
