# GAR0000-016 e-file error

```
Consolidated Group FEIN Does Not Match the Consolidated Parent FEIN: (GAR0000-016) When Consolidated return filed, Consolidated return Tax ID must match with Consolidated Parent FEIN field populated.
```

This happens when the **Tax ID** or **FEIN**of a Consolidated Group doesn’t match the Consolidated Parent FEIN.

## Solution

- In Organizer, select **States**, then **Common State**.
- Select**General Information** , then **Basic Return Information**, then **Filing Status**.
- Review all members for the Common parent EIN column.
- Consolidated return tax ID or FEIN needs to match the Consolidated Parent **FEIN**field which is populated on the Parent and Subsidiary return.
- Consolidate the return in Organizer.
- Select**Consolidated Returns**, then **Step 1 – What to Consolidate**, then **Subsidiary Listing**.
- Select **Step 4 - Review Preconsol Checklist**, then**Out of balance and compute pending**, then **Compute subsidiaries** with compute pending then **Compute all subsidiaries now**.
- Select **Step 5 – Consolidate**, then **Consolidation**, then **Consolidate**.
- After consolidating recreate the e-file for Georgia.
