GAR0000-010 e-file error

Federal return must be included.
This happens when the Federal Return is not included when state return was filed.

Solution

  1. In Organizer, select
    States
    , then
    State E-file
    .
  2. elect
    Enable/Create Returns
    .
  3. Select
    Federal Copy
    .
  4. Select
    Attach a federal XML created in a different locator
    .
  5. Populate the federal return information on all the columns such as the EIN, locator number and account number.
  6. Do full compute, recreate e-file and resubmit the return.
note
An XML return can't be attached if the federal return is 1120-REIT because this type of return can't be e-filed. Also, Georgia doesn't allow PDF copies of the federal return for e-file. Therefore, if the federal return was paper filed, the Georgia return will need to be paper filed also with the State Reject Codes printed and attached with the paper-filing.
