# E-file diagnostic: Incomplete signature information

Incomplete Signature Information: There are empty fields for the return's signature information. Please fill out these fields (First name, last name, title, email, signature date).

Navigation: Organizer, select 

**States****Common State****General Information****Basic Return Information****Signature Information**

 tab.

This happens when you haven’t entered the basic signature information details.

**Solution**

- Go to the 

  **States****Common State****General Information****Basic Return Information****Signature Information**

   tab.
- For the **Georgia** row, enter the details in Columns **C**, **D**, **F**, **G**, **K** and **L**.
- Do a full Recompute.
- Recreate the e-file.
