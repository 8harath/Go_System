# E-file diagnostic: Invalid Filer Phone Number Format

```
Invalid Filer Phone Number Format: Georgia requires that the phone number provided be exact ten digits long.
```

This happens when you haven’t entered the phone number.

## Solution

- Go to the **Organizer**, **States**, **Common State**, **General Information** folder.
- Select **Basic Return Information**.
- Go to the **Entity Information** tab.
- For the **Georgia** row, enter the **Phone Number** in **Column D**.
- Do a full recompute.
- Recreate the e-file.
