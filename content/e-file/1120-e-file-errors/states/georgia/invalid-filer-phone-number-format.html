E-file diagnostic: Invalid Filer Phone Number Format 

Invalid Filer Phone Number Format: Georgia requires that the phone number provided be exact ten digits long.
This happens when you haven’t entered the phone number.

Solution

  1. Go to the
    Organizer
    ,
    States
    ,
    Common State
    ,
    General Information
     folder.
  2. Select
    Basic Return Information
    .
  3. Go to the
    Entity Information
     tab.
  4. For the
    Georgia
     row, enter the
    Phone Number
     in
    Column D
    .
  5. Do a full recompute.
  6. Recreate the e-file.
