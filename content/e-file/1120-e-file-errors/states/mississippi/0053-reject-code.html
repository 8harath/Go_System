Severity Error
Data Value

Message Required Combined Income Tax Schedule (Form 83-310) was not transmitted
This happens when the filing status did not match the entity type submitted.

Solution

  1. In Organizer, select
    States
    , then
    Common State
    .
  2. Select
    General Information
    , then
    Basic Return Information
    .
  3. Select the
    Filing Status
     tab.
  4. Go to the row for
    Mississippi
    .
  5. When Column C shows as combined, the return shouldn't be filed out of this locator with this status, it should be filed at the Topcon level.
  6. If Mississippi is being filed out of this locator, then set Column C to
    single
    , and the State and City Activation
    single
    as well.
  7. Do a full recompute, recreate, and resubmit the e-file.
