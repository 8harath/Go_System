MS84122-9 e-file error 

MS84122-9: Mississippi Composite Net Taxable Income or Loss not Transmitted.
This happens when Mississippi form 84-122 line 29 doesn’t match form 84-131 line 4a.

Solution

  1. In Organizer, select
    States
    , then
    Common State
    .
  2. Select
    General Information
    , then
    Basic Return Information- S Corp
    .
  3. Select the
    Filing Status
     tab.
  4. Select the row for
    Mississippi
    .
  5. Remove the selection for
    Column G, Composite Return
    .
    note
    Mississippi form 84-122 is only visible in the Tax Form view for an 1120s.
