# E-file diagnostic: Form 83/84-105: Required Officer Name, Title, Address, SSN

```
Form 83/84-105: Required Officer Name, Title, Address, SSN and Ownership percentage Go to :Organizer Income and Deductions Deductions Officers' Compensation Individual OfficersCause.
```

This happens when in State Mississippi Form 83/84-105 Officer Name, Title, Address, SSN and Ownership percentage are not entered.

**Solution**

- Go to the **Organizer**, **Income and deductions** folder, then **deductions**.
- Go to **Officers Compensation**, **Individual Officers**, then **Name**.
- Select the **States** hyperlink and select **Mississippi**.
- Enter the details. Include Name, Title, Address, SSN, and ownership percentage.
- Do a full recompute.
- Recreate the e-file.
