# E-file diagnostic: If MS 83-110 or 84-110 Line 8 is populated: Required form 83-120

```
If MS 83-110 or 84-110 Line 8 is populated: Required form 83-120 PDF Attachment (MS Balance Sheet) Go to : Organizer /Mississippi/E-file/Attachments/Summary/Attach required pdf and check the box for pdf attached.
```

This happens when for state Mississippi Form MS 83-110 or 84-110 Line 8 is populated: Required form 83-120 PDF Attachment.

## Solution

- In Organizer, select **States**, then **Mississippi**.
- Select **E-File**.
- Select **Attachments**, then **Summary**.
- Select **Attach a PDF**.
- Attach a PDF for Form MS 83-120.
- Perform a full recompute.
- In the **PDF Attachments Included in E-file** section.
- Select **83/84-110, line 8 Total Capital Base -Balance Sheet Per Books**.
- Perform a full recompute and recreate the e-file.
