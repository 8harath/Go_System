E-file diagnostic: MS County Code 83

If State is not MS use County Code 83. Code 83 is for an out of state address.
This happens when the country code is incorrect.

Solution

  1. In Tax Forms, select
    States
    , then
    Mississippi
    .
  2. Select
    83-105 - S-Corp. Inc and Franchise Tax
    , and check 84-105, Page 1.
  3. Verify the country code. Out of state entities exclusively have a county code of 83.
  4. In Organizer, select
    States
     then
    Common State
    .
  5. Select
    General Information
    , then
    Basic Return Information
    .
  6. Select the
    Address
     tab and in Column K, either choose a county or select “none selected” if the state is not Mississippi.
  7. Perform a full recompute and recreate e-file.
