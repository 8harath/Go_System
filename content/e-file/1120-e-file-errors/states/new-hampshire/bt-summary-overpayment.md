# BT-Summary Overpayment e-file error

```
BT-Summary Overpayment: Line 7(a) ‘credit to next year’ cannot be greater than Line 6(a). Please adjust Line 7(1) to be less than or equal to Line 6(a).
```

This happens when BT-Summary Overpayment line 7(a) is greater than line 6(a).

## Solution

- Go to 

  **Tax Forms****States****New Hampshire****BT-Summary**

  .
- Select **BT-Summary, Page 2**. **Step 4 line 7(a)** can't be greater than **line 6(a)**.
- Adjust line 7(a) to be less than or equal to line 6(a).
- Perform a full recompute and recreate the e-file.

note

New Hampshire added the rule that any overpayment can't exceed the amount on line 6(a). Line 6(a) is 500% times the amount on line 1(c).
