# NH1120-006 e-file error

```
NH1120-006: If form NH-1120, Line 8, NH Apportionment is < 1.000000 then form DP-80 must be present.
```

This happens when the value in Form NH-1120 Line 8 is less than 100% and Form DP 80 isn't present.

## Solution

- Go to 

  **Tax Forms****States****New Hampshire**

  . Select **Form NH 1120 BPT Page 2**.
- If the Line 8 value is other than 100%, complete the **Form DP 80 BPT Apportionment Schedule**.
- Go to 

  **Organizer****States****New Hampshire**

  .
- In the **New Hampshire** folder, select **General Information**, then go to the **General Information** section. Select **Yes** for **Required to file BPT**.
- Do a full recompute and recreate the e-file.
