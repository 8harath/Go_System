# 200779 e-file error

```
Error: Duplicate CBTU Found. You need to ensure the state ID is unique and entered for all members in the reconsolidated and regenerated e-file. Recreate the E-File and resubmit the return.
```

## Solution

- In the **Organizer**, select **States**, then **New Jersey**
- Select **Combined Return Information**.
- In the **Combined report Options** section, the Unitary ID entered here is all 9's. You need to enter a valid New Jersey Unitary ID here, do a full recompute, then select **Transfer to All**.
- Consolidate the return by going to **Organizer | Consolidated Returns | Step 1 - What to Consolidate**.
- Select **Subsidiary Listing**.
- Step 4 - **Review Preconsol Checklist/Out of balance** and compute pending | Compute all subsidiaries now.
- Step 5 - **Consolidate.**

If you do not have a valid unitary ID you will have to [contact the state](https://www.nj.gov/treasury/taxation/contact.shtml) to determine what to enter as the unitary ID or you can paper file
