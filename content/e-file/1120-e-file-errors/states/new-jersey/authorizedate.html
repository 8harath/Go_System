E-file error: Element name 'AuthorizeDate'

The field 'AuthorizeDate' with value '0', data is missing.
You'll get this error if date approved to do business or the state of incorporation information is missing.

Solution

  1. Go to
    Organizer
    ,
    States
    , then
    Common State
    .
  2. Select
    Basic Return Information
     then
    Entity Information
     tab.
  3. For the
    New Jersey
    :
    1. Select a
      State of incorporation
       in column
      F
      .
    2. Enter a
      Date Qualified in State
       in column
      I
       in mm/dd/yyyy format. .
  4. Perform a full re-compute, re-create the e-file, then re-submit.
