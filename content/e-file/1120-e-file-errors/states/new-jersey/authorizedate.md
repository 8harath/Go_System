# E-file error: Element name 'AuthorizeDate'

```
The field 'AuthorizeDate' with value '0', data is missing.
```

You'll get this error if date approved to do business or the state of incorporation information is missing.

## Solution

- Go to **Organizer**, **States**, then **Common State**.
- Select **Basic Return Information** then **Entity Information** tab.
- For the **New Jersey**:


  - Select a **State of incorporation** in column **F**.
  - Enter a **Date Qualified in State** in column **I** in mm/dd/yyyy format. .
- Perform a full re-compute, re-create the e-file, then re-submit.
