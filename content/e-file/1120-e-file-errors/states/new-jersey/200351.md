# 200351 e-file error

## Error

```
UnitaryID does not begin with NU or invalid length (200351)
```

## Cause

This Tax ID has already been used on an accepted return.

## Solution

- In the **Organizer**, go to **States**.
- Open **New Jersey** and select **Combined Return Information**.
- In the Combined Report Options section, make sure the **Unitary ID number** is entered for all members.

  note

  It must be 10 numeric digits without the "NU-".
- Once entered, select **Transfer to all**.
- Do a full recompute and re-consolidate the TopCon. Then re-create the e-file and re-submit the return.
