# E-file error: BooksAddress cannot be empty

```
BooksAddress cannot be empty
```

An address field for Books and Records is empty.

## Solution

- Go to **Organizer**, **States**, then **Common State**.
- Select **General Information**, **Books and Records**, **Location of Books and Records**.
- Enter the complete domestic or foreign address.
- Make sure that Columns C, E, F, G, and H have an entry.
- Do a full recompute and recreate the e-file.
