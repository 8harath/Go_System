# 200902 e-file error

New Jersey counts tax periods by month. This reject happens when the tax period end date is missing, invalid, or exceeds 12 months. Fiscal year filers and 52/53 week filers often get this error when dates don't align with New Jersey's requirements.

## Error message

```
State NJ
Severity REJECT
State Record
Record Name NA
Form Occurrence No 0
Field Seq No 0
Page No 1
Reject Code 200902
Rule Number 200902
XML Path /ReturnState/ReturnHeaderState/TaxPeriodEndDate
Error Message Header Return Period End Date Missing/Invalid[/STYLE]
```

## Solution

Complete these steps to resolve the reject:



- Go to 

  **Organizer****General Information****Basic Return Information**

  .
- Find the **Dates** section.
- Review the **Fiscal year beginning** and **Fiscal year ending** dates. The period can't exceed 12 months.

  important

  New Jersey doesn't have a 52/53 week filer option. For federal 52/53 week returns, override the dates to match the 12-month return dates used for the federal return.
- Go to 

  **Organizer****States****Common State****General Information****State Dates**

  .
- Locate the **Fiscal Year Date Overrides** section.
- Enter the deemed 12-month return dates used for the federal return.
- If the return still gets rejected, contact the New Jersey Division of Taxation to double check the correct dates.
