200779 e-file error

Error: Duplicate CBTU Found. You need to ensure the state ID is unique and entered for all members in the reconsolidated and regenerated e-file. Recreate the E-File and resubmit the return.

Solution

  1. In the
    Organizer
    , select
    States
    , then
    New Jersey
  2. Select
    Combined Return Information
    .
  3. In the
    Combined report Options
     section, the Unitary ID entered here is all 9's. You need to enter a valid New Jersey Unitary ID here, do a full recompute, then select
    Transfer to All
    .
  4. Consolidate the return by going to
    Organizer | Consolidated Returns | Step 1 - What to Consolidate
    .
  5. Select
    Subsidiary Listing
    .
  6. Step 4 -
    Review Preconsol Checklist/Out of balance
     and compute pending | Compute all subsidiaries now.
  7. Step 5 -
    Consolidate.
If you do not have a valid unitary ID you will have to contact the state to determine what to enter as the unitary ID or you can paper file
