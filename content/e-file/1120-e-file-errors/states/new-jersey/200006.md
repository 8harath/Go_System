# 200006 e-file error

## Error

```
Duplicate Return. NJ return with this Tax ID and return period already filed. (200006)
```

## Cause

The e-file database shows this Tax ID has already been used on an accepted return.

## Solution

- In the **Organizer**, go to **States**.
- Open **New Jersey** and select **Combined Return Information**.
- Make sure a valid **Unitary ID** is entered. If the Unitary ID is correct, contact the New Jersey Division of Revenue and Enterprise Services at 609.292.9292.
