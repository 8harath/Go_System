# X0000-006 e-file error

```
Federal or state IA ReturnRecord No NAForm Occurrence No 0Field Seq No 0Form No X0000Page No 1Reject Code X0000-006Path to XML
ErrorError Category Schema ValidationRule Number X0000-006Severity ErrorData ValueAlternate Reject Code 0Message
The element ItemizedOtherAdditionsSchedule in namespace http://www.irs.gov/efile has incomplete content.
List of possible elements expected: OtherSource in namespace http://www.irs.gov/efile.
```

This happens when Other Additions doesn’t have a value.

## Solution

- In Organizer, select **States**, then **Iowa**.
- Select **State Adjustments**, then the **State Adjustments** tab.
- In the Additions section, in the Other Additions section, enter the details.
- Do a full recompute and recreate the e-file.
- Submit the return.
