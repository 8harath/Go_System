The element ItemizedOtherAdditionsSchedule in namespace http://www.irs.gov/efile has incomplete content.
List of possible elements expected: OtherSource in namespace http://www.irs.gov/efile.
This happens when Other Additions doesn’t have a value.

Solution

  1. In Organizer, select
    States
    , then
    Iowa
    .
  2. Select
    State Adjustments
    , then the
    State Adjustments
     tab.
  3. In the Additions section, in the Other Additions section, enter the details.
  4. Do a full recompute and recreate the e-file.
  5. Submit the return.
