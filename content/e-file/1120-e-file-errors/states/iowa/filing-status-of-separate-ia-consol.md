# For filing status of Separate IA/Consol e-file error

```
For filing status of Separate IA/Consol Fed or Consol IA/Consol Fed, Sch.: H2 & 3 are required. Go to Organizer/States/Iowa/Combined Return Information to enter the information.
```

## Solution

- Go to **Organizer**, **States**, **Iowa**, **Combined Return Information**, **Schedule H1**, and then **Parent Information**.
- Enter parent information. If you don't have any data to input, enter NONE. This will need to be completed in all the lower members as well.
- Next, go to **Organizer**, **State**, **Common State**, **General Information**, and then **Basic Return Information**.
- Go to the **Filing Status** worksheet, and make sure **Separate IA/Consol Fed** is selected.
- Perform a full re-compute, and re-create the e-file.
