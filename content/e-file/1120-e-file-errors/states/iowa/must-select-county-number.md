# E-file diagnostic: Must select county number

```
County number must be selected. Go to Organizer/States/Common State/General: Information/Basic Return Information/Address to select the county number for Iowa.
```

This happens when the country for the address is missing or is not being picked up.

## Solution

- In Organizer, select 

  **States****Common State****General Information****General Information****Basic Return Information**

  .
- Select the **Address** tab.
- Populate the **K County** column for Iowa.
- Run a full recompute and recreate the e-file.

  note

  If there is a code already selected for the county, change it to something else with a full recompute. Then change it back to the original selection with a full recompute.
