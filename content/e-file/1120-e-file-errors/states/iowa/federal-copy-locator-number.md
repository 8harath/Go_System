# E-file diagnostic: Iowa Federal Copy locator number

```
Iowa Electronic Filing: Please go to Organizer > States > State E-file > Enable/Create Returns > Federal Copy tab to check if the locator number is correct.
```

This happens when the federal return is required to be attached to the state return, but is missing required information.

## Solution

- Go to **Organizer**, then the **States** folder.
- Go to **State E-file**, then the **Enable/Create Return** folder.
- Go to the **Federal Copy** tab.
- In **Column B Federal Copy**, make the selection **Attach a federal XML created in a different locator/binder** for **Iowa Column A**.
- Fill in **Columns G**, **H**, and **I**.
- Do a full recompute, and recreate the e-file.
