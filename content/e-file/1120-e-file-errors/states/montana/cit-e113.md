# CIT-E113 e-file error

## Error

```
Missing supporting schedule for page 3, Line 3g. (CIT-E113)
```

## Cause

The Other Reductions Schedule isn't attached to the return.

## Solution

- In the **Tax Forms**, go to **States**.
- Select **Montana**, then **CIT - Corporation Income Tax Return**.
- Check Form CIT, Page 3, line 3g. If it's correct, you need to include a detailed breakdown attachment as a PDF.


  - Go to the **Organizer**, **States**, then **Montana**.
  - Go to **E-file**, then **Attachments**.
  - In the Summary section, add an attachment with the name "OtherReductionsSchedule.pdf".
  - Do a full re-compute, recreate the e-file and resubmit the return.
