# CIT-E107 e-file error

```
Montana CIT-E107: If an amount is present on Federal Form 1120, line 17, Taxes and licenses, then supporting schedule with the Line 17 taxes breakdown named FederalLine17TaxSchedule.pdf must be attached. Do NOT include spaces in the PDF name. Organizer/States/Montana/E-file/Attachments/Summary/Enable the checkbox once the PDF is attached. If this is not attached with the correct name, your return will be rejected by Montana.
```

This happens when an amount exists on Federal Form 1120, Page 1, Line 17, Taxes, and licenses, then a PDF named FederalLine17TaxSchedule.pdf must be attached.

## Solution

- Verify that an amount exists on the Federal Form 1120 Line 17.
- Go to **Tax Forms**, then select the **Federal** folder.
- Go to **1120-US Corporation Income Tax Return**, then **1120-US Corporation Income Tax Return**, **Page 1**.
- On **line 17**, **Taxes and licenses**, if an amount exists, then **FederalLine17TaxSchedule.pdf** needs to be attached.
- Go to **Organizer**, **States**, then **Montana**.
- Select **E-file**, **Attachments**, **Summary**, and then **Attach PDF**.
- Select **Add**.
- In the **Attachment Jurisdiction**, select **Montana**.
- Select **Browse for File**, and attach the PDF named **FederalLine17TaxSchedule.pdf**.
- Select **Upload**, then select **DONE**.
- On the **Summary** page, check the field **CIT- E107, Attach FederalLine17TaxSchedule.pdf**.
- Select **Compute** or **Full Recompute**.
- Go to **Organizer**, **States** folder, then **Enable/Create Returns**.
- Select **Create** e-file for Montana.
