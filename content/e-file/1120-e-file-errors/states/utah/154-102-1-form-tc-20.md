# E-file diagnostic: 154.102.1: Form TC-20, Page 2 - Question 3

```
* 154.102.1: Form TC-20, Page 2 - Question 3 - Information is not fully entered. In parent/single company return, go to Tax Forms/States/Utah/TC-20, Tax Return/Page 2/Question 3/Detail hyperlink/yellow screen. Complete all Mandatory E-file fields. (Note: If no UT organizer data, information already populated for this question is flowing from Common State at Organizer/States/Common State/General Information/50% or More Owner.)
```

This happens when in state Utah Form TC-20 (Utah Corporation Franchise or Income Tax Return) in what appears to be tax preparation software. The error indicates that Question 3 on Page 2 of Form TC-20 is incomplete. This question likely relates to ownership information for the corporation.

## Solution 1

- In the parent return, go to **Organizer**, **States**, and the **Utah** folder.
- Select **General Information**, **50% or More Owned**, then the **corporation** name.
- Be sure all address fields are filled out, even **address line 2 and c/o**. If there is nothing to put in, such as, **no province** or **state**, use **NA**.
- Do a full recompute, and recreate the e-file.

note

Enter this information only at the **parent** level for consolidated returns. Don't enter it at the **topcon** level or **subsidiary** level.

## Solution 2

- In **Organizer**, select **Consolidated Returns**, then **Step 1-what to consolidate**.
- Select **Subsidiary listing complete**.
- Go to **Step 4 Review Preconsol Checklist**, then **Out of Balance and compute Pending**.
- Select **Compute all subsidiaries now**.
- Go to the **Step 5 Consolidate** screen and select **Consolidate**.
- Enter either a full **Domestic** or **Foreign Address**.
- Do a full recompute, and recreate the e-file.
