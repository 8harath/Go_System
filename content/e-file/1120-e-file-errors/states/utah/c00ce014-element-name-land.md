# c00ce014 e-file error Element name: Land

## Error

```
Element 'Land' is unexpteced according to content model of parent element 'SchTC20-J.' Expecting: DescNatureAndLoc.
```

## Cause

This description for 'Nature and locations' is missing.

## Solution

- Go to **Organizer**, **States**, **Utah**, **Allocation and Apportionment**, and lastly **Allocation and Apportionment**.
- Enter a description in **Nature and location(s) of Utah business activities**.
- Perform a full re-compute, re-create the e-file, then re-submit.
