# E-file Diagnostic: Utah TC-40, State and Local income tax

```
Utah TC-40: State and Local income tax taken as an itemized deduction entered on TC-40, line 14 is limited to $10,000
```

This happens when line 14 on the TC-40 is over $10,000.

**Solution**

- Go to the **Organizer**, **State** folder.
- Go to the **Utah**, **Adjustments to Federal Amounts** folder.
- Go to the **State income tax deducted as itemized deduction (override)** line and enter **10,000**.
- Do a full recompute and recreate the e-file.
