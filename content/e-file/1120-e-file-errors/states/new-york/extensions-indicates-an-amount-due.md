# Extensions indicates an amount due to an e-file error

Mark a payment option for an extension with an amount due in the Bank Information spreadsheet.

## Error message

```
Electronic Filing - Extension: The extension indicates an amount due. Mark the option "Authorization to Debit Funds", "ACH Credit Option" or "Payment by Check" on the Bank Information spreadsheet, Extension-Debit (tab), columns E, F or I
```

## Solution

- Go to 

  **Organizer****States****Common State****General Information****Bank Information**

  .
- Select the **Extension Debit** tab.
- Mark one of the following payment options in the selected column:

  * **Authorization to Debit Funds** (column E).
  * **ACH Credit Option** (column F).
- **Payment by Check** (column I).
- Run a full recompute.
- Recreate the e-file.

note

If you're paying by check, EFT, or through the state website, don't enter an amount in the bank spreadsheet, column I.
