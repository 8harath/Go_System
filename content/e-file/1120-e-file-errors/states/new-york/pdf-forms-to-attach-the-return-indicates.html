E-file diagnostic: PDF Forms To Attach: The return indicates the NYC-222 is present

Electronic Filing - PDF Forms To Attach: The return indicates the NYC-222 is present and must be attached as a PDF. Mark the option indicating this form has been attached
This happens when the return indicates the NYC-222 is present but it is not attached as a PDF.

Solution

  1. Go to
    Organizer
    States
    New York City, NY
     folder.
  2. Go to
    E-File
    , then
    Attachments
     folder.
  3. Select
    Summary
    , then
    Attach PDF
    . This opens the
    Electronic Filing Attachments
     window.
  4. Select the
    Add
     button, then
    Attachment Jurisdiction
    : New York City.
  5. Select
    Browse for file
    , then attach the PDF without spaces or special characters.
  6. Go to
    PDF Attachments Included in E-file
     section.
  7. Mark the
    Form NYC-222
     checkbox.
  8. Do a full recompute and recreate the e-file.
