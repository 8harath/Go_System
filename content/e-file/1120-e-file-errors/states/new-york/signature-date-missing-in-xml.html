Error: 1120 New York Extension Signature Date Missing In XML

This e-file error happens when the signature date for the New York extension is missing from the return. Enter the signature date in the Extension Detail screen and regenerate the e-file.

Error message

1120 New York Extension Signature Date Missing In XML

Solution

  1. Go to
    Organizer
    States
    Common State
    Estimates and Extensions
    Extension Detail
     screen, Section
    New York
    , Subsection
    Extension Information
     and enter the
    signature date
    .
  2. Run a full recompute.
  3. Recreate the e-file by going to the
    E-file
     menu and generating a new e-file for the New York extension.
  4. Do a full recompute and recreate the e-file.
