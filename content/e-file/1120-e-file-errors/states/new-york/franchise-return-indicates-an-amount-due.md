# E-file diagnostic: The franchise return indicates an amount due.

```
Electronic Filing - Franchise Return: The franchise return indicates an amount due. On the "Bank Information" spreadsheet, "Direct Deposit" tab, Column E select an option. The choices are ACH Debit(e-file), Check(NYC 200-V), Do not debit(penalties may apply ) or EFT(ACH Credit or FedWire). If you choose EFT(ACH Credit or FedWire) you must also provide additional information in the New York City Organize Organizer E-file folder on the additional information page.
```

This happens when there is some bank information entered for the state but the rest of the bank information is missing.

## Solution

- Go to 

  **Organizer****States****Common State****General Information**

  .
- Go to the **Bank Information** folder, then **Direct Debit** tab.
- You need to either fill out all the bank information for New York or remove the information if not doing Direct Debit.
- Run a full recompute and recreate the e-file.
