# E-file diagnostic: Electronic Filing: Form CT-399

```
Electronic Filing: Form CT-399 should be attached as a PDF. Check the box indicating it has been attached to clear this diagnostic.
```

This happens when the attached form CT-399 checkbox is not selected.

## Solution

- Go to 

  **Organizer****States****New York**

   folder.
- Go to the 

  **E-File****Attachments****PDF Attachments**

   folder.
- Select **Summary**, then select **Attach PDF**. This opens the **Electronic Filing Attachments** window.
- Select the **Add** button.
- Select the **Attachment Jurisdiction: New York**.
- Select **Browse for file**, then attach the PDF without spaces or special characters in the name.
- Go to **PDF Attachments Included in E-file** section.
- Mark the **Form CT-399** checkbox.
- Do a full recompute and recreate the e-file.
