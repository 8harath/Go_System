# E-file diagnostic: Account Type, Routing Number (9-digit), Account Number, Account Holder Type, and Date to be Debited must be present

```
ACCOUNT TYPE, ROUTING NUMBER(9 digit), ACCOUNT NUMBER, ACCOUNT HOLDER TYPE and DATE TO BE DEBITED must all be present. Review your bank information here: Organizer\States\Common State\General Information\Bank Information\Direct Debit(tab)\Columns B,C,D,I and M.
```

This happens when required bank information is missing for the direct debit for the state.

## Solution

- Go to **Organizer**, then the **States** folder.
- Go to **Common State**, **General Information**, then the **Bank Information** folder.
- Go to the **Direct Debit** tab.
- Fill out Columns **B**, **C**, **D**, **F**, **G**, **K**, **L**, and **N** for **New York**.


  - Make sure **Column F Routing** is 9 digits long.
- Do a full recompute, and recreate the e-file.
