# E-file diagnostic: PDF Forms To Attach: The return indicates the NYC-222 is present

```
Electronic Filing - PDF Forms To Attach: The return indicates the NYC-222 is present and must be attached as a PDF. Mark the option indicating this form has been attached
```

This happens when the return indicates the NYC-222 is present but it is not attached as a PDF.

## Solution

- Go to 

  **Organizer****States****New York City, NY**

   folder.
- Go to **E-File**, then **Attachments** folder.
- Select **Summary**, then **Attach PDF**. This opens the **Electronic Filing Attachments** window.
- Select the **Add** button, then **Attachment Jurisdiction**: New York City.
- Select **Browse for file**, then attach the PDF without spaces or special characters.
- Go to **PDF Attachments Included in E-file** section.
- Mark the **Form NYC-222** checkbox.
- Do a full recompute and recreate the e-file.
