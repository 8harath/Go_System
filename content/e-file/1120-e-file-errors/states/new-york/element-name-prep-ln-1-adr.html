This generally occurs when the tax office has already transmitted this return and the reject is simply a duplicate filing. It also occurs when the preparer is attempting to amend the Form
1120
 and has failed to mark the return as an amended return.

Solution

  1. In Organizer, select
    States
    Common State
    Basic Return Information
    .
  2. Open the
    Signature Information
     tab.
  3. Go to the row for
    New York
    , Column L and enter the
    Signature Date
     for all members.
  4. If this is a consolidation then select
    Subview
     in the field and verify all members and enter their information.
  5. Do a full recompute of all members, reconsolidate, then create the e-file.
