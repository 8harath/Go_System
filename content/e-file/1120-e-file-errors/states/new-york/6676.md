# 6676 e-file error

```
Form must be present when required attachments checkbox is checked.
```

This happens when there are missing attachments.

## Solution

- Go to **Tax Forms**, **States**, **New York**, **CT-3**, then **Page 2**.
- In **Section C**, line **3**, if **CT-225** is marked, then an attachment is also needed.
- To attach PDF, go to **Organizer** folder: **States** then **New York**.
- Select **E-file**, **Attachments**, and **Summary**. Attach your PDF and select the option **for Form CT-225-A/B** in the **PDF Attachments Included in E-File** section.

To Attach PDF:

- Go to **Organizer**, **States**, **New York**.
- **E-file**, **Attachments**, **Summary**.
- Select **Attach PDF**. This opens the **Electronic Filing Attachments Dialogue**.
- Select **Add**, then select the **Attachment Jurisdiction**: choose **New York**.
- Select **Browse for file** and add your attachment.
- Use a **Predefined description**, and select **UPLOAD**.
- Do a full recompute, and recreate the e-file.

note

On the CT-3-page 2, Section C, don't override any of these boxes or your return will be rejected.
