# E-file diagnostic: The authorized person's Signature date has not been entered

```
Electronic Filing - Returns: The authorized person's "Signature date" has not been entered. Note: CT-3-A filers should transfer signature, paid preparer and authorization information to the subsidiary CT-3-A/BC returns using the buttons on the "Additional Information" screen after clearing all New York diagnostics at the topcon level. Path: Organizer\States\New York\E-file\Additional Information
```

This happens when the signature date is missing.

## Solution

- Go to **Organizer**, **States**, then select **Common State**.
- Go to **General Information** and select **Basic Return Information**.
- Open the **Signature Information** tab and enter the date in **Column L**.
- Do a full recompute and recreate the e-file.
