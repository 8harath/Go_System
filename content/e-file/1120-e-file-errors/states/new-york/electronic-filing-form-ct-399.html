E-file diagnostic: Electronic Filing: Form CT-399

Electronic Filing: Form CT-399 should be attached as a PDF. Check the box indicating it has been attached to clear this diagnostic.
This happens when the attached form CT-399 checkbox is not selected.

Solution

  1. Go to
    Organizer
    States
    New York
     folder.
  2. Go to the
    E-File
    Attachments
    PDF Attachments
     folder.
  3. Select
    Summary
    , then select
    Attach PDF
    . This opens the
    Electronic Filing Attachments
     window.
  4. Select the
    Add
     button.
  5. Select the
    Attachment Jurisdiction: New York
    .
  6. Select
    Browse for file
    , then attach the PDF without spaces or special characters in the name.
  7. Go to
    PDF Attachments Included in E-file
     section.
  8. Mark the
    Form CT-399
     checkbox.
  9. Do a full recompute and recreate the e-file.
