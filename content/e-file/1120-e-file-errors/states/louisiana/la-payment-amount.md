# E-file diagnostic: LA-Payment amount

```
LA-Payment Amount: The Financial Transaction payment does not equal the Balance Due on Louisiana. Reason: You can't submit a Louisiana return unless there is a payment due.
```

This happens when the financial transaction payment doesn’t equal the balance due.

## Solution

If no payment is due, the return won't be filed, since this is an automatic process. If you're submitting a payment, you need to enter all the required information. Bank information is mandatory to e-file. If you want to pay by check/EFT, you need to paper file the return.

- In Organizer, select 

  **States****Common State****General Information****Bank Information**

  .
- Select the**Debit**tab.
- Enter information in the columns Account Type, Routing Number, Account Number, Date to be Debited, Amount to be Debited, and Authorization to Debit.
- Perform a full compute and create the return.
