# E-file diagnostic: Missing Paid Preparer Information

```
Missing Paid Preparer Information: Paid Preparer Information has not been suppressed. Go to the Paid Preparer Information spreadsheet and enter the missing information. All information is required unless suppressed.
```

This happens when information is missing for the Paid preparer.

## Solution

- Go to **Organizer**, **States**, **Common State**, **General Information**, then **Basic return information**.
- Select the **Signature Authorization** tab.
- On the **Michigan** row, make sure to fill in the following information: **First name**, **Last name**, **Title**, **E-Mail**, **Phone**, and the **Signature date**.
- Select **Compute**, and **Full Recompute**.
- Go to **States**, **State E-file**, then **Enable/create returns**.
- Select the **Create** button for Michigan.
