# E-file diagnostic: Gross Receipts Worksheet 4700 must be attached

```
PDF attachment: If filing Form 4567 or Form 4583, Gross Receipts Worksheet - 4700 must be attached. Once attached, check the corresponding box in Organizer.
```

This happens if the form isn’t attached, or if you haven’t chosen the field that the form is attached to.

## Solution

- Go to **Organizer**, then the **States** folder.
- Go to **Michigan**, then the **E-file** folder.
- Go to **Attachment**, then the **Summary** folder.
- Select the **Attach PDF** button.
- Attach the PDF document.
- Once it is attached, on the previous screen, go to the **PDF ATTACHMENTS INCLUDED IN E-FILE** section.
- Select the field for the form you attached.
- Run a full recompute, and recreate the e-file.
