# F4893-001 e-file error

```
If Form 4893 is present in the return, Form 4894 must also be present.
```

This happens when the 4893 is being included in the e-file but the 4894 isn't being included. If 4893 line 2 has an amount on it, then the 4894 needs to be included.

## Solution 1

- Go to **Organizer**, then the **States** folder.
- Go to **Michigan**, then the **Shareholder Information** folder.
- Select **Add new Shareholder and Officer Information**.
- Fill out the information for this folder.
- Do a full recompute, and recreate the e-file.

## Solution 2

- Go to **Tax Forms**, then the **States** folder.
- Go to **Michigan CIT**, **4893, CIT Small Business Alt. Credit** folder.
- Go to line 2. If there is an amount on the line, then you will have to fill out the 4894 or remove the amount.
- If you don't want the amount on line 2, you can space through the amount.
- Do a full recompute, and recreate the e-file.
