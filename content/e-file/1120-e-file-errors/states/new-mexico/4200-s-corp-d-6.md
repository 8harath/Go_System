# E-file diagnostic: 4200: S-Corp-D 6

```
If box 5 Withholding Required is not checked, must use a reason code 1-11.
```

This happens when the withholding required has no indicator selected.

## Solution

- Go to **Tax Forms**, **States**, then select **New Mexico**.
- Continue to the **NM-S-D** folder and look for **Owner Detail link**.
- For each shareholder, you must select either:


  - Check **No** next to **Withholding Required** and provide the reason for not withholding 1 through 11.
  - Select **Yes** next to **Withholding Required**.
- Do a full recompute and recreate the e-file.
