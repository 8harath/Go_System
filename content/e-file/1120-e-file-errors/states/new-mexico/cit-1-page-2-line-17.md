# E-file diagnostic: If CIT-1 page 2 line 17 has an amount, form RPD-41379 must be attached

```
Form CIT-1: If CIT-1 page 2 line 17 has an amount, form RPD-41379 must be attached.
```

This happens when the New Mexico form CIT-1 Page 2 Line 17 has an amount but the RPD-41379 PDF is missing.

## Solution

- Go to **Organizer**, **States**, then the **New Mexico** folder.
- Go to **E-file**, and the **Forms Included in E-file** folder.
- Select the **RPD-41379** field.
- Attach your RPD-41379 PDF document to New Mexico.
- Go to **Organizer**, **States**, and the **New Mexico** folder.
- Go to **E-file**, **Attachments**, and the **Summary** folder.
- Select **Attach PDF**.
- In the **Electronic Filing Attachments** screen, select **Add**.
- For the **Jurisdiction**, select **New Mexico**.
- Find your RPD-41379.pdf and attach it.
- Select the **User Defined Description**, and make sure the name matches the PDF of RPD-41379.pdf.
- Select **Upload**.
- Do a full recompute, and recreate the e-file.
