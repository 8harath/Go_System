# 1095 e-file error

```
Form CIT-1, line 1. Taxable income before federal NOL and special deductions must equal line 28 of federal Form 1120. (1095)
```

This happens when New Mexico Form CIT-1, Page 2, line 1 doesn’t equal Federal Form 1120, Page 1, line 28 amount, or when the extension is either too early or too late to be filed.

## Solution

- Go to the **Organizer**, **States**, **State E-File** folder.
- Select **Enable/Create Returns**, then go to the **Federal Copy** tab.
- If you have selected **Attach a Federal located in a different locator/binder** in **Column B**, look for that Federal return to compare the line items. Don't compare the one within this binder.
- Verify the values entered in the following path.
- Go to the **Tax Forms**, **Federal**, **1120-US Corporation Income Tax Return** folder.
- Select **1120-US Corporation Income Tax Return**, then go to **Page 1**, **Line 28** must match with the New Mexico amount.
- Go to **Tax Forms**, **States**, **New Mexico** folder.
- Select **CIT-1 - Tax Return**, then go to **CIT - 1 Pg 2**,**Line 1** amount.
- Do a full recompute, then recreate the e-file and resubmit.

note

* The Federal 1120, Page 1, line 28 and Form CIT-1, line 1 must match to clear the rejection. Either enter the correct value for line 1 or adjust the federal copy option to reflect the proper numbers.
* You will need to make sure that the values in the Federal that you are using match the New Mexico values as stated in the reject.
* Additionally, the State of New Mexico requires an accepted federal copy of the return to be included. If these changes can't be applied, the client must paper file the return or contact the State of New Mexico to verify the rejection error at 1-866-285-2996.
