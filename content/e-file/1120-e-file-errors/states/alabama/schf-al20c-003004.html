SchF-AL20C-003/004 e-file error

SchF-AL20C-003/004: If Schedule F, line 6, BOY and/or EOY is populated then a pdf named OtherCurrentAssets.pdf or or WksNetWorthStmts.pdf is required to be attached. Note: Do not include the .pdf in the actual pdf name. The .pdf extension is automatically added when e-file is created.
This happens when OtherCurrentAssets.pdf or WksNetWorthStmts.pdf attachments are missing.
Solution
  1. Go to
    Organizer
    ,
    States
    , and the
    Alabama
     folder.
  2. Go to
    E-file
    , and
    Attachments
     folder.
  3. Select
    Summary
    , and the
    Attach PDF
     button. It opens the
    Electronic Filing Attachments
     Dialogue.
  4. Select the
    Add
     button.
  5. Select the
    Attachment Jurisdiction: Alabama
    .
  6. Select the
    Browse for file
     button. Attach the
    OtherCurrentAssets.pdf
     PDF or
    WksNetWorthStmts.pdf
     PDF without spaces or special characters.
  7. Do a full recompute and recreate the e-file.
note
Don't include the
.pdf
 in the actual PDF name. The
.pdf
 extension is automatically added when an e-file is created.
