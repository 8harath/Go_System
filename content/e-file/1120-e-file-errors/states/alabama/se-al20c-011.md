# SE-AL20C-011 e-file error

## Error

```
20C Pg 1 Part of consol federal and Sch E line 12 not equal to 0 or NONE. Attach: 1552a1.pdf.
```

## Cause

You receive this error when Alabama Form 20C, Schedule E, line 12 is greater than 0, and there's no 1552a1.pdf attached to the e-file.

## Solution

Review Alabama's Form 20C, page 4, Schedule E, line 12.

**If Schedule E, line 12 is greater than 0:**

- Go to **Organizer**, **States**, **Alabama**, **E-file**, **Attachments**, and then **Summary**.
- Select **Attach PDF**.
- Select **Add**.
- Select Alabama for **Attachment Jurisdiction**.
- Go to the file to upload.
- Select 1552a1 for **Predefined description**.
- Select **Upload**, and then **Done**.
- Perform a full re-compute, re-create the e-file, then re-submit.

**If Schedule E, line 12 is blank:**

- Go to **Organizer**, **States**, **Alabama**, **E-file**, **Attachments**, and then **Summary**.
- Remove any 1552a1.pdf attachment, if any.
- Perform a full re-compute, re-create the e-file, then re-submit.
