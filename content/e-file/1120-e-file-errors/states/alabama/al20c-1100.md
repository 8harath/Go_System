# AL20C-1100 e-file error

```
The xml listing of PDF attachments does not match the attachments listed in the file directory.
```

This happens when PDF attachments have an invalid name.

## Solution

- Go to **Organizer**, **States**, then **Alabama**.
- Select **E-file**, **Attachments**, then **Summary**.
- Remove the attachment and rename it to ensure it is fewer than 23 characters including spaces. The PDF attachments shouldn't have special characters in their names, and they shouldn't exceed 23 characters.
- Recreate the e-file, and resubmit the e-file.
