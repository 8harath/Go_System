# AL20C-072 e-file error

```
Rule AL20C-072: Date signed by Business Representative is missing. Navigation: Organizer/ States/Common State/General Information/Basic Return Information/Signature Information tab/Alabama row/Column K Signature Date. (#78).
```

This happens when you haven’t entered the signature date for Alabama.

## Solution

- Go to **Alabama**, **States**, **Common State**, then the **General Information** folder.
- Select **Basic Return Information**.
- Go to the **Signature Information** tab.
- Enter the **Signature Date** in **Column L** of the **Alabama** row.
- Do a full recompute and recreate the e-file.
