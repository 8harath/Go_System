# E-file diagnostic: Federal Efile Validation Errors

```
Federal Efile Validation Errors: State of Alabama requires Federal Efile to be clean of validation errors Clear all validation errors Recreate the State Electronic File to clear this diagnostic. (#15)
```

This happens when the federal return has diagnostics and needs to be cleared.

## Solution 1

Follow these steps if you're only filing the CPT.

- Go to the **Organizer**, and **States** folder.
- Go to **States**, **State E-file**, and the **Enable/Create Returns** folder.
- In **Column A**, go to **Alabama**.
- Clear or unmark the field in **Column C** for **Alabama**.
- Run a full recompute, then recreate the e-file for the Alabama CPT.

## Solution 2

- Go to the **Organizer**, and **States** folder.
- Go to the **State E-file**, and **Enable/Create Returns** folder.
- Go to the **Federal Copy** tab.
- The **Federal E-file Status (State Copy Only)** column needs to say qualified for the Federal e-file. If it isn’t qualified, then you will need to clear the diagnostics for the Federal Return.
- Run a full recompute and recreate the e-file.
