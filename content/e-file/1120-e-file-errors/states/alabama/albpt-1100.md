# ALBPT-1100 e-file error

```
The xml listing of PDF attachments does not match the attachments listed in the file directory.
```

This happens when there could be 2 issues with the CPT attachment. First, if the PDF name contains any spaces, and 2nd, when the PDF name must match the attachment title or file name. This can be observed by viewing the attachments; if the Binary attachment description differs from the file name, they should match except the file name has the extension .pdf.

## Solution

- Go to 

  **Organizer****States****Alabama Financial**

  .
- Select **E-file CPT**, **Attachments**, then **Summary**.
- Open the attachments wizard.
- Delete all attachments that are not meant for AL CPT. Ensure only the necessary attachments required for e-filing AL CPT are attached.
- Verify that the remaining attachments are correctly named and formatted according to the requirements.
- Reattach the PDF correctly named **CPT PDF**. Don’t override the attachment title or file name when attaching. The PDF name and attachment title/file name must be the same.
- Recreate the CPT e-file and resubmit the e-file.

note

If the answer to question H is yes, you need to populate the Affiliated Entities section. If the answer to question L is yes, you need to populate the Foreign Parent and Affiliated Entities section.
