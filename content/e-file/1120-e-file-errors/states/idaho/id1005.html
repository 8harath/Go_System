ID1005 e-file error

XML Error Checking: Rule Number: ID1005 Description: If Form 41, line 50 has value, then form 41ESR is required, attach a PDF with the filename 'Form_41ESR_01.pdf'. To attach a PDF: Navigation Edit Insert EFile attachments.
This happens when there is an amount on form 41, page 2, line 50 and a PDF attachment with the name is not correct.
Solution 1
  1. Go to
    Organizer
    , then to the
    States
     folder.
  2. Go to the
    Idaho
    , then
    E-file
     folder.
  3. Go to the
    Attachments
    , then
    Summary
    folder.
  4. Select the
    Attach PDF
     button.
  5. The file name must be
    Form_41ESR_01.pdf
    .
  6. If there isn’t an attachment add one with that name.
  7. If there is an attachment, delete it, and add a new one with the correct file name.
  8. Run a full recompute, then recreate the e-file.
Solution 2
  1. Go to
    Tax Forms
    , then the
    States
     folder.
  2. Go to the
    Idaho
    ,
    41 – Tax Return
     folder.
  3. Go to the
    41, Page 2
     tab.
  4. Go to line
    50
    . If there isn't an amount there, then this attachment isn't required and needs to be removed.
  5. Run a full recompute, then recreate the e-file.
