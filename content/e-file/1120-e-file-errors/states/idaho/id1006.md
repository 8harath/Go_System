# ID1006 e-file error

```
If Form 41, line 7 has value, then form Form_41A_01 and Combined reporting spreadsheet with value is required, attach a PDF with the filename 'Form_41A_01.pdf' and 'Comb_Report_Sheet_0001.pdf.'
```

This happens when there's a missing PDF attachment or the naming convention isn't matching 'Form\_41A\_01.pdf' and 'Comb\_Report\_Sheet\_0001.pdf.'

## Solution

- For this diagnostic, perform a print preview of the Idaho return.
- Save the Idaho 41A as Form\_41A\_01.pdf.
- Save the Idaho combined statements as Comb\_Report\_Sheet\_0001.pdf.

  note

  These file names must match exactly and are case-sensitive.
- Go to **Organizer**, **States**, **Idaho**, **E-File**, **Attachments**, and then **Summary**.
- Select **Attach PDF**, and then add these 2 PDFs.
- Perform a full re-compute, re-create the e-file, then submit.
