# E-file diagnostic: Form 100S, Schedule K-1

```
Form 100S, Schedule K-1, Shareholder Name: California requires the shareholder's first name, middle initial, and last name be listed in separate fields.
```

This happens when you are missing information that is required by the state or updating information in the incorrect format. California requires the shareholder's first name, middle initial, and last name to be listed in separate fields.

**Solution 1**

- Go to the **Organizer**, **Shareholder Information** folder.
- Go to **Shareholder Data, Shareholder Information** folder.
- Select the **Shareholder Name**.
- Go to **Shareholder Information**.
- Under the **Shareholder Information** section, select **Reformat for state purpose** hyperlink.
- Then select **View all shareholders** hyperlink.
- Make sure that all the shareholders have the **first name**, **last name** and **middle initial**.
- Do a Full Recompute and recreate the e-file.

**Solution 2**

- Go to the **Organizer**, **Shareholder Information** folder.
- Go to **Shareholder Data, Shareholder Information** folder.
- Select the **Shareholder Name**.
- Go to **Shareholder Information**.
- Go to **Schedule B-1 Information** section, and to**Column C - Type of Shareholder of Record Line**.
- Make a selection other than **None Selected**.
- Do a Full Recompute and recreate the e-file.
