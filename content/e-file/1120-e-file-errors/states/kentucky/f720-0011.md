# F720-0011 e-file error

## Error

```
Form 720 - Based on FEIN provided, the Kentucky Corporate/LLET Account Number does not match the Kentucky Department of Revenues records. Please contact taxpayer registration at 502-564-3306. (F720-0011)
```

## Cause

The Kentucky Corporate/LLET Account Number used in the return doesn’t match the database.

## Solution

Review the Kentucky Corporate/LLET Account Number:

- Go to **Organizer**, then select **States**.
- Select **Common State**, then **General Information**.
- In the State /City ID Numbers section, check the **Kentucky: Account Number**.
- Contact the state at (502)-564-3306 to verify the number matches their records.
