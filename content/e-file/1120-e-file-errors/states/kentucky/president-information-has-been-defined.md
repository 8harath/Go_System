# President information has been defined e-file error

```
Electronic Filing: Please verify whether all set of President information has been defined: Address, SSN and Phone number.
```

This happens because Kentucky requires ‘president’ information be entered.

## Solution

- Go to **Organizer**, **Income and Deductions**, **Deductions**, **Officers Compensation**, then **Individual Officers**.
- Adjust an officer's title to include ‘PRESIDENT.’ For example, if you've entered CEO, you can update to PRESIDENT/CEO.
- Also make sure a valid address and SSN has been entered.
- Perform a full re-compute, re-create the e-file, then re-submit.
