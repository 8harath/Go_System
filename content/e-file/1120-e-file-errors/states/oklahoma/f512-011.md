# F512-011 e-file error

```
Form 512, Part 2, line 4 (NetApportionableIncome) multipled by the Apportionment Formula, line 6 (ApportionmentFormula, AveragePercent) should equal Schedule B, line 5 (StateApportionedIncome).
```

This happens when there's no Oklahoma apportioned income.

## Solution

- Go to **Tax Forms**, **States**, **Oklahoma**, **512 - Tax Return**, **512, Page 4**, and **Part 2**.
- Enter 

  NONE

   on Line 5.
- Perform a full re-compute, re-create the e-file to clear the diagnostic.
