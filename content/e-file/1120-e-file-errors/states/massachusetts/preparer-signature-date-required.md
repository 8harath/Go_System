# E-file diagnostic: Preparer signature date is required

```
Preparer: Preparer signature date is required. Enter on Organizer\States\Common State\General Information\Paid Preparer Information\Paid Preparer Information tab.
```

This happens when a preparer information and/or signature date is missing.

## Solution

- In Organizer, select 

  **States****Common State****General Information****Paid Preparer Information**

  .
- Select the Preparer Information tab.
- In Massachusetts, column H, make sure the preparer information is filled out and the Signature Date.
- Perform a full recompute and recreate the e-file.
