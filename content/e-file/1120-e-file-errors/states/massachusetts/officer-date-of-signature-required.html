E-file diagnostic: Officer date of signature is required

Officer: Officer date of signature is required. Enter on Organizer\States\Common State\General Information\Basic Return In formation\Signature Information tab.
This happens when the officer’s signature information is missing the signature date.

Solution

  1. In Organizer, select
    States
    , then
    Common State
    .
  2. Select
    General information
    , then
    Basic return information
    .
  3. Select the tab
    Signature information
    .
  4. In Column L, enter the signature date for Massachusetts.
    note
    If any of the other information is missing pertaining to the signature information such as first name, last name, e-mail, phone, and SSN, enter it to resolve this diagnostic.
  5. Do a full recompute and recreate the e-file.
