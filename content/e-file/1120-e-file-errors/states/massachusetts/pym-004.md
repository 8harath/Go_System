# PYM-004 e-file error

```
355-7004 was filed with no payment information. According to TIR 15-15 extensions are granted automatically if 50% of the total excise has been paid by the original due date. Form 355-7004 should only be filed if a payment needs to be made in order to satisfy the minimum 50% requirement for the automatic extension.
```

Form 355-7004 was submitted without a payment.

## Solution

According to TIR 15-15, extensions are granted automatically if 50% of the total excise has been paid by the original due date. Only file Form 355-7004 if a payment needs to be made to satisfy the minimum 50% requirement for the automatic extension. Massachusetts doesn’t accept e-filed extensions without payment. Refer to TIR 15-15 for additional information.

Follow these steps to make a payment with the extension:



- Go to **Organizer**, **States**, **Common State**, **General Information**, **Bank Information**, then the **Extension Debit** tab.
- On the line for Massachusetts, mark **Column B for Authorization to Debit Funds**.
- Complete the following fields:


  * Account Number
  * Amount to be Debited
  * Account Type
  * Date Amount to be Debited
  * Routing Number
- Perform a full recompute, re-create the e-file, then re-submit.

note

For processing payments through the website, you may try removing the debit amount to see if it qualifies, as the system only supports Direct Debit for e-filing. Alternatively, you can paper file the return and pay through the Massachusetts website via EFT. When the Tax Payment Method is grayed out, there is no option to select a different method other than Direct Debit.
