Error: Schedule U-NOL: The date of most recent ownership

You'll get this diagnostic if either the date of the most recent ownership change or date or incorporation is missing.

Error Message

Schedule U-NOL: The date of the most recent ownership: If there have been no changes then enter the date of incorporation. Review Return XXXXXX.

Solution

For each entity preparing Schedule U-NOL, you'll need to enter either the
Date of most recent ownership change
 or
Date or incorporation
 if there was no change in ownership. The diagnostic will list the return number of the entity with the issue after
Review Return
.
  1. From the TopCon, go to
    Organizer
    States
    Massachusetts
    Net Operating Loss
    .
  2. Go to the
    Schedule NOL
     section, then the
    Date of most recent ownership change or date or incorporation if no change in ownership (Mandatory)
     field.
  3. Right-click the field, then select
    Subview
    .
  4. The
    Subview
     window will show the return number for each entity. Open any entities missing the date, and enter the date of most recent ownership change or date or incorporation if there was no change in ownership.
    note
    This information has to be entered in
    Organizer
     and not directly on Schedule U-NOL.
  5. Recompute each subsidiary.
  6. Reconsolidate the TopCon.
  7. Do a full recompute, then print.
