# E-file diagnostic: Schedule M-1 enter EIN or missing reason

```
Schedule M-1: Enter the EIN or missing reason for all entities listed in Schedule M-1, part 2, line 1.
```

**Solution**

- In Organizer, select **States**, then **Massachusetts**.
- Select **M-1/U-M Adjustments** and go to the **Entities without an FEIN** section.
- Make sure **Entities without an EIN** has **None Selected**.
- If this is marked **None selected**, make a different selection, do a full recompute then change it back to **None selected**.
- Do a full recompute again.
