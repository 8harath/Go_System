# FNRCR-018 e-file error

```
FNRCR-018: The Form MA NRCR must have 2 or more members included on the return.
```

You get this error when a Massachusetts Composite return is created, but 1 or less members are selected for composite.

## Solution

**If you aren't filing the Massachusetts Composite return**

- Go to **Organizer** and select **States** then **State E-file**.
- Select **Enable/Create Returns**.
- On the **Return** tab, clear the checkbox to enable the Massachusetts Composite e-file.
- Do a full recompute to clear the diagnostic.

**If you are filing the Massachusetts Composite return**

For each shareholder that should be included:

- Go to **Organizer** and select **Shareholder Information**, then **Shareholder Data**.
- Select **Shareholder Information**, the folder for the shareholder's name, then **State Shareholders Information**.
- Select the Massachusetts for composite return option.
- Do a full recompute.
