# X0000-001 e-file error

```
State MA
   Severity Error
   State Record X0000
   Record Name NA
   Form Occurrence No 0
   Field Seq No 0
   Page No 1
   Reject Code X0000-001
   Rule Number X0000-001
   Error Message The element FID in namespace http://www.irs.gov/efile has incomplete content. List of possible elements expected: EIN, Other in namespace http://www.irs.gov/efile.
```

This happens when the SSN is missing or incorrect.

## Solution

- In Organizer, 

  **States****Common State****General Information****Basic Return Information**

  .
- Select the **Signature Information** tab.
- Go to the Massachusetts row, column J and enter the SSN.
- Do a full recompute.
- Recreate the e-file and re-submit.

  note

  If you do not have a valid SSN to enter, contact the IRS e-file help desk at **(866) 255-0654** to resolve this issue.
