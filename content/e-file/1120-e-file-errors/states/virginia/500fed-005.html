500FED-005 e-file error

500FED-005: Schedule 500FED line 3 must be populated with a value greater than zero when Form 500 Line C (2) is populated with a value greater than zero.
This happens when Form 500FED - Line 3 isn't populated with a value greater than 0 when Form 500, Page 1 Line C (2) has an amount greater than 0.

Solution

  1. Go to
    Organizer
    States
    Virginia
    Net VA Modification - Year of Loss
    Federal NOL Adjustment Section
    Federal NOL
     field
  2. Enter an amount or
    NONE
     if no amount is available.
  3. Perform a full recompute and re-create the e-file.
