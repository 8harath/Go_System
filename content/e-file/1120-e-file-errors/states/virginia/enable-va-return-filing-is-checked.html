Efile diagnostic: Enable VA Return Filing is checked

VA Return:: Enable VA Return Filing is checked. The System has determined that not all information required to create a VA e-file return has been completed. It is mandatory to enter or select the following information: 1.Enter Electronic Filing Identification Number(EFIN). 2.Select the Type of Originator, ERO or Large Taxpayer. 3.Select the Signature Option, PIN or Scanned VA-8453C document.
This happens when you are missing the signature option selection.
Solution
  1. Go to the
    Organizer
    ,
    States
    ,
    State E-file
    folder.
  2. Then go to
    Enable/Create Returns
    folder.
  3. On the row for
    Virginia
    , go to column K.
  4. Select
    Signature Option
    for Virgina.
  5. Do a Full Recompute and recreate the e-file.
