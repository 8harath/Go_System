# E-file diagnostic: Schedule 500AC income doesn’t equal member amounts

```
Schedule 500AC: Total of Schedule 500AC Income subject to Virginia tax does not equal the total of all member amounts.
```

This happens when line 16 doesn't equal the sum of lines 14 and 15.

## Solution

- In Tax Forms, select **States**, then **Virginia.**
- Select **500AC - Schedule of Affiliated Corp**. parent, then **500AC, Page 1**.
- Line 16 total of all members needs to match the top con 500 Page 2 line 8a.

  note

  If amounts are totaling correctly, delete previously transferred state data at the Topcon. In Organizer, select **States**, **State Combined Returns**, **State Consolidation Steps**, then **Step 6**. Delete previously transferred state data, Virginia. Then consolidate the return.
