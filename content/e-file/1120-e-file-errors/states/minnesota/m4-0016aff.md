# M4-0016(AFF) e-file error

```
The same FEIN has been used for more than one entity associated with this tax return.
```

This happens when duplicate EIN information is entered in the tax return; all EINs must be unique. Additionally, Minnesota mandates a valid 7-digit Tax ID. Zeros and 9s are not permitted.

## Solution 1

To fix duplicate EIN numbers:

- Go to 

  **Organizer****General Information****Basic Return Information**

  .
- Go to the **Entity Information** tab. Right-click and select **Subview**.
- Ensure that no same EIN number is entered for two or more different locators.
- Once you’ve fixed the EIN, reconsolidate the TopCon locator and recreate the e-file.

## Solution 2

To fix Minnesota Tax ID:

- In the lower members, go to 

  **Organizer****States**

  .
- Select **Common States**, **General Information**, then **State/City ID numbers**.
- Enter a valid 7-digit Tax ID for **Minnesota**.
- Do a full recompute on all lower members as well as the TopCon.
- Once you’ve fixed the Tax ID, reconsolidate the TopCon locator and recreate the e-file.
