# M4-0015 e-file error

```
The parent MN tax ID has been used for more than one entity associated with this tax return.
```

The consolidated return has the same Tax ID entered on the parent and one of the subsidiaries.

## Solution

- Go to **Organizer**, **States**, then **Common state**.
- Select **General information**, then **State / City ID Numbers**.
- On the line for Minnesota: Identification number, right-click on the ID number and look for an ID number on 1 or more of the subsidiaries that is the same as the ID number on the parent. This will need to be changed to be its own unique MN ID Number.


  - If the ID number for a subsidiary is unknown, you can call the MN Business Registration office at: (651) 282-5225 to verify the MN ID Number.
- Do a full recompute, and recreate the e-file.
