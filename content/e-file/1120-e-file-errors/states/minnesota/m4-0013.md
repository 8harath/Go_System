# m4-0013 e-file error

```
Federal or state MN Return
Record No NA
Form Occurrence No 0
Field Seq No 0
Form No
Page No 1
Reject Code M4-0013
Path to XML Error
Error Category Acceptance Validation
Rule Number 0013
Severity Error
Data Value
Alternate Reject Code 0
```

The Subsidiary MN Tax ID submitted must match Minnesota Department of Revenue records and be active.

## Solution

- In Organizer, go to 

  **States****Common State****General Information****State/City ID Numbers**

  .
- Enter the MN identification number (7-digits).

  note

  This is required to e-file the MN return. If you are filing a combined MN return, you need to enter this for all members with Nexus in Minnesota.

  To verify or get a Minnesota Tax ID number, call the Minnesota Department of Revenue at 651-282-5225.

If the subsidiary doesn't have any activity:

- Remove the **X** for members that don’t have nexus.
- Select the **Tax Forms** tab, then 

  **States****Minnesota**

   **Selected Options** **Combined Options**.
- Select the line **If this company has nexus in MN and needs to be add to Sch AFF Affiliations for combined return. If you have entered a MN ID number, we assume that the entity has nexus**.
- In Organizer, go to 

  **States****Common State****Gen Info****State/City ID Numbers****MN**

  .
- Remove the **Minnesota Tax ID**.
- Reconsolidate.
- Recreate the e-file to get the diagnostics.
