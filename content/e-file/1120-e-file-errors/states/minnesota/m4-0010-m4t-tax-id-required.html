M4-0010(M4T): A 7 digit MN tax ID is required

Organizer/States/Common State/General Information/State /City ID Numbers For MN :
Each subsidiary must have a Minnesota state ID given out by the state of Minnesota.
A valid 7 digit ID number is required. (0000001, 0000000, 0000002 and 9999999) are not allowed.
This happens when each subsidiary does not have a valid 7-digit ID number entered in the form.

Solution

  1. Consolidate the Topcon and recreate the e-file; and/or at the subsidiary level in Organizer (
    General Information
    Questions
    Schedule K
    Question 3
     ).
  2. Select
    Yes
    .
  3. Complete the parent information.
  4. Perform a full re-compute and consolidate.
  5. The information above must match the information on this screen in Organizer, 
    States
    Minnesota
    Combined Return Information
    Combined Return Information
    Affiliations
    Federal ID Number
     .
  6. Enter the tax ID at sub levels.
  7. Perform a full re-compute for members after changes.
  8. Consolidate the Topcon and recreate the e-file
Call the MN Business Registration office at (651) 282-5225 to verify your tax ID number.
