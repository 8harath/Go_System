# 2055 e-file error

```
If Line E equals Standard then Schedule E Lines E4 and E5 is required. (2055)
```

This error happens when the STANDARD box on line E of Arizona Form 120 is marked but there are no standard apportionment values for lines E4 and E5 of Schedule E.

## Solution

- Review lines E4 and E5 of Schedule E to ensure the standard apportionment values are valid. Invalid values are NONE, 0 or blank.
- Make the necessary changes in the application.
- If there are no apportionment values to report, select **Organizer**, **States**, **Arizona**, **Allocation and Apportionment**.
- In the **Multi-State Apportionment** section, select **Not Applicable** or **Sales Factor Only**.
- Recompute, recreate then retransmit the return.
