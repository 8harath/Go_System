# AZ2072Description e-file error

```
XML Error Checking:Rule Number: AZ2072Description: If Line C5 contains a value other than zero or null, attach a Line C5 SchedulePDF titled 'OtherIncomeLoss'. To attach a PDF: Please go to Edit Insert e-file Attachments or go to Organizer StatesArizona E-file Attachments PDF Summary Attach PDF.
```

This happens when line C5 contains a value but there is no pdf attachment named OtherIncomeLoss.

## Solution

- In Organizer, select **States**, then **Arizona**.
- Select **E-File**, then **Attachments**.
- Select **Summary**, then select **Attach PDF**. This opens the 

  Electronic Filing Attachments

   window.
- Select **Add**.
- Select the Attachment Jurisdiction **Arizona**.
- Select **Browse for file**, then attach the **OtherIncomeLoss** PDF. Name the file without spaces or special characters.
- Do a full recompute and recreate the e-file.
