# 2015: 120 e-file error

```
* 2015: 120: If Line E contains a value for Air Carrier, Standard, or Sales Factor Only, Lines 6, 8, 9, 10 and 12 cannot be NULL.
```

This happens when the apportionment is not populated for the state, or it is none.

## Solution

- In Organizer, select **States**, then **Arizona**.
- Select **Allocation and Apportionment**.
- Go to the **Multi-state Apportionment** section.
- Select the option **Not Applicable**.
- In the **Overrides** section, go to the **Other income allocation to Arizona** line and enter in **None**.
- Run a full recompute, then recreate the e-file.
