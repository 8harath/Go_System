2100-S e-file error

Schedule D, line D7, sum of the totals of column c and column d (total estimated payments), does not match line 22.
This happens when 120S, Page 5, Schedule D, Line D7 totals of Column C and Column D don't match 120S, Page 1, Part 1 Line 22.

Solution

  1. In Tax Forms, select
    States
    , then
    Arizona
    , then
    120S – Tax Return
    .
  2. Select 120S Page 1, Part 1, line 22 and make note of the amount.
  3. Drill down on line 22, Prior year overpayment, then drill down on
    Last year's overpayment applied
    . This opens Organizer.
  4. Select
    States
    , then
    Arizona
    , then
    Payment of Tax
    . This amount should be the same as for 120S Page 1, Part 1, line 22.
  5. Perform a full recompute and recreate the e-file.
