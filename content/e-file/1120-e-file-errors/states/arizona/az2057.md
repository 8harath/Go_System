# AZ2057 e-file error

```
If B3 is checked and Line C matches the Period End, then Form 122 is required. Attach a schedule PDF titled 'ConsentSubCoConsol'. To attach a PDF: Please go to Edit Insert e-file Attachment
```

This happens when Arizona form 120, page 1, Box B3 is checked and there is a Period End date entry at line-item C, but the ConsentSubCoConsol.pdf attachment is missing.

## Solution

- Go to **Organizer**, **States**, and select the **Arizona** folder
- Go to **E-File**, then the **Attachments** folder.
- Select **Summary**, then select the **Attach PDF** button.
- Select the **Add** button.
- Select Attachment Jurisdiction: **Arizona**.
- Select the **Browse for file** button, then attach the PDF named ConsentSubCoConsol.pdf without spaces or special characters.
- Do a full recompute, and recreate the e-file.

note

Ensure the predefined name ConsentSubCoConsol is used for the attachment.
