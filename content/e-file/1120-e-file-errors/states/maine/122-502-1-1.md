# 122.502.1.1 e-file error

## Error

```
1120ME: Business Representative information is required, please add the name, title, PIN, phone number, email address and date signed fields.
```

## Cause

Business representative information is missing from the e-file.

## Solution

- Go to **Organizer**, **States**, **Common State**, **General Information**, then **Basic Return Information**.
- Go to the **Signature information** tab and enter:


  - Name
  - Title
  - PIN
  - Phone
  - Email address
  - Date signed
- Go to **Organizer**, **General Information**, then **Basic Return Information**.
- On the **Return Information** tab, complete the **Signing Officer** section.
- Go to **Organizer**, **States**, **Maine**, and **General Information**.
- On the **General Information** tab, complete the **Business Representative** section.
- Perform a full re-compute, re-create the e-file, then re-submit.
