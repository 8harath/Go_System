E-file diagnostic: Texas return payment option

Return has a tax due, but no payment option has been selected. Navigation: Organizer \ States \ Common State \ General Information \ Bank Information \ Direct Debit tab \ Column E
If there's a tax due in the Texas return,
Bank information
 needs to be populated.

Solution

  1. Go to
    Organizer
    States
    Common State
    .
  2. In
    General Information
    , go to the
    Bank Information
     folder.
  3. Go to the
    Direct debit
     tab. Mark the checkbox in Column B, and populate Columns C, D, F, G, K, and L.
  4. Do a full recompute and recreate the TX return.
