# 1120 Texas Reject Code 5206

```
For Report Years 2024 and onward, Form 05-163 is now obsolete.
```

You get this error because this form is now obsolete.

## Solution

In Organizer, go to 

**State Franchise Tax****Texas Franchise****E-file****Additional Information****E-file Form 05-102 Option**

.

Please read the disclaimer about the No Tax Due Scenario within the Texas website. <https://comptroller.texas.gov/taxes/franchise/forms/2024-franchise.php>

You can contact the state e-help desk for further information.

Texas e-help desk on (800) 252-1381
