# Form 05-102 e-file error

```
Information should not be entered in the top consolidation. It should be entered in the lower level entities.
```

This happens when officers are entered in the top consolidated return.

## Solution

Check these following items to resolve this diagnostic.

- Go to **Organizer**, **State Franchise Tax**, **Texas Franchise**, **Information Report**, and then **Common Information**. Remove any information from these screens.
- Review officer entries entered in **Organizer**, **State Franchise Tax**, **Texas Franchise**, **Information Report**, **Public Information Report**, **Officers, Directors, or Members**. Officers entered in this section of the return apply to TopCon, which will prompt the diagnostic.
- In the TopCon, go to **Organizer**, **Income and Deductions**, **Deductions**, **Officers' Compensation**, **Individual Officers**, **Officer Name** and make sure no officers have been selected to apply to all states or selectively applied to Texas.

Once these items are reviewed and adjusted where needed, perform a full re-compute.
