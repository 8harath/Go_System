# 3020 e-file error

## Error

```
Taxpayer number not found on the taxpayer database, tax return must be submitted by mail. (3020)
```

## Cause

The state doesn't recognize the taxpayer number submitted with the return.

## Solution

- Go to the **Organizer**, then **State Franchise Tax**.
- Select **Texas Franchise**, then go to **General Information**.
- Check the **Taxpayer number**.


  - If it's wrong, fix it. Then do a Full Recompute, recreate the e-file, and retransmit the return.
  - If it's correct, contact the state at 800.442.3453.
