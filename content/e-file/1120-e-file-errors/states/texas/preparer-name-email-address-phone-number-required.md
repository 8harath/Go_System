# E-file diagnostic: The preparer name, email address, and phone number is required

```
Preparer Information: The preparer name, email address, and phone number is required. Go to Organizer / Common State / General Information / Paid Preparer Information / Preparer Information tab to enter this.
```

This happens when Preparer information is missing or incomplete.

## Solution

- Go to 

  **Organizer****States****Common State****General Information****Paid Preparer Information****Preparer Information**

   tab.
- Complete all fields for Texas, including **Name**, **Email**, **Phone**.
- Do a full recompute and recreate the e-file.
