# 3696 e-file error

```
Reject Code 3696 : Invalid Security Information. Webfile number or last reported revenue is incorrect or blank. Contact Texas Comptroller @1-800-442-3453 for your WebFile Number. Line Number: H.
```

This happens when the Webfile number or last reported revenue is incorrect or blank.

## Solution

- In Organizer, select **States**, then **Texas**.
- Select **E-file**, then **Additional Information**, then **Preparer Validation**.
- Verify the **Webfile number** and **Total revenue on last return is accurate**.
- If there isn't a webfile number or the total revenue on the latest return is blank, enter the **Webfile number**and enter an amount for the **Total revenue on latest return**.
- Perform a full recompute, recreate the e-file and resubmit the return.

  note

  If you don’t have a Webfile number or last year’s total revenue, you will need to contact the Texas Comptroller at (800) 442-3453.
