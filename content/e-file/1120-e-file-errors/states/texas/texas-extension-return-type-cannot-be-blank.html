E-file diagnostic: Texas extension return type cannot be blank

Texas extension common data: Return type cannot be blank. All severe diagnostics related to this Texas extension has to be cleared.
This happens when you have severe diagnostics for the Texas extension.

Solution 1

  1. Go to
    Organizer
    States
    Common State
    .
  2. Go to
    Estimates and Extensions
    Estimates and Extensions
    Extension
     tab.
  3. Mark the
    Return on Extension
    checkbox in Column B for Texas.
  4. Do a full recompute and recreate the e-file.

Solution 2

  1. In the
    Organizer
    , select
    Diagnostics
    .
  2. Mark the
    Severe
     and
    Texas
     checkboxes.
  3. Clear these diagnostics.
