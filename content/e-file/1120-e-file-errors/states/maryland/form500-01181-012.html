FORM500-01181-012 e-file error

* FORM500-01181-012: Navigation: Tax forms / Maryland / 500C / Page 2 / Line 3D
This happens when in Maryland this line is populating with code that the amount populating needs to be greater than or equal to the amount that is populating.

Solution 1

  1. In Organizer, select
    States
    , then
    Maryland
    .
  2. Select
    State Adjustments
    , then
    State Adjustments
     or select
    Decoupling Modification
    .
  3. Make the changes.
  4. Do a full recompute and recreate the e-file.

Solution 2

  1. In Tax Forms, select
    States
    , then
    Maryland
    .
  2. Select
    Form 500-Corporation Income Tax Return
    , select
    500, Page 2
    .
  3. Line 3d, which is populated with code J, CD, J, DM or K, this amount needs to be greater than or equal to the amount that is populating.
  4. In Tax Forms, select
    States
    , then
    Maryland
    .
  5. Select the
    Form 500DM-Decoupling Modification
    , line 6 amount.
  6. Do a full recompute and recreate the e-file.
