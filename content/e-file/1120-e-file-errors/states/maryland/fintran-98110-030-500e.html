FinTran-98110-030 (500E) e-file error

Enter bank information for the financial transaction when e-filing a Maryland Form 500E extension with a tax payment amount greater than 0. The system requires payment details to match the tax due on the extension.

Error message

FinTran-98110-030 (500E): State payment in Financial Transaction is required when tax paid with extension is greater than 0. 80210-010: Tax Paid with this Extension - must be equal to Payment Amount on Financial Transaction.

Solution 1: Enter bank information for the extension payment

  1. Go to
    Tax Forms
    States
    Maryland
    500E-Extension of Time to File Income Tax
    .
  2. Confirm the
    Tax Paid with Extension
     field shows an amount greater than 0. If no amount is due, go to Solution 2.
  3. Go to
    Organizer
    States
    Common State
    General Information
    Bank Information
    Extension Debit
     tab.
  4. Enter the
    Routing Number
    ,
    Account Number
    , and
    Account Type
     for the
    Maryland
     row.
  5. Run a full recompute and recreate the Maryland e-file extension.

Solution 2: File directly with the state

  1. If paying Maryland directly instead of through e-file, submit your extension on the state website or by phone: (866) 859-2254.
  2. Contact Maryland directly for guidance on e-filing when paying online through their website.

Solution 3: Paper file the extension

You can paper file the extension.
