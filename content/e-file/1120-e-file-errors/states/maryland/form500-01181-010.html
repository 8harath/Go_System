Form500-01181-010 e-file error

Form500-01181-010: Line 3d Decoupling Modification Subtraction Adjustments - Must be equal to the sum of all occurrences for decoupling modification subtraction code amounts.
This happens when Form 500DM – Decoupling Modification Line 6 doesn't match Form 500-Corporation Income Tax Return Page 2 Line 3d.

Solution

  1. Go to
    Tax Forms
    , then select
    States
    , then
    Maryland
    .
  2. Check the amount on 500DM-Decoupling Modification line 6.
  3. Go to
    500-Corporation Income Tax Return,
     500, Page 2 line 3d. Make sure this matches the amount on 500DM-Decoupling Modification line 6.
  4. Do a full recompute and recreate the e-file.
note
Per the Jurisdiction Form 500-Corporation Income Tax Return, 500, Page 2, line 3d can't have a negative amount unless you paper file the return.
