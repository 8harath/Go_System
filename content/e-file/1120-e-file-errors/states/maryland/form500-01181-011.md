# FORM500-01181-011 e-file error

```
FORM500-01181-011: Navigation : Tax forms / Maryland / Form500C / Page 2 / line 3d.
```

This happens when in Form 500 Page 2 in line 3d is not equal to Form 500DM Page 1 line 6.

## Solution

- In Tax Forms, select**States**, then**Maryland**.
- Select **Form 500-Corporation Income Tax Return, Page 2**, line 3(d).
- In Tax Forms, in **Maryland** the value on line 3(d) must be equal to the amount on Form 500DM, Page 1, line 6 .
- Perform a full recompute and recreate the e-file.
