# E-file diagnostic: Schedule A, Line 1a(g1) and Schedule A, Line 2e(1)

```
XML Error Checking: Rule Number: Schedule A, Line 1a(g1)Description: Schedule A, Line 1a(g1) is populatedattach'OtherIncomeSched.pdf'.To attach a PDF: Navigation Edit Insert EFile attachmentsXML Error Checking: Rule Number: Schedule A, Line 2e(1)Description: Schedule A, Line 2e(1) is populatedattach'TangibleAssetsSched.pdf'.To attach a PDF: Navigation Edit Insert EFile attachments.
```

This happens when Form 500, Page 4 Schedule A line 1A(g) or Line 2e(1) have amounts.

## Solution 1

- In Organizer, select **States**, then **Maryland**.
- Select **E-file**, then **Attachments**, then **Summary**.
- Select **Attach PDF**.
- Select **ADD**.
- Go to the **Attachment Jurisdiction** and select **Maryland**.
- Select **Browse for file**.
- Select **Upload**.

note

If these lines have an amount, attach the PDF as described in the diagnostic. Before attaching the PDF, make sure the file name is exactly what is listed in the diagnostic. The file should be named **OtherIncomeSched.pdf** for line 1A(g) and **TangibleAssetsSched.pdf** for line 2e(1).

## Solution 2

If there are no within Maryland amounts for these lines, remove any attachments for these lines.

- In Organizer, select **States**, then **Maryland**.
- Select **E-file**, then **Attachments**, then **Summary**.
- Select **Attach PDF** and remove attachments for this line that are not needed.
- Perform a full recompute.
- In Organizer, select **States**, then **Enable/Create Returns**.
- Select **Create** for **Maryland**.

note

Having the attachment when there are no longer any amounts on the lines will trigger the diagnostic.
