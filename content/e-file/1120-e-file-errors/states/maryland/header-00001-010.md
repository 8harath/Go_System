# HEADER-00001-010 e-file error

```
Binary attachment count - Must be equal to the number of PDF documents attached to this return.
```

This happens when there are e-file attachments for Maryland that are not using a Predefined description and need one selected or the PDF removed.

## Solution

- Go to **Organizer**, then the **State** folder.
- Go to **Maryland**, then the **E-file** folder.
- Go to **Attachments**, **PDF Attachments**, then the **Summary** folder.
- Select the **Attach PDF** button.
- Either remove the attachments or update the PDF by selecting a name from the predefined description list.

  note

  PDFs names need to be 23 characters or less and no special characters and no spaces.
- Do a full recompute, and recreate the e-file.
