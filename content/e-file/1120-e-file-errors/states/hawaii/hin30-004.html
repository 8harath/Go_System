HIN30-004 e-file error

XML Error Checking: Rule Number: HIN30-004 Description: If FormN30, Page 1, Line 6a is present, then a binary attachment with the file name titled 'ScheduleD.pdf' must be present.
This happens when in state Hawaii FormN30 Page 1 line 6a is present and the attachment for Schedule D is missing.

Solution

  1. In
    Tax forms
    , select
    States
    , then
    Hawaii
    .
  2. Confirm if Form N-30 Page 1 line 6a amount is populated.
  3. If it is, then you need to attach
    Schedule D
    .
  4. Attach
    Schedule D
     with the correct naming convention per the efile error "ScheduleD.pdf".
  5. Perform a Full recompute and recreate the e-file.
    note
    If FormN30 Page 1 line 6a is blank, the attachment isn't required.
