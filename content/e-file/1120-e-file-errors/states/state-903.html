State-903 e-file error

Error

Electronic Filing Identification Number (EFIN) in the State Submission Manifest must be approved and present in the e-File database.

Cause

The EFIN used in the return doesn’t match the IRS's e-file database.

Solution

  1. Go to
    Organizer
    , then select
    States
    .
  2. Select
    State E-File
    , then open
    Enable/Create Returns
    .
  3. Check that the EFIN entered is correct for each applicable state.
  4. If any EFIN is incorrect, fix it then recompute, recreate the e-file, and retransmit the return.
  5. If the EFIN is correct for each state, contact the IRS e-file help desk at (866) 255-0654.
