Reject Code CT024-MEF-CORP

1120 Connecticut Reject Code CT024-MEF-CORP
The unique member ID is assigned to company that is part of the combined group on the CT-1120CU-MI and is used to identify that company throughout the return. The reject is due to a member being improperly included or excluded from a particular schedule in the return.

Solution

Example 1:
 CT-1120CU-NCB Part 1 must have an entry for all taxable members. If any member listed as taxable on CT-1120CU is not included on CT-1120CU-NCB Part 1, the CT-024-MEF reject for each missing member would trigger.
Example 2:
 CT-1120CU-NI, CT-1120CU-MTB and CT-1120CU-MI must have the same members. If one of these combined schedules has 7 members, but the other two have 8 members, two CT-023MEF rejections will trigger.
