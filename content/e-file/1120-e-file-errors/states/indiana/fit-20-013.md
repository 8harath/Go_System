# FIT-20-013 e-file error

```
If Line 16d INApportPercentage is zero, then Line 17 INApportBusIncome must equal zero.
```

This happens when 1120 Indiana IT-20 Corporate Income Tax Return, Page 1, line 16d doesn’t match line 17.

## Solution

- In Tax Forms, select **States**, then **Indiana**, then **IT-20 Corporate Income Tax Return**.
- Select IT-20, PG 1, line 16d, then select the drilldown arrow, to see where line 16d gets its data.
- Or, you can go to Tax Forms and select **States**, then **Indiana**, then **IT-20 Corporate Income Tax Return**, then IT-20, PG 3 - Part I, line 9.
- To change the apportionment percentage on IT-20, PG 3 - Part I for line 9:
- In Organizer, select **States**, then **Indiana**.
- Select **Allocation and Apportionment**.
- In the Overrides section, enter data for **Apportionment percentage** (100% is invalid; if e-filing leave blank).
- Perform a full recompute and recreate e-file.

  note

  If no values are anticipated forIT-20, PG 1 line 16d and line 17, enter None on IT-20, PG 3 - Part I line 9, then do a full recompute and recreate e-file.
