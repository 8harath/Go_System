# E-file diagnostic IT-20S: If page 1, line 2f is present

```
IT-20S: If page 1, line 2f is present, then all the codes, descriptions and amounts must be entered in the Organizer under modification. Go to Organizer, State, Indiana, State Adjustment, Modification for state adjustment and enter the data.
```

This happens when there is an amount on line 2f but the detail and codes in the organizer don’t match what is on the tax forms.

## Solution

- Go to **Tax Forms**, then the **States** folder.
- Go to **Indiana**, then the **IT-20S-S Corporation Income Tax Return** folder.
- Go to the **IT-20S, PG 1** tab.
- Go to line **2b** and select the **Modification Detail** hyperlink.
- Make note of the amounts and the codes that the amounts are linked to.
- Go to **Organizer**, then the **States** folder.
- Go to **Indiana**, then the **State Adjustments** folder.
- Go to the **MODIFICATIONS FOR ADJUSTED GROSS INCOME – IT-20S, SCH A LINE 2A THRU 2F** section.
- In this section, fill in the codes and the amounts.
- Run a full recompute, and recreate the e-file.
