# CIT2023-0071e-file error

```
Federal or state AR 1100CTRecord No NAForm Occurrence No 0Field Seq No 0Form No CIT2023Page No 1Reject Code CIT2023-0071Path to XML ErrorError Category Acceptance ValidationRule Number CIT2023-0071Severity ErrorData ValueAlternate Reject Code 0Message AR1100CT - Missing Tax Preparer Information.
```

This happens when paid preparer information is incomplete.

## Solution

- Go to **Organizer**, **States**, **Common State**, and the **General Information** folder.
- Select **Paid Preparer Information**, then go to the **Firm Information** tab.
- In the **Arkansas** row, enter the information.
- Do a full recompute, recreate the e-file, and re-submit.

note

If Column B is checked, it will suppress the paid preparer information. Make sure it is unchecked.
