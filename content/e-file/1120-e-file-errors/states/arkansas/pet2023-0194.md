# PET2023-0194 e-file error

```
The sum of Add Adjustments and Deduct Adjustments from the Additional Information Schedule must match the corresponding lines on the Apportionment of Income schedule.
```

This happens when there is a missing description for adjustment included in the XML.

## Solution

- Go to **Tax Forms**, **States**, and select **Arkansas**.
- Go to **Electing PTE Return** and **AR1100PET Pass-Through Entity Return**.
- Go to page 4 of **AR1100PET Pass-Through Entity**, then go to line 2 of Section 2.
- On the worksheet, go to the interest income to the Workpaper: Interest Income.
- If there is an amount for interest income, there needs to be a description. Otherwise, the amount should be removed.
- Do a full recompute, and recreate the e-file.
