NCCD405-2410 e-file error

NCCD405-2410: [CD-405] For each Schedule N entry, column E must be less than or equal to column D
This happens when CD-405, Page 5, Schedule N column D needs to be less than or equal to Column E but the state e-file doesn’t let you use negative data.

Solution

  1. Go to
    Tax Forms
    ,
    States
    , then the
    North Carolina
     folder.
  2. Select the
    CD-405 - Corporate Franchise
    folder, then go to the
    CD-405, Page 5
     tab.
  3. Find the
    Sch. N
    .
  4. Make changes so that Column D is less than or equal to Column E. The state e-file doesn’t let you use negative data. If the data is correct and it is negative, then you will have to paper file the return.
    1. Go to
      Organizer
      ,
      States
      ,
      North Carolina
      , then the
      Allocation and Apportionment
       folder.
    2. Select
      New Nonbusiness Detail
      , then go to
      Nonbusiness Income Detail
      .
    3. In
      Gross Amounts
      , adjust the amounts.
  5. Run a full recompute, then recreate the e-file.
