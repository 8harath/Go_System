# NCCD405-2210 e-file error

```
Schedule M-1 line 5 must equal the sum of Line 5a, Line 5b, Line 5c, and all associated itemized amounts. If there is an amount for other expenses, please make sure there is a corresponding description.
```

This happens when the total reported on Schedule M-1, Line 5 doesn’t match the sum of the detailed entries on Lines 5a, 5b, 5c, and any additional itemized amounts. It also requires that any amounts listed under “other expenses” have a corresponding description.

## Solution

- Go to **Tax Forms**, **States** and select **North Carolina**.
- Go to **Form CD-405**, **Page 4, Sch M-1**.
- On Line 5c labeled Other (detail), select **Other expenses recorded on books but not deducted**.
- Populate the descriptions for each item listed under this section.
- Verify that all individual amounts listed add up to the total of the workpaper.
- Run a full recompute and recreate the e-file.
