NC X0000-005 e-file error

State NCSeverity Reject and StopState Record X0000Record Name ReturnDataStateForm Occurrence No 0Field Seq No 0Page No 1Reject Code X0000-005Rule Number X0000-005XML Path /ReturnState/ReturnDataState/FormNCCD405/ScheduleF/OffNameAddrPres/AddressError Message The element Address in namespace http://www.irs.gov/efile has incomplete content. List of possible elements expected: USAdress, ForeignAddress in a namespace http://www.irs.gov/efile.
This happens when Business representative Pin is incomplete.
Solution 1
  1. Go to
    Organizer
    ,
    States
    , then the
    North Carolina
    ,
    E-File
     folder.
  2. Select
    Additional Information
    , then go to the
    Business Representative (Mandatory)
    section.
  3. Enter the
    PIN Type
    ,
    PIN Entered By
    , and the
    State Issued PIN
    .
  4. Run a full recompute, recreate the e-file, and resubmit.
Solution 2
  1. Go to
    Organizer
    ,
    States
    , and then the
    North Carolina
     folder.
  2. Select
    General Information
    , and go to the
    Officer Name and Address (Override)
     section.
  3. Select the
    View Officers Information Details
     hyperlink.
  4. Populate the officer information including the complete address.
  5. Run a full recompute, recreate the e-file, and resubmit.
