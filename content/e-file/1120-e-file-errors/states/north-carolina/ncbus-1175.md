# NCBus-1175 e-file error

```
Tax period begin date must be within the tax year indicated in the submission.
```

This happens when the tax year beginning is in 2023, then the 2023 software must be used to file this return. The beginning date should be the same year as the return you are preparing.

## Solution

- Go to **Organizer**, **General Information** and then select **Basic Return Information**.
- In the **Entity Information** tab, go to the **Dates** section and change the **Fiscal year beginning date**.
- After making changes, initiate a full recompute and recreate the e-file.
