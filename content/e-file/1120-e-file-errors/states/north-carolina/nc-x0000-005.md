# NC X0000-005 e-file error

```
State NCSeverity Reject and StopState Record X0000Record Name ReturnDataStateForm Occurrence No 0Field Seq No 0Page No 1Reject Code X0000-005Rule Number X0000-005XML Path /ReturnState/ReturnDataState/FormNCCD405/ScheduleF/OffNameAddrPres/AddressError Message The element Address in namespace http://www.irs.gov/efile has incomplete content. List of possible elements expected: USAdress, ForeignAddress in a namespace http://www.irs.gov/efile.
```

This happens when Business representative Pin is incomplete.

**Solution 1**

- Go to **Organizer**, **States**, then the **North Carolina**, **E-File** folder.
- Select **Additional Information**, then go to the **Business Representative (Mandatory)** section.
- Enter the **PIN Type**, **PIN Entered By**, and the **State Issued PIN**.
- Run a full recompute, recreate the e-file, and resubmit.

**Solution 2**

- Go to **Organizer**, **States**, and then the **North Carolina** folder.
- Select **General Information**, and go to the **Officer Name and Address (Override)** section.
- Select the **View Officers Information Details** hyperlink.
- Populate the officer information including the complete address.
- Run a full recompute, recreate the e-file, and resubmit.
