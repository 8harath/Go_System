NCCD405-2300 e-file error

NCCD405-2300: Schedule M-2 line 3 must equal the sum of all associated itemized amounts. If there is an other income amount there must be a corresponding description.
This happens when Schedule M-2 line 3 doesn’t have any description or amount.
Solution
  1. Go to
    Tax Forms
    ,
    States
    , and the
    North Carolina
     folder.
  2. Select
    Form CD-405 - Corporate Franchise
    .
  3. Go to
    CD-405, Page 5
    .
  4. Go to
    Schedule M-2
     section and select the blue arrow on
    Line 3
    .
  5. Make sure there is a description and an amount populated.
  6. To populate the description and amount, go to
    Organizer
    , then the
    Balance Sheet/M1-M2 -M3
     folder.
  7. Select
    Schedule M1 / M2
    , and then go to the
    Ret. Earnings (M-2)
     tab.
  8. Go to
    Other Increases - TRC 62-300
     section and enter the description and amount.
  9. Do a full recompute and recreate the e-file.
