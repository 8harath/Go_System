# E-file diagnostic: PIN Enter all mandatory fields

```
PIN: Organizer States North Carolina E-file Additional Information and entering all mandatory PIN related fields.
```

This happens when information is missing for the PIN Signature.

**Solution**

- Go to the **Organizer** folder, **States**, then **North Carolina**.
- Select **E-file**, then **Additional information**.
- Go to the **Business Representative (Mandatory)** section.
- Fill in all the related information for the PIN Signature.
