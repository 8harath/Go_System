# NCCD405-2320 e-file error

```
NCCD405-2320: Schedule M-2 line 6 must equal the sum of all associated itemized amounts. If there is an other deduction amount there must be a corresponding description.
```

This happens when other decreases have a value but no description added.

**Solution**

- Go to **Tax Forms**, **States** and select **North Carolina**.
- Go to **CD-405 - Corporate Franchise** and then **CD-405, Page 5**.
- Under the **Sch M-2**, go to Line 6 **Other decreases**.
- Go to **Other decreases detail**.
- Add a description.
- Run a full recompute and recreate the e-file.
