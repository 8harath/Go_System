# NC-001-C e-file error

```
* NC-0001-C: Non negative amount for total assets : Tax Forms \ States \ North Carolina \ CD-405 \ Page 4 \ Sch. L \ Line 6 & Line 14 & Line 15.
```

This happens when Form CD-405, Page 4, Schedule L, lines 6, 14, and 15 are negative for either the beginning or ending amounts.

## Solution

important

To e-file the return, all negative amounts must be changed to positive; otherwise the return needs to be paper filed.

- Review Form CD-405 by going to **Tax Forms**, **North Carolina**, **CD-405 - Corporate Franchise**, and then the **CD-405, Page 4**.
- Make note of any negative amounts on Schedule L, lines 6, 14, and 15. Any negative amount needs to be changed to a positive amount in the work paper.
