# NCCD405-1284 e-file error

```
NCCD405-1284: Schedule B line 24c must equal the sum of all lines 7 on associated partnership (D-403) NC K-1s received. Please enter separate entity detail at Organizer / States / North Carolina / Received Income / D403 K-1
```

This happens when you are missing the information that is required by the state for e-filing.

**Solution**

- Go to **Tax forms**,**States**, then the **North Carolina** folder.
- Select the **Form CD-405**, **Page 2** tab, then go to the **Sch B** section.
- Go to **Line 24C Payments and Credits - Partnership (include Form D-403, NC K-1)**.
- The input for **(D-403) NC K-1** was defined in a schema, which our system doesn’t support.
- Since this line is populating, you will need to paper file this return and attach a copy of **(D-403) NC K-1** to support the amount on Form **CD-405 Page 2 Schedule B line 24c**.
- To remove from the organizer, go to **Organizer**, **States**, then the **North Carolina** folder.
- Go to the **Received Income** folder.
- Go to the **D403 K-1** folder and select **Add new D403 K-1**.
- Enter the amount from line 24C to the Nonresident's share of net tax paid by the manager of the partnership.
- Run a full recompute and recreate the e-file.
