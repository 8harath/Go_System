# NCCD405-1200 e-file error

```
NCCD405-1200: [CD-405] If CD-405CW is filed, Schedule B Line 7 must equal CD-405CW Schedule C Combined Totals Line 30; otherwise, Schedule B line 7 must equal Schedule G line 30, if Schedule G is present.
```

This happens when you are missing the required state information for e-filing.

**Solution**

- If you are filing for Form **CD-405 CW**, go to **Tax Forms**, **States**, and the **North Carolina** folder.
- Select Form **CD-405**, and the **Page 2** tab.
- In the **Sch B** section, the value in **Line 7** must match the value in the **Tax Forms**, **States**, and the **North Carolina** folder.
- Go to the **CD-405 CW**,**Combined Return** folder.
- Select the **CD-405 CW Page 2****Sch C** section **Line 30** value.
- Otherwise, the **Sch B Line 7** value should **match Schedule G line 30**, if **Schedule G** is present.
- Update the amount in the **Organizer**, **States**, **North Carolina** folder.
- Go to **State Adjustments**, then the **Federal Overrides** section.
- Enter the amount under Line **Federal taxable income (Override)**.
- Do a full recompute and recreate the e-file.
