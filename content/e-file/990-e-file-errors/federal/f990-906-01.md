# F990-906-01 e-file error

## Error

```
The return type indicated in the return header must match the return type established with the IRS for the EIN. (value 990XX, rule F990-906-01).
```

## Cause

This error occurs when the EIN isn't classed as an exempt organization in the IRS database.

## Solution

- Check the **EIN** and the **Organization type** in the return.
- If these are correct, contact the IRS e-help desk at 866-255-0654.
