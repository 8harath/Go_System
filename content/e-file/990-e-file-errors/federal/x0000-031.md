# X0000-031 e-file error

## Error

```
Zip Entry names must conform to the guidelines in Publication 4164.
```

## Cause

A PDF attached to the return has an improper name or title.

## Solution

- Go to **Organizer**, **E-File**, then **Return**.
- Select **Attachments**, **PDF Attachments**, then **Summary**.
- Select **Attach PDF**.
- Check the name and title of your PDF attachments meet the following e-file requirements:


  - 23 characters or less.
  - No spaces.
  - No special characters.
- If you need to change the name or title of a PDF attachment, delete the PDF, make the change, then reattach it.
