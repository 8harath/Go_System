# F990T-041 e-file error

```
* F990T-041: If Form 2220 is present in the return, then Form 990-T, 'ESPenaltyAmt' must be equal to Form 2220, 'TotalPenaltyAmt'.
```

This happens when Form 990-T e-file requires line 8 to be selected when Form 2220 is included in the e-file.

## Solution

To resolve:

- Go to **Organizer**, **Form 990-T**, **Form 2220 Underpayment Penalty**, and then **Penalty Options**.
- Select **Always sort Form 2220 with the tax return**.
- Perform a full recompute, re-create the e-file, and submit.
