F990PF-905-01 e-file error

Error

If Form 990-PF, Item G, "Initial return of a former public charity" checkbox is not checked, then the 'EIN' of the Filer in the Return Header must be established as a private foundation filer in the e-File database. (value 990PF, rule F990PF-905-01).

Cause

The EIN and return type don't match what the IRS has in the e-File database.

Solution if an initial return

  1. Go to
    Organizer
     then
    General Information
    .
  2. Select
    Basic Return Information
    .
  3. Select the
    Return Information
     tab.
  4. Mark the
    Initial return
     or
    Initial Return of a former public charity
     checkbox.
  5. Do a full recompute, recreate the e-file, and resubmit the return.

Solution if not an initial return

  1. Go to
    Organizer
     then
    General Information
    .
  2. Select
    Basic Return Information
    .
  3. Make sure the
    EIN
     is correct.
    1. If you corrected the
      EIN
      , do a full recompute, recreate the e-file, and resubmit the return.
    2. If the
      EIN
       is correct, contact the IRS e-help desk at 1-866-255-0654. If you can't resolve it, you'll need to paper file.
