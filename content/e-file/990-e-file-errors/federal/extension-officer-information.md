# E-FILING EXTENSION - OFFICER INFORMATION diagnostic

```
E-FILING EXTENSION - OFFICER INFORMATION: You must enter all officer information in Organizer - General Information - Basic Return Information - Return Information - Officer Information. This includes officer name, title, date signed and phone number.
```

This happens when there's missing officer information or when the wrong signature date field was used.

## Solution

To resolve:

- Go to **Organizer**, **General Information**, and then **Basic Return Information**.
- Select **Return Information**.
- In the **OFFICER INFORMATION (MANDATORY)** section, make sure all entries are complete, such as officer name, title, date signed, and phone number. Make sure you use the correct date field (return vs extension).
- Perform a full recompute, and then recreate the e-file.
