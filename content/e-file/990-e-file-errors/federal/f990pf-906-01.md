# F990PF-906-01 e-file error

## Error

```
If Form 990-PF, Item G, "Initial return of a former public charity" checkbox is not checked, then Item H, the type of organization checked must match data in the e-file database. (value X, rule F990PF-906-01).
```

## Cause

The EIN and return type don't match what the IRS has in the e-File database.

## Solution if an initial return

- Select **Organizer** then **General Information**.
- Select **Basic Return Information**.
- Select the **Return Information** tab.
- Mark the **Initial return** or **Initial Return of a former public charity** checkbox.
- Do a full recompute, recreate the e-file, and resubmit the return.

## Solution if not an initial return

- Go to **Organizer** then **General Information**.
- Select **Basic Return Information**.
- Check the**EIN**.


  - If the **EIN** is wrong, correct it, do a full recompute, recreate the e-file, and resubmit the return.
  - If the **EIN** is correct, contact the IRS e-Help desk at 1-866-255-0654. If you can't resolve it, you'll need to paper file.
