R0000-058-01 e-file error

Error

An XML document that represents a binary attachment must have a valid reference to an attached file. (value, rule R0000-58-01).

Cause

The file name of the PDF attachment doesn't meet the IRS e-filing requirements.

Solution

  1. Go to
    Organizer
    ,
    E-File
    , then
    Return
    .
  2. Select
    Attachments
    ,
    PDF Attachments
    , then
    Summary
    .
  3. Select
    Attach PDF
    .
  4. Check that the file names of your PDF attachments meet the following e-file requirements:
    1. 23 characters of less.
    2. No spaces.
    3. No special characters.
  5. If you need to change the file name of a PDF, delete it, change the file name, then reattach.
  6. Do a full recompute, recreate the e-file, and resubmit the return.
