# F990-902-01 e-file error

## Error

```
'EIN' of the Filer in the Return Header must be established as an exempt organization filer in the e-File database. (rule F990-902-01).
```

## Cause

This error occurs when the EIN isn't classed as an exempt organization in the IRS database.

## Solution

- If this isn't an initial year return, check the **EIN** and **Organization type**.
- If these are correct, contact the IRS e-help desk at 866-255-0654
