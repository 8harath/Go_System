R0000-937-01 e-file error

Error

Database Validation Error: /Return/ReturnData/IRS990PF/Organization501c3ExemptPFInd: If Form 990-PF, Item G, "Initial return of a former public charity" checkbox is not checked, then Item H, then the return type indicated in the Return Header must match the return type established with the IRS for the EIN. (value X, rule R0000-937-01).

Cause

The EIN and return type don't match what's in the IRS e-file database.

Solution if an initial return

  1. Go to
    Organizer
     then
    General Information
    .
  2. Select
    Basic Return Information
    .
  3. Select the
    Return Information
     tab.
  4. Mark the
    Initial return
     or
    Initial Return of a former public charity
     checkbox.
  5. Do a full recompute, recreate the e-file, and resubmit the return.

Solution if not an initial return

  1. Go to
    Organizer
     then
    General Information
    .
  2. Select
    Basic Return Information
    .
  3. Check the
    EIN
    .
    1. If the
      EIN
       is wrong, correct it, do a full recompute, recreate the e-file, and resubmit the return.
    2. If the
      EIN
       is correct, contact the IRS e-help desk at 1-866-255-0654. If you can't resolve it, you'll need to make a paper return.
