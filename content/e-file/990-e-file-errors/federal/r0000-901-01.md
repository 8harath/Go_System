# R0000-901-01 e-file error

## Error

```
Filer's EIN and Name Control in the Return Header must match data in the e-File database. (value #########, rule R0000-901-01)
```

## Cause

The IRS e-File database has a different EIN and Name Control combination on file.

## Solution

- Check the name control:


  - Go to **Organizer**, **E-file**, then **Return**.
  - Select **Additional Information** then **Business Name Control**.
  - If **Business name control (Override)** is completed, review Publication 4163 to make sure it's correct.
- Check the **EIN**:


  - Select **General Information** then **Basic Return Information**.
  - Make sure the **EIN** is correct.
- If you corrected either field, recreate the e-file, and resubmit the return.
- If you're not overriding the name control and the EIN is correct, call the IRS e-help Desk at 866-255-0654 and verify the EIN.
