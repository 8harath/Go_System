F8868-908 e-file error

Error

If Form 8868, Item 'ExtensionReturnCd' is any value other than "03" (Form 4720 individual), "08" (Form 1041-A) or "10" (Form 5227), or Line 2, 'InitialReturnInd', 'FinalReturnInd', or 'AccountingPeriodChangeInd' checkbox is not checked, then tax year ending date ('TaxPeriodEndDt' specified in the Return Header) must match data in the e-file database. (value YYYY-MM-DD, rule F8868-908).

Cause

This error occurs because the tax year end date in the IRS database doesn't match the tax year end date in the e-file. For example, when the return has a calendar year end (12/31/YY) but the IRS database shows the client's year end as a fiscal year end (06/30/YY).

Solution

  1. Go to
    Organizer
     then
    General Information
    .
  2. Select
    Basic Return Information
    .
  3. On the
    Entity Information
     tab, make sure the following fields are correct:
    1. Return Type
      .
    2. EIN
      .
    3. Fiscal Year Ending Date
      .
  4. Select the
    Return Information
     tab.
  5. Make sure the
    Return Type
     checkboxes in the Check If section are marked.
  6. Go to
    Organizer
     then the
    E-file
     folder.
  7. Select
    Extension
    ,
    Additional Information
    , then
    Business Name Control
    .
  8. If
    Business name control (Override)
     is completed, review Publication 4163 to check it's correct.
  9. If you corrected any fields, do a full recompute, recreate the e-file, and resubmit the return.
  10. If you didn't make changes, contact the IRS e-help desk at 1-866-255-0654 to verify what they have on record.
