# R0000-058-01 e-file error

## Error

```
An XML document that represents a binary attachment must have a valid reference to an attached file. (value, rule R0000-58-01).
```

## Cause

The file name of the PDF attachment doesn't meet the IRS e-filing requirements.

## Solution

- Go to **Organizer**, **E-File**, then **Return**.
- Select **Attachments**, **PDF Attachments**, then **Summary**.
- Select **Attach PDF**.
- Check that the file names of your PDF attachments meet the following e-file requirements:


  - 23 characters of less.
  - No spaces.
  - No special characters.
- If you need to change the file name of a PDF, delete it, change the file name, then reattach.
- Do a full recompute, recreate the e-file, and resubmit the return.
