# E-file diagnostic: Business Representative

```
Business Representative: Required First name, last name, title, phone number, and date signed are required fields.
```

There are many variations of this diagnostic, but all reference business representative information is required.

## Solution

- In **Organizer**, go to **States**.
- Select **Common State** then **General Information**.
- Select **Basic Return Information** then go to the **Signature Information** tab.
- Enter the required data in Columns B, D, E, F, G, K, and L for the state you're getting the error on.
- Do a full recompute and recreate the e-file.
