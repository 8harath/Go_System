R0000-932-02 or R0000-933-02 e-file error

If "Amended Return" or (Superseded for 1120/1120S/1120-F/1041/1042/1065) checkbox is not checked, then taxpayer TIN in the Return Header must not be the same as a TIN of a previously accepted electronic return for the return type and tax period indicated in the tax return. (value #########, rule R0000-932-02 or R0000-933-02).
The taxpayer identification number (EIN/SSN) has already been used for this return type and tax period.

Solution

  1. Go to the
    Organizer,
     then
    General Information
    .
  2. Select
    Basic Return Information
    .
  3. Make sure the
    EIN
     or
    SSN
     is correct.
    1. If the EIN/SSN is wrong, fix it. Then re-create and retransmit the e-file.
    2. If the EIN/SSN is correct, contact the IRS e-help Desk at 866-255-0654 to resolve the rejection.
If this is an amended or superseded return, complete the following:
  1. Go to the
    Organizer
    , then
    General Information
    .
  2. Open
    Return Information
    .
  3. Make sure either the
    Amended return
     or
    Superseded return
     checkbox is marked.
    1. If neither checkbox is selected, choose a box then recreate and retransmit the e-file.
    2. If the selection is correct, contact the IRS e-help Desk at 866-255-0654.
