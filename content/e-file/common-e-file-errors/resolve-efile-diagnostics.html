Resolve e-file diagnostics

Learn about the 3 types of e-file diagnostics and how to review and correct errors before transmitting returns to the IRS.
The system generates 3 types of diagnostics to help you identify and correct issues before transmission:
  • E-file rejects:
     These diagnostics identify conditions that will cause the IRS to reject your return if you transmit it. Correct all reject diagnostics before transmitting the file. Rejects typically flag missing information, mismatched data, or incorrect entries.
  • E-file alerts:
     Alert diagnostics won’t prevent you from e-filing the return. However, you should still investigate these conditions, as they may reveal data entry errors that could cause problems later.
  • XML validation errors:
     The system generates these errors only after it creates the XML file. The IRS determines the conditions that trigger validation errors, which generally relate to data formatting issues and unexpected information.
Follow these steps to review and correct e-file diagnostics:
  1. Select
    View
    , then
    Diagnostics
    .
  2. You will see 2 folders:
    Types
     and
    Jurisdictions
    .
  3. Expand each folder to view the diagnostics.
  4. Select each diagnostic to go directly to the condition that created it (if necessary).
  5. Make the necessary changes in the Organizer.
  6. Run a full recompute to verify you have resolved all issues.
