# 9983 e-file error

This rejection happens when the state return is submitted before the federal return is accepted.

## Error message

```
Non-Federal return is missing the Federal File Type XML comment, FEDERALFILETYPE
```

## Solution

- Wait until the IRS accepts the federal return.
- Go to 

  **Organizer****E-file****Enable/Create**

  .
- Recreate and resubmit the state e-file.
