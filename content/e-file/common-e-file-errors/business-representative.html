E-file diagnostic: Business Representative

Business Representative: Required First name, last name, title, phone number, and date signed are required fields.
There are many variations of this diagnostic, but all reference business representative information is required.

Solution

  1. In
    Organizer
    , go to
    States
    .
  2. Select
    Common State
     then
    General Information
    .
  3. Select
    Basic Return Information
     then go to the
    Signature Information
     tab.
  4. Enter the required data in Columns B, D, E, F, G, K, and L for the state you're getting the error on.
  5. Do a full recompute and recreate the e-file.
