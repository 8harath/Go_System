Qualified Mismatch e-file error

Qualified Mismatch
This happens when information in the return may have changed since the e-file was created.

Solution

If you receive this error, review the XML file and the return data in the locator for any differences.
  1. To remove the Qualified Mismatch error, open the return.
  2. Do a full compute, then recreate the e-file.
  3. Once the e-file is recreated, review the XML information.
note
As long as the XML now contains the correct values, the Qualified Mismatch message is the result of the system not updating in a timely manner and won’t hinder the return from being accepted.
