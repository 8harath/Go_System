# R0000-932-02 or R0000-933-02 e-file error

```
If "Amended Return" or (Superseded for 1120/1120S/1120-F/1041/1042/1065) checkbox is not checked, then taxpayer TIN in the Return Header must not be the same as a TIN of a previously accepted electronic return for the return type and tax period indicated in the tax return. (value #########, rule R0000-932-02 or R0000-933-02).
```

The taxpayer identification number (EIN/SSN) has already been used for this return type and tax period.

## Solution

- Go to the **Organizer,** then **General Information**.
- Select **Basic Return Information**.
- Make sure the **EIN** or **SSN** is correct.


  - If the EIN/SSN is wrong, fix it. Then re-create and retransmit the e-file.
  - If the EIN/SSN is correct, contact the IRS e-help Desk at 866-255-0654 to resolve the rejection.

If this is an amended or superseded return, complete the following:

- Go to the **Organizer**, then **General Information**.
- Open **Return Information**.
- Make sure either the **Amended return** or **Superseded return** checkbox is marked.


  - If neither checkbox is selected, choose a box then recreate and retransmit the e-file.
  - If the selection is correct, contact the IRS e-help Desk at 866-255-0654.
