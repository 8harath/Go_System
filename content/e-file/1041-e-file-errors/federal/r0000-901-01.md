# R0000-901-01 e-file error

## Error

```
Filer's EIN and Name Control in the Return Header must match data in the e-File database. (value #########, rule R0000-901-01)
```

## Cause

The IRS e-File database has a different EIN and Name Control combination on file.

## Solution

- Check the name control.


  - Go to the **Organizer**, then **E-file**.
  - Select **Additional Information**, then **Business Name Control**.
  - If **Business name control (Override)** is completed, check Publication 4163 to make sure it's correct.
- Check the EIN/SSN


  - Go to **General Information**, then **Basic Return Information**.
  - Make sure that the **EIN** or **SSN** is correct.
- If you fix either field, re-create and retransmit the e-file.
- If you aren't overriding the name control and the EIN/SSN is correct, call the IRS e-help Desk at 866.255.0654 to find out what EIN/SSN they have on file.
