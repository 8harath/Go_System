# R0000-905-01 e-file error

## Error

```
Electronic Filing Identification Number (EFIN) in the Return Header must be listed in the e-File database and in accepted status. (R0000-905-01)
```

## Cause

The EFIN included in the return is invalid.

## Solution

- Go to the **Organizer**, then **E-file**.
- Select **Enable/Create**.
- Make sure the EFIN column is correct.


  - If it's wrong, fix it and do a Full Recompute. Then recreate and retransmit the e-file.
  - If the EFIN is correct, call the IRS e-help Desk at 866.255.0654 to resolve the rejection.
