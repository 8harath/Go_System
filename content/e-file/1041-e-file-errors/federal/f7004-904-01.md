# F7004-904-01 e-file error

## Error

```
Form 7004, the tax year ending date (TaxPeriodEndDt specified in the Return Header) must match the data in the e-file database unless one of the checkboxes in Line 5b - "Initial Return", "Final Return" or "Consolidated return to be filed" is checked. (value YYYY-MM-DD, rule F7004-904-01)
```

## Cause

This error happens because the tax period end date, return type, or EIN in the IRS database doesn't match the information in the e-file.

## Solutions

- If the entity doesn't have a short tax year, check Form 7004, line 5b. Those checkboxes are for short year returns only.
- Check the tax period ending date, return type, and EIN. If they're correct, contact the IRS e-Help Desk at 866-255-0654.
