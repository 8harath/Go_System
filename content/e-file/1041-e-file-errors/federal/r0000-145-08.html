R0000-145-08 e-file error

Error

For a return filed for tax year 2022, the tax period ending date in the Return Header must be [ one of following values ("20211231", "20220131", "20220228", "20220331", "20220430", "20220531", "20220630", "20220731", "20220831", "20220930", "20221031", "20221130") OR (1-3 days after the beginning of the month) OR (1-6 days before the end of the month) ] unless one of the following is true: 1. checkbox "Final Return" is checked. 2. checkbox "Initial Return" is checked. 3. return is a short year return, i.e., difference between the tax period beginning date and tax period ending date is less than 12 months.

Cause

The tax period end date is invalid.

Solution

  1. Go to the
    Organizer
    , then
    General Information
    .
  2. Select
    Basic Return Information
    .
  3. Make sure the
    Fiscal Year Beginning
     and
    End
     fields are correct.
  4. Go back to the
    Organizer
    , then
    General Information
    .
  5. Select
    Return Information
     and check the following:
    • If this is a final return, mark the
      Final return
       checkbox.
    • If this is an initial return, mark the
      Initial return
       checkbox.
    • If this is a short year return, mark the
      Short-Year return
       checkbox.
  6. Do a Full Recompute, recreate the e-file, then resubmit.
