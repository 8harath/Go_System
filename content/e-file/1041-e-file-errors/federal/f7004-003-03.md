# F7004-003-03 e-file error

## Error

```
Form 7004, the application for extension can only be filed after the Tax Period End Date ("TaxPeriodEndDate" specified in the "ReturnHeader") and on or before the due date of the return to which the extension applies as specified in the Form 7004 Date Charts in Publication 4164. (value YYYY-MM-DD, rule F7004-003-03)
```

## Cause

The extension is e-filed either before the tax year end or after the return due date. For example, on a return with a tax year end of 3/31, you would receive this rejection if you filed an extension before 3/31 or after 6/15.

## Solution

Check for a mistake in the year-end date or an override in the extension date:

- Check the fiscal year end date:


  - Go to the **Organizer**, then **General Information**.
  - Select **Basic Return Information**.
  - On the **Entity Information** tab, check the **Fiscal year ending date**. If the date is wrong, fix it.
- Check the extension dates:


  - Go to the **Organizer**, then **Payments and Extensions**.
  - Select **Automatic Extensions**, then **7004 Basic Data**.
  - Make sure the override dates entered in the Dates section are correct. If any dates are wrong, fix them.
- Compare the extension file date, the fiscal year-end date, and the extension date.


  - If the extension is too early to file based on the client's tax year end, wait until the appropriate date to file the extension.
  - If the extension is late or if the return due date has passed, file the return instead of the extension.
