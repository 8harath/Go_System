# X0000-031 e-file error

## Error

```
Zip Entry names must conform to the guidelines in Publication 4164.
```

## Cause

A PDF attached to the return has an improper name or title.

## Solution

- Go to the **Organizer**, then **E-File**.
- Select **Attachments**, then **Summary**.
- Select **Attach PDF** and review your PDF attachments for the following e-file requirements:


  - Shorten the name of the attachments to 23 characters or less.
  - Remove any spaces in the file name.
  - Remove any special characters from the file name.
- Delete and reattach any PDF with an updated file name.
- Do a Full Recompute, recreate the e-file, and submit the return.
