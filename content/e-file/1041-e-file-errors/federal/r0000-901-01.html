R0000-901-01 e-file error

Error

Filer's EIN and Name Control in the Return Header must match data in the e-File database. (value #########, rule R0000-901-01)

Cause

The IRS e-File database has a different EIN and Name Control combination on file.

Solution

  1. Check the name control.
    1. Go to the
      Organizer
      , then
      E-file
      .
    2. Select
      Additional Information
      , then
      Business Name Control
      .
    3. If
      Business name control (Override)
       is completed, check Publication 4163 to make sure it's correct.
  2. Check the EIN/SSN
    1. Go to
      General Information
      , then
      Basic Return Information
      .
    2. Make sure that the
      EIN
       or
      SSN
       is correct.
  3. If you fix either field, re-create and retransmit the e-file.
  4. If you aren't overriding the name control and the EIN/SSN is correct, call the IRS e-help Desk at 866.255.0654 to find out what EIN/SSN they have on file.
