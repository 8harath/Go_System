# 725 e-file error

```
Form 2210: The Form 2210 has not been electronically filed even though the form was sorted with the hardcopy return per client return options selection. IRS reject code 725 (IRS Publication 1438) indicates that the return will be rejected if Form 2210 is filed and none of the boxes on Form 2210, page 1, part II are checked.
```

This happens when Form 2210 isn't required to be filed.

## Solution

- Go to **Organizer**, **Estimates and Penalties**, and then **Underpayment Penalty**.
- In the **Underpayment Penalty Sort Option** section, select **Always sort Form 2210 immediately following Form 1041-ES**.
