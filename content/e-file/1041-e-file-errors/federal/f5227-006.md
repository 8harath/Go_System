# F5227-006 e-file error

```
ChrtblRemainderUnitrustInd: If Form 5227, ['ChrtblRemainderAnnuityTrustInd' or 'ChrtblRemainderUnitrustInd'] is checked and 'FinalReturnInd' is not checked, then each of the following must have a value on Form 5227, Schedule A: 'TotalDistributableIncomeGrp' and 'Sect664TrCurrentDistriSchGrp' and 'Sect664TrAssetsDonorGrp'.
```

This happens when asset and donor information isn't entered for the Charitable Remainder Unitrust.

## Solution

- Go to **Organizer**, **Forms 5227**, **Split-Interest Trust**, and then **Asset and Donor Information**.
- Select **Add new Asset and Donor Information**.
- Complete data entry for assets and donors.
- Perform an full recompute and re-create the e-file.
