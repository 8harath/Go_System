# R0000-202 e-file error

## Error

```
If Form 965 is present in the return, then Form 965-A must be present. (rule R0000-202)
```

## Cause

Form 965-A is missing from the return.

## Solutions

If Forms 965 and 965-A are not needed, there is likely accidental data entry:

- Go to the **Organizer**, then **Income**.
- Open **§965 Inclusion of Deferred Foreign Inc**.
- Make sure the fields in this folder are correct. Remove any extra data entry.
- Do a Full Recompute, then recreate and re-transmit the return.

If the 965 and the 965-A are needed for the return:



- Go to the **Organizer**, then **Income**.
- Open **§965 Inclusion of Deferred Foreign Inc**.
- Go to **Payment Information** and open**2022 Inclusion Payment Information**.
- Check the fields in this screen. If none of the amounts are relevant, put "NONE" in those fields.
- Do a Full Recompute, then recreate and re-transmit the return.
