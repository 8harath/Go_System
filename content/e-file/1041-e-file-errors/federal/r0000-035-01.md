# R0000-035-01 e-file error

## Error

```
The 'TaxPeriodEndDt' in the Return Header must be less than the Received Date. (value YYYY-MM-DD, rule R0000-035-01).
```

## Cause

The tax year end date is after the date the return was filed.

## Solution

Check the year end:

- Go to the **Organizer**, then **General Information**.
- Select **Basic Return Information**.
- Make sure the **Fiscal year ending** field is correct.
- If it's wrong, fix it and do a Full Recompute, then recreate the e-file and submit the return.
- If it's correct, call the IRS e-help Desk, and 866.255.0654 and check what they have on their record.
