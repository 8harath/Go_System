R0000-905-01 e-file error

Error

Electronic Filing Identification Number (EFIN) in the Return Header must be listed in the e-File database and in accepted status. (R0000-905-01)

Cause

The EFIN included in the return is invalid.

Solution

  1. Go to the
    Organizer
    , then
    E-file
    .
  2. Select
    Enable/Create
    .
  3. Make sure the EFIN column is correct.
    1. If it's wrong, fix it and do a Full Recompute. Then recreate and retransmit the e-file.
    2. If the EFIN is correct, call the IRS e-help Desk at 866.255.0654 to resolve the rejection.
