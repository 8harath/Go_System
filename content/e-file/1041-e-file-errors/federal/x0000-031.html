X0000-031 e-file error

Error

Zip Entry names must conform to the guidelines in Publication 4164.

Cause

A PDF attached to the return has an improper name or title.

Solution

  1. Go to the
    Organizer
    , then
    E-File
    .
  2. Select
    Attachments
    , then
    Summary
    .
  3. Select
    Attach PDF
     and review your PDF attachments for the following e-file requirements:
    1. Shorten the name of the attachments to 23 characters or less.
    2. Remove any spaces in the file name.
    3. Remove any special characters from the file name.
  4. Delete and reattach any PDF with an updated file name.
  5. Do a Full Recompute, recreate the e-file, and submit the return.
