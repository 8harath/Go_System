R0000-007-02 e-file error

Error

For US Addresses, the first five digits of the Zip Code of the Filer's address in the Return Header must be within the valid ranges of zip codes for the corresponding State Abbreviation. See Publication 4164. (rule R0000-007-01)

Cause

A zip code used in this return doesn't match the list of valid zip codes for the state listed.

Solution

  1. Go to the
    Organizer
    , then
    General Information
    .
  2. Select
    Basic Return Information
    .
  3. Check the
    State
     and
    ZIP
     fields.
  4. Go back to the
    Organizer
    , then
    General Information
    .
  5. Select
    Basic Return Information
    , then
    Paid Preparer/ERO Information
    .
  6. Check the
    State
     and
    ZIP
     fields.
  7. Do a Full Recompute, recreate the e-file and submit the return.
