X0000-010 e-file error

Error

Your State submission does not match the latest published FTB Schema or is not well formed. You must contact your software provider to resolve this error. XPath to Error /CA-Return/CA-ReturnData/CAForm541ScheduleK-1/BeneficiaryInformation/USAddress/StreetAddress

Cause

The beneficiary address is too long for the form.

Solution

  1. Go to
    Beneficiary Info (1041)
     in the
    Organizer
    .
  2. Select
    Beneficiary Data
    , then
    Beneficiary Information
    .
  3. Remove some characters from
    Street Address Line
    . Use
    Street Address Line 2
     if you need to include this info.
  4. Do a full recompute.
  5. Recreate e-file.
  6. Resubmit the return.
