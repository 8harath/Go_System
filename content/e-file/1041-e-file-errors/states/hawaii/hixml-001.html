HIXML-001 e-file error

The XML data has failed schema validation. The file name of supporting binary attachments must match their name in the XML file.
This happens when Hawaii’s PDF Attachment names don't match its e-file schema requirements.

Solution

Hawaii has a set of specific names for PDFs that it allows as attachments to its e-filed returns. If those names are not used, and only when required, then the return will get rejected.
  1. In
    Organizer
    , select
    States
    .
  2. Select
    Hawaii
    and then
    E-file
    .
  3. In
    Attachments
    , go to
    PDF Summary
    to review the attached PDF names.
Hawaii e-file attachment file names need to match the names listed in the instructions, starting on page 9 of 11.
Remove incorrect PDF attachments, rename the files outside the program, and then reattach to the state. Full recompute and recreate the e-file.
