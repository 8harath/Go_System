ILK1P-500-3 e-file error

Error

SchILK1P Step 1 Line 3 must contain a valid FEIN. (ILK1P-500-3)

Cause

Illinois requires a valid Federal Employee Identification Number (FEIN) on the K-1-P form for each trustee.

Solution

  1. Go to
    States
     in the
    Organizer
    , then select
    Illinois
    .
  2. Select
    K-1-P Received by Trustee
    , then a trustee.
  3. Enter a valid
    FEIN
    .
  4. Do a full recompute, recreate the e-file, and submit the return.
