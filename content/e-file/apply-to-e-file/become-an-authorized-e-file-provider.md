# Become an authorized e-file provider

Apply for IRS e-file provider authorization by setting up an account, submitting an application, and passing a suitability check.

Follow the [steps on the IRS website to become an authorized e-file provider](https://www.irs.gov/e-file-providers/become-an-authorized-e-file-provider).

note

* The IRS charges no fee for this process, which takes up to 45 days. Refer to the [IRS website](https://www.irs.gov/e-file-providers/become-an-authorized-e-file-provider) for more guidance.
* One EFIN covers all preparers in a firm.
