# Sign a Form 990 e-file

Sign exempt organization federal tax returns electronically using a practitioner PIN or Form 8453-EO.

Tax practitioners can sign exempt organization federal tax returns electronically using a personal identification number (PIN). You may use either the practitioner PIN method or Form 8453-EO.

Follow these steps to sign a 990 e-file:

- Go to 

  **Organizer****E-file****Return****Signature Authorization**

  .
- Select **PIN options**.
- On the 

  Signature Authorization

   screen, select one of these options:

  * **Form 8879-TE - Practitioner PIN**: The taxpayer and ERO will each select a PIN (or use the auto-generate option) to sign the return. As the ERO, you'll complete Form 8879-EO and retain it for 3 years.
  * **Form 8453-TE - scanned signature document**: The ERO completes and prints Form 8453-EO. Have all required parties sign the form, scan it into a PDF document, and attach it as a binary attachment. Limit the PDF file name to 23 characters.
- If you chose to use the practitioner PIN method, indicate who entered the PIN: ERO or Officer. You can also select to generate the PINs automatically.
- Enter the PINs.
