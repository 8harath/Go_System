# Use a self-selected PIN for e-file authorization

Set up self-select PIN authorization by entering taxpayer PINs and prior year information for identity verification.

Go to 

**Organizer****E-file****Signature Authorization**

 and select **Self-select PIN** as the PIN type.

To set up self-select PIN authorization:

- Select who entered the PIN: **ERO (Electronic Return Originator)** or **taxpayer/spouse**.
- Enter the 5-digit self-selected PIN for the taxpayer and spouse (if filing jointly).
- Enter the prior year AGI or prior year PIN for identity verification.

  note

  The IRS requires prior year AGI or prior year self-select PIN to verify taxpayer identity when using the self-select PIN method.
- Enter the date you entered the PINs into the Organizer.

The self-selected PIN information is saved for signature authorization.

note

Form 8879 won’t print when using the self-selected PIN method. The taxpayer uses their self-selected PIN and prior year information to sign electronically.
