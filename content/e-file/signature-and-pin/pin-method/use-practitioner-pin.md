# Use practitioner PIN for 1040 e-file authorization

Set up practitioner PIN authorization using Form 8879 by entering or generating PINs for the taxpayer, spouse, and ERO.

In the Organizer, go to 

**Organizer****E-file****Signature Authorization**

, and select **Practitioner PIN (Form 8879)** as the PIN type.

To set up practitioner PIN authorization:

- Select who entered the PIN: **ERO (Electronic Return Originator)** or **taxpayer/spouse**.
- Select the option to generate random PINs for the taxpayer and spouse.
- Select the option to generate a random ERO PIN.
- Select the option to print taxpayer and spouse PINs on Form 1040, page 2 signature lines.
- Enter the 5-digit PIN for the taxpayer and spouse (if filing jointly).
- Enter the ERO PIN.
- Enter the date you entered the PINs into the Organizer.

Form 8879 generates with the PIN information for signature authorization.

important

Form 8879 won’t print if you select a taxpayer or spouse as the PIN entry person and select self-select PIN as the PIN type.
