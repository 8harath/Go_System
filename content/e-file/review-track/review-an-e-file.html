Review XML files before submitting e-files

Review the XML file using the EFile Reviewer or an internet browser to verify accuracy before you submit the e-file to the IRS.
The system transmits an e-file to the IRS as an XML file. After you create an e-file, review the XML file to verify its accuracy before you submit it.
You can review the XML file in 2 ways:
  • Use the
    EFile Reviewer
     in the application.
  • Download and view the XML file with an internet browser or a text editor.
After you review the XML file and clear all errors, you can submit the e-file.
