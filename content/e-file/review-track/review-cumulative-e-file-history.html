Review the cumulative e-file history

Access cumulative e-filing history and filing status summaries directly from the returns list for a specific jurisdiction.
You can review the cumulative history for a jurisdiction from the returns list where the system displays specific returns.
  1. Select
    Returns
    . Enter the criteria and options to find your e-filed return.
  2. Mark the checkbox next to the return to turn it on.
  3. Select
    Info
    .
  4. Select the
    E-filing
     tab and review the results.
  5. Select the jurisdiction link to show the cumulative history.
  6. Select the filing status to show a printable summary of the e-file.
