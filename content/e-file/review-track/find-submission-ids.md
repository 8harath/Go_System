# Find submission IDs in e-file status reports

Use the acknowledgment information in e-file status reports to locate the submission ID for accepted returns.

You can find the submission ID by using the acknowledgment information in e-file status reports.

- In the browser, go to 

  **Returns Processing****E-Status Reports**

  .
- Select the return criteria including **Account**, **Year**, **Tax Type**, and **Sort List By information**.
- Select **e-file Type**.
- For **Federal Status**, select **Accepted** from the dropdown.
- Use the calendar date control to enter a date range in the **Fed. Ack. Date From** fields.
- Select **Continue**.
- Use the navigation bar to find the **Submission ID**.
