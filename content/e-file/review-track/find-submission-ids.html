Find submission IDs in e-file status reports

Use the acknowledgment information in e-file status reports to locate the submission ID for accepted returns.
You can find the submission ID by using the acknowledgment information in e-file status reports.
  1. In the browser, go to
    Returns Processing
    E-Status Reports
    .
  2. Select the return criteria including
    Account
    ,
    Year
    ,
    Tax Type
    , and
    Sort List By information
    .
  3. Select
    e-file Type
    .
  4. For
    Federal Status
    , select
    Accepted
     from the dropdown.
  5. Use the calendar date control to enter a date range in the
    Fed. Ack. Date From
     fields.
  6. Select
    Continue
    .
  7. Use the navigation bar to find the
    Submission ID
    .
