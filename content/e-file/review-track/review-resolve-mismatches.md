# Review and resolve e-file mismatches

View the e-file summary to identify mismatches between locator amounts and e-file amounts, and resolve differences by recreating the e-file XML.

You can still submit the return for e-filing even if there are differences. The mismatch status alerts you that the system calculated the return with different key amounts after its last e-file XML creation.

You can view the e-file summary in 2 places:

* **E-file Viewer**: Select the PDF folder to open the PDF in a separate window.
* **E-file Submission**: If the amounts match between the locator and the e-file, the e-file status displays as **Qualified**.

When amounts in the locator and e-file don't match, the e-file status shows **Qualified – Mismatch** instead of **Qualified**. This occurs when locator amounts change but you don't create a new e-file.

Select **Qualified – Mismatch** to display the **E-file Summary Report**. The system shows differences in red.

note

You can still submit the return for e-file if the e-file status is **Qualified Mismatch**. This only alerts you that the system computed the return with different key amounts after its last e-file XML creation.

To resolve any differences between the e-file and the tax return numbers, open the locator and re-create the e-file XML file.
