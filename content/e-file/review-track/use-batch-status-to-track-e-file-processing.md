# Use batch status to track e-file processing

Use the Batch Status tab to review the processing status of your e-filed returns by batch ID.

Follow these steps to use batch status to review the e-file processing status.

- Select **Returns Processing**, **E-file**, then **Status Report** or **E-file Submission**.

  - Select the **Batch Status** tab on the main e-file screen. ![](/content/dam/helpandsupp/en-us/Topics/ONESOURCE-family/e-file/files/efile-batch.png/_jcr_content/renditions/original)
  - Review the batch status options, which display your sign-in ID, today’s date, tax years, and tax return types. Use the dropdowns to refine your choices.
  - Review the batch ID and batch detail that the system displays based on your criteria.
- Select the batch ID link to review the e-file processing status.
