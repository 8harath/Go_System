Use batch status to track e-file processing

Use the Batch Status tab to review the processing status of your e-filed returns by batch ID.
Follow these steps to use batch status to review the e-file processing status.
  1. Select
    Returns Processing
    ,
    E-file
    , then
    Status Report
     or
    E-file Submission
    .
    1. Select the
      Batch Status
       tab on the main e-file screen.
    2. Review the batch status options, which display your sign-in ID, today’s date, tax years, and tax return types. Use the dropdowns to refine your choices.
    3. Review the batch ID and batch detail that the system displays based on your criteria.
  2. Select the batch ID link to review the e-file processing status.
