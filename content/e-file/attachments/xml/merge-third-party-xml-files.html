Merge third-party XML files with your international e-file

Upload third-party XML files to include international forms in your e-file submission and learn how to complete the merge process.

Upload third-party XML files

When you upload or attach a third-party XML e-file, the system includes only the following international forms in the final XML file: Forms 926, 1118, 5471, 8621, 8858, and 8865. Ensure your third-party files use the XML file extension.

Attach PDF files separately

The system doesn’t include PDF attachments from third-party e-files in the merge process. Instead, attach all PDF files separately by going to
Edit
Insert
E-file Attachments
 in the browser.

Complete Schedule N manually

The system doesn’t automatically update Schedule N Questions - Foreign Operations of U.S. Corporations with information from merged XML files. Manually update these questions in
Organizer
General Information
Miscellaneous Information
Schedule N Questions
.

Validate third-party files before merging

Validate your third-party XML file to detect XML errors before attempting to merge. If the third-party XML file contains validation errors, the system won't complete the merge process.

Create the e-file

The Create Electronic File process merges third-party XML files with other XML files. This creates the final XML for IRS submission. You can merge third-party XML files only in single or top consolidation returns.
