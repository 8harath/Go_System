# Attach third-party XML files to your international e-file

Combine multiple returns into a single e-file by attaching third-party XML files.

Before you begin, make sure you have the XML files you want to attach saved and accessible.

When you need to include multiple returns in a single e-file submission, attach third-party XML files to your primary return. This process is called aggregating returns.

- Open the primary return and go to 

  **Organizer****E-file****International****Third-Party XML**

  .
- Select **Attach Third-Party XML File**.
- Select **Add**.
- Select **Third-Party XML File**, then **Associate Existing**.
- Go to the XML file you want to attach and select **Upload**.
- Repeat steps 2-5 for each additional XML file you want to attach.
- Select **Done**.
- Review the **Third-Party Attachments Summary** section to verify all XML files are attached.
- Select **Validate Third-Party XML File**.

  note

  The attached XML file names include the locator number of the primary return.

The third-party XML files are now attached to your primary return and ready for e-filing.
