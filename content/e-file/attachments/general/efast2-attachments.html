File format requirements for EFAST2 attachments

Learn which file formats you can use when submitting attachments with your EFAST2 filing based on the attachment type.
You can submit any information that can't fit on the 5500 series forms and schedules as an unstructured attachment on EFAST2.
The acceptable file formats vary by attachment type:
  • Accountant's Opinion and Signed MB or SB
    : Attach the Independent Qualified Public Accountant (IQPA) report and signed Schedule MB or SB as a PDF.
  • Other Attachments
    : Attach other documents as either a PDF file or an ASCII Text file. The system doesn't accept any other file formats.
