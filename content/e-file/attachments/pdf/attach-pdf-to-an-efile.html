Attach a PDF to an e-file

Add and review PDF attachments for e-filed returns.
Follow these steps to attach a PDF:
  1. With the return open, select
    Edit
    ,
    Insert
    , then
    EFile Attachments
    .
  2. Select
    Add
    .
  3. Select the jurisdiction or form.
  4. Select
    Browse
    , then select the PDF you want to attach.
  5. Select
    Next
    .
  6. Select a predefined title or enter your own. The default user-defined title is the file name, without the extension.
    important
    When you select the PDF, the system automatically populates the description with the PDF file name. If necessary, change the description to an IRS-accepted name. Make sure the attachment file name matches the IRS-required descriptions. For attachments not listed in the IRS specifications, use meaningful and descriptive names. Your actual file name becomes the description of the attachment and can't exceed 100 characters.
    note
    You can't change the Thomson Reuters file name and date modified.
  7. Select
    Next
    .
    The system displays the selected PDF with the jurisdiction, attachment title, file name, file size, and date modified in the
    E-file Attachments
     window.
  8. Select
    Done
     to complete the attachment.
Select

 on the
