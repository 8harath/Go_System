# Delete trapped PDF attachments

Clear PDF attachments that appear in the Organizer's summary but don't show when you try to attach them.

Follow these steps to delete trapped attachments:

- Go to 

  **Organizer****Federal E-file****Attachments****PDF Attachments****Summary**

  .
- Select **Attach PDF**.
- Add any document as a PDF to this return.
- Close the 

  PDF Attachment

   window.
- Select **Attach PDF** again to re-open the window.
- Delete the PDF you attached and close the window.
- Perform a full recompute.

The trapped PDF attachments should now be gone.
