Error: The file you attempted to upload doesn’t meet minimum file requirements (fillable form)

Resolve the minimum file requirements error that occurs when you upload fillable form PDFs to an e-file.

Scenario

When you attempt to attach a fillable form PDF file to an e-file, you may receive this error message:
Error message
The file you attempted to upload does not meet minimum file requirements. Please correct the file and try again.

Solution

Fillable form PDF files must be saved as a standard PDF before you can attach them to an e-file.
  1. Open the PDF you're attempting to attach.
  2. Select
    Print
    .
  3. Select
    Microsoft Print to PDF
     or
    Save as PDF
    .
  4. Select
    Print
     and save the PDF to your computer.
  5. Reattach the PDF and the e-file attachment.
