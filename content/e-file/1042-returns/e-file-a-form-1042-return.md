# e-file a Form 1042 return

Form 1042's prepared inside a 1065 or 1120 return; however, the e-file's a stand-alone creation and submission process. This process doesn't interfere with the regular 1065 or 1120 return.

note

If this return's a partnership, you don't need to enter partner information for the 1042 e-file.

- Before e-file creation, ensure the following items get entered in the return:

  - Entity name
  - EIN
  - Complete address
  - Signing officer (name, title, and signing date)
  - EFIN
  - Type of originator (ERO or large taxpayer)
  - Signature option (8453 or 8879
  - Form specific requirements (Chapters 3 and 4 status codes)
- To create the 1042 e-file, go to **Organizer**, **Informational Forms**, **Withholding for Foreign Persons**, **Federal 1042 E-file**, and then **Create E-file**.
- Select **Create e-file**.
