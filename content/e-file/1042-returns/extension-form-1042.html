e-file extension for Form 1042, Annual withholding tax return

important
Beginning with tax year 2023, no duplicate locator's needed when needing to file an extension for both the regular return and the 1042 return.
  1. Go to
    Organizer
    ,
    Informational Forms
    ,
    Withholding for Foreign Persons
    , and then
    Extension
    .
  2. Select
    File Form 7004
    .
  3. Next go to
    Federal 1042 E-file Extension
    , and then
    Enable Extension
    .
  4. Select
    Enable federal 1042 extension e-file
    , enter the EFIN (electronic federal identification number), and then select the
    Type of originator
    .
  5. Next, go to
    Signature Authorization
    , and complete this information.
  6. If an extension payment's made through direct debit, go to
    Additional Information
     and
    Bank Information
     to complete any required information.
  7. To create the 1042 extension e-file, go to
    Create E-file Extension
    , and select
    Create Federal 1042 Extension E-file
    .
  8. Once a qualified extension e-file's created, submit the e-file using the
    Federal 1042 Extension
     jurisdiction description in the e-file submission.
