# e-file an amended 1042 return

You can amend and e-file a 1042 return.

- Make a copy of the original locator.
- In the new locator, go to **Organizer**, **Informational Forms**, **Withholding for Foreign Persons**, and then **Withholding for Foreign Persons**.
- Select **Amended**, and enter the necessary changes throughout the return.
- Next, go to **Organizer**, **Informational Forms**, **Withholding for Foreign Persons**, **Additional E-file Information**, and then **Additional Information**.
- Enter an explanation in the **Reasonable Cause for Superseded or Amended Return** field. This explanation is required for the IRS to accept the e-file.
- Perform a full re-compute, create the 1042 e-file, and then submit.
