# e-file a superseded 1042 return

You can e-file a superseded 1042 return.

- Go to **Organizer**, **Informational Forms**, **Withholding for Foreign Persons**, **Electronic Filing**, **Additional Information**, and then **Additional Information**.
- Select **Superseded return**, and enter the necessary changes throughout the return.
- Next, go to **Organizer**, **Informational Forms**, **Withholding for Foreign Persons**, **Additional E-file Information**, and then **Additional Information**.
- Enter an explanation in the **Reasonable Cause for Superseded or Amended Return** field. This explanation is required for the IRS to accept the e-file.
- Perform a full re-compute, re-create the 1042 e-file, and re-submit.
