# F8621-026-02 e-file error

## Error

```
F8621, 'PFICOrQEFEIN' or 'ForeignEntityReferenceIdNum' must have a value. (rule F8621-026)
```

## Cause

The return is missing either an EIN or Reference ID for a foreign entity for form 8621.

## Solution

- Go to the **Organizer**, then **Foreign Information**.
- Select **Return by Shareholder of PFIC or QEF**.
- Select an entity, then go to **General**.
- Enter the EIN and/or Reference ID number.

If the entity doesn't have an EIN or Reference ID number, you'll need to paper file the return.
