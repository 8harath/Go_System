# IND-041 e-file error

## Error

```
If 'ThirdPartyDesigneeInd' in the return has a choice of 'Yes' indicated, then 'ThirdPartyDesigneePIN' must have a value.
```

## Cause

Third-party designee is incomplete on Form 1040 Schedule 6.

## Solution

- Go to the **Organizer**, then **General Information**.
- Open **Basic Return Information**, then **Paid Preparer Information**.
- Correct any fields in the Third-Party Designee section.
