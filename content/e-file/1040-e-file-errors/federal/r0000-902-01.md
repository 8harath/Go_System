# R0000-902-01 e-file error

## Error

```
Taxpayer TIN in the Return Header must not be the same as a TIN of a previously accepted electronic return for the return type and tax period indicated in the tax return. (value #########, rule R0000-902-01)
```

note

The value represents the taxpayer SSN causing the rejection.

## Cause

The IRS e-File database shows this SSN has already been used on an accepted return.

## Solution

- Go the **Organizer** and select **General Information**.
- Select **Basic Return Information**, then **Taxpayer Information**.
- Make sure the **SSN** field is correct.
- If it's incorrect, correct it. Then recompute the return, create the e-file, and submit the return.
- If the taxpayer's SSN is correct, contact the IRS e-Help desk at 866.255.0654.
