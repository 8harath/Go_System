# IND-116-01 e-file error

## Error

```
Each dependent in DependentDetail on the return with EligibleForChildTaxCreditInd checked needs to be under the age of 17. You may be eligible to claim the Credit for other dependents if you meet the requirements for the credit.
```

## Cause

If claiming the **Child Tax Credit** for any dependents, the dependent needs to be under the age of 17.

## Solution

If you want to claim the Child Tax Credit:

- Go to the **Organizer**, then **General Information**.
- Select **Dependents**, then **Dependent Input**.

  note

  If you used the Columnar Dependents Entry method, open that instead.
- Select the dependent causing the rejection.
- Check the **Social Security Number (or ITIN / ATIN)** field and make sure it is correct. If it isn't, correct it.

  note

  If the number in the field begins with any number between 900 and 999, it is an ITIN and therefore not eligible for the credit per [Publication 4164](https://www.irs.gov/pub/irs-pdf/p4164.pdf).
- If the SSN is correct, paper file the return or contact the IRS e-Help Desk at 866-255-0654.

If you don't want to claim the Child Tax Credit:

- Go to the **Organizer**, then **General Information**.
- Select **Dependents**, then **Dependent Input**.

  note

  If you used the Columnar Dependents Entry method, open that instead.
- Select the dependent causing the rejection.
- Check that the **Qualifies for Child Tax Credit** and/or **Qualifies for Additional Dependent Needs** fields are empty.
