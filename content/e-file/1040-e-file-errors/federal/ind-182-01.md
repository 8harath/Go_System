# IND-182-01 e-file error

## Error

```
The Spouse Identity Protection Personal Identification Number (IP PIN) must match the e-File database. Please double check your entry and resubmit your return with the correct number. (value #########, rule IND-182-01)
```

## Cause

The IP PIN issued to the spouse was entered incorrectly in the return.

## Solution

Check the IP PIN:

- In the **Organizer**, select **General Information**.
- Select **Basic Return Information**, then **Taxpayer Information**.
- Make sure the correct IP PIN is entered in the **Identity Protection PIN** field in the Spouse column. You can retrieve the IP PIN at <https://www.irs.gov/identity-theft-fraud-scams/retrieve-your-ip-pin>.

If you can't retrieve the IP PIN, or the PIN entered is correct, the client (or the taxpayer) will need to contact the IRS E-file Help desk at 866.255.0654 for more information.
