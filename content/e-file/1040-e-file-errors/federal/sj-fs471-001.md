# SJ-F5471-001 e-file error

## Scenario

```
If Schedule J (Form 5471) is present in the return, then it must be referenced from one and only one Form 5471. (value YYYY-MM-DD, rule SJ-F5471-001)
```

## Cause

You can't file the return electronically if Schedule J or Schedule M is present in more than 1 Form 5471.

## Solution

If you have more than 1 Schedule J or Schedule M, you'll have to file on paper.
