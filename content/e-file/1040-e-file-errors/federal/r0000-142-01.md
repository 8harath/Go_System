# R0000-142-01 e-file error

## Error

```
If you are a paid tax return preparer, you must use a Preparer Tax Identification Number (PTIN) issued by the Internal Revenue Service (IRS) to identify yourself in the paid preparer section of the tax return. In future years, tax returns may be rejected if an SSN, or any number that is not a valid PTIN, is included in this field. (value, rule R0000-142-01),
```

## Cause

Paid tax return preparers must use a Preparer Tax Identification Number (PTIN) when they file a tax return.

## Solution

- Go to **Organizer**, then **General Information**.
- Select **Basic Return Information**, then **Paid Preparer Information**.
- Check the **PTIN** is correct.


  - If the **PTIN** is wrong, correct it, do a **Full Recompute**, re-create the e-file, and resubmit the return.
  - If the **PTIN**, contact the IRS e-Help Desk at 866-255-0654.
