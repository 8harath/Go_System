F8962-070 e-file error

Error

The e-file database indicates that Form 8962 or a binary attachment with description containing ‘ACA Explanation’ must be present in the return.

Cause

The taxpayer received an Advanced Premium Tax Credit (APTC) payment reported on Form 1095-A. Form 8962 reconciles APTC and, because it wasn't included in the return, the return is rejected.
note
The IRS has the ability to verify the receipt of the APTC payment before accepting the return. In the past, the return was accepted, and would later result in a notice sent to the taxpayer and recalculation of the refund or amount owed.

Solution

  1. Go to
    Organizer
    , select
    Source Documents
    , then
    Form 1095-A
    .
  2. Enter amounts for Form 1095-A.
  3. Next, attach a file with a description containing an
    ACA Explanation
    . Go to
    Organizer
    ,
    E-file
    ,
    Attachments
    ,
    PDF Attachments
    ,
    Summary
    , then
    Attach PDF
    .
  4. Select
    Add
    .
  5. Select
    Federal
     in the
    Attachment Jurisdiction
     dropdown.
  6. Select
    Browse for file
     and attach either Form 1095-A or Form 8962.
  7. Select
    ACA Explanation
     in the
    Predefined description
     dropdown, then select
    Upload
     and
    Done
    .
  8. Perform a full recompute, re-create the e-file, then re-submit.
