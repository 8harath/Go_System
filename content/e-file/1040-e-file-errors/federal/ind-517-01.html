IND-517-01 e-file error

Error

A Dependent SSN in the return must not be the same as the Primary or Spouse SSN on another return where 'PrimaryClaimAsDependentInd' or 'SpouseClaimAsDependentInd' is not checked. (value XXXXXXXXX, rule IND-517-01).
note
The value represents the Social Security number (SSN) of the dependent causing the rejection.

Cause

The dependent's Social Security number you entered in the return was used on another return this year. This can happen because of incorrect data entry or because the dependent filed their own tax return.

Solution

  1. Go to
    Organizer
    , then
    General Information
    .
  2. Select
    Dependents
    , then
    Dependent Input
    .
  3. Select the dependent whose SSN caused the rejection.
  4. Check the
    Social Security Number (or ITIN / ATIN)
    :
    • If the SSN is not correct, correct it.
    • If the SSN is correct, find out if the dependent filed their own return and claimed their exemption. If they didn't, contact the IRS e-Help Desk at 866-255-0654.
