# FPYMT-074-01 e-file error

## Error

```
If the return is received after the due date of the return, then the RequestedPaymentDt in the IRS Payment Record must not be later than the date the return was received.
```

## Cause

The **Requested Payment Date** on the return can't be later than the date you transmit the return.

## Solution

- Go to **Organizer**, then select **General Information**.
- Select **Basic Return information**, then **Bank Information**.
- In the Direct Debit section, enter the date you'll submit the return in **Date to be debited**.
- Do a **Full Recompute**, re-create the e-file, and resubmit the return.
