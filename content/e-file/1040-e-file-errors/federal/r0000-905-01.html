R0000-905-01 e-file error

Error

Electronic Filing Identification Number (EFIN) in the Return Header must be listed in the e-File database and in accepted status. (R0000-905-01)

Cause

The EFIN included in the return is invalid.

Solution

  1. In the
    Organizer
    , select
    E-file
    , then
    Enable/Create
    .
  2. Review the number entered in the EFIN column.
  3. If it's incorrect, correct it. Do a full recompute, recreate, and retransmit the e-file.
  4. If the EFIN is correct, call the IRS e-help Desk at 866.255.0654 to resolve the rejection.
