IND-516-01 e-file error

Error

Incorrect Data: /Return/ReturnHeader/Filer/PrimarySSN: If Form 1040, 'PrimaryClaimAsDependentInd' is not checked, then the Primary SSN must not be the same as a Dependent SSN on another return. (value #########, rule IND-516-01)
note
The value indicates the SSN of the dependent causing the rejection.

Cause

According to the IRS e-file database, the taxpayer's SSN has been used on a different return to claim a dependent exemption. For example, a student tries to file their own tax return and claim, after their parents filed a tax return and claimed the student as a dependent.

Solution

  1. Go to
    Organizer
    ,
    General Information
    , then
    Dependents
    .
  2. Select
    Dependent Input
    .
  3. Find the dependent rejection value references.
  4. Check this dependent's
    SSN
    :
    1. If the
      SSN
       is wrong, correct it, do a
      Full Recompute
      , re-create the e-file, and resubmit the return.
    2. If the taxpayer is not supposed to be claimed as a dependent, file the tax return on paper with Form 8948, and contact the IRS e-Help Desk at 866-366-0654 for more information.
