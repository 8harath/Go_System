# SH-F1040-520-01 e-file error

## Error

```
Schedule H (Form 1040), EmployerEIN and EmployerNameControlTxt must match data in the e-file database.
```

## Cause

The employer identification number (EIN) doesn't match what's listed in the IRS e-file database.

## Solution

Review the EIN entered in **Organizer**, **Taxes**, **Household Employment Tax**.

* If the EIN is correct, contact the IRS e-file Help Desk at 1-866-255-0654.
* If the EIN is incorrect, fix the entry and then perform a full re-compute, re-create the e-file, and then re-submit the return.
