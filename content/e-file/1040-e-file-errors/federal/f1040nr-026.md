# F1040NR-026 e-file error

## Error

```
If Form 1040NR, 'WithholdingTxFrom8805Amt' has a non-zero value, then Form 8805 must be attached to 'WithholdingTxFrom8805Amt'.
```

## Cause

There's a difference between Form 1040NR and Form 8805 in this return, usually from forced data entry or a missing form.

## Solution

- In Tax Forms, open **Federal**.
- In the 1040NR - Nonresident Alien Income Tax, open Pages 1-5.
- On page 2, line 62b (Form 8805), check if there is manual data entry.
- If so, check that it's correct and that Form 8805 is included with the return.
- Run a full recompute and recreate the e-file.
