# IND-508 e-file error

## Error

```
Primary SSN in the Return Header must not be equal to the Spouse SSN on another tax return for which filing status is Married Filing Jointly or [filing status is Married Filing Separately and the Spouse exemption is claimed]. (value #########, rule IND-508).
```

note

The value represents the Social Security number of the person causing the rejection.

## Cause

The SSN entered for the taxpayer on this return matches the SSN of a spouse on another return already accepted by the IRS.

## Solution

- Go to **Organizer**, then **General Information**.
- Select **Basic Return Information**, then **Taxpayer Information**.
- Check the **Taxpayer SSN/ITIN**:


  - If the information is wrong, correct it, do a **Full Recompute**, re-create the e-file, and resubmit the return.
  - If the information is correct, contact the IRS e-Help desk at 866-255-0654 to verify the SSN.
