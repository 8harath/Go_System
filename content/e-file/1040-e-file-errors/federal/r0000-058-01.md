# R0000-058-01 e-file error

## Error

```
An XML document that represents a binary attachment must have a valid reference to an attached file. (value, rule R0000-58-01).
```

note

The value will represent the PDF attachment causing the rejection.

## Cause

The file name of the PDF attachment doesn’t meet e-filing requirements.

## Solution

- Go to **Organizer**, then **E-File**.
- Select **Attachments**, then **Summary**.
- Select **Attach PDF**.
- Check the files names of your PDF attachments meet the following e-file requirements:


  - 23 characters or less.
  - No spaces.
  - No special characters.
- If you need to change the file name of an attachment, delete it, make the change, then reattach it.
- Do a **Full Recompute**, re-create the e-file, and resubmit the return.
