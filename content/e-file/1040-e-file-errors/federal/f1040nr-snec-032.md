# F1040NR-SNEC-032 e-file error

## Error

```
If there is no Form 1042-S with 'IncomeTypeCd' having the value "01" in the return and Form 1040NR, Schedule NEC, 'OtherInterestAmt' in 'IncomeTaxRtOthUndTrtyRuleGrp' or 'IncomeTaxRtOth2UndTrtyRuleGrp' has a non-zero value, then the corresponding 'TaxRt' must be greater than 30%. (value xx.xxxx rule F1040NR-SNEC-018)
```

note

The value represents the Schedule NEC rate below 30%.

## Cause

The return doesn't have a Form 1042-S with a **1** in **Box 1** and the **Rate** on Schedule NEC, lines 1 or 2, column d is 30% or less. (This is an IRS e-file limitation).

## Solution

- Go to **Organizer**, then **Source Documents (W-2, 1099s, 1098)**.
- Select **1042-S**.
- Review **Box 1**, **Income Code** on each of the 1042-S forms.
- If incorrect, change the code, do a **Full Recompute**, re-create the e-file, and resubmit the return.
- If the code is correct and is not a **1**, go to **Organizer**, **Foreign Information**, then **Nonresident Alien**.
- Select **Not Effect. Connected Inc - Other Rates**.
- Check that the tax rate is **30%** or higher.

  important

  If the tax rate is lower than **30%** and there is not a Form 1042-S with code **1** in **Box 1**, you can't e-file the return.
