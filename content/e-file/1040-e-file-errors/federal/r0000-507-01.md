# R0000-507-01 e-file error

## Error

```
'DependentSSN' in 'DependentDetail' on the return was used as a Dependent SSN on a previously filed tax return for the same tax period. (value #########, rule R0000-507-01)
```

note

The value represents the Social Security number (SSN) of the dependent causing the rejection.

## Cause

The dependent SSN entered in the return was used on another return this year. This can happen because of incorrect data entry or because the dependent filed their own tax return.

## Solution

- Go to the **Organizer**, then **General Information**.
- Select **Dependents**, then **Dependent Input**.
- Verify that the dependent SSN information is correct. If it's correct and the dependent didn't file their own return claiming their exemption, contact the IRS e-Help Desk at 866.255.0654.
- Correct any wrong information. Then do a full recompute, re-create the e-file, and retransmit the return.
