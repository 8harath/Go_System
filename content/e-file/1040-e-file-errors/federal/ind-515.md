# IND-515 e-file error

## Error

```
Duplicate Condition: /Return/ReturnHeader/Filer/PrimarySSN: The Primary SSN in the Return Header must not be equal to the Primary SSN in another return filed for the same tax year. (value #########, rule IND-515)
```

## Cause

The SSN used for the taxpayer has already been used for a taxpayer on another return.

## Solution

- In the **Organizer**, select **General Information**.
- Select **Basic Return Information**, then **Taxpayer Information**.
- Check the SSN entered.


  * If it's incorrect, correct it. Then do a full recompute and e-file the return.
  * If it's correct, you'll need to file the paper with Form 8948. You can contact the IRS at 866.255.0654 to inquire about the SSN in question.
