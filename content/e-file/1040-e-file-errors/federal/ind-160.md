# IND-160 e-file error

This error happens when there is a duplicate SSN entered in **Taxpayer Information**.

## Error message

```
Form 1040: On Form 1040, the Social Security Number of the Qualifying Child entered is identical to the Taxpayer or Spouse SSN. They must be unique.
```

## Solution

- In the **Organizer**, select **General Information**.
- Go to **Basic Return Information**, then **Taxpayer Information**.
- In the **Filing Status** section, remove the duplicate entry.
- Do a full recompute.
- Recreate the e-file.
