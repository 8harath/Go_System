F1040-034-05 e-file error

Error

Form 1040, ‘WithholdingTaxAmt’ must be equal to the sum of the following: [(1) all ‘WithholdingAmt’ with corresponding ‘WithholdingCd’ having the value "FORM 1099" in the attached [OtherWithholdingStatment] and (2) all Forms W-2, ‘WithholdingAmt’ and (3) all Forms W-2G, ‘FederalIncomeTaxWithheldAmt’ and (4) Form 8959, ‘AddlMedcrRRTTaxWithholdingAmt’ and (5) ‘TotalAmt’ in [BackupWhSchedulesK1Statement] and (6) all Forms RRB 1042-S, ‘FederalIncomeTaxWithheldAmt’ and (7) all Forms SSA 1042-S (‘NetTaxWithheldAmt’ if it has a non-zero value, otherwise ‘FederalIncomeTaxWithheldAmt’)] unless Form 8958 is present in the return. When evaluating this, a tolerance of $5.00 is allowed. (value, rule F1040-34-05).

Cause

This can be caused by an override on Form 1040 line 17, withholding on a form that can't be e-filed (such as Form 1042-S or 8288-A), or by an IRS error.

Solution

  1. Select
    Tax Forms
    .
  2. Select
    Federal
    .
  3. Select
    1040 — Income Tax Return
    .
  4. Check line 17 for an override.
    1. If it is overridden, remove the override, do a
      Full Recompute
      , re-create the e-file, and resubmit the return.
    2. If there isn't an override, you'll need to paper file.
      note
      This may be due to withholding on a form or other source document that you can't attach to the electronic file.
note
The IRS has had problems with this error in the past. It's possible everything in the return is correct, but the IRS rejects the return incorrectly. These returns still need to be paper filed.
