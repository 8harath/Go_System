R0000-058-01 e-file error

Error

An XML document that represents a binary attachment must have a valid reference to an attached file. (value, rule R0000-58-01).
note
The value will represent the PDF attachment causing the rejection.

Cause

The file name of the PDF attachment doesn’t meet e-filing requirements.

Solution

  1. Go to
    Organizer
    , then
    E-File
    .
  2. Select
    Attachments
    , then
    Summary
    .
  3. Select
    Attach PDF
    .
  4. Check the files names of your PDF attachments meet the following e-file requirements:
    1. 23 characters or less.
    2. No spaces.
    3. No special characters.
  5. If you need to change the file name of an attachment, delete it, make the change, then reattach it.
  6. Do a
    Full Recompute
    , re-create the e-file, and resubmit the return.
