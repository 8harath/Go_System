R0000-503-02 e-file error

Error

'SpouseSSN' and 'SpouseNameControlTxt' in the Return Header must match the e-File database. (value #########, rule R0000-503-02)

Cause

The IRS e-file database includes a name control and Social Security number for each filer. This rejection means that the information sent in the e-file doesn't match what the IRS has in the database.

Solution

Make sure the spouse's social security number and last name are entered correctly:
  1. In the
    Organizer
    , select
    General Information
    , then
    Basic Return Information
    .
  2. Select
    Taxpayer Information
    .
  3. Make sure the
    First name
    ,
    Last Name
    , and
    SSN
     are correct.
  • If the information is correct, contact the IRS e-Help desk at 866.255.0654.
  • If the taxpayer and spouse recently married and the spouse hasn't changed their last name with the Social Security Administration (SSA), the taxpayer can contact the SSA at 800.772.1213.
  • If the return doesn't have a filing status of married filing joint or married filing separate, remove the spouse information from the return.
