# IND-181-01 e-file error

## Error

```
The Primary Taxpayer did not enter a valid Identity Protection Personal Identification Number (IP PIN). Please visit http://www.irs.gov/getanippin for further information and resubmit your return with the correct number.
```

## Cause

The taxpayer's return is missing their IP PIN or it's incorrect.

## Solution

Review the taxpayer's IP PIN information.

- Go to **Organizer**, **General Information**, **Basic Return Information**, and then **Taxpayer Information**.
- Review any entry in the **Identify protection PIN** field or enter their IP PIN.
- Perform a full re-compute, re-create the e-file, then re-submit.

note

If the taxpayer's IP PIN is unknown, the taxpayer can contact the IRS e-file Help Desk at 1-866-255-0654.
