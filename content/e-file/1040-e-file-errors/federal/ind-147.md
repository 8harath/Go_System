# IND-147 e-file error

## Error

```
Missing Data: /Return/ReturnHeader/Filer/PrimarySSN: The e-File database indicates a First Time Homebuyer Installment Payment is due for the Primary SSN. Include amount on 'FirstTimeHmByrRepaymentAmt' of the return and attach Form 5405 if required. (value #########, rule IND-147)
```

## Cause

The IRS has determined that the taxpayer on this return still needs to repay First-Time Homebuyer amounts.

## Solutions

If the taxpayer believes they don’t owe anything, they'll need to paper file or contact the IRS e-file help desk at 1-866-255-0654.

If the taxpayer does still owe, do the following:

- Go to the **Organizer**, then **Credits**.
- Open the Repayment of the First-Time Homebuyer Credit and review the data entry here. If there's missing or incorrect information, correct it.
- Do a full-recompute, recreate, and retransmit the e-file.
