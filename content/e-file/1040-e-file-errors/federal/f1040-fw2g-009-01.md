# F1040-FW2G-009-01 e-file error

## Error

```
1040 federal Reject: FW2G-009-01: Form W-2G Line 14 has an amount, but there is not a state or state identification number entered.
```

## Cause

The Form W-2G has an amount entered on Line 14 (State winnings), but the corresponding state information is missing. This error occurs when there are state-specific winnings reported, but the system cannot associate these winnings with a particular state due to the missing information.

## Solution

- Go to **Organizer**, then select **Source Documents (W-2, 1099s, 1098)**.
- Select**W-2G**.
- For each W-2G form that has an amount on line 14:


  - Locate line 13
  - Enter the name of the state
  - Enter the state identification number
- Repeat step 4 for all relevant W-2G forms.
- Save the changes.
- Recompute the return.
- Attempt to e-file again.
