FW2-499 e-file error

Error

Form W-2, Line B 'EmployerEIN' is invalid for processing an Individual e-filed return. (value #########, rule FW2-499).
note
The value represents the EIN causing the rejection.

Cause

The IRS doesn't recognize an employer EIN used in this return.

Solution

  1. Go to the
    Organizer
    , open
    Source Documents
     (W-2, 1099, 1098).
  2. Check that all SSNs and EINs are correct.
  3. Contact the IRS e-Help desk at (866) 255-0654 or paper file the return if the SSNs and EINs are correct.
