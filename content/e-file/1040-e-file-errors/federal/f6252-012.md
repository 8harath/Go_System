# F6252-012 e-file error

```
Form 6252, PropSoldRltdPartyMrktblSecInd must not have a choice of "Yes" and "No" indicated.
```

This happens when Form 6252, PropSoldRltdPartyMrktblSecInd has **Yes** and **No** indicated.

## Solution 1

To fix this:

- Go to **Tax Forms**, then **Federal**, and select **6252 - Prior Yr - Installment Sale**.
- On **Page 1**, locate Line 4 and remove the "X" from the tax form where "No" is currently marked.
- Perform a full recompute and recreate the e-file.

## Solution 2

If the error persists:

- Go to the **Organizer** under **Gains and Losses**, then to **Installment Sales**, select **Prior Year-Other**, and go to **Property**.
- Locate the question Was property sold a marketable security?
- Verify that the selection defaults back to **BLANK**, ensuring that there should not be an X marked either for **Yes** or **No**.
- Either change the answer at this location or manually remove the X on Line 4 again.
- Perform a full recompute and recreate the e-file.
