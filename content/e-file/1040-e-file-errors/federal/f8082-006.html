F8082-006 e-file error

Error

If Form 8082, 'AARAdjImputedUnderpaymentInd', is checked "No", then a binary attachment document with Description "8082 Signature Document" must be present.

Cause

A PDF attachment is missing for Form 8082.

Solution

  1. Select
    Tax Forms
    , then
    Federal
    .
  2. Select
    8082 - Notice of Inconsistent Treatmen
    , then the name of the entity.
  3. If
    No
     is entered in Item E, attach 8082 Signature Document.pdf with the federal e-file.
  4. Print Form 8082 from the return and save it as a PDF.
  5. Rename the PDF to 8082 Signature Document.pdf.
  6. Go to
    Organizer
    , then select
    E-file
    .
  7. Select
    Attachments
    , then
    PDF attachments
    .
  8. Select
    Attach PDF
    , then
    Add
    .
  9. Select
    Federal
     from
    Attachment Jurisdiction
    .
  10. Attach the PDF and select
    8082 Signature Document
     from
    Predefined description
    .
  11. Upload the PDF.
  12. Do a
    Full Recompute
    , re-create the e-file, and resubmit.
