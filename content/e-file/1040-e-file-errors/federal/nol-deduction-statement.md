# E-file diagnostic: NOL Deduction statement

Learn how to complete the required Net Operating Loss (NOL) deduction statement when Schedule 1, line 8a contains an NOL deduction amount to resolve e-file errors.

```
Schedule 1: If there is a net operating loss deduction amount on line 8a, then the net operating loss carryforward deduction statement must have data in order to e-file. Navigate to Organizer \ Income \ Miscellaneous Income \ Miscellaneous Income \ Miscellaneous Income \ Button for NOL Statement (Rule Numbers: IND-368-01)
```

## Cause

This diagnostic occurs when Schedule 1, Line 8a has an amount but the data entry for the NOL deduction statement is missing.

## Solution

- Go to 

  **Tax forms****Federal****Sch 1**

   and confirm that **Line 8a** has an amount.

  note

  If no amount is present on Schedule 1, Line 8a, then the NOL Deduction statement should be blank.
- Go to 

  **Organizer****Income****Miscellaneous income**

  .
- Then go to **Miscellaneous income**, select **Miscellaneous income**.
- In the **Net Operating Loss** section, select **NOL Deduction Statement – Required**.
- Make the necessary data entries.
- Do a full recompute then recreate and resubmit the return.
