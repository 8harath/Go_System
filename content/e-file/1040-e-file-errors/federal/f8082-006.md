# F8082-006 e-file error

## Error

```
If Form 8082, 'AARAdjImputedUnderpaymentInd', is checked "No", then a binary attachment document with Description "8082 Signature Document" must be present.
```

## Cause

A PDF attachment is missing for Form 8082.

## Solution

- Select **Tax Forms**, then **Federal**.
- Select **8082 - Notice of Inconsistent Treatmen**, then the name of the entity.
- If **No** is entered in Item E, attach 8082 Signature Document.pdf with the federal e-file.
- Print Form 8082 from the return and save it as a PDF.
- Rename the PDF to 8082 Signature Document.pdf.
- Go to **Organizer**, then select **E-file**.
- Select **Attachments**, then **PDF attachments**.
- Select **Attach PDF**, then **Add**.
- Select **Federal** from **Attachment Jurisdiction**.
- Attach the PDF and select **8082 Signature Document** from **Predefined description**.
- Upload the PDF.
- Do a **Full Recompute**, re-create the e-file, and resubmit.
