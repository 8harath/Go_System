# F1040NR-017 e-file error

## Error

```
Form 1040NR, WithholdingTxFrom8805Amt must be equal to the sum of all Forms 8805, TotalAllowedTaxCreditAmt (rule F1040NR-017)
```

## Cause

There's a difference between Form 1040NR and Form 8805 in this return, usually from forced data entry or a missing form.

## Solution

- Go to **Tax Forms**, then **Federal**.
- Select **1040NR - Nonresident Alien Income Tax**, then **Pages 1–5**.
- On **page 2**, line 62b (**Form 8805**), check if there's a manual data entry.
- If so, check it's correct and that Form 8805 is included with the return.
- Go to the **Organizer**, then select **Income**.
- Select**Schedule K-1**, then the entity.
- If the **Foreign Partners information** area is blank and the 8805 must be included, complete this information.
- Run a **Full Recompute**, re-create the e-file, and resubmit the return.
