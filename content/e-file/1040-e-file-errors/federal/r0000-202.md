# R0000-202 e-file error

## Error

```
If Form 965 is present in the return, then Form 965-A must be present. (rule R0000-202)
```

## Cause

Form 965-A is missing from the return.

## Solution 1: Forms 965 and 965-A aren't needed

- Go to the **Organizer**, select **Income**, then **§965 Inclusion of Deferred Foreign Inc**.
- Review the fields in this folder for accuracy. Remove any unnecessary data entry.
- Recompute, recreate, and re-transmit the return.

## Solution 2: Forms 965 and 965-A are needed

- Go to the **Organizer**, select **Income**, then **§965 Inclusion of Deferred Foreign Inc**.
- Select **Payment Information**, then **2019 Inclusion Payment Information**.
- Review the data entry on this screen. If no amounts are relevant, then **NONE** in those fields.
- Recompute, recreate, and re-transmit the return.
