# F1116-004-02 e-file error

## Error

```
Form 1116 E-file: If Form 1116/1116AMT Line 10 has a non-zero value, then a PDF is required to be attached, with the description ‘Form 1116ScheduleB,’ and Section 951A income type must not be checked.
```

## Cause

Form 1116, line 10 has an amount greater than 0 so you must add an attachment.

## Solution

Review Form 1116, line 10 for accuracy. If the amount is indeed greater than 0 and is correct, follow these steps to add an attachment to the return.

- Go to **Organizer**, **E-file**, **Attachments**, **PDF Attachments**, **Summary**, and select **Attach PDF**.
- Select **Add**.
- Select Federal in the **Attachment Jurisdiction** dropdown.
- Select **Browse for file** and attach a Form 1116, Schedule B PDF.
- Select **Form1116ScheduleB** in the **Predefined description** dropdown.
- Select **Upload**, and then **Done**.
- Perform a full re-compute, re-create the e-file, then re-submit.
