E-file diagnostic: Balance or refund change

Recreate your e-file when the balance due or refund amount changes to ensure the electronic file matches the current return.
Electronic Filing: The balance due or refund changed since you last created an electronic file. Recreate the electronic file to match the current return.

Solution

Recreate the e-file to ensure it contains the current balance due or refund amount and matches the return data.
note
This diagnostic may not disappear after recomputing. After you recreate the e-file, review and verify the return. Submit the return if the e-file is accurate.
