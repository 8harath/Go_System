# R0000-500-01 e-file error

## Error

```
'PrimarySSN' and 'PrimaryNameControlTxt' in the Return Header must match the e-File database. (value #########, rule R0000-500-01)
```

note

The value represents the Social Security number of the person causing the rejection.

## Cause

The IRS e-file database includes a name control and Social Security number for each filer. This rejection means that the information sent in the e-file doesn't match what the IRS has in the database.

## Solution

- Go to the **Organizer**, then **General Information**.
- Select **Basic Return Information**, then **Taxpayer Information**.
- Make sure the **First name**, **Last Name** and **SSN** are correct.
- If any field was incorrect, correct it. Then recompute the return, recreate the e-file, and submit the return.
- If the name and SSN are already correct:


  * If the taxpayer has multiple last names, refer to the Individual Name Control section of [Publication 4164](https://www.irs.gov/pub/irs-pdf/p4164.pdf). You may need to enter their name differently to correct this rejection.
  * Contact the IRS e-help desk at 866.255.0654 for more information.
