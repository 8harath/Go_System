E-file diagnostic: Form ESW is under development

Montana ESW: Montana Form ESW is currently under development, we will update the system as soon as possible.
This happens when the Form ESW is currently under development.

Solution

To file the return without this form, you can suppress it.
  1. In Organizer, select
    States
    , then
    Common State
    .
  2. Select
    Estimates
    , then
    Estimate Options
    .
  3. Select
    Montana
    .
  4. Select option 2 to
    suppress compute and print of Form ESW
    .
  5. Do a full recompute and recreate the e-file.
