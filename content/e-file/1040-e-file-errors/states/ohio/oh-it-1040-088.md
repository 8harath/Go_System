# OH-IT 1040-088 e-file error

## Error

```
The Total Pass-Through Entity credit claimed must equal the sum the total amount of Ohio Tax Paid from all K-1s. Please correct and retransmit. (OH-IT1040-088)
```

## Cause

A Form K-1 is required for one or more of the refundable credits you're claiming.

## Solution

- In the **Organizer**, go to **Income**.
- Select **Schedule K-1**, then the appropriate K-1.
- Select **State Information**, then **State Allocation of Inc/Ded/Withholding**.
- In the State Allocation spreadsheet, select the **State Whld and Tax Exempt Int** tab.
- Review information entered for Ohio.
- Complete a Full Recompute, and recreate the XML.
- Resubmit the return.
