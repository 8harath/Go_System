E-file diagnostic Ohio IT 1040 W-2 information

Ohio IT 1040: Ohio includes all W-2 information in the efile. Local wages (box 18) and local income tax withholding (box 19) are present but locality name (box next to 20) and/or the State Code (box 15) are not present. Locality name can be typed in the "MS paper returns or Efile only' column under Organizer / Source Documents / W-2 / Boxes 15-20 section. The State Code can be selected from the drop down box 15 in this same section. Please note that the state of Ohio requires this information regardless of the state where the Local Wages / Withholding occurred. OHCOM-036
This happens when there is state income and withholding for Ohio but boxes 18, 19 and 20 are incomplete.

Solution

  1. In Organizer, select
    Source Documents (W-2, 1099s, 1098)
    ,
    W-2, [Name]
    .
  2. Select the
    W-2
     tab.
  3. Enter amounts in lines 18 and 19.
  4. Select an option from the dropdown for line 20.
  5. Do a full recompute and recreate the e-file.
