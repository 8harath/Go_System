# OH-IT 1040-087 e-file error

## Error

```
You are claiming a refundable credit that requires K-1 information to be entered. Please enter the K-1 information and retransmit. (OH-IT1040-087)
```

## Cause

A Form K-1 is required for one or more of the refundable credits you're claiming.

## Solution

- In **Organizer**, go to **Income**.
- Select **Schedule K-1**, then the appropriate K-1.
- Choose **State Information**, then **State Allocation of Inc/Ded/Withholding**.
- In the State Allocation spreadsheet, select the **State Whld and Tax Exempt Int** tab.
- Enter information for Ohio.
- Complete a Full Recompute, and recreate the XML.
- Resubmit the return.
