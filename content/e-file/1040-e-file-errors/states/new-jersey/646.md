# 646 e-file error

```
NJ-1040NR Total Tax, Penalty contains Invalid +/or Missing Req. Data
```

This happens when the total tax and penalty contains invalid or missing data.

## Solution

- In Organizer, select **States**, then **New Jersey**.
- Select **Penalties and Interest**.
- Go to the **Compute Other Penalties and Interest** section.
- Clear any marked checkboxes.

  note

  These can't be marked when e-filing.
- Do a full recompute and recreate the e-file.
