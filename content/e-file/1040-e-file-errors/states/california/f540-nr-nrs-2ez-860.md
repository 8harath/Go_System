# F540/NR/NRS/2EZ-860 e-file error

```
California Electronic Funds Withdrawal Date: Please make sure you indicated an Electronic Funds Withdrawal date from your bank account between 01/02/YYYY and 10/15/YYYY. If you want to avoid late penalties and interest, you must indicate an Electronic Funds Withdrawal date on or before 04/18/YYYY. Please enter the date in Organizer/Common State/ Bank Information/Return Tab. Rule Number: F540/NR/NRS/2EZ-860
```

## Solution

To resolve:

- Go **Organizer**, **States**, **Common State**, **Bank Information**.
- Change the dates to match with mentioned in this error or paper file the return.
