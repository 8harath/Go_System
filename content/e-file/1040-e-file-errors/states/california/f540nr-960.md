# F540NR-960 e-file error

```
If Form 540NR Line 91 [SharedResponsibilityPenalty] is present, then Form 353 must be attached.
```

## Solution

To resolve:

- Go to **Organizer**, **States**, **California**, **Health Care**, and then **Shared Responsibility Penalty**.
- In the **Full Year Coverage Declaration** section:


  - Select yes if there's full year coverage.

    important

    If yes was already selected, select N/A and then re-select Yes. Next move on to step 3.
  - Select no, if applicable, and the system will determine if a shared responsibility penalty is to calculate.
- Perform a full re-compute, re-create the e-file, then re-submit.
