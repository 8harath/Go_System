CA extensions: General partner's phone number must be present e-file error

Resolve the California 1065 extension e-file error by entering the General Partner's phone number in Signature Information.

Error message

CA Extensions: General Partner's phone number must be present. Navigation: Organizer>States>Common State>General Information>Basic Return Information>Signature Information tab

Solution

California requires the General Partner's phone number to e-file the extension. Use the following steps to resolve this issue.
  1. Go to
    Organizer
    States
    Common State
    General Information
    Basic Return Information
    .
  2. Select the
    Signature Information
     tab.
  3. In the row for California, enter a
    Phone Number
     in column G.
  4. Do a full recompute on the return.
  5. Recreate the extension e-file.
