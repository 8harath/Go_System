# F540NR-800 e-file error

```
* F540NR-800: If Form 540NR, Line 123 [EstimatedTaxPenalty] amount is significant and indicates Form 5805, then Form 5805 must be attached.
```

## Solution

To resolve:

- Go to **Organizer**, **States**, **California**, **Penalties and Interest**.
- Select **Penalties and Interest**.
- In the **Underpayment of Estimated Tax** section, select **Suppress penalty computation and do not print form**.
- Perform a full recompute, recreate the e-file, and resubmit.
