# F3801-020/020NR e-file error

```
Rule Number F3801-020
California Form 3801: Federal rent/royalty/pass through income on Form 3801, page 2, line 2d does not equal federal rent/royalty/pass through income on Schedule CA, Section B, line 5, column A. If a full compute doesn't clear this diagnostic, review Form 3801 and Schedule CA.
```

```
Rule Number F3801-020NR
If Form 3801, Side 2, Line 2d amount is significant, then amount must equal Schedule CA (540NR), Part II, Section B, Line 5, column A.
```

This happens when the amount from Form 3801, page 2, line 2d doesn't match Schedule CA, section B, line 5, column A.

## Solution

To clear this diagnostic:

- Go to **Tax Forms** and select **States** then **California**.
- In the **Part-year Resident/Nonresident** folder, select **3801 - Passive Activity Loss Limitation**.
- Select **As if a resident**, then **Passive Activity Loss**.
- On the **Page 2** tab, and make note of the amount on page 2, line 2d.
- Next go to **Tax Forms**, **States**, **California**, **Part-year Resident/Nonresident**, and then **Sch CA(540NR) - Adjustments**.
- Review the amount on Part II, Section B, line 5, column A. If it doesn't match Form 3801, enter an override.
- Perform a full re-compute, and re-create the e-file.
