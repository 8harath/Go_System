# F3853-020 e-file error

```
* F3853-020: If Form 3853 Part II Line 1 [IncomeBelowFilingThreshold] is not checked, then Part III [CoverageExemptionClaimed] must be present.
```

This happens when there's no full year health care coverage, and yet health care information's needed for each taxpayer and dependent.

## Solution

To resolve, choose one of the following based on the return's situation:

* Go to **Organizer**, **States**, **California**, **Health Care**, and then **Shared Responsibility Penalty**.


  + Enter coverage information for both the taxpayer, spouse, and dependent(s), including start and end months, or
  + Select **Yes** for **Full year Coverage Declaration**.
* Perform a full recompute, recreate the e-file, and then resubmit.
