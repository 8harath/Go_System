# e-filing W-2, boxes 15 and 16

```
Massachusetts W-2 entry: To e-file the state of Massachusetts, W-2 box 15 and Box 16, State and State Wages must be present. Please review the W-2 input. The State of Massachusetts verifies all income based off entries in the State Information Section of the W-2. Massachusetts assumes all income earned in any state will be associated with that state. If W-2 does not have any Massachusetts taxable wages go to Organizer/States/E-file/Additional Information and indicate W-2 does not contain state income.
```

This happens because Massachusetts requires W-2 wages to carry from boxes 15 and 16. If the W-2 doesn't have amounts in those boxes, the state advises to request a corrected W-2. All income should be reported in the state earned, not state taxable.

note

* NONE is not a valid entry.
* This can happen to other states, not just Massachusetts.

## Solution

To correct this error:

- Go to **Organizer**, **States**, **Massachusetts**, **E-File**, and then **Additional Information**.
- Select **W-2 contains no Massachusetts taxable income**.
- Perform a full re-compute, re-create the e-file, then re-submit.
