E-file diagnostic: Driver license/ID last four characters

Add driver's license or state ID information to resolve this Colorado e-filing diagnostic.
You may see this error message:
Colorado Electronic Filing: Failure to include the driver license/ID last four characters, state of issue, and/or date of issue may delay the processing of the return.
Colorado requires driver's license or state ID information for e-filed returns. This diagnostic appears when the required information is missing or incomplete.
  1. Go to
    Organizer
    General Information
    Basic Return Information
    Taxpayer Information
    .
  2. Complete the
    Driver's license or state issued ID number
     field.
    Enter the last 4 characters, state of issue, and date of issue.
  3. Recompute the return to clear the diagnostic.
