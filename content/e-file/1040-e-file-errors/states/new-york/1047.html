1047 e-file error

New York - Form IT-225: You have one of the following item for other additions or other subtractions. State did not assign specific code for these items. Code is always required for efile. You can't e-file this return. (Reject Code 1047) * Miscellaneous additions, Miscellaneous subtractions, Adjustment for income coded exempt for state purposes, Adjustment to income/loss from pass through entities (K-1 "State if different").
This happens when Form IT-225 – NYS Modifications Schedule A and B have an amount but the code is missing for an amount.

Solution 1

Look for overrides or accidental entries in Schedule A:
  1. In Tax Forms , select
    States
    , then
    New York
    , then
    Resident
    .
  2. Select IT-225 – NYS Modifications, Page 1, Schedule A, Part 1, line 1, select the
    Details
    hyperlink.
  3. Clear any overrides and remove the amount on
    Adjustments for income coded exempt for state purposes
     since there is no code associated with this line.
  4. To edit this line, go to Organizer, select
    States
    , then
    New York
    , then
    Part-year/Nonresident Allocation
    .
  5. Select the
    Part-year/Nonresident Allocation
     tab, and then the Other Additions (New York Column).
  6. Perform a full recompute and recreate the e-file.

Solution 2

Look for overrides or accidental entries in Schedule B:
  1. In Tax Forms, select
    States
    New York
    .
  2. Select Resident, IT-225 – NYS Modifications, Page 2, Schedule B, Part 1, line 10, then select the
    Details
    hyperlink.
  3. Clear overrides and amounts on
    Adjustments for income coded exempt for state purposes
    . Remove the amount since there is no code associated with this line.
  4. To edit this, go to Organizer, select
    States
    , then
    New York
    , then
    Part-year/Nonresident Allocation
    .
  5. Select the
    Part-year/Nonresident Allocation
     tab.
  6. Go to
    Other Subtractions (New York Column
    ) and edit the amount.
  7. Perform a full recompute and recreate the e-file.
    note
    Per the state e-file schema, there are no assigned codes for the following items:
    • Miscellaneous additions
    • Adjustments for income coded exempt for state purposes
    • Miscellaneous subtractions
    • Adjustments to income/loss from pass-through entities (K-1 “State if different).
