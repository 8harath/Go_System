1048 e-file error

New York - Form IT-201/IT-203: As a preparer you must enter a NYTPRIN or an exclusion code. (Reject Code 1048)
This happens when a NYTPRIN or an Exclusion Code is missing.

Solution

  1. In Organizer, select
    General Information
    , then
    Basic Return Information
    .
  2. Select
    Paid Preparer Information
    , then
    Paid Preparer Information
    .
  3. In the State specific preparer ID number section:
    1. Select
      Preparer code for this return
       or,
    2. Select
      State Specific Preparer ID Numbers
      , then
      New York Exclusion Code
       or,
    3. Select
      Exclusion Code
       and enter the
      New York NYTPRIN
      .
  4. Do a full recompute and create the e-file.
