# 1048 e-file error

```
New York - Form IT-201/IT-203: As a preparer you must enter a NYTPRIN or an exclusion code. (Reject Code 1048)
```

This happens when a NYTPRIN or an Exclusion Code is missing.

## Solution

- In Organizer, select **General Information**, then **Basic Return Information**.
- Select**Paid Preparer Information**, then **Paid Preparer Information**.
- In the State specific preparer ID number section:


  - Select **Preparer code for this return** or,
  - Select **State Specific Preparer ID Numbers**, then **New York Exclusion Code** or,
  - Select **Exclusion Code** and enter the **New York NYTPRIN**.
- Do a full recompute and create the e-file.
