E-file diagnostic: 149/4079

New York Electronic Return Signature: The E-File signature authorization for this return is incomplete. The ERO and Preparer must 'sign' this return by making a selection in the Persons Electronically Filing Main Return (Mandatory) area. GoSystem is professional software and ERO indicator is mandatory. Self-prepared by Taxpayer or Spouse option will not applicable. These fields are found by going to Organizers / States / New York / Electronic Filing / Additional Information tab. You can put "Self Prepared" for the name. (Reject code 149/4079)
This happens when the New York e-file is created, but the return signature section has not been filled out.

Solution

  1. In Organizer, select
    States
    , then
    New York
    .
  2. Select
    E-file
    , then
    Additional information
    .
  3. If this is for an extension, in the section Signature Authorization,
    Person(s) electronically filing extension (mandatory)
    , select
    ERO
    . You need to have a selection and can't leave this as Not Applicable.
  4. For the option,
    ERO Certification
    , select
    I have read the certification above and agree
    .
  5. If this is for the return, go to the Return section, for the option
    Person(s) electronically filing main return (Mandatory)
     select an option other than Not Applicable.
  6. For the option
    ERO / Preparer certification
    , select
    I have read the certification above and agree
    .
  7. If the name of the ERO and Preparer are not the same, enter the name of the ERO.
  8. Do a full recompute and recreate the e-file.
