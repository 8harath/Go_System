# R0149 e-file error

This happens when the ERO signature authorization isn't selected for a New York e-filed return. Select the signature authorization to ERO before you resubmit.

## Error message

```
State NY Severity C State Record Record Name 0 Form Occurrence No 0 Field Seq No 0 Page No 1 Reject Code R0149 Rule Number R0149 Error Message ERO Signature Indicator not set
```

- Go to 

  **Organizer****States****New York****E-file****Additional information****Extension****Signature authorization**

  .
- Select **ERO**.
- Do a full recompute and recreate the e-file to submit.Resubmit the return.
