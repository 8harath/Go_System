# E-file diagnostic: Supported source documents are W-2, 1099-R, 1099-Misc, etc.

```
This return cannot be electronically filed and will be rejected. Return must be paper filed. E-file supported source documents are W-2, 1099-R, 1099-Misc, W2-G and 1099-G.
```

This happens when the tax return includes withholding information from documents that are not supported for e-filing in Indiana, such as documents other than W-2, 1099-R, 1099-Misc, W2-G, and 1099-G.

## Solution 1

To correct withholding sources for e-filing:

- In Tax Forms, select **States**, then **Indiana**.
- Select **Part-year Resident/Nonresident** , then **Sch F - Credits**, then drill down on line 1.
- Review the withholding sources and ensure that all of them are from W-2, 1099-R, 1099-Misc, W2-G, or 1099-G.
- Remove any withholding amounts reported from Schedule K-1s.
- Perform a full recompute and recreate the e-file.

## Solution 2

If you need to include withholding from Schedule K-1s you can't file the return electronically. You'll need to paper file the return to include the withholdings.
