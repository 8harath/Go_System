# 1280 e-file error

```
Idaho Form 43 Line 68: An income tax withheld from K-1 has been entered which indicates that a copy of Form(s) ID K-1 needs to be included with the tax return. This tax return cannot be e-filed. (Reject Code 1280)
```

This happens when there is withholding from a Schedule K-1 so the Form ID K-1 must be included but is not supported.

## Solution

- In Tax Forms, select **States**.
- Select **Part-year Resident/Nonresident**, then **43 – Income Tax Return**.
- Select **Page 3**, then line 68.
- If there is tax withheld on the Idaho return from a Schedule K-1, then Form ID K-1 must be attached. This form is not available in the system so you need to remove the amount or paper file the return.

  note

  PDF attachments of the ID K-1 will not clear the diagnostic.
- Do a full recompute and recreate the e-file.
