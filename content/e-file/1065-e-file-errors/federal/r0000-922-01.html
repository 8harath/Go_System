R0000-922-01 e-file error

Error

Filer's EIN and Name Control in the Return Header must match data in the e-File database, unless "Name Change" or "Name or Address Change" checkbox is checked, if applicable. (value #########, rule R0000-922-01)

Cause

The IRS e-File database has a different EIN and Name Control combination on file.

Solution

  1. Address or name change:
    1. If the partnership changed its address or name, go to
      Organizer
      , then
      General Information
      .
    2. Select
      Basic Return Information
      .
    3. Mark the
      Address change or Name change
       checkbox.
  2. Check the name control:
    1. Go to
      Organizer
      , then
      Federal E-file
      .
    2. Select
      Additional Information
      , then
      Business Name Control
      .
    3. If the
      Business name control (Override)
       field is completed, review Publication 4163 and make sure it's correct.
  3. Check the EIN:
    1. Go to
      General Information
      , then
      Basic Return Information
      .
    2. Make sure that the EIN field is correct.
  4. If you correct any field, do a
    Full Recompute
    . Then create the e-file and submit the return.
  5. If you aren't overriding the name control and the EIN is correct, call the IRS e-help Desk at 866.255.0654, and have them verify the client's EIN.
