# R0000-922-01 e-file error

## Error

```
Filer's EIN and Name Control in the Return Header must match data in the e-File database, unless "Name Change" or "Name or Address Change" checkbox is checked, if applicable. (value #########, rule R0000-922-01)
```

## Cause

The IRS e-File database has a different EIN and Name Control combination on file.

## Solution

- Address or name change:


  - If the partnership changed its address or name, go to **Organizer**, then **General Information**.
  - Select **Basic Return Information**.
  - Mark the **Address change or Name change** checkbox.
- Check the name control:


  - Go to **Organizer**, then **Federal E-file**.
  - Select **Additional Information**, then **Business Name Control**.
  - If the **Business name control (Override)** field is completed, review Publication 4163 and make sure it's correct.
- Check the EIN:


  - Go to **General Information**, then **Basic Return Information**.
  - Make sure that the EIN field is correct.
- If you correct any field, do a **Full Recompute**. Then create the e-file and submit the return.
- If you aren't overriding the name control and the EIN is correct, call the IRS e-help Desk at 866.255.0654, and have them verify the client's EIN.
