# F1065-053-01 e-file error

## Error

```
If Form 1065, Line 2 'CostOfGoodsSoldAmt' has a non-zero value, then it must equal Form 1125-A, Line 8 'CostOfGoodsSoldAmt'.
```

## Cause

The amount on Form 1065, line 2, doesn't match an amount that should be reported on Form 1125-A, line 8. This may be due to incorrect data entry or a missing Form 1125-A.

## Solution

- Go the **Organizer**, then **Ordinary Income and Deductions**.
- Select **Income Summary**, then the **Cost of Goods Sold** tab.
- Select the **Force print Form 1125-A** option.
