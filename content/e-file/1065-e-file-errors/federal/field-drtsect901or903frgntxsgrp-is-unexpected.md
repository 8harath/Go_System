# E-file error: Field 'DrtSect901Or903FrgnTxsGrp' is unexpected

```
Field 'DrtSect901Or903FrgnTxsGrp' is unexpected
```

## Solution

- Go to 

  **Organizer****Foreign Information****Ptr Distributive Share-International****Foreign Taxes-III****Taxes Reduction and Other Cat Codes****Direct (section 901 or 903) foreign taxes**

  .
- Select an option for either **Paid** or **Accrued**.
- Do a full re-compute, recreate the e-file, and resubmit.
