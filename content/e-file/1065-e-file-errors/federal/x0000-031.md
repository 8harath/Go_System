# X0000-031 e-file error

## Error

```
Zip Entry names must conform to the guidelines in Publication 4164.
```

## Cause

A PDF attached to the return has an improper name or title.

## Solution

- Go to **Organizer**, then **Federal E-File**.
- Select **Attachments**, **PDF Attachments**, then **Summary**.
- Select **Attach PDF**. Review your PDF attachments for the following e-file requirements:


  * Shorten the name of the attachments. File names should be 23 characters or less.
  * Remove any spaces in the name.
  * Remove any special characters.
- Delete and reattach PDFs with changed file names.
