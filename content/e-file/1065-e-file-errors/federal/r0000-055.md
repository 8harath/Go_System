# R0000-055 e-file error

```
If "Binary Attachment 8453 Signature Document" is selected a Binary attachment with a description of "8453 Signature Document" must be attached. Select the Predefined Title: Edit - Insert - Efile Attachments
```

The e-file's missing the PDF attachment for Form 8453, the PDF attached is a fillable input form, or the PDF attachment is password-protected.

## Solution

- Go to **Organizer**, **Federal E-file**, **Attachments**, **PDF Attachments**, and then **Summary**.
- Select **Add PDF** to attach Form 8453 to the e-file.
- Select **8453 Signature Document** in the predefined field.
- Do a full re-compute, recreate the e-file, then resubmit.
