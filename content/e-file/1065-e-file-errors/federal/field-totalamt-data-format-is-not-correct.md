# E-file error: The field 'TotalAmt' with value '-1', data format is not correct

```
The field 'TotalAmt' with value '-1', data format is not correct.
```

The aggregation attachment can't contain negative amounts.

## Solution 1

- Go to **Organizer**, **Federal E-File**, **Attachments**, **K-1 Aggregation**, **K-1 Aggregation**.
- Correct the attachment so it doesn't contain negative amounts.

  note

  You can change the amount to NONE. If None isn't accepted, do a space override so that it will be blank.
- Delete the original aggregation file and upload the corrected file.
- Do a full re-compute, recreate the e-file, and resubmit.

## Solution 2

If you want to keep the negative amounts, you'll need to file the return on paper.
