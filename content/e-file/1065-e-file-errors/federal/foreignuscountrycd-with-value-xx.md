# E-file error: The field 'ForeignUSCountryCd' with value 'XX', data format is not correct

```
The field 'ForeignUSCountryCd' with value 'XX', data format is not correct.
```

## Solution

- Go to 

  **Organizer****Foreign Information****Ptr Distributive Share-International****Foreign Tax Credit Limitation-II****Gross Income****By Country****XX**

  .
- Go to the COUNTRY CODE OR CATEGORY CODE OR CODE XX (MANDATORY (SEE BELOW)) section.
- Make a selection for **Country**.
- Do a full re-compute.
- Change **Country** to **(None selected)**.

  note

  If the client is using a Direct K-1 or K-1 aggregation file, correct the import file and reimport.
- Do a full re-compute, recreate the e-file, and resubmit.
