# SK2-F1065-019 e-file error

```
Severity
Reject
Form No SK2-F1065
Record Name IRS1065ScheduleK2
Form Occurrence No 0
Field Seq No 0
Page No 1
Reject Code SK2-F1065-019
Rule Number SK2-F1065-019
XML Path /efile:Return/efile:ReturnData/efile:IRS1065ScheduleK2/efile:PartVIIIAttachedInd
```

You get this error when you need to make a selection for the Separate Category option. You must also enter the EIN or reference ID number.

## Solution

- Go to **Organizer** and select **Foreign information**.
- Select **Ptr Distributive Share international**, then **Pshp Int Foreign Cirp inc (960)-VIII**.
- Select**CFC name**, then **Pshp Int In Foreign corp inc-sec 960**.
- Make a selection for **Separate category**.
- Enter either the EIN or reference ID.
- Enter the foreign base company services income.
- Do a full recompute.
- Recreate the e-file.
