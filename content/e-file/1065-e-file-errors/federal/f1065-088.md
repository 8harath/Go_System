# F1065-088 e-file error

## Scenario

You may get the following error message if both Form 1065 AmendedReturnind and Form 8082, BBAAARind are selected, then Schedule K-1 (Form 1065) must not be present in the return.

**Error message**

```
If both Form 1065 AmendedReturnind and Form 8082, BBAAARind are selected, then Schedule K-1 (Form 1065) must not be present in the return.
```

## Solution

- Go the **Organizer**, then **General Information**, then **Return and Print Options**.
- Select **Sch K, K-1 and Activity Schedules** tab.
- In the **Print or Suppress** section, select **Suppress** for **Schedule K-1, partner activity schedules**....
- Then select **Tax Forms**, then **Federal**.
- Select **1065 - US Partnership Return of Income**, then **Page 1**.
- Go to Item 1 and override **Full Recompute**, then **Recreate E-file**.
- When you attach the document, select **User defined description**.
- Enter **8082 Signature Document** for the description.
