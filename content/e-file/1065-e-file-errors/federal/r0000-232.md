# R0000-232 e-file error

```
IRSResponsiblePrtyInfoCurrInd in the Return Header does not have a choice of "Yes" indicated. Therefore, (1) Form 8822BAttachedInd must be checked in the Return Header and (2) a binary attachment with description containing "Form 8822-B" must be present in the return. This return does not satisfy both conditions (1) and (2). IRS regulations require any entity with an EIN to update the Responsible Party information within 60 days of any change by filing Form 8822-B, Change of Address or Responsible Party - Business.
```

## Solution

This is an informational alert. You can submit the e-file.
