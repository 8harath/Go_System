# R0000-058-01 e-file error

## Error

```
An XML document that represents a binary attachment must have a valid reference to an attached file. (value, rule R0000-58-01)
```

note

The value will represent the PDF attachment causing the rejection.

## Cause

The file name of the PDF attachment doesn't meet e-filing requirements.

## Solution

- Go to the **Organizer**, then **Federal E-File**.
- Select **Attachments**, **PDF Attachments**, then **Summary**.
- Select **Attach PDF** and review your PDF attachments for the following e-file requirements:


  * Shorten the name of the attachments. The file names should be 23 characters or less.
  * Remove and spaces in the name.
  * Remove any special characters.
- Delete and reattach any PDFs with name changes.
- Do a **Full Recompute**, create the e-file, and submit the return.
