E-file diagnostic: Schedule K1- Partner Count

ScheduleK1- Partner Count Description: Number of Schedule K-1 included on Form 1065, Line I = 2 Number of IRS1065ScheduleK1 included in the XML file = 0 If these value
This diagnostic is caused by the mismatch of partner count.

Solution

  1. Go to
    Organizer
    , then
    General Information
    .
  2. Select
    Basic Return Information
    , then proceed to the
    Entity Information
     tab.
  3. Remove any entry in
    Number of partners in partnership (Override)
     in the section for Number of Partners.
  4. Do a full recompute and recreate the e-file.
