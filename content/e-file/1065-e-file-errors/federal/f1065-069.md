# F1065-069 e-file error

```
F1065-069: If Form 1065, Item F, "Total Assets" is equal to or greater than 50,000,000, then Schedule C (Form 1065) must be present in the return and Item J, 'ScheduleCAndScheduleM3AttInd', checkbox must be checked. Navigation: Tax Forms\Federal\1065\Page 1, Item F
```

This happens when the total assets are greater than 50,000,000 and the M-3 is missing.

## Solution

- Go to **Organizer**, then **General Information** folder.
- Select the **Questions** folder.
- Go to **line 4 Miscellaneous Conditions** and mark the question **No**.
- If it is marked **No** already, change it to **Yes** with a full recompute, then back to **No**.
- Do a full recompute and recreate the e-file.
