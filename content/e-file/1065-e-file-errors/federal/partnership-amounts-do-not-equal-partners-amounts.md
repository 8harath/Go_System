# E-file diagnostic: Partnership amounts for Income do not equal total of partners amounts

```
Partnership amounts for Income do not equal total of partners' amounts: Please check the Reconciliation of Partnership to Partner Amounts.
```

This e-file error will show if the federal Partnership amounts for Income don’t equal total of partners' amounts or blank.

## Solution 1

Enable Partner Allocations:

- In Organizer, check if **Partner Allocations** are enabled. If not, select the checkbox for **Enable Partner Allocations**.
- Do a full recompute to apply the changes.

## Solution 2

Verify Override Amounts in Schedule K:

- Go to Organizer then **Sch K**.
- Make sure any overridden amounts match the amounts on Form 1065 Schedule K.
- Check Tax Forms for any overrides that affect the Schedule K.
- Do a full recompute to apply any changes.

## Solution 3

Review Income Summary for Allocation Codes:

- In Organizer go to **Sch K**, then **Income Summary** and open **Income summary**.
- If an allocation code for **Ordinary Income** has been entered read the associated warning for this item.
- Check for Over-Allocation in Income and Deduction Summary:


  - Go to Organizer then **Sch K**.
  - Select **Income Summary** then **Deduction Summary**
  - Make sure Allocation Codes haven’t been entered for total amounts and detail items that could cause overallocation.

    note

    * Don't allocate Other Interest income on the Income Summary tab.
    * Don't allocate detail lines for Other Interest Income on the Income Other Interest tab.
- Do a full recompute to apply any changes.
