# F1065-037-02 e-file error

```
If Form 1065, Schedule B, Line 15 has a non-zero value, then 1 or more Forms 8865 must be present in the return.
```

This happens when Form 1065, Schedule B, Line 15 indicates a Form 8865 is attached, but there isn't an attachment to the e-file.

## Solution

- Go to **Organizer**, **General Information**, and then **Questions**.
- Find question 15. Review your data entry.


  - If no Form 8865 needs to be attached, remove an amount entered in this field. You'll also want to review data entry in **Organizer**, **Federal E-file**, **International**, and then **Third Party XML**. Review the **Form 8865** section and the **Number of Forms 8865 attached through XML** field.
  - If 1 or more Form 8865 needs to be attached, attach the form to the e-file.
- Perform a full re-compute, re-create the e-file, then re-submit.
