# SM3-F1065-010-01 e-file error

```
SM3-F1065-010-01: If Schedule M-3 (Form 1065), Part I, Line 11, 'NetIncomeLossPerIncomeStmtAmt' has a non-zero value, then it must be equal to Part II, Line 26, column (a), IncomeLossPerIncomeStmtA.
```

This happens when in Federal Form 1065 Schedule M-3, Part 1, Line 11 not equal to Part 2, Line 26, Column A.

## Solution

- Go to 

  **Tax forms****Federal****Schedule M-3 and 8916-A**

   folder.
- Go to **Schedule M-3**, then **Page 1**.
- Make sure Part I Line 11 is not 0 or NONE.
- Then it must be equal to the amount at 

  **Tax forms****Federal****Schedule M-3 and 8916-A**

   folder.
- Compare the amount from Part I Line 11 against the Schedule M-3, Page 2, Line 26, Column A. The amounts should match.
- If the amounts aren’t supposed to match, go to 

  **Organizer****General Information****Questions**

   folder.
- Make sure to select **Yes** for **Question 4**.
- Do a full recompute and recreate the e-file.
