# E-file error: The field 'CountryCd' with value 'X', data format is not correct.

```
The field 'CountryCd' with value 'X', data format is not correct.
```

## Solution 1

- Go to **Organizer**, **Foreign Information**, **Foreign Corporation**, and select the partner name.
- Go to **Schedule Q**, **GEN**, **Tested Income Group**, then **Schedule Q, Line 3 - Tested Income Group**.
- Select the country.
- Do a full re-compute, recreate the e-file, and resubmit.

## Solution 2

- Go to **Tax Forms**, **Federal**, **Direct K-1 Import**, and select the partner name.
- Select **Import K1 Partner Information** and enter the correct country code.
- Check the partner's country code and foreign address information from the XML data imported.
- Reimport the Direct K-1.
- Do a full re-compute, recreate the e-file, and resubmit.
