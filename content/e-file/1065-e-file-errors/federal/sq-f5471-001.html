SQ-F5471-001 e-file error

SQ-F5471-001: Form 5471 Schedule Q SeparateCategoryCd has a value of "PAS", but PassiveCategoryIncomeGroupCd does not have a value for foreign corporation %S
This happens when no information is entered for question B about the foreign corporation.

Solution

  1. Go to
    Organizer
     and select
    Foreign Information
    , then
    Foreign Corporation
    .
  2. Select the company, then select
    Schedule Q
    .
  3. Select
    PAS
     then
    General Information
    .
  4. Enter information for question B.
