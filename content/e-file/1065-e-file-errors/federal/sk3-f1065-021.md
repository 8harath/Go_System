# SK3-F1065-021 e-file error

```
If Schedule K-3 (Form 1065), PartIXAttached has a choice of "Yes" indicated, then SchK3PartnerInfoBEATGrp must have a value.
```

This happens when the e-file doesn't include partner or K-3 information.

## Solution

- Go to **Organizer**, **General Information**, and then **Return and Print Options**.
- Select **Sch K, K-1 and Activity Schedules**.
- Make sure these items aren't suppressed. If they are, select **Print**.


  - Schedule K-1, partner activity schedules, and Schedule K-3
  - Partner activity schedules
- Next go to **Organizer**, **Partner Information**, **Common Partner Data**.
- Select **Common K-3 Print Options**.
- Select **All partners' Schedule K-3**.
- Perform a full re-compute, re-create the e-file, then re-submit.
