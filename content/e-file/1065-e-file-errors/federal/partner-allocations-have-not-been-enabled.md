# E-file diagnostic: Partner Allocations have not been enabled

```
Partner Allocations: Partner Allocations have not been enabled. Amounts will not be computed for the Schedule K-1s. To enable partner allocations, select Options from the menu bar and then select Partner Allocations.
```

This happens when the partner allocations have not been enabled.

## Solution

This is a severe diagnostic and doesn’t stop you from e-filling the return.

- Go to **Organizer**, then **Partner Allocations Disabled** folder.
- Mark the **Enable Partner Allocations** checkbox.
- Run a full recompute.

note

**Enable Partner Allocations** push the partner information into the tax forms, so if you are doing a direct K-1 import or a K-1 aggregation, then you don't need to mark this checkbox.
