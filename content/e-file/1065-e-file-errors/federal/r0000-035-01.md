# R0000-035-01 e-file error

## Error

```
The 'TaxPeriodEndDt' in the Return Header must be less than the Received Date. (value YYYY-MM-DD, rule R0000-035-01).
```

## Cause

The tax year-end date within the rejected return is after the date on which the electronic file was received by the IRS. For example, a fiscal year return with a year-end date of April 30 must be received by the IRS after April 30.

## Solution

Follow these steps to check the year end:

- Go to **Organizer**, then **General Information**.
- Select **Basic Return Information**.
- Verify that the date in the **Fiscal year ending** field is correct.


  - If the date is wrong, correct it. Then do a **Full Recompute**, create the e-file, and submit the return.
  - If the date is right, call the IRS e-help Desk and 866.255.0654 and verify what they have on their record.
