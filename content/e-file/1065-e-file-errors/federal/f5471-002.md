# F5471-002 e-file error

```
Form 5471: RuleNumber:F5471-002 If Form 5471, Item B, checkbox "3" is checked, then one or more "Category 3 Filer Statements" must be attached.
```

This happens when Form 5471 Item B box 3 is marked and a Category 3 Filer Statement is missing.

## Solution 1

To clear Form 5471 Item B, box 3:

- Go to the 

  **Organizer****Foreign Information****Foreign Corporation****NAME****Filer Information****Filer Information****Category of Filer**

  .
- Clear **Category 3 US person acquiring/disposing of 10% or more stock of a foreign corporation during the year**.
- Do a full-recompute and recreate the e-file.

## Solution 2

To attach a Category 3 Filer Statement:

- Go to 

  **Organizer****Federal E-file folder****Attachments****PDF Attachments****Summary**

  , then select **Attach PDF**.
- Select **Add**.
- For **Attachment Jurisdiction**, select **Federal**.
- Select **Browse for file**, then **Done**.
- Select **Upload**, then **Done**.
- Do a full recompute and recreate the e-file.

note

You also have the option to contact the IRS e-file help desk at 1-866-255-0654 to determine your best course of action.
