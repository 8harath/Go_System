# TTA-FBAR-AdditionalMessage e-file error

```
This FBAR had warning errors that must be re-filed as Amended reports correcting the errors. The errors can be corrected in this original locator, but the Amended box must be marked before e-file is re-created and resubmitted.
```

This happens when the e-file doesn't indicate an amendment.

## Solution

- Go to **Organizer**, **Foreign Information**, **Foreign Bank Account**, **Foreign Bank Account**, **FinCen - General Information**, then **General Information**.
- Select **Amended**.
- Enter all paid preparer firm and/or paid preparer information.
- Perform a full re-compute, re-create the e-file, then re-submit.

note

When an FBAR electronic file is conditionally accepted, this means the return was accepted but may be subject to additional review. It's not the default status. The status won't change, but the taxing agency may send a notice requesting additional information from the taxpayer.

At this time, no additional information has been given to OneSource/Gosystem for this. So you will need to wait if the return becomes accepted, or if they send a notice asking for additional information.

These FBARs require additional data entry and resubmission as amended FBARs. FinCEN recommends these are resubmitted within 30 days of the conditional acceptance.
