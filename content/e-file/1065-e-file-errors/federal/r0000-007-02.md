# R0000-007-02 e-file error

## Error

```
For US Addresses, the first five digits of 'ZipCd' of the Filer's address in the Return Header must be within the valid ranges of zip codes for the corresponding 'StateAbbreviationCd'. See Publication 4164. (rule R0000-007-02)
```

## Cause

A ZIP Code used in this return doesn't match the list of valid ZIP Codes for the state listed.

## Solution

- Go to **Organizer**, then **General Information**.
- Select **Basic Return Information**.
- Review the **State** and **ZIP** fields.
- Go to **Organizer**, then **General Information**.
- Select **Basic Return Information**, then **Paid Preparer/ERO Information**.
- Review the **State** and **ZIP** fields.
- **Full Recompute** the return, create the e-file, and submit the return.
