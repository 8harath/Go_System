# R0000-901-01 e-file error

## Error

```
Filer's EIN and Name Control in the Return Header must match data in the e-File database. (value #########, rule R0000-901-01)
```

## Cause

The IRS e-File database has a different EIN and Name Control combination on file.

## Solution

- Check the name control:


  - Go to **Organizer**, then **Federal E-file**.
  - Select **Additional Information**, then **Business Name Control**.
  - If the **Business name control (Override)** field is completed, review Publication 4163 and make sure it's correct.
- Check the EIN:


  - Select **General Information**, then **Basic Return Information**.
  - Make sure that the EIN field is correct.
- If you correct either field, do a **Full Recompute**. Then create the e-file and submit the return.
- If you aren't overriding the name control and the EIN is correct, call the IRS e-help Desk at 866.255.0654, and have them verify the client's EIN.
