F7004-011-03 e-file error

Error

Taxpayer EIN in the Return Header must not be the same as an EIN of a previously accepted electronic return for the return type and tax period and Type of Return Code indicated for the tax return type. (value #########, rule 7004-011-03)

Cause

An extension has already been accepted by the IRS using the EIN in this return.

Solution

  1. Go to
    Organizer
    , then
    General Information
    .
  2. Select
    Basic Return Information
    .
  3. Make sure the
    EIN
     is correct.
    1. If the EIN is wrong, correct it. Then do a
      Full Recompute
      , create e-file, and submit the return.
    2. If the EIN is correct, contact the IRS e-help Desk at 866-255-0654 to resolve the rejection.
