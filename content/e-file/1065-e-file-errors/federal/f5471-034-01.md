# F5471-034-01 e-file reject code

```
1065 Federal Reject Code F5471-034-01
```

This Requires the Category 3 Filer Statement to be populated.

## Solution

- In Organizer, go to 

  **Foreign Information****Foreign Corporation****Foreign Corporation****(Company)****Filer Information****Category 3 Filer Statement**

  .
- Add a new subscriber.
- Do a full re-compute and re-create the e-file.
