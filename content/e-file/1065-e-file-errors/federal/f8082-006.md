# F8082-006 e-file error

## Error

```
If Form 8082, AARAdjImputedUnderpaymentInd , is checked "No", then a binary attachment document with Description "8082 Signature Document" must be present.
```

## Cause

A PDF attachment is missing for Form 8082.

## Solution

- Go to **Tax Forms** and select **Federal**.
- Select **8082 - Notice of Inconsistent Treatment** and the name of the entity.
- If **Item E** is marked **No**, you'll need to attach the **8082 Signature Document.pdf** to send with the federal e-file.
- Print Form 8082 from the return and save it as a PDF.
- Rename the PDF file to **8082 Signature Document.pdf**.
- Go to **Organizer** and select **E-file**.
- Select **Attachments**, then **PDF attachments**.
- Select **Attach PDF**, then **Add**.
- Select **Federal** in the **Attachment Jurisdiction** field.
- Attach the PDF and select **8082 Signature Document** in the **Predefined description** field.
- Upload the PDF.
- Do a full recompute, re-create the e-file, and resubmit.
