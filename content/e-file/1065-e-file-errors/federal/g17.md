# G17 e-file error

## Error

```
The element is not recorded or does not contain a value (i.e. the value is null).
```

## Cause

The name or address for the foreign institution is missing.

## Solution

- Go to **Organizer**, then **Foreign Bank Account**.
- Select **FinCen**, then **Part V**.
- Open the financial institute information and correct the name and address fields.
- Do a full recompute, re-create the e-file, and resubmit.
