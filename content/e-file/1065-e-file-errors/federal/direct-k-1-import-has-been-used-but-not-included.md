# E-file diagnostic: Direct K-1 Import has been used but is not included in the federal e-file

```
Federal K-1 E-File: Direct K-1 Import has been used but is not included in the federal e-file. To include the direct K-1 in the federal e-file Go to Organizer Electronic Filing - Return Step 1 - Enable Electronic Filing Under Enable Electronic K-1 Filing, check the box to "Enable electronic file Schedule K-1's. If you do not wish to electronically file Direct K-1s check the box: "Do not include federal Direct K-1 in federal e-file" located in Organizer Partner Information Common Partner Data last tab Direct K-1 Import.
```

This happens when Direct K-1 import was used and was not suppressed in the Federal XML file.

## Solution

- In **Organizer**, select **Partner Information**, then **Common Partner Data**.
- Go to the **Direct K-1 Import** tab and look for the **Not Using Direct K-1 Import for Federal E-File** section.
- Mark the **Do not include Federal Direct K-1** checkbox in federal e-file.
- Do a full recompute and recreate the e-file.
