F7004-905-03 e-file error

Error

Database Validation Error: /Return/ReturnData/IRS7004/ExtensionReturnCd: In Form 7004, Line 1, 'ExtensionReturnCd' the return for which the extension is filed must match the return type established with the IRS for the EIN. (value xx, rule F7004-905-03)
note
The value represents the extension return code included in the e-file.

Cause

The form code listed on line 1 of Form 7004 doesn't match what the IRS e-file database has on file for the EIN included in the e-file.

Solution

  1. Go to
    Organizer
    , then
    General information
    .
  2. Go to
    Basic Return Information
    , then select the
    Entity Information
     tab.
  3. Check if the EIN is correct.
    1. If it's wrong, correct it, then do a
      Full Recompute
      , create the e-file, and submit the return.
    2. If the EIN is correct, contact the IRS e-Help Desk at 866.255.0654.
Verify that the EIN and return type are both correct. If this information is correct in the return, contact the IRS e-Help Desk at 866.255.0654.
