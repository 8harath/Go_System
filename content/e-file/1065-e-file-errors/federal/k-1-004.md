# K-1-004 e-file error

```
Partner is missing City in the partner address.
```

You get this error when partner information is missing a city entry for a partner or partners.

## Solution

**If using direct K-1 import:**

- Go to **Tax Forms**, **Federal**, then **Direct K-1 Import**.
- Select a partner, **Import K1 Partner Information**, then**Item F**. Make sure all partners have a full U.S. or foreign address entered.
- Do a full re-compute, re-create the e-file, then re-submit.

**If using K-1 aggregation:**

- Review your aggregation file for any missing address information for each partner (U.S. or foreign).
- Re-upload the aggregation file.
- Do a full re-compute, re-create the e-file, then re-submit.
