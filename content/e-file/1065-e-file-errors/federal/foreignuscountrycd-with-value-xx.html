Solution

  1. Go to
    Organizer
    Foreign Information
    Ptr Distributive Share-International
    Foreign Tax Credit Limitation-II
    Gross Income
    By Country
    XX
    .
  2. Go to the COUNTRY CODE OR CATEGORY CODE OR CODE XX (MANDATORY (SEE BELOW)) section.
  3. Make a selection for
    Country
    .
  4. Do a full re-compute.
  5. Change
    Country
     to
    (None selected)
    .
    note
    If the client is using a Direct K-1 or K-1 aggregation file, correct the import file and reimport.
  6. Do a full re-compute, recreate the e-file, and resubmit.
