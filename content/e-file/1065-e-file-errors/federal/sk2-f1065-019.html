SK2-F1065-019 e-file error

Severity
Reject
Form No SK2-F1065
Record Name IRS1065ScheduleK2
Form Occurrence No 0
Field Seq No 0
Page No 1
Reject Code SK2-F1065-019
Rule Number SK2-F1065-019
XML Path /efile:Return/efile:ReturnData/efile:IRS1065ScheduleK2/efile:PartVIIIAttachedInd
You get this error when you need to make a selection for the Separate Category option. You must also enter the EIN or reference ID number.

Solution

  1. Go to
    Organizer
     and select
    Foreign information
    .
  2. Select
    Ptr Distributive Share international
    , then
    Pshp Int Foreign Cirp inc (960)-VIII
    . 
  3. Select
    CFC name
    , then
    Pshp Int In Foreign corp inc-sec 960
    .
  4. Make a selection for
    Separate category
    .
  5. Enter either the EIN or reference ID.
  6. Enter the foreign base company services income.
  7. Do a full recompute.
  8. Recreate the e-file.
