E-file error: "AtSubmissionCreationDeviceId" not correct

The field 'AtSubmissionCreationDeviceId' with value 'NONE', data format is not correct.

Solution

  1. Go to
    View
    , then
    Diagnostics
     and select the diagnostic.
  2. Go to the DETAILS OF XML FILE / Common E-file Issue Fields section.
  3. Delete the information in the Initial Device ID, IP Address, IP Time lines.
  4. Do a full re-compute, recreate the e-file, and resubmit.
