E-file diagnostic: You may not activate E-filing for the tax return (Form 1065) and the extension (Form 7004) concurrently

Federal 1065 MeF: You may not activate E-filing for the tax return (Form 1065) and the extension (Form 7004) concurrently.
This happens when e-file's enabled for both the federal return and the extension.

Solution

  1. Go to
    Organizer
     and select:
    1. Federal E-file
      , and then
      Enable E-file
      . If you're e-filing the extension at this time, select
      Enable federal e-file
       to unmark this option.
    2. Federal E-file Extension
      , and then
      E-file Extension
      . If you're e-filing the federal return at this time, select
      Enable federal e-file extension
       to unmark this option.
  2. Perform a full recompute, recreate the e-file, then submit.
