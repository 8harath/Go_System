# E-file error: Field 'TaxYearBeginDt' is unexpected

```
Field 'TaxYearBeginDt' is unexpected
```

## Solution

- Go to **Organizer**, then **Foreign Information**.
- Select **Ptr Distributive Share-International**, then **General Information On PFIC or QEF-VII**.
- Select **Per Partner**, then **PFIC Information** and enter address information.
- Do a full re-compute, recreate the e-file, then resubmit.
