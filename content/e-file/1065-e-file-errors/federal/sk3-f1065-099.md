# SK3-F1065-099 e-file error

You'll get this error if Schedule K-3 isn't correctly referenced in the return.

## Error message

```
Federal  
  Severity: Reject
  Form No: SK3-F1065
  Record Name: NA
  Form Occurrence No: 0
  Field Seq No: 0
  Page No: 1
  Reject Code: SK3-F1065-099
  Rule Number: SK3-F1065-099
  XML Path: //efile:IRS1065ScheduleK3[./@documentId = IRS1065ScheduleK3A1 ]
  Error Message: If Schedule K-3 (Form 1065) is present in the return, then it must be referenced from one and only one Schedule K-1 (Form 1065).
```

## Solution

- Go to 

  **Organizer****Partner Information****Common Partner Data**

  .
- In the **Defaults for All Partners** section, go to the **Attach Schedule K-3 to Schedule K-1 (Override)** subsection.
- Select an option other than **None Selected**.
- Do a full recompute, recreate the e-file, and resubmit the return.
- Verify each Schedule K-1 with a Schedule K-3 has Line 16 marked. If you're using Direct K-1, verify this under the **DK1** folder in **Tax Forms**.
- Verify there's a Schedule K-3 outputting in the XML for each Schedule K-1 that's marked.
- Verify that Schedule K-3 is aligned with each Schedule K-1, especially if you're using Direct K-1.
