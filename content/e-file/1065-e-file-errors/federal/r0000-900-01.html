R0000-900-01 e-file error

Error

The return type indicated in the return header must match the return type established with the IRS for the EIN. (value, rule R0000-900-01)

Cause

The type of return on file with the IRS doesn't match the EIN included in the electronic file.

Solution

  1. Go to
    Organizer
    , then
    General Information
    .
  2. Select
    Basic Return Information
    , then
    Entity Information
    .
    1. Make any necessary changes, do a full recompute, recreate the electronic file, and resubmit.
    2. If the information is already correct, contact the IRS e-help Desk at 866-255-0654 for further assistance.
