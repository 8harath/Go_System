# F1065-048-02 e-file error

```
If Form 1065, Schedule B, Line 4 'PrtshpSatisfyAllConditionsInd' is "No", then Schedule L must be present in the return.
```

This happens when Question 4 in Schedule B is set to **No**, and the Schedule L is missing.

## Solution

If Question 4 is incorrect:

- Go to **Organizer**, then **General Information**.
- Select **Questions**, then the **Schedule B Questions** tab.
- Set Question 4 to **No** or select **Blank**. This action will prompt you to complete Schedule L.
- In Schedule L, enter an amount or 

  NONE

  .
- Do a full recompute and recreate the e-file.
