E-file diagnostic: Based on state specifications, General Partner or LLC Member Manager signature information must be completed

Georgia E-file: Based on state specifications, General Partner or LLC Member Manager signature information must be completed. Go to Organizer\ General Information\ Basic Return Information\ 2nd tab Return Information. Enter the First and Last name.
This happens when 1065 Georgia return is missing the
General Partner
 or
LLC Member Manager
 signature information.

Solution

  1. In
    Organizer
    , then select
    General Information
    .
  2. Select
    Basic Return Information
    .
  3. On the
    Return Information
     tab, locate the
    Signing General Partner or LLC Member Manager
     section.
  4. Complete the following fields:
    • First name
    • Last name
    • Title
    • Date
  5. Once done, do a full recompute and recreate the e-file.
note
Georgia pulls directly from Federal and doesn’t consider Common State.
