# IL1120B-3000-2 e-file error

```
IL1120B-3000-2: If SchILB Section B Line H is greater than zero, then SchILB Section B Line J of the same occurrence cannot be less than the result of SchILB Section B Line H minus SchILB Section B Line I of the same occurrence.
```

This happens Form IL Schedule B Line H is greater than 0 and Schedule B Col J doesn’t equal Column H minus Column I.

## Solution

- Go to 

  **Tax Forms****States****Illinois****Sch B – Partner Identification****Schedule B****Schedule B, Page 2****Schedule B Summary**

  .
- Remove all overrides in Column H and Colum K.
- Go to 

  **Organizer****States****Illinois****State Adjustments****Partner Share**

  .
- Go to the **PASS THROUGH ENTITY TAX CREDIT OVERRIDES** section.
- Create a new special allocation code and enter an amount for Column K.
- Go to 

  **Organizer****Partner Information****Allocations****Special Allocations****Add new Special Allocation Code**

  .

  note

  The allocation code should include either an amount or ratio for each partner.
- For Column H, go to 

  **Tax Forms****States****Illinois****Sch K-1-P****Partner Name****Sch K-1-P, Page 2****Line 55**

  .

  note

  Line 55 pulls directly from 

  **Tax Forms****States****Illinois****Sch K-1-P****Sch K-1-P (3)****Partner Name****Line 19**

  .
- Do a full recompute and recreate the e-file.
