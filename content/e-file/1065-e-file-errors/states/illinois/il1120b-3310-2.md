# IL1120B-3310-2 e-file error

```
IL1120B-3310-2: If FormIL1065 is attached then the sum of all occurrences of SchILB Section B Line K cannot be greater than FormIL1065 Step 8 Line 61.
```

This happens when IL-1065 Page 3 Line 61 doesn’t match the Partner amounts on Schedule B Summary Column K.

## Solution

- Go to 

  **Tax Forms****States****Illinois**

  .
- Make sure **IL-1065, IL-1065, Page 3, Step 9, Line 61** is equal to the total Partners.
- Go to 

  **Tax Forms****States****Illinois**

  .
- Select **Sch B Partner Identification**, then **Schedule B**.
- Go to **Schedule B, Page 2** and select **Schedule B Summary**.
- Make sure Column K amounts match Line 61.
- Do a full recompute, recreate the e-file, and resubmit the return.
