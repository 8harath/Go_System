# IL1120B-3410-7 e-file error

```
If SchILB Line Section B Col G is greater than zero and the same occurrence of SchILB Line Section B Col B contains a T or A, then the same occurrence of SchILB Line Section B Col H must be equal to or greater than the sum of SchILB Line Section B Col G multiplied by 4.95% (.0495) and SchILB Line Section B Col G multiplied by 1.5% (.015).
```

You'll get this error if column H isn't adding up for partners with a T or A in column B.

## Solution

- Go to **Tax Forms**, **States**, **Illinois**, **Sch B-Partner Identification**, **Schedule B**, and then the **Schedule B, Page 2** tab.
- Select **Schedule B Summary** to review all entries.
- For partners with a T or A in column B, if column G is greater than zero, column H needs to be equal to or greater than the sum of column G \* .0495 + column G \* .015.

  note

  If an aggregate file's being used, review the file, and make any necessary changes and re-attach the file.
- Perform a full recompute, recreate the e-file, then resubmit.
