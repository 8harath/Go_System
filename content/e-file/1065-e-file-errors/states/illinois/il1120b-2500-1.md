# IL1120B-2500-1 e-file error

```
IL1120B-2500-1: If the same occurrence of SchILB Line Section B Col C (SSN) and SchILB Line Section B Col C (FEIN) is blank, then the same occurrence of SchILB Section B Col A (Foreign Mailing Line 1) must be present.
```

This happens when a partner has a U.S. state selected and a domestic zip code entered, but the SSN and EIN are not provided.

## Solution

- Go to 

  **Organizer****Partner Information****Partner by Partner Data**

  .
- Select the partner's name then **Partner Information**.
- On the **Partner Information** tab, make sure the partner address is correct.

note

If the partner has a U.S. state selected and a domestic zip code entered, you must enter either an SSN or EIN or Paper file.

If you are using the K-1 Aggregation file, you'll need to make corrections in the K-1 aggregation file and then reattach before clearing the diagnostic:

- In **Organizer**, select **States**, then **Illinois**.
- Select **E-file**, then **Attachments**.
- Select **K-1 Aggregation** then **Summary**.
- Go to the 

  Attach K-1 Aggregation XML File

   section, then select **Suppress Schedule B partner information**.

note

If you are not using the K-1 Aggregation file you will have to uncheck the **Suppress Schedule B partner information.**
