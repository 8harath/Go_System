IL1120B-3100-8 e-file error

Error

If SchILB Line Section B Col B contains an I, M, C, T, S, P, N, or A and either FormIL1065 Step 1 Line F (PTP) or FormIL1065 Step 1 Line F (Inv Ptnrship) contains an X, then SchILB Line Section B Col F must contain a P. Otherwise SchILB Line Section B Col F can't contain a P. (IL1120B-3100-8)

Cause

If a partner has a P on Illinois Schedule B, Page 2, Column F, then IL-1065, Step 1, Line F, needs to have either PTP or Investment Partnership checked.

Solution

  1. Go to the Organizer then select
    States
    .
  2. If the return is an Investment Partnership, complete the following:
    1. Select
      Illinois
      , then
      Return Options
      .
    2. Mark the
      Print Investment Partnership
       checkbox on Form IL-1065 and each
      Schedule K1P
       checkbox.
