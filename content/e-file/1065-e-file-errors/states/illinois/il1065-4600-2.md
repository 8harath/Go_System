# IL1065-4600-2 e-file error

```
IL1065-4600-2: FormIL1065 Step 3 Line 11 (Total) must equal the total of all occurrence of FormIL1065 Step 3 Line 11 (Amount).
```

This happens when Form IL-1065, Page 1, Line 11 **Other expenses** does not equal the amount of **itemized other expenses** entered.

## Solution

- In Tax Forms, select **States**, then **Illinois**.
- Go to**IL-1065, line 11** and make sure this line doesn't have an override.
- Drill down ![](/content/dam/helpandsupp/en-us/Topics/ONESOURCE-family/images/drill-down.png/_jcr_content/renditions/cq5dam.web.1280.1280.jpeg) on line 11.
- Make sure that the line for: **Other deductions**is not overridden.
- If you need to correct the amount, drill down on the line, **Other expenses**, and then enter the appropriate expenses in Organizer.
- Once the amounts are correct, select **Compute**, then **Full Recompute**.
- Then in Organizer, select **States**, then **State E-File**, then **Enable/create Returns**.
- Select **Create** on row 31 for Illinois.
