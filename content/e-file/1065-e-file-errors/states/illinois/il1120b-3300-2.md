# IL1120B-3300-2 e-file error

```
IL1120B-3300-2: Sch B Section A Line 5 must equal the sum of all occurrences of Sch B Section B Line J.
```

This happens when Schedule A, line 5, doesn’t match Schedule B section B line J.

## Solution

- Go to 

  **Tax Forms****States****Illinois**

  .
- Select **Sch B-Partner Identification**, then **Schedule B**.
- Go to **Page 1, Section A**. **Line 5** must equal **Schedule B, section B, line J**.
- Go to **Tax Forms**, **States**, **Illinois**.
- Go to **Sch B-Partner Identification** and select **Schedule B**.
- Go to **Page 2, Section B** and select **Schedule B Summary**.
- To enter the amount on Column J:


  - Go to 

    **Organizer****Partner Information****Partner by Partner Data**

    .
  - Select the **Partner**, then the**State Information** tab.
  - Go to the **Illinois** section, and enter the amount on the **Pass-through Entity Payment (Override)** line.
- Do a full recompute and recreate the e-file.
