# ILHeader-10700-1 e-file error

```
ILHeader-10700-1: IL-Header BusinessRepresentative/SignatureDt cannot be blank. Navigate to the Organizer \ States \ Common State \ General Information \ Basic Return Information \ Signature Information \ Complete column J.
```

This happens when signature information is missing.

## Solution

Complete all fields including the signature date.

- Go to **Organizer**, **States**, **Common States**.
- Select **General Information**, **Basic Return Information**, then the **Signature Information** tab.
- Complete all information for Illinois including **Column K, Signature date**.
- Do a full recompute and recreate the e-file.
