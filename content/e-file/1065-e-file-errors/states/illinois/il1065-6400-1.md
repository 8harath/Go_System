# IL1065-6400-1 e-file error

```
IL1065-6400-1: If Form IL-1065 Step 5 Line 27 is greater than zero, then Sch B Section A Line 3 must be greater than zero.
```

This happens when the value of Form IL-1065 Step 5 Line 27 is not equal to Sch B Section A Line 3.

## Solution 1

- Go to the **Tax Forms**, **States**, **Illinois** folder.
- Select **IL-1065**, then go to **IL-1065, Page 2**.
- Go to **Step 5, In Line 27** if you have a value greater than 0.
- **Step 5, Line 27** value must equal the following line.
- Go to **Tax Forms**, **States**, **Illinois** folder.
- Select **Schedule B**, then go to **Schedule B, Page 1**.
- Go to **Totals from Schedule B**, **Section B**, and review the amount in **Line 3**.

note

If **IL-1065, Page 2, Step 5 Line 27** is greater than 0, then **Form IL-1065 Step 5 Line 27** must equal **Sch B Section B Line 3**.

## Solution 2

Check for an aggregated Schedule K-1.

- Go to **Organizer**, **States**, **Illinois**.
- Go to **E-file**, **K-1 Aggregation**, and select **Summary**.
- If the system-generated Schedule K-1s aren't available and an aggregated XML file is present, select **Attach K-1 Aggregation XML File**.
- Select the aggregated XML file, then **Retrieve**.
- Update the aggregated XML file to have the correct amounts so they’ll add up to the grand total.
- Delete the existing aggregated XML file from the electronic filing attachments screen.
- Select **Add**.
- Select **Attachment Jurisdiction for NOS K-1 Aggregation**.
- Select **Browse for file** and attach the updated **XML Aggregation**.
- Select **Upload**, then **Done**.

## Solution 3

Check for Direct K-1 Import.

- Go to **Organizer**, **Partner Information**.
- Select **Common Partner Data**.
- Look for a tab called **Direct K-1 Import**.


  - If you don’t see the **Direct K-1 import** tab, it's not enabled.
  - If you do see the **Direct K-1 import** tab, select it.
- If the option to **Enable Direct K-1 Import to replace the computed Schedule K-1s** is not available, it's not being used.
- If it is available, update the import file and reimport the Direct K-1 Import file or go to 

  **Tax forms****States****Illinois**

  .
- Select **Schedule K-1** and change the amounts directly on the tax form.
