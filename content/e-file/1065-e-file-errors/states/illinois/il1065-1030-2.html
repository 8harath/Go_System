IL1065-1030-2 e-file error

If Form IL-1065 Step 1 Line F (Inv Ptnrship) contains an 'X', then all occurrences of Sch B Step 2 Col F must contain a 'P'.
This happens when the
1065 Illinois IL-1065, Page 1 Line F, classified as an investment partnership
 checkbox is marked, and Schedule B, Page 2, Schedule B Summary, Column F for partners doesn’t contain a P.

Solution

  1. Go to
    Tax Forms
    , then
    States
     and select
    Illinois
    .
  2. Select
    Sch B-Partner Identification
    , then
    Schedule B
    .
  3. Go to
    Schedule B, Page 2
     and select
    Schedule B Summary
    .
  4. For
    Schedule B Partners' or Shareholders' Identification
    , make sure that
    Column F
     contains a
    P
     and is clear of any override.
  5. Do a full recompute and recreate the e-file.
note
In case Sch B Aggregation is being used, the changes need to be applied in the attached aggregation.
