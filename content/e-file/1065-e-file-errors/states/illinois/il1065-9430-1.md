# IL1065-9430-1 e-file error

```
Form IL-1065 (Rule IL1065-9430-1): Form IL-1065 Step 7 Line 51 must equal Form IL-1065 Step 7 Line 47 divided by Form IL-1065 Step 7 Line 50. If greater than 1 or less than zero, enter 1.000000. Note: If the denominator of the division equals zero, the result of the division is assumed to be 1.000000.
```

This e-file error will show if the Form IL-1065 Step 7 line 51 doesn’t equal Form IL-1065 Step 7 line 47.

## Solution

- In Tax Forms, select **States**, then **Illinois**.
- Select **IL-1065**.
- Go to Page 3, line 51 and clear the override.
- In Organizer, select **States**, then **Illinois**, then **State Adjustments**.
- Go to **Net Income and Tax Penalties and Payments Pass-through entities payment** and clear the override amount.
- In Tax Forms, select **States**, then **Illinois**.
- Select **Sch B**, then go to **Page 2**.
- Select **Schedule B Summary**.
- Column G needs to have an amount greater than 0.
- Column B contains P so column H must equal column G 1.5%
- If Column G (amount) is greater than 0 and Column B contains N then verify that Column H equals Column G multiplied by 7%.
- Perform a full recompute and recreate the e-file
