# IL1120B-2400-3 e-file error

```
IL1120B-2400-3: If SchILB Line Section B Col B contains a C, S, P, A, N, or M, then the same occurrence of SchILB Line Section B Col C (SSN) must be blank.
```

This happens when a partner has an SSN but is classified as a C, S, P, A, N, or M on the Sch B-Partner Identification Page 2.

## Solution

- Go to 

  **Tax Forms****States****Illinois****Sch B-Partner Identification****Schedule B, Page 2, Sch B**

   and select **Summary**.
- Identify your partners or shareholders.


  - **Partner Type (B)** can't have an SSN for C, S, P, A, or M Partners and must be blank.
  - **N Partners** need to have an FEIN.
- Perform a full recompute and re-create the e-file.
