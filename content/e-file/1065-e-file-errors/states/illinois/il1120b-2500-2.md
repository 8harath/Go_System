# Il1120B-2500-2 e-file error

```
If Sch B Line Section B Col C (FEIN) is present, then Sch B Line Section B Col C (FEIN) must contain a valid FEIN. According to the Internal Revenue Service, the FEIN prefixes of 69, 70 and 79 have never been valid. In addition, 00-0000000, 11-1111111, 22-2222222, 33-3333333, 44-4444444, 55-5555555, 66-6666666, 77-7777777, 88-8888888, 99-9999999, 12-3456789 are not valid FEIN's.
```

This happens when a partner’s FEIN is incorrect.

## Solution

- Go to 

  **Tax Forms****States**

  .
- Select **Sch B-Partner Identification**, **Schedule B**.
- Select the **Schedule B, Page 2** tab.
- Select **Schedule B Summary**.
- Remove entries that are only 0’s or only 9’s (00-0000000 or 99-9999999) for each foreign partner in the Social Security or FEIN (C) column.
