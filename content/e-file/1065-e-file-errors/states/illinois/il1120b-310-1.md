# IL1120B-310-1 e-file error

```
If any occurrence of SchILB Line Section B Col A (U.S. State Abbr) or SchILB Line Section B Col A (Foreign Country) are present, then SchILB Section A Line 3 must equal the sum of all occurrences of SchILB Line Section B Col E when the same occurrence of SchILB Line Section B Col D contains an X. (IL1120B-310-1)
```

This happens when the amounts on the Schedule B Summary Column E don’t agree with the Schedule B, page 1, line 3 amount. All amounts need to be rounded to the nearest whole dollar on the Illinois Schedule B, Page 2.

## Solution 1

- Go to **Tax Forms** then select **Illinois**.
- Select **Sch B-Partner Identification** then **Schedule B**.
- Go to **Schedule B, Page 2**, and select **Schedule B Summary**.
- Review the amounts. Round any amounts to the nearest whole dollar, no decimal points.
- Additionally, **Total amount of base income/loss distributable (E)** in column E needs to equal the result from Form IL-1065:


  - Step 5, Line 35 + Line 26 + Line 27 - Line 21.
- Do a full recompute, recreate the e-file, and resubmit the return.

## Solution 2

- Go to the **Tax Forms**, **States** folder.
- Go to **Illinois**, **Sch B-Partner Identification**, **Schedule B** folder.
- Go to the **Schedule B, Page 1** tab.
- Verify there's an amount in **Section A**, **Line 3**.
- Go to the **Schedule B, Page 2** tab.
- Select **Schedule B Summary**.
- Add up all the amounts in **Column E** with **X** in **Column D**. The total of **Column E** needs to match the amount in **Section A**, **Line 3**.

## Solution 3

- Go to the **Tax Forms**, **States** folder.
- Go to the **Illinois**, **Il-1065** folder.
- Go to the **Il-1065, Page 2** tab.
- Go to the **Step 5** section.
- Add line **35**, line **26**, and line **27** together.
- Subtract line **21** from the total in step 5.
- This total needs to match the amount in **Schedule B, Page 1**, **Section A**, **Line 3**.

note

If doing a K-1 aggregation, you will need to check the file so that all the amounts in the previous lines match for Solution 2.
