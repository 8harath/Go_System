# IL1120B-3140-8 e-file error

## Error

```
If SchILB Line Section B Col G is greater than zero and the same occurrence of SchILB Line Section B Col B contains a C or N, then the same occurrence of SchILB Line Section B Col H must be equal to or greater than the sum of SchILB Line Section B Col G multiplied by 7.0% (.07) and SchILB Line Section B Col G multiplied by 2.5% (.025). (IL1120B-3140-8)
```

## Cause

Illinois Schedule B, Page 2, Column H needs to equal the sum of Column G multiplied by 7% and Column G multiplied by 2.5%.

## Solution

- Go to **Tax Forms** then select **Illinois**.
- Select **Sch B-Partner Identification** then **Schedule B**.
- On Schedule B, Page 2, review the amounts entered in Columns G and H.
- Column H need to equal the sum of Column G multiplied by 7% and Column G multiplied by 2.5%.
- Do a full recompute, recreate the electronic file, and resubmit the return.
