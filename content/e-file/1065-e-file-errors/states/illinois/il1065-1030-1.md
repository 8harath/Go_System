# IL1065-1030-1 e-file error

```
IL1065-1030-1: If FormIL1065 Step 1 Line F (Inv Ptnrship) contains an X, then FormIL1065 Step 5 Line 35 Box B must contain an X and FormIL1065 Step 6 Line 36 through FormIL1065 Step 7 Line 47 must be equal to zero.
```

This happens when there’s inconsistent data in the Illinois 1065 on Step 1 Line F, Step 5 Line 35 Box B, and from Step 6 Line 36 through Step 7 Line 47.

## Solution 1

- Go to 

  **Tax Forms****States****Illinois**

   folder.
- Select **IL-1065**, then go to **IL-1065, Page 1**.
- Clear the **Line F classified as an investment partnership** checkbox if you want to keep the values.


  - Go to 

    **Organizer****States****Illinois**

     folder.
  - Select **Return Options** and go to the **Print Options** section.
  - Clear the **Print Investment Partnership with no numeric data on Form IL-1065, Step 6** checkbox.
- Do a full recompute and recreate the e-file.

## Solution 2

To update the values for Step 6 Line 36 to Step 7 Line 47:

- Go to 

  **Tax Forms****States****Illinois**

   folder.
- Select **IL-1065**, then go to **IL-1065, Page 2**.
- In Step 6, **Line 36** through **IL-1065, Page 3, Step 7, Line 47** must equal 0.

  note

  If you have entered **NONE**, remove it and leave the field blank.
- To make changes in Step 6:


  - Go to 

    **Organizer****States****Illinois**

     folder.
  - Select **State Adjustments**, then **Base Income Allocation** and remove the values.
- To make changes in Step 7:


  - Go to 

    **Organizer****States****Illinois**

     folder.
  - Select **Net Income and Tax**, then **Net Income and Replacement Tax**.
- Do a full recompute and recreate the e-file.

## Solution 3

If you want to keep the values or **NONE**, follow these steps to adjust Step 1, Line F.

To change Step 5 Line 35 Box B:

- Go to 

  **Tax Forms****States****Illinois**

   folder.
- Select **IL-1065**, then **IL-1065, Page 2**.
- In Step 5, **Line 35, Box B** must contain **X**.
- To select the box:


  - Go to 

    **Tax Forms****States****Illinois**

     folder.
  - Select **General Information**, then go to the **General Information** section.
  - Mark **If base income or net loss is derived out of state**.
- Do a full recompute and recreate the e-file.
