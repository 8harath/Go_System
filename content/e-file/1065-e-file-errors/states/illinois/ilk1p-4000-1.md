# ILK1P-4000-1 e-file error

```
ILK1P-4000-1: SchILK1P Step 3 Line 19 Col A must equal the sum of all occurrences of SchILK1P Step 3 Line 19 (resident amt.).
```

This happens when the description is missing for Sch K-1-P step 3 line 19.

## Solution

- Go to 

  **Organizer****States****Illinois****State Adjustments**

  .
- Select **Pass Through Input, Schedule K-1-P**, then **[Name of Schedule] K-1-P**.
- Go to **Step 3 – Share of Nonbusiness Income**.
- On **Line 19 Other Nonbusiness Income**, enter a description for any lines that have amounts in Column A or Column B.
- Run a full recompute and recreate the e-file.
