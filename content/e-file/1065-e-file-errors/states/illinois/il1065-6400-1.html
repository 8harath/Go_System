IL1065-6400-1 e-file error

IL1065-6400-1: If Form IL-1065 Step 5 Line 27 is greater than zero, then Sch B Section A Line 3 must be greater than zero.
This happens when the value of Form IL-1065 Step 5 Line 27 is not equal to Sch B Section A Line 3.

Solution 1

  1. Go to the
    Tax Forms
    ,
    States
    ,
    Illinois
     folder.
  2. Select
    IL-1065
    , then go to
    IL-1065, Page 2
    .
  3. Go to
    Step 5, In Line 27
     if you have a value greater than 0.
  4. Step 5, Line 27
     value must equal the following line.
  5. Go to
    Tax Forms
    ,
    States
    ,
    Illinois
     folder.
  6. Select
    Schedule B
    , then go to
    Schedule B, Page 1
    .
  7. Go to
    Totals from Schedule B
    ,
    Section B
    , and review the amount in
    Line 3
    .
note
If
IL-1065, Page 2, Step 5 Line 27
 is greater than 0, then
Form IL-1065 Step 5 Line 27
 must equal
Sch B Section B Line 3
.

Solution 2

Check for an aggregated Schedule K-1.
  1. Go to
    Organizer
    ,
    States
    ,
    Illinois
    .
  2. Go to
    E-file
    ,
    K-1 Aggregation
    , and select
    Summary
    .
  3. If the system-generated Schedule K-1s aren't available and an aggregated XML file is present, select
    Attach K-1 Aggregation XML File
    .
  4. Select the aggregated XML file, then
    Retrieve
    .
  5. Update the aggregated XML file to have the correct amounts so they’ll add up to the grand total.
  6. Delete the existing aggregated XML file from the electronic filing attachments screen.
  7. Select
    Add
    .
  8. Select
    Attachment Jurisdiction for NOS K-1 Aggregation
    .
  9. Select
    Browse for file
     and attach the updated
    XML Aggregation
    .
  10. Select
    Upload
    , then
    Done
    .

Solution 3

Check for Direct K-1 Import.
  1. Go to
    Organizer
    ,
    Partner Information
    .
  2. Select
    Common Partner Data
    .
  3. Look for a tab called
    Direct K-1 Import
    .
    1. If you don’t see the
      Direct K-1 import
       tab, it's not enabled.
    2. If you do see the
      Direct K-1 import
       tab, select it.
  4. If the option to
    Enable Direct K-1 Import to replace the computed Schedule K-1s
     is not available, it's not being used.
  5. If it is available, update the import file and reimport the Direct K-1 Import file or go to
    Tax forms
    States
    Illinois
    .
  6. Select
    Schedule K-1
     and change the amounts directly on the tax form.
