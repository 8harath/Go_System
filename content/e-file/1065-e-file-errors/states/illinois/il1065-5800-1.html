IL1065-5800-1 e-file error

* IL1065-5800-1: If Form IL-1065 Step 4 Line 21 is greater than zero, then Sch B Section A Line 3 must be less than zero.
This happens when the form IL-1065 Step 4 line 21 has an amount greater than zero but Schedule B Section A line 3 need to be less than zero.

Solution

  1. Go to
    Tax Forms
    , then select the
    States
     folder.
  2. Select
    Illinois
    , then the
    IL-1065
    folder.
  3. Select
    IL-1065, Page 2
    .
  4. Go to Step 4, line 21. This amount needs to match the line mentioned in the next steps except as a negative amount.
  5. In
    Illinois
    , select the
    Sch B-Partner Identification
     folder.
  6. Select
    Schedule B, Page 1
    .
    1. Line 3 must match line 21 mentioned in the previous steps except line 3 is negative.
    2. Line 3 pulls from Schedule B, Page 2.
  7. Select the hyperlink
    Schedule B Summary
    . The total comes from
    Column E, Total Amount of base income/loss distributable
    .
