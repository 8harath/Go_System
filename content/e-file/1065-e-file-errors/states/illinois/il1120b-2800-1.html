IL1120B-2800-1 e-file error

If SchILB Line Section B Col A (US State Abbr) or SchILB Line Section B Col A (Foreign State Abbr) is present, then the same occurrence of SchILB Line Section B Col E must be present.
This happens when Illinois Schedule B Section B Column A is populated and Illinois Schedule B Section B Column E is empty.

Solution

  1. Go to
    Tax Forms
    States
    Illinois
    .
  2. Select
    Sch B-Partner Identification
    , then
    Schedule B, Page 2
    .
  3. Select
    Schedule B Summary
    . If Column A is populated, then Column E must be populated as well.
  4. To specially allocate the amount in Column E, go to
    Organizer
    States
    Illinois
    Federal Overrides
    .
  5. In the
    Federal Overrides
     tab, enter amounts and allocation codes in the entry fields, or use the
    Sch B - Total amount of base income (loss) distributable
     line.
  6. Do a full recompute and recreate the e-file.
note
If using an aggregation file for Schedule B, correct the data on the aggregation file, then reattach it and recreate the e-file.
