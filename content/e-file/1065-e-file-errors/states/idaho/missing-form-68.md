# E-file diagnostic: missing Form 68

```
ID E-file: Missing Form 68 with value on Form 44, Part I, line 5, Column A or Column B
```

This happens when there is an amount on line 5 of form 44 but form 68 isn’t populated.

## Solution

- In Organizer, select **States,**then **Idaho**, then**Credits**.
- Select **Broadband Equipment Credit**.
- Complete information in this area.
- Run a full recompute and recreate the e-file.
