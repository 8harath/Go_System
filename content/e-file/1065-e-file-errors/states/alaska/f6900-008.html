F6900-008 e-file error

F6900-008: Total of Schedule B corporations and partnerships + Total of Schedule B natural persons has to equal 100.
This happens when Total of Schedule B corporations and partnerships + Total of Schedule B natural persons don't equal 100%.

Solution 1

  1. Go to
    Tax Forms
    ,
    States
    ,
    Alaska
    .
  2. Select
    Form 6900
    , then
    6900
    ,
    Page 3
    .
  3. In
    Schedule B
    ,
    Line 2
     +
    Line 4
     should equal
    100%
    .
    note
    If the ratios don't equal 100%, you'll need to file the return on paper.
  4. Select
    View Schedule B Details
    .
  5. Clear all overrides on the
    Schedule B
     yellow worksheet.
  6. Go to
    Organizer
    Partner Information
    Partner by Partner Data
    .
  7. Select
    Columnar Partner Entry
    , then the
    Ratios\Units
     tab.
  8. Enter the
    Federal partner Ownership%
     to transfer to the
    Alaska
     return.

Solution 2

Check for an aggregated Schedule K-1.
  1. Go to
    Organizer
    States
    Alaska
    .
  2. Select
    E-file, K-1 Aggregation
    , then
    Summary
    .
  3. If the
    System generated Schedule K-1s are disabled
     and an aggregated XML file is present, select
    Attach K-1 Aggregation XML File
    .
  4. Select the aggregated XML file, then
    RETRIEVE
    .
  5. Update the aggregated XML file with the correct amounts so they’ll add up to the grand total.
  6. Delete the existing aggregated XML file from the electronic filing attachments screen.
  7. Select
    Add
    .
  8. Select
    Attachment jurisdiction
     for
    Alaska K-1 Aggregation
    .
  9. Select
    Browse for file
     and attach the updated XML Aggregation.
  10. Select
    Upload
    , then
    Done
    .

Solution 3

Check for Direct K-1 Import.
  1. Go to
    Organizer
    ,
    Partner Information
    .
  2. Select
    Common Partner Data
    .
  3. Select the
    Direct K-1 Import
     tab.
    note
    If the Direct K-1 Import tab isn't available, this option isn't available.
  4. If
    Enable Direct K-1 Import to replace the computed Schedule K-1s
     isn't turned on, then it's not being used.
  5. Update the import file and reimport the Direct K-1 Import file or go to
    Tax forms
    States
    Alaska
    .
  6. Select
    Schedule K-1
     and change the amounts directly on the tax form.
