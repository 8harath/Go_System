# E-file error: Field 'SchCP' is unexpected

```
Field 'SchCP' is unexpected
```

You'll get this error when Pennsylvania expects a Form 65-Corp instead of a PA-20S/65 Information return.

## Solution

- Go to **Organizer**, **States**, **Pennsylvania**, **E-file PA20S/PA-65**, then **Forms Included in E-file**.
- Go to the **Forms Included in E-file** section.
- Clear the **PA-20S/65: PA S Corporation/Partnership Information Return** checkbox.
- Do a full recompute, re-create the e-file, and resubmit the return.
