# PA20-S/PA-65-009 e-file error

```
PA20-S/PA-65-009 (PA20S\PA-65, Page 3, Part IX): Business Name Line 1 must be present, left justified and must not contain any special characters (. # \ & / , ') other than a hyphen or more than one consecutive space. See XXXXX.
```

The business name is what causes the error is in the error message.

## Solution 1

- Go to 

  **Organizer****Activity Information****Pass-Through Entity**

  .
- Select the partner's name, then **Pass - Through Entity Activity**.
- On the **K-1 Line, Lines 1-15** tab, remove any special characters in the **Pass-Through name (Mandatory)** field.
- Do a full recompute and re-create the e-file.

## Solution 2

- Go to **Organizer**, then **States**, and select **Pennsylvania**.
- Select **Schedule E**.
- Go to the section **Ownership of Pass-Thru Entities** and make sure there are no special characters in the **Name (override)** column.
- Do a full recompute and re-create the e-file.

## Solution 3

- Go to **Organizer**, then **States**, and select **Common State**.
- Select **General Information**, then **Basic Return Information**.
- On the **Address** tab, go to the Pennsylvania row and make sure there aren't special characters in the **Name** column B.
- Do a full recompute and re-create the e-file.
