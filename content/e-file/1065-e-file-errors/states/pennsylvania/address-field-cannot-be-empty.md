# E-file error: Field 'Address' cannot be empty

```
Form: SchDirectory[1] PartMembShr[74]/NameAddr[1]/Address[1]
Error: Address
ActionNeeded: Field 'Address' cannot be empty
```

This happens when the attached aggregation file and addresses don't have each partner's address entered.

## Solution

- In Organizer, go to one of the following screens:
- If you've already entered a partner, go to Partner Information, then **Partner by Partner Data**, then **Columnar Partner Entry**.
- If you need to add a new partner, go to Partner Information, then **Partner by Partner Data**


  - Select **Add new Partner name**.
  - Enter the name for this partner.
- Enter the complete address for each partner. Make sure there are no special characters in the name or address (No dashes, comas, periods, etc.).
- To attach a new aggregation file in Organizer, go to **States**.
- Make sure  **Pennsylvania** is activated.
- In Pennsylvania, select **E-file PA20S/PA-65**.
- Select **Attachments**, then **K-1 Aggregation**, then **Summary** .
- Re-attach the file.
- Do a full recompute and recreate the e-file.
