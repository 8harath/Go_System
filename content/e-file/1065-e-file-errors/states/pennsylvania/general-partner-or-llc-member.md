# E-file diagnostic: General Partner or LLC Member

```
Missing required general partner's first name, last name, title and/or signature date.
```

This diagnostic occurs when some information is missing such as first name, last name and signature.

**Solution**

- In Organizer, select **States**, then **Common State**.
- Select **General Information** then the **Basic Return Information** folder.
- On the **Signature Information** tab, enter the first name, last name, and the signature date for Pennsylvania.
- Do a full recompute and recreate e-file.
