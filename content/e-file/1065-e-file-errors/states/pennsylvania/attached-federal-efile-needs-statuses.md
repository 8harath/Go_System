# E-file error: The attached Federal Efile needs to have one of the following statuses: Qualified, Accepted, or Awaiting Acknowledgement

```
The attached Federal Efile needs to have one of the following statuses: "Qualified", "Accepted", or "Awaiting Acknowledgement".
```

The attached federal return must have a status of Qualified, or a submission status of Awaiting Acknowledgement or Accepted.

## Solution 1

- Go to **Organizer**, **States**, **State E-file**, **Enable Create Returns**, then the **Federal Copy** tab.
- Make sure the correct federal return is attached.
- If you haven't filed the federal return:


  - Clear all diagnostics for the federal return.
  - Create a qualified federal e-file.
  - Recreate the PA e-file to clear this diagnostic.
- If you're still seeing this diagnostic, recreate the federal e-file, then recreate the PA e-file.
- Do a full recompute, re-create the e-file, and resubmit the return.

## Solution 2

- Go to **Organizer**, **States**, **State E-file**, **Enable/Create Returns**, then the **Federal copy** tab.
- Make sure the federal e-file is qualified.
- Do a full recompute, re-create the e-file, and resubmit the return.
