E-file error: Field 'ForOperOwnForAcct' is unexpected

Requirement: Expecting ElectEntLevlAssmnt
Error: Field 'ForOperOwnForAcct' is unexpected.
There is an issue with the Pennsylvania Partnership Return e-file. Please contact Thomson Reuters Support for this issue.
This happens when you need to make a selection in the Tax Form column for each shareholder.

Solution

  1. Go to
    Tax Forms
    ,
    States
     and select
    Pennsylvania
    .
  2. Select
    Schedule NW
     and
    Sch NW, Page-2
    .
  3. View
    Schedule Detail
    .
  4. Make a selection in the Tax Form column for each shareholder.
  5. Do a full re-compute, recreate the e-file, then resubmit.
