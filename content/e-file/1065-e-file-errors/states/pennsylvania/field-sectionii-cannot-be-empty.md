# E-file error: Field 'SectionII' cannot be empty

```
Field 'SectionII' cannot be empty
```

You'll get this error if Line C of Schedule NW doesn't have an amount.

## Solution

- Select **Organizer**, **States**, then **Pennsylvania**.
- Select **Return Options**.
- Go to the Print Suppression section and mark the checkbox for **Schedule NW**.
- Do a full re-compute, recreate the e-file, and resubmit.
