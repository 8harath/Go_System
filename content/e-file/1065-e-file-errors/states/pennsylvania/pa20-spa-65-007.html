PA20-S/PA-65-007 e-file error

* PA20-S/PA-65-007: Missing required forms for return type - E-filing PA20S/PA65 requires at least one SchRK1 or SchNRK1 element.
This happens when the partner the Sch RK and Sch NRK is not included in the XML.

Solution 1

If using K-1 Aggregation:
  1. Go to
    Organizer
    States
    Pennsylvania
    .
  2. Select
    E-file PA20S/PA-65
    , then
    Attachments
    .
  3. Go to
    K-1 Aggregation
    , then
    Summary
    .
  4. Do 1 of the following:
    • Attach the
      K-1 XML Aggregation
       file.
    • Clear the
      Suppress system generated Schedule K-1s
       checkbox.
  5. Do a full recompute and recreate the e-file.

Solution 2

If using a system generated K-1:
  1. Go to
    Organizer
    General Information
    Return and Print Options
    .
  2. Go to the
    Sch K, K-1 and Activity Schedules
     tab and set
    Sch K-1 and partner activity schedules
     to print.
  3. Do a full recompute and recreate the e-file.
