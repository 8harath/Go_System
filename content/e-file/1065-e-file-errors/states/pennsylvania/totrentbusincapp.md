# E-file error: TotRentBusIncApp

```
The field 'TotRentBusIncApp' with value '-28', data format is not correct.
```

This happens when the you need negative numbers aren't allowed.

## Solution

- Go to **Tax Forms**, **States**, **Pennsylvania**, then **Schedule M**.
- Select **Schedule M - Rent and Royalty - Col F tab, Section III**.
- Ensure **Line 8** isn't a negative number. The line can't be in a negative format. It needs to be positive number to E-file or qualify the return.
