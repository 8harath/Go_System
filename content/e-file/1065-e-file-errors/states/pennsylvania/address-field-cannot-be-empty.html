E-file error: Field 'Address' cannot be empty

Form: SchDirectory[1] PartMembShr[74]/NameAddr[1]/Address[1]
Error: Address
ActionNeeded: Field 'Address' cannot be empty
This happens when the attached aggregation file and addresses don't have each partner's address entered.

Solution

  1. In Organizer, go to one of the following screens:
  2. If you've already entered a partner, go to Partner Information, then
    Partner by Partner Data
    , then
    Columnar Partner Entry
    .
  3. If you need to add a new partner, go to Partner Information, then
    Partner by Partner Data
    1. Select
      Add new Partner name
      .
    2. Enter the name for this partner.
  4. Enter the complete address for each partner. Make sure there are no special characters in the name or address (No dashes, comas, periods, etc.).
  5. To attach a new aggregation file in Organizer, go to
    States
    .
  6. Make sure 
    Pennsylvania
     is activated.
  7. In Pennsylvania, select
    E-file PA20S/PA-65
    .
  8. Select
    Attachments
    , then
    K-1 Aggregation
    , then
    Summary
     .
  9. Re-attach the file.
  10. Do a full recompute and recreate the e-file.
