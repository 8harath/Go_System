E-file diagnostic: Enable e-file - Return / REV-276 Extension

Enable e-file: Return / REV-276 Extension: The enable e-file checkboxes for the Return and REV-276 Extension should not be checked at the same time. Having these selected at the same time will cause errors. Navigation: Organizer\States\State E-file\Enable/Create Returns\ PENNSYLVANIA. Organizer\States\State E-file\Enable/Create Extensions\PENNSYLVANIA REV-276.
This happens when the e-file is enabled for the Pennsylvania return and REV-276 extension.

Solution

  1. Go to the
    Organizer
    ,
    States
     folder.
  2. Go to the
    State E-file
    ,
    Enable/Create Extension
     folder.
  3. Go to the
    Pennsylvania
     line in
    Column C
    .
  4. Clear the checkbox.
  5. Do a full recompute and recreate the e-file.
