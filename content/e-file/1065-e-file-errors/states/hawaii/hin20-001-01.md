# HIN20-001-01 e-file error

```
If [OrdinaryIncome] or [SchKOrdinaryIncome.Hawaii] or [SchKNetIncomeRent.Hawaii] is present then [ScheduleK1Included] must be marked and a binary attachment with the filename beginning with ScheduleK1 must be present. To clear this diagnostic, attach a PDF file using predefined description located in Edit Insert Efile attachments. Filename must match predefined description.
```

This diagnostic happens when a Schedule K-1 needs to be attached to the e-file.

## Solution

- Go to **Organizer**, **States**, **Hawaii**, **E-file**, **Attachments**, **PDF Attachments**, and then **Summary**.
- Select **Attach PDF**.
- Select **Add** and enter this information:


  - **Attachment Jurisdiction**: Hawaii
  - **Predefined description**: ScheduleK1Included

  note

  The PDF file name is **ScheduleK1Included.pdf**.
- Go to the file on your computer or network drive.
- Select **Upload**, and then **Done**.
- Perform a full recompute, re-create the e-file, then re-submit.
