HIN20-003 e-file error

HIN20-003 If Line 8(b)[SchKNetShortCapGains] or Schedule K Line 9(b) [SchKNetLongCapGains] is present, then binary attachment with the filename beginning with ScheduleD must be present. Name the file ScheduleD.PDF and attach Edit\Insert\EFile Attachment. Filename must match predefined description.
This happens when you have attached the Schedule D PDF with incorrect file name or if you haven’t attached the Schedule D PDF attachment.

Solution

  1. Go to
    Organizer
    States
    Hawaii
     folder.
  2. Go to the
    E-file
    Attachments
    PDF Attachments
     folder.
  3. Select
    Summary
    , then
    Attach PDF
     to open the
    Electronic Filing Attachments
     window.
  4. Select
    Add
    Attachment Jurisdiction: Hawaii
    Browse for file
    .
  5. Attach a PDF file named
    ScheduleD.pdf
    .
  6. Do a full recompute and recreate the e-file.
note
The file name must be named exactly as
Scheduled.pdf
. There should not be any special characters or spaces. Additionally, use the predefined Description.
