# HIN20-002 e-file error

```
HIN20-002: If N20 Line 11b Net gain(loss) from Schedule D1 or Schedule K line 10(b) Net gain(loss) under IRC section 1231 is present, then ScheduleD1 must be attached as a PDF. Name the file ScheduleD1.PDF and attach in Hawaii with predefined description "ScheduleD1.pdf". Edit\Insert\Efile Attachment. (Automatic GOTO is not available) Navigation path: Organizer/Hawaii/E-file/Attachments/PDF Attachments/Summary/Attach PDF.
```

This happens when the ScheduleD1.pdf is missing.

## Solution

- Go to the 

  **Organizer****States****Hawaii**

   folder.
- Go to the 

  **E-File****Attachments****PDF Attachments**

   folder.
- Select **Summary**, then select the **Attach PDF** button.
- Select the **Add** button.
- Select **Attachment Jurisdiction: Hawaii**.
- Select the **Browse for file** button, then attach PDF named **ScheduleD1.pdf** without spaces or special characters.
- Do a full recompute and recreate the e-file.

note

Attach a PDF named **ScheduleD1.pdf**, both the description and file name should match.
