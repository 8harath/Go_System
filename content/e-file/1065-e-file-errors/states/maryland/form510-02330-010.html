Form510-02330-010 e-file error

Form510-02330-010: Line 16c - Credit for nonresident tax paid on behalf of PTE by another PTE - If greater than 0, reference document id must be supplied or Form 510 Schedule K-1 must be present.
If there is an amount on Form 510, line 16c, you'll need to attach Maryland Schedule K-1 (510).

Solution

  1. In
    Tax Forms
    , go to the
    States
     folder and select
    Maryland
    .
  2. Select
    MD 510
    , then the
    MD 510, Page 2
     tab.
  3. If there is an amount on line 16c, you'll need to attach the PDF:
    1. Create a PDF of the Maryland Schedule K-1s, either from printing from the return, or another mean.
    2. Name the file and description as
      NonResTaxSchedK1.pdf
      .
    3. Attach the PDF
    4. Do a full recompute and recreate the e-file.
