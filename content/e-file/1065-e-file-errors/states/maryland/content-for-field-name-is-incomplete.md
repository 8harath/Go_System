# E-file error: 1065 Element name: 'Name' is incomplete or empty

```
Content for field 'Name' is incomplete.
```

```
Field 'Name' cannot be empty
```

This happens when first or last name is missing.

## Solution 1

- Go to **Tax Forms**, **States** and **Maryland**.
- Select **MD 510**, **Sch B**, **Part I**, **IND yellow workpaper there are some blank partner**s.
- Delete the data from the blank or deleted partners or update the details.

## Solution 2

- Go to **Organizer**, **Partner Information** and select **Partner by Partner Data**.
- Select **Columnar Partner Entry**, **Reformat Partner Name for State Purpose**, then**First Name and Last Name**.
- Remove the override and then drill down to edit the First and Last name of the Partners.
- Do a full re-compute, recreate the e-file, then resubmit.

## Solution 3

- Go to **Organizer**, **States**, then **Maryland**.
- Select **E-file**, **Attachments**,**K-1 Aggregation**, then **Summary**.
- Check the box for **Suppress system generated Sch B - Part 1 Individual Member Information**.
