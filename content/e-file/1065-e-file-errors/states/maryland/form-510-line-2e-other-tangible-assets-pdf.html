E-file diagnostic: Form 510, line 2e Other Tangible Assets PDF

1065 Maryland MD E-File: According to Maryland Business Rules, if an amount exists on Form 510, Schedule A, line 2e- Other tangible assets, schedule of tangible assets should be attached to MD E-file as a PDF attachment. To clear this diagnostic, attach a PDF file using predefined description located in edit insert Efile attachments.
This happens when Maryland form MD 510 page 4, Schedule A, line 2e has a value but there is not a PDF attachment, or the attachment is named incorrectly.

Solution

  1. Go to
    Tax forms
    States
    Maryland
    MD 510
    .
    note
    MD 510 page 4, Schedule A line 2e has a value, so a PDF attachment is expected.
  2. Go to
    States
    Maryland
    E-file
    .
  3. Select
    Attachments
    ,
    PDF attachments
    , then
    Summary
    .
  4. Select
    Attach PDF
    . This will open
    Electronic Filing Attachments
    .
  5. Select
    Add
    , then
    Maryland
    .
  6. In the
    Attachment Jurisdiction
     field, select
    Browse for file
    .
  7. Select
    Predefined descriptions
    , then
    TangibleAssetsSched
    .
  8. Select
    Upload
    .
    note
    The file name should be
    TangibleAssetsSched.PDF
    .
