# ScheduleK1-61020-010 e-file error

```
ScheduleK1-61020-010: Members Income Line 2 - Distributive or prorata share of income allocable to Maryland (Nonresidents/Residents) must be present.
```

## Solution

- Go to **Organizer**, **States**, **Maryland**, **E-file**, then **Additional Information**.
- Mark the checkboxes for the following:


  - Suppress Individual member PTE K-1 from E-file
  - Acknowledgement of Individual Member PTE K-1 not included in E-file
- Do a full re-compute, recreate the e-file, then resubmit.
