# E-file diagnostic: Form 510, line 3a PDF Attachment

```
MD E-File: According to Maryland Business Rules, if an amount exists for Form 510, line 3a, non-Maryland income worksheet should be attached to the MD E-File as a PDF attachment. To clear this diagnostic, attach a PDF file using the predefined description located in Edit Insert Efile Attachments.
```

This happens when an amount exists on form 510, Line 3a for non-Maryland income or loss and the PDF attachment to explain this amount is missing.

## Solution

- In Organizer, select 

  **States****Maryland E-file****Attachments****PDF Attachments****Summary**

  .
- Select **Attach PDF** and then **Add**.
- For **Attachment Jurisdiction**, select **Maryland**.
- Select **Browse for file**.
- For the predefined description, select **NonMDIncWrksht**.
- Select **Upload**, then **Done**.
- Select **Compute**, then **Full Recompute**.
- In Organizer, select **States**, then **State E-File**, then **Enable/Create Returns**.

  Select **Create** on Row 43 for **Maryland**.
