# Form510-02330-010 e-file error

```
Form510-02330-010: Line 16c - Credit for nonresident tax paid on behalf of PTE by another PTE - If greater than 0, reference document id must be supplied or Form 510 Schedule K-1 must be present.
```

If there is an amount on Form 510, line 16c, you'll need to attach Maryland Schedule K-1 (510).

## Solution

- In 

  Tax Forms

  , go to the 

  States

   folder and select **Maryland**.
- Select **MD 510**, then the **MD 510, Page 2** tab.
- If there is an amount on line 16c, you'll need to attach the PDF:


  - Create a PDF of the Maryland Schedule K-1s, either from printing from the return, or another mean.
  - Name the file and description as 

    NonResTaxSchedK1.pdf

    .
  - Attach the PDF
  - Do a full recompute and recreate the e-file.
