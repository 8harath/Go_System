# Form 510-02170-010 e-file error

```
Line 3b Maryland apportionment factor - if greater than 0.000001, it should be equal to Maryland apportionment factor on Line 4, Schedule A
```

This happens when the Form MD 510 Page 4 Line 14 is not equal to Form MD 510 Page 1 Line 3b.

**Solution**

- In the **Organizer**, go to the **States** folder and select **Maryland**.
- Select **State Information** and **Tax Computation**.
- Go to **Allocation of Income - Form 510**, and select **Partnership uses separate accounting for Maryland**.
- Go to **Tax Forms**, **States**, **Maryland**, **Form MD 510 Page 4**, **Line 1A Column 2**.
- Make an entry or populate with NONE.
- Run a full recompute and recreate e-file for Maryland.
