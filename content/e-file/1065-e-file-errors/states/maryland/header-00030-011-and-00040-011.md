# Header-00030-011 and 00040-011 e-file error

```
Header-00030-011
  XPath to Error /ReturnState/ReturnHeaderState/TaxPeriodBeginDt
  Message: Tax Year Begin date - day(DD) must be first day of begin month.
```

```
Header-00040-011
  Path to XML Error /ReturnState/ReturnHeaderState/TaxPeriodEndDt
  Message: Tax Year Ending Date - day (DD) must be last day of the month in which the tax year ends.
```

Maryland's e-filing system doesn't recognize a tax year beginning other than the 1st day of the month. They realize that may not match the federal return. Also, the ending date must be on the last day of the month.

## Solution

Either paper file the return or change the dates. To change the dates:

- Go to 

  Organizer

   and select **General Information**.
- Select **Basic Return Information** then the **Entity Information** tab.
- Use the 

  Dates

   section to enter different dates.
- Do a full recompute and re-create the e-file.
