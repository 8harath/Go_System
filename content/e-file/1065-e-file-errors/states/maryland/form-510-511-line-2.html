E-file error: Form 510/511: Line 2

Form 510/511: Line 2 - Total distributive or pro rata share of income per federal return must be equal to the sum of distributive income for all members as listed on Schedule B Parts I, II, III, and IV.
This happens because MD 510, Page 1 Line 2, must match the Schedule B Distributive Income totals.

Solution 1

  1. Go to the
    Tax Forms
    States
    Maryland
     folder.
  2. Select
    MD 510
    , then go to
    MD 510, Page 1
    .
  3. Line 2 amount must match with the
    TOTAL
     amounts in the
    Distributive Income
     column on MD 510:
    1. Sch B, Part I, IND
      ,
    2. Sch B, Part II, FID
      ,
    3. Sch B, Part III, PTE
      , and
    4. Sch B, Part IV, COR
  4. To adjust the amounts, go to
    Organizer
    ,
    States
    ,
    Maryland
     and select
    Other State Forms
    .
  5. Select
    PTE Amounts for Sch K-1
     and
    Distributive
     or
    pro rata share of income from federal Schedule K-1
    .
  6. Review the data entries.

Solution 2

Check for an aggregated Schedule K-1.
  1. Go to
    Organizer
    States
    Maryland
  2. Select
    E-file
    Attachments
    K-1 Aggregation
    Summary
  3. If the System generated Schedule K-1s are disabled and an aggregated xml file is present, select
    Attach K-1 Aggregation XML File
     .
  4. Select the aggregated xml file and then select
    Retrieve
    .
  5. Update the aggregated xml file to have the correct amounts so they’ll add up to the grand total.
  6. Delete the existing aggregated xml file from the electronic filing attachments screen.
  7. Select
    Add
    .
  8. Select attachment jurisdiction for
    Maryland K-1 Aggregation
  9. Select Browse for file and attach the updated XML Aggregation.
  10. Select
    Upload
     and then select
    Done
    .

Solution 3

Check if you're using Direct K-1 Import.
  1. Go to
    Organizer
    Partner Information
    Common Partner Data
    .
  2. Check if the
    Direct K-1 Import
     tab is the available. If the tab isn't there, then Direct K-1 Import isn't enabled and these steps aren't applicable to you.
  3. If the
    Direct K-1 Import tab
     is available, select it.
  4. If the option to
    Enable Direct K-1 Import to replace the computed Schedule K-1s
     is not selected, then you aren't using it.
  5. If it's selected, update the import file and reimport the direct k1 import file, or go to
    Tax Forms
    States
    Maryland
    Sch K-1
     and change the amounts directly on the tax form.
