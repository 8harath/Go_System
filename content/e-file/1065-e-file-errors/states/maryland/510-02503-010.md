# Form510-02503-010 e-file error

```
Form510-02503-010: Total Distributive or Prorata share of tax paid for PTE/sCorp Members must equal sum of tax paid for all PTE/sCorp Members on Schedule B, Part III.
```

This happens when the total share of tax paid doesn’t add up to the members on schedule B.

## Solution 1

- Select **Tax Forms**, then **States**.
- Go to the **Maryland, MD 510** folder.
- Select the **Sch B, Part II, FID** tab.
- The **Distributive Tax Paid** and **Distributive Tax Credit** columns must match.
- To update these columns, go to 

  **Organizer****States****State Information****Tax Computation**

   tab.
- Run a full recompute and recreate the e-file.

## Solution 2

- Go 

  **Tax Forms****States****Maryland, MD 510****MD 510, Page 1**

   tab.
- The amount in line 2 must match the total of all partner’s Distributive Income from schedule B parts I, II, III, and IV.
- To create and enter an allocation code, go to 

  **Organizer****States****Maryland****Other State Forms, PTE Amounts for Sch K-1****Member’s Income**

   section.
- Enter the amount and allocation code on the **Distributive or pro rata share of income from federal Schedule K-1** line.
- Do a full recompute and recreate the e-file.

note

If you are doing a K-1 aggregation attachment, the diagnostics will come from that file. You will need to fix the file so the amounts match and reattach the file to the return.
