# Form 510-02140-011 e-file error

```
State MDSeverity RejectData Value Incorrect DataState Record FORM510-02140Record Name MD510Form Occurrence No 0Field Seq No 0Page No 1Reject Code FORM510-02140-011Rule Number FORM510-02140-011XML Path //ReturnDataState/Form510/NumberOfMembers/TotalError Message Line 1e - Total number of partners, shareholders or members; Must be equal to the sum of members listed on Schedule B Part I, II, III, and IV. This rule should not be applied when PTE has only tax exempt members.
```

This happens when Line 1e total number of partners, shareholders, or members doesn’t equal to the sum of members listed on Schedule B Part I, II, III, and IV.

## Solution 1

- Go to 

  **Tax Forms****States****Maryland**

  .
- Select **MD 510**.
- Go to **MD 510, Page 1, Line 1e**. The amount must equal the sum of members listed on **Schedule B Part I, II, III, and IV Part III (2)** + **Part IV (2)**.
- To verify, go to 

  **Organizer****States****Maryland****E-file**

  .
- Select **Additional Information**.
- Go to the **Partner Count** section and verify the partner count.
- Do a full recompute and recreate the e-file.

note

If you are using a K-1 Aggregation file, make the necessary changes in the K-1 Aggregation file and reattach.

## Solution 2

- Go to 

  **Organizer****Partner Information****Partner by Partner Data**

  .
- Go to the **Partner Name** folder.
- Select **Partner Information**, then go to the **State Partner Information** tab.
- Go to the **Maryland** section.
- Mark the **Partner should be treated as Other (Entity is registered with Maryland)** checkbox.
- Do a full recompute and recreate the e-file.

## Solution 3

Maryland expects the special apportionment formula to be used with Schedule A. You can verify in the following path.

- Go to 

  **Tax Forms****States****Maryland**

  .
- Select **MD 510**, then **Page 4**.
- Mark the **Check here if special apportionment or alternative apportionment formula is used** checkbox.
- Go to 

  **Organizer****States****Allocation and Apportionment****Options**

  .
- Select **Optional Methods**.
- Go to the **Maryland** section.
- Mark the **Compute using special apportionment formula** checkbox.
- Do a full recompute and recreate the e-file.

note

The full XML is taking partner count from the K-1 Aggregation file. If you are using K-1 Aggregation, then the total on Form 510, Page 1, line 1e must match the number of members included in the e-file. You will need to correct the K-1 Aggregation file and reattach it.
