# E-file error: Field 'NotIATTransaction' is unexpected

```
Requirement: Expecting TelephoneNumber, RoutingTransitNumber 
Error: Field 'NotIATTransaction' is unexpected
```

This error happens when banking information is missing for Maryland.

## Solution

- Go to **Organizer** and select **States**.
- Select **Common State**, then **General Information**.
- On the **Bank Information** screen, select the **Direct Deposit** tab.
- Make sure that the row for Maryland has information in all columns.
- Do a full re-compute, recreate the e-file, then resubmit.
