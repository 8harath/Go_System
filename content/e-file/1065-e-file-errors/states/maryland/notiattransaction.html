E-file error: Field 'NotIATTransaction' is unexpected

Requirement: Expecting TelephoneNumber, RoutingTransitNumber 
Error: Field 'NotIATTransaction' is unexpected
This error happens when banking information is missing for Maryland.

Solution

  1. Go to
    Organizer
     and select
    States
    .
  2. Select
    Common State
    , then
    General Information
    .
  3. On the
    Bank Information
     screen, select the
    Direct Deposit
     tab.
  4. Make sure that the row for Maryland has information in all columns.
  5. Do a full re-compute, recreate the e-file, then resubmit.
