# 43158 e-file error

```
TotPartIncColAAllSource amount invalid
```

You may get this error if Lines 19a and 22a have different amounts.

## Solution

- Go to **Tax Forms**, **States**, **New Jersey**, **NJ-1065**, then **NJ-1065, Page 2**.
- Review line 19, Column A and line 22, column A. They must match.
- To update amounts:


  - Go to 

    **Organizer****States****New Jersey**

    .
  - Select **Federal Overrides**.
  - In the

    Income And Subtractions

     section, enter the amount and allocation code in **22 Partnership Income (loss) override**
- Do a full recompute, re-create the e-file, and resubmit the return.
