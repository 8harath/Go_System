200779 e-file error

ERROR: Duplicate CBTU Found
Ensure that the State ID is unique and entered for all members in a Consolidated Return.

Solution

  1. Go to
    Organizer
    ,
    States
    ,
    New Jersey
    , and select
    Combined Return Information
    .
  2. In the Combined report Options section, the Unitary ID entered here is all 9's.
  3. You will have to enter a valid New Jersey Unitary ID here, full recompute, then select the
    Transfer to All
     button.
  4. Do a full re-compute and re-create e-file.
  5. If you don't have a valid unitary ID, you will have to contact the state to determine what to enter as the unitary ID or you can paper file.
