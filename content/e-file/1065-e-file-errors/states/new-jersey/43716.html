43716 e-file error

Error

Noncorporate Partner s share of tax (Column J) missing /Invalid. (43716)

Cause

Amounts in Column J for the NJ 1065 Partner's Directory need to compute according to the state's instructions.

Solution

  1. In Tax Forms, go to
    States
    .
  2. Select
    New Jersey, NJ-1065 Partners Directory (Unsorted)
    .
  3. Remove any overrides in Column J.
  4. Column J needs to calculate according to the state instructions.
  5. If needed, you can change the entity codes for the partners.
  6. To change the entity code, go to the
    Organizer
    , then
    States
    .
  7. Select
    New Jersey
     then
    Partner Information
    .
  8. Change the code entered in the Entity Code column.
