E-file error: Field 'USAddress' cannot be empty

Form: FormNJ1065E[1] NJ1065Ept3[1]/AddressList[1]/USAddress[1] 
Error: USAddress 
ActionNeeded: Field 'USAddress' cannot be empty
You can get this error when address information is missing from the New Jersey return.

Solution

Make sure an address is entered in the following areas:
  1. In
    Organizer
     open the
    States
     folder.
  2. Select
    New Jersey
    , then
    Corporation Allocation
    .
  3. Make sure an address is entered in the Schedule J section.
  4. Then go to the
    Business Locations
     screen and make sure all address related information is complete, including the zip code.
  5. Then go to the
    Partner Information
     folder and select
    Partner by Partner Data
    .
  6. Select
    Columnar Partner Entry
     and make sure address information is complete on the
    Name and Address
     screen.
  7. Do a full re-compute and e-file the return.
