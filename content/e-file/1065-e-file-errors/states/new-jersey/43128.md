# 43128 e-file error

```
43128: NJ 1065 Page 2 Line 7 does not match Schedule A Column C Line 7
```

## Solution

- Go to **Organizer** and select **States**, then **New Jersey**.
- Select **Schedule A Information**.
- In Column B - INCOME EARNED BY OTHER PARTNERSHIP INCOME, enter 

  NONE

   for line 7, Royalty Income.
- Do a full re-compute and re-create e-file.
