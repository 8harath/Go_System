43138 e-file error

43138: NJ Partner Directory, Partner Entity Code is missing.
This happens when a partner is missing the entity code on the partners directory.

Solution

  1. In Organizer, select
    States
    .
  2. Select
    New Jersey
    , then
    Partner Information
    .
  3. Go to
    Partner Information
    tab.
  4. In the
    Entity Code
     column fill in the entity code for the partner.
  5. Perform a full recompute and recreate the e-file.
