# 43147 e-file error

```
* 43147: Schedule NJK-1 Part I, Date Partner's Interest in Partnership began must be present.
```

This happens when you haven’t entered the Date interest began in New Jersey for the partners.

## Solution 1

- In **Organizer**, select **Partner Information**, then the **Partner by Partner Data** folder.
- Select **Columnar Partner Entry**, then the **State Information** tab.
- Go to the **State Information for Partners** section, select the **New Jersey** hyperlink.
- Go to the **Partners' State Information - Maryland to New Mexico** section.
- In the **Date Partner's Int Began in NJ** column, enter the date for all partners.
- Do a full recompute and recreate the e-file.

## Solution 2

- In **Organizer**, select **Partner Information**, then the **Partner by Partner Data** folder.
- Select the **Partner Name** folder.
- Select **Partner Information**, then go to the **State Partner Information** tab.
- Go to the **New Jersey** section.
- Enter the date in Line **Date interest began in New Jersey**.
- Do a full recompute and recreate the e-file.
