# 43717 e-file error

## Error

```
Corporate Partner s share of tax (Column K) missing /invalid. (43716)
```

## Cause

Amounts in Column K for the NJ 1065 Partner's Directory need to compute according to the state's instructions.

## Solution

- In the Tax Forms, go to **States**.
- Select **New Jersey, NJ-1065 Partners Directory (Unsorted)**.
- Remove any overrides in Column K.
- Column J needs to calculate according to the state instructions.
- If needed, you can change the entity codes for the partners.
- To change the entity code, go to **Organizer** then **States**.
- Select **New Jersey** then **Partner Information**.
- Change the code entered in the Entity Code column.
