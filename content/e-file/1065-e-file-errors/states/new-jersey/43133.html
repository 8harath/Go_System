43133 e-file error

43133: Line 26 does not match total of all Column K on Partners Directory.
This happens when Line 26 doesn’t match total of all Column K on Partners Directory.

Solution 1

  1. In
    Tax Forms
    , select
    States
    , then the
    New Jersey
     folder.
  2. Go to
    Form NJ-1065
    , then
    NJ-1065, Page 2
    .
  3. The amounts on
    Line 25
     and
    Line 26
     must match the following path.
  4. Total of
    Column J
     and
    K
     from all partners in the
    Tax forms
    States
    New Jersey
     folder.
  5. Go to
    NJ-1065 Partners Directory (Unsorted)
    .
  6. Make the necessary changes.
  7. Do a full recompute and recreate the e-file.

Solution 2

If you are using an Aggregated Schedule K-1:
  1. In
    Organizer
    , go to
    States
    , then the
    New Jersey
     folder.
  2. Go to
    E-file
    K-1 Aggregation
    Summary
    .
  3. Check if the
    System generated Schedule K-1s are disabled
     and an aggregated XML file is present.
  4. Select
    Attach K-1 Aggregation XML File
    .
  5. Select the aggregated XML file, then
    RETRIEVE
    .
  6. Update the aggregated XML file to have the correct amounts so they’ll add up to the grand total.
  7. Delete the existing aggregated XML file from the electronic filing attachments screen.
  8. Select
    Add
    .
  9. Select attachment jurisdiction for
    New Jersey K-1 Aggregation
    .
  10. Select
    Browse for file
     and attach the updated XML Aggregation.
  11. Select
    Upload
    , then
    Done
    .
  12. Do a full recompute and recreate the e-file.

Solution 3

Check for Direct K-1 Import.
  1. In
    Organizer
    , go to
    Partner Information
    Common Partner Data
    Direct K-1 Import
     tab.
    note
    If you don’t see the
    Direct K-1 import
     tab, then it's not enabled.
  2. If the option to
    Enable Direct K-1 Import to replace the computed Schedule K-1s
     is enabled, update the import file and reimport the
    Direct K-1 Import
     file.
  3. Or in
    Tax forms
    , select
    States
    , then
    New Jersey
    .
  4. Select
    NJ-1065 Partners Directory (Unsorted)
     and change the amounts directly on the tax form.
  5. Do a full recompute and recreate the e-file.
