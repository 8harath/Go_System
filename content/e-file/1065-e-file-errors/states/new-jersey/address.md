# E-file error: Field 'Address' cannot be empty

```
Form: SchPD[1] PartnersDirect[45]/Address[1]
Error: Address
ActionNeeded: Field 'Address' cannot be empty
```

You'll get this error if a partner's address information is blank.

## Solution

- Select **Organizer**, **Partner Information**, then **Partner by Partner Data**.
- Select **Partner Information**, then **Partner Information** again.
- Make sure all partners have an address, state, city, and ZIP Code.
- Do a full recompute, recreate the e-file, then resubmit.
