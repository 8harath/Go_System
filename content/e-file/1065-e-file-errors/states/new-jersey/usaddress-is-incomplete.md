# E-File error: Field 'USAddress' is incomplete

```
Form: SchJ[1] SchJPt1[1]/PartLocation[1]/USAddress[1]
Requirement: Expecting AddressLine2Txt, CityNm
Error: Content for field 'USAddress' is incomplete
```

This happens when you need the complete the Address, City, State, and Zip code for a US address, or complete the Address, City, and Country code for a foreign address under the section for Location of the actual seat of management.

## Solution

- Go to **Organizer** and select **States**.
- Select **New Jersey** and go to **Corporation Allocation**.
- Under the section for Location of the actual seat of management, either complete the Address, City, State, and Zip code for a US address, or complete the Address, City, and Country code for a foreign address.
