# E-file diagnostics: NJ e-file: When using New Jersey K-1 aggregation

```
NJ E-File: When using New Jersey K-1 aggregation, Form NJ-1065 Page 3 Line 2c Columns J and K must have amounts populated. To enter amounts, go to Organizer New Jersey E-file - NJ 1065 Additional Information.
```

This happens when the Corporate and Noncorporate Share of tax is blank.

## Solution

- In **Tax Forms**, select **States**, then **New Jersey**.
- Select the **NJ-1065** folder, then **NJ-1065 Page 3**.
- Line 2c, Columns J and K need to have a value.
- To update those fields, go to 

  **Organizer****States****New Jersey****E-File - NJ 1065****Additional Information**

   folder.
- In the **K-1 Aggregation Only** section, enter an amount for Line Column J and Line Column K.
- Do a full recompute and recreate the e-file.
