# 43716 e-file error

## Error

```
Noncorporate Partner s share of tax (Column J) missing /Invalid. (43716)
```

## Cause

Amounts in Column J for the NJ 1065 Partner's Directory need to compute according to the state's instructions.

## Solution

- In Tax Forms, go to **States**.
- Select **New Jersey, NJ-1065 Partners Directory (Unsorted)**.
- Remove any overrides in Column J.
- Column J needs to calculate according to the state instructions.
- If needed, you can change the entity codes for the partners.
- To change the entity code, go to the **Organizer**, then **States**.
- Select **New Jersey** then **Partner Information**.
- Change the code entered in the Entity Code column.
