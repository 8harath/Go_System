# 43138 e-file error

```
43138: NJ Partner Directory, Partner Entity Code is missing.
```

This happens when a partner is missing the entity code on the partners directory.

## Solution

- In Organizer, select **States**.
- Select **New Jersey**, then **Partner Information**.
- Go to**Partner Information** tab.
- In the **Entity Code** column fill in the entity code for the partner.
- Perform a full recompute and recreate the e-file.
