E-file diagnostic: NJ e-file extension: Currently, more than one NK electronic filing extensions

NJ E-File Extension: Currently, more than one NJ electronic filing extensions have been enabled at the same time. To prevent validation and reject errors, only one type should enable and generate at a time.
This happens when you have more than 1 extension enabled for e-file for New Jersey.

Solution

  1. In
    Organizer
    , select the
    States
     folder.
  2. Go to
    State E-file
    , then select the
    Enable/Create Extensions
     folder.
  3. Select
    New Jersey
    , then clear the
    New Jersey
     or
    New Jersey CBT-1065
     checkbox in
    Column C
    .
  4. Do a full recompute and recreate the e-file.
