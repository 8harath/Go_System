# 43143 e-file error

```
NJ-1065 Partners Directory, if partner is a "Foreign US Partner" or "Applied For", Partner's ID must be blank. DO NOT enter as FOREIGNUS, APPLD FOR, or all 9s (999999999, 999-99-9999, 99-9999999). Go to: Organizer\Federal\Partner Information.
```

enter cause and intro (e.g. "This happens when" or "You get this error when")

## Solution 1

- Go to **Organizer**, **Partner Information**, **Partner by Partner Data**, **Columnar Partner Entry**, then the Name and Address tab.
- Remove all partners with 9s entered for their Social Security number (SSN).

  note

  The Partner ID for foreign partners needs to be blank. Remove the SSN or employer identification number (EIN) for all foreign partners. If you're importing partners, make changes in the file. If you entered it in the Organizer, it should be in the following location: 

  **Organizer****States****New Jersey****E-file - NJ 1065****Attachments****K-1 Partners Directory Aggregation****Summary****K-1 Partners Directory Aggregation XML file**

  .
- Do a full recompute, re-create the e-file, and resubmit the return.
