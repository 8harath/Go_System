# E-file error: Field 'Percent' with value '100.0001', data format is not correct

```
Form: FormNCD403[1] Part4[1]/PartnersTotal[1]/PartA[1]/PercentOwnership[1]/Percent[1]
Error: The field 'Percent' with value '100.0001', data format is not correct.
```

The Partner's share percentage (total) should not be over 100% and also can't be negative or none.

## Solution

- Go to **Tax Forms**, **States** and select **North Carolina**.
- Select **D-403**, **D-403**, **Page 3**, **Part 4**, **Line 4** -  The Partner's share percentage (total) should not be over 100% and also can't be negative or none.
- If there is no partner share percentage, 0 and none work, Spacebar overriding will allow the return to qualify.
- Select **Partner Information** and correct partners' share percentage.
- Do a full re-compute, recreate the e-file, then resubmit.
