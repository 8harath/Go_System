# NCD403-1156 e-file error

```
NCD403-1156: [D-403] Part 1 Line 14b must be equal to the sum of the following lines from all the associated forms received by the partnership: Partnership (D403) NC-K1 Line 9.
```

This happens when North Carolina Form D-403, D-403, Line 14b doesn't equal "Net Tax Due" in Tax Forms.

## Solution

- Review and copy the amount on line 14b in 

  **Tax Forms****States****North Carolina****D-403****D-403, Page 2**

  .
- Go to **Organizer**, then **States**.
- Select **North Carolina**, **Additional K-1 Information**, then **Other Partnerships**.
- Add a new NCK-1 from Partnership.
- Populate this area because it's associated with line 14b of Form D-403.
- Make sure that the total for **Net Tax Due** and **Share Tax Withheld** amounts match the amount on Line 14b.
- Do a full recompute and recreate the e-file.
