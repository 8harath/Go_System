# NCBus-1235 e-file error

```
NCBus-1235: [NC K-1 Supplemental Schedule-D403 NC K1] If D-403 NC K-1 Line 3 (Deductions) is greater than zero, then Line 3 must equal NC K-1 Supplemental Schedule Part B Line 41 from Column A.
```

This happens when NC K-1 Line 3 (Deductions) is greater than 0, but Line 3 doesn’t equal to NC K-1 Supplemental Schedule Part B Line 41 from Column A.

## Solution

- In Tax Forms, select **States**, then **Nort Carolina**.
- Select **Sch NC K-1**, then **Partner Name**, and then go to **Sch NC K-1**.
- Line 3 must be equal to Sch NC K-1 Supp, Page 2, line 41, Column A.

  To adjust the amounts on Page 3, in Organizer, select **States**, then **North Carolina**.
- Select **State Adjustments**, then the **Deductions from Federal Taxable Income** section.
- Adjust the amounts on the lines in the schedules mentioned in the previous steps.
- Do a full recompute and re-create the e-file.
