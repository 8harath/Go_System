NCD403-NCNPA e-file error

NCD403-NCNPA: if Tax Forms / States / North Carolina / D-403 / D-403, Page 2 / Part 4 / Partner Information/ NC-NPA Form attached marked as yes then go to Organizer / States / North Carolina / E-file / Attachments / PDF Attachments /
This happens when NC-NPA Form attached option marked as yes and there is no attachment exist inside the return.

Solution

  1. In Organizer, select
    States
    , then
    North Carolina
    .
  2. Select
    E-File
    , then
    PDF Attachments
    , then
    Summary
    .
  3. Select
    Attach PDF
     to open the
    Electronic Filling Attachments
     window.
  4. Select
    Add
    .
  5. Select the
    Attachment Jurisdiction
     North Carolina.
  6. Select
    Browse File
    .
  7. Select your file, and then select
    Open
    .
  8. Select
    Upload
    .
  9. Do a full recompute and recreate the e-file.
note
The file should have the file name FormNCNPA. There should not be a space between the words Form and NCNPA.
