NCD403-3000 e-file error

NCD403-3000: [D-403NCK1] The sum of Line 1 from all issued D403 NC K-1's must equal D403, Part 1, Line 1.
This error may occur if: there's a rounding issue on NC K-1, Line 1; there's a direct k1 import with information on Line 1 that doesn't match with Form D403, Part 1, Line 1; or there's an aggregated XML file for NC K-1 with information on Line 1 that doesn't match with form D403, Part 1, Line 1.

Solution

  1. Go to
    Tax Forms
    ,
    States
    ,
    North Carolina
    ,
    D-403
    ,
    Page 1
    ,
    Part I
    ,
    Line 1
    .
  2. Right-click Line 1 and select
    Allocation Display
     to see where the amounts for Line 1 are coming from.
  3. If the issue is caused by a rounding issue, you can override NC-K-1, Line 1, so that all the K-1s for NC will equal to Form D403, Part 1, Line 1.
  4. If there's a direct K-1 import with mismatching information for Line 1, update the import file to resolve for Line 1 so that it adds up properly, then re-import.
  5. If there's an aggregated K-1 XML file with mismatching information for Line 1, update the XML file to resolve for line 1 so that it adds up properly, then re-attach the XML file.
  6. Do a full recompute, re-create the e-file, and resubmit the return.
