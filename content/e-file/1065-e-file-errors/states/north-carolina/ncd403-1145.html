NCD-403-1145 e-file error

NCD403-1145: [D-403] If election to be a Taxed Partnership is "Yes", Part 1 Line 11 must equal Part 4 Line 18 from the Partners Total Column and Part 4 Line 25 from the Partners Total Column; otherwise Part 1 Line 11 must equal Part 4 Line 18 from the Partners Total Column.
This happens when Form D-403, Page 2, line 11 has a value that is not equal to Page 3, Section C line 18 and Page 3, Section E line 25.

Solution

  1. In
    Tax forms
    , select
    States
    , then
    North Carolina
    .
  2. Select
    Form D-403
    .
  3. Select
    D-403, Page 2
    , and make sure Part 1, line 11 is correct.
  4. elect
    D-403, page 3
    . In the section:
    C. Tax Computation for Nonresident Partners
     make sure line 18 is correct.
  5. Finally, in the section:
    E. Tax Computation of taxed Partnership
     make sure line 25 is correct.
  6. Lines 18 and 25 should add up to equal Page 2, line 11. If this is not the case then check line 18 in the next step.
  7. If Form D-403, Page 3 is incorrect and not overridden, select
    Partner information
     in Part A and make sure that for each partner, line 18 is correct and not overridden.
