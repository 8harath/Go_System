# NCD403-1390 e-file error

## Error

```
Message [D-403] If NC-NPA is attached, the Reference Document ID attribute must equal a Binary Attachment Document ID attribute. (NCD403-1390)
```

## Cause

North Carolina Form D-403, Page 2, Part 4, Line 18 equals Line 17 multiplied by .0525.

## Solution

- In the Organizer, go to **States** then select **North Carolina**.
- Select **E-File** then **Attachments**.
- Select **K-1 Aggregation** then **Summary**.
- Open the **K-1 aggregation file**.
- The file should look like the following:
- Update the file to the following:


  * <IsNCNPAAttached>true</IsNCNPAAttached>
  * <FormNCNPA referenceDocumentId="BinaryAttach">Attach</FormNCNPA>
- Do a full recompute, recreate the e-file, then retransmit the return.
