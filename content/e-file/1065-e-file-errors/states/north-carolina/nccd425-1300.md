# NCCD425-1300 e-file error

```
NCCD425-1300 - S: [CD-425] Line 24 must equal CD-405 Schedule B line 23 or CD-401S Schedule B line 19.
```

This happens when you need a value on line 8 for form CD-425.

## Solution

- Go to **Tax Forms**, **States**,**North Carolina**, **CD-425 Tax Credit Summary**, and then **CD-425 Tax Credit Summary**.
- If there isn't a value enter **NONE** on line 8.
- Do a recompute and re-create the e-file
