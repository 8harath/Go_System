# E-file error: Field 'PartnersTotal' is unexpected

```
Field 'PartnersTotal' is unexpected
```

You'll get this error if you mark the **Suppress partner information** checkbox.

## Solution

- Go to **Organizer**, **States**, **North Carolina**, **E-file**, **Attachments**, **K-1 Aggregation**, then **Summary**.
- Clear the **Suppress partner information** checkbox.
- Do a full recompute, re-create the e-file, and resubmit the return.
