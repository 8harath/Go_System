# NCD403-1140 e-file error

```
NCD403-1140: [D-403] If Part 3 is present, then Part 1 Line 10 must equal Part 3 Line 2; otherwise, Part 1 Line 10 must be zero or blank.
```

This happens when Form D-403, Page 2 Part 3 Line 2 has an amount then Nonapportionable Net Distributive Partnership Income (Loss) requires an explanation.

## Solution

- In Tax Forms, select **States**, then **North Carolina**.
- Select **D-403**, then**D-403, Page 2**, then **Part 3 Nonapportionable Net Distributive Partnership Income (Loss) requires an Explanation**.
- In Organizer, select **States**, then **North Carolina**, then **State Adjustments**.
- Select **Nonapportionable Net Distributive Partnership Income**.
- Enter an explanation where it states Explanation for why income is listed as nonapportionable income; rather than apportionable income.
- Perform a full recompute and recreate the e-file.
