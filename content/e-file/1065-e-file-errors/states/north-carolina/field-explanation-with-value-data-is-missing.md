# E-file error: The field 'Explanation' with value '', data is missing

```
The field 'Explanation' with value '', data is missing.
```

This error displays if you didn't enter an explanation for nonapportionable income.

## Solution

- Go to **Organizer**, **States**, **North Carolina**, then **State Adjustments**.
- Go to the Nonapportionable Net Distributive Partnership Income section.
- Enter information for **Explanation of why income is listed is nonapportionable income; rather than apportionable income**.
- Do a full recompute, recreate the e-file, and resubmit.
