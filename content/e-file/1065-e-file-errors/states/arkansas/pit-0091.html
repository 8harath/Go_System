PIT-0091 e-file error 

PIT-0091: Form AR1050 - Line 19 (Column A) is populated, then Federal Form 4562 should be attached as a PDF file. Navigate to the following location: Organizer\States\Arkansas\E-file\ Attachments\PDF Attachments\Summary and click the button "Attach PDF". Make sure to select the predefined description for Form 4562.
This happens when Form AR1050, Page 1, Line 19, Column A, is populated with an amount but the Federal Form 4562 isn’t attached as a PDF file.

Solution

  1. In
    Organizer
    , select
    States
    , then
    Arkansas
    .
  2. Select
    E-file
    Attachments
    PDF Attachments
    Summary
    .
  3. Select
    Attach PDF
    , then
    Add
    .
  4. Select
    Arkansas
     for the Attachment Jurisdiction.
  5. Select
    Browse for file
    , then
    Upload
    .
  6. Select
    Predefined description
     for the
    Attachment description
    , then select
    Form 4562
     from the dropdown.
  7. Perform a full recompute and recreate the e-file.
