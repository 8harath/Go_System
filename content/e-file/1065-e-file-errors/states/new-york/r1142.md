# R1142 e-file error

Either message applies to this e-file error.

```
IT-204 Item F2 must be > 0 when an IT-204-CP is present (R1142)
```

```
XML Error Checking: Rule Number: NY Reject Code R1142 Description: Form IT-204, Page 1, Item F2 - Article 9-A, the number of IT-204-CP entered on the tax form is = , Based on the NY Aggregation file
```

New York states that if the IT-204-CP is included in the return, you need to have at least 1 article 9-A on line F2.

This happens when Partners that are partnership entities do not file a IT-204-CP. Once corrected you must recreate the NY XML to clear this reject diagnostic.

## Solution 1

- In the Tax Forms, go to **States**.
- Select **New York** then **IT-204**.
- Make sure you have a number on Page 1, line F2.
- Do a full recompute, recreate the e-file, and resubmit the return.

## Solution 2

- In Organizer, select **States** then **New York**.
- Select the **General information** tab then go to the line**Total Number of Partners (Override)**. The line **Article 9-A** can't be Blank or NONE. You need to have at least 1 partner number entered.
- Do a full recompute, recreate the e-file, and resubmit the return.

## Solution 3

- If using an aggregation file, in Organizer, select **States**, then **New York**.
- Select 

  **E-File****Attachments****K-1****Aggregation****Summary**

  .
- Select **Attach K-1 Aggregation XML File**.
- Make sure there is more than 0 on line F2 for **Article 9-A** .
- Do a full recompute, recreate the e-file, and resubmit the return.
