# R1140 e-file error

```
R1140: Total number of IT-204-IPs included in NY XML must be greater than or equal to Form IT-204 Item F1 (number of Article 22 partners) if Item B1 is Yes. NOTE: New York K-1s (IT-204-IP and IT-204-CP) can NOT be PDF attached. They MUST be included in XML
```

This can happen when the IT-204-IP and IT-204-CP aren't included in the e-file.

## Solution

- Open **Organizer**, go to **States**, and select **New York**.
- Select **E-file**, **Attachments**, then **K-1 Aggregation**.
- Open **Summary** and clear the checkbox **Suppress system generated Form IT-204-IP**.
- Go back to **New York** and select **Return options**.
- In the Suppression section, clear the checkbox for **Form IT-204-IP nonresident partners**.
- Do a full recompute and, recreate the e-file, then resubmit.
