# R1138 e-file error

## Error

```
Total number of IPs and CPs must be >= IT-204 Item B2 if Item B1 = No (rule R1138)
```

## Cause

The number of partners listed on Form IT-204, line B2 doesn't equal the amount of partners listed in the Organizer and/or partner's Schedule K-1s.

## Solution

- In the Organizer, go to **Partner Information**.
- Open **Partner by Partner Data** and select **Columnar Partner Entry**.
- In the list of partners, count how many partners are NY residents.
- Go to **Tax Forms** then **States**.
- Select **New York, IT-204**.
- Count the number of partners on IT-204, Page 1, line B2. The number of NY residents here needs to match what is in Columnar Partner Entry.
