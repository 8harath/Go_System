R1143 e-file error

Error

Name of entity and EIN information is required when Line 117c = Yes (R1143)

Cause

The return indicates that this partnership is a partner in another partnership or LLC, yet EIN and entity information is missing.

Solution

  1. In the Organizer, go to
    States
    .
  2. Select
    New York
     then
    State Information
    .
  3. In the Business Address tab, review the
    Is this partnership a partner in another partnership or LLC
     field.
  4. If it's marked Yes, confirm you've entered information in the
    If Yes, list name and EINs below
     fields. Attach additional sheets if necessary.
