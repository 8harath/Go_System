# F568-055 e-file error

## Scenario

You may get the following error message when submitting a return.

## Error

```
Form 568, filers Secretary of State Number [SOSNumber], LLC Temp Number [LLCTempNumber] or Not applicable reason [NotApplicable] in the CA-ReturnHeader must be present. (F568-055).
```

## Cause

California requires a valid Secretary of State number, LLC Temp number, or a **not applicable** reason to file the return.

## Solution

- Go to **Organizer**, then **States**.
- Select **California**, then **General Information**.
- Select 1 of the following ID number options:


  * **Secretary of State ID number**.
  * **LLC temporary number assigned by FTB**.
  * An option from the **Select one of the following options if the entity does not have a state ID number** group.
- If you don't know the entity's Secretary of State ID number, contact the California E-Help Desk at 916-845-0353.
- Do a **Full Recompute**, re-create the e-file, and resubmit the return.
