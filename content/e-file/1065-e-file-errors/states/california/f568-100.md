# F568-100 e-file error

```
Form 568 Question J [BusinessActivityCode] must be a valid 6-digit Principal Business Activity (PBA) code per the current Form 568 Booklet. (F568-100).
```

You'll get this if a valid **Principal business code** is missing from the California return.

## Solution

- Go to **Organizer**, then **States**.
- Select **Common State**, then **General Information**.
- Select **Basic Return Information**, then go to the **Entity Information** tab.
- In the spreadsheet, review column K, **Principal Business Activity code** for the California row. Make sure a valid code is entered. Valid codes are on the [California FTB's website](https://www.ftb.ca.gov/forms/2023/2023-568-booklet.html#Codes-for-Principal-Business-Activity).

  note

  For more information, contact the California Help Desk at 916-845-0353.
- Do a **Full Recompute**, re-create the e-file, and resubmit the return.
