F568-100 e-file error

Form 568 Question J [BusinessActivityCode] must be a valid 6-digit Principal Business Activity (PBA) code per the current Form 568 Booklet. (F568-100).
You'll get this if a valid
Principal business code
 is missing from the California return.

Solution

  1. Go to
    Organizer
    , then
    States
    .
  2. Select
    Common State
    , then
    General Information
    .
  3. Select
    Basic Return Information
    , then go to the
    Entity Information
     tab.
  4. In the spreadsheet, review column K,
    Principal Business Activity code
     for the California row. Make sure a valid code is entered. Valid codes are on the California FTB's website.
    note
    For more information, contact the California Help Desk at 916-845-0353.
  5. Do a
    Full Recompute
    , re-create the e-file, and resubmit the return.
