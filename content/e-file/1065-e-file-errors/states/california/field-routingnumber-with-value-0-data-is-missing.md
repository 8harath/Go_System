# E-file error: The field 'RoutingNumber' with value '0', data is missing

```
The field 'RoutingNumber' with value '0', data is missing
```

You'll get this error if the routing number field is blank or contains a 0.

## Solution 1

- Go to **Organizer**, **States**, **Common State**, **General Information**, **Bank Information**, then the **Direct Debit** tab.
- Enter all information for line **California**.
- Go to **Organizer**, **States**, **Common State**, **General Information**, Basic Return Information, then the Signature Information tab.
- Enter a phone number in column H.
- Do a full recompute, re-create the e-file, and resubmit the return.

## Solution 2

- Go to **Organizer**, **States**, **California**, **Disregarded Entity**, then **Tax and Fee Calculation**.
- Go to the Tax Calculation and Overrides section for California.
- Mark **Check if not subject to LLC tax of $800**.
- Do a full recompute, re-create the e-file, and resubmit the return.
