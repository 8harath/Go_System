# X0000-020 e-file error

## Scenario

You may get the following error message when submitting a return.

## Error

```
Your State submission does not match the latest published FTB Schema or is not well formed. You must contact your software provider to resolve this error.
```

```
XPath to Error /Return/ReturnHeader/PartnerInformationGrp/SignatureDt
```

## Cause

The IRS hasn't accepted the federal return.

## Solution

- Submit the federal return.
- Once the federal return has been accepted, re-create the e-file, and resubmit the California return.
