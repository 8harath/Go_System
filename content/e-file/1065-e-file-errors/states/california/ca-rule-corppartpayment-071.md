# E-file error: CA Rule CorpPartPayment-071

```
CA Rule CorpPartPayment-071: If filing Form 3893 PTE Tax, Entity type must be present. Navigation: Tax Form>States>California>Form 565 Side 2 Item J.
```

## Solution

- Go to **Organizer**, **States**, **State E-file**, then **Enable/Create Returns**.
- In Column C, clear the checkboxes for **California PTE TAX 1** and **California PTE TAX 2**.
- Do a full re-compute, recreate the e-file, and resubmit.
