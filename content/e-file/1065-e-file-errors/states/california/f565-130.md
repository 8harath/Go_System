# F565-130 e-file error

```
CA Rule F565-130: Form 565 Line 2, amount must equal Schedule A Line 8 amount.
```

This happens when Form 565 Schedule A Line 8 doesn’t equal Schedule B Line 2.

## Solution

- Go to **Tax Forms**, **States**, and select **California**, **568**, **568, Side 4**.
- **Schedule A**, Line 8 needs to match **Schedule B**, Line 2.
- Go to **Organizer**, **States**, and select **California, Federal Overrides**, **Ordinary Income and Deductions**.
- Go to **Income Summary**, then the **Cost of Goods Sold** tab.
- Enter an amount for line 2.
- Do a full recompute and recreate the e-file.
