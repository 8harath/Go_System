11329099 e-file error

Error

F565-030 F568-030: Form 565/568, Tax Period Begin Date cannot be later than the current date.

Cause

The Tax Period Begin Date is later than the current date.

Solution

  • Do a full recompute.
  • In the Organizer, go to
    States
    ,
    State E-File
    , and then select the
    Return
     tab.
  • Create the e-efile.
