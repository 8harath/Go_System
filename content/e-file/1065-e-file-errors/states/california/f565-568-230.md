# F565/568-230 e-file error

```
CA Rule F565/568-230: If Line 17a amount is present, then FTB 3885P/3885L must have data.
```

Form 565/568: Form 565, Side 1/Form 568, Side 4 Line 17a Depreciation and Amortization amount must match Form 3885P/3885L Line 6 amount.

## Solution

Go to 

**Tax Forms****States****California**

 and review Form 565 or 568, line 17a. If there is any amount on this line, Form 3885 needs to calculate and line 6 needs an amount.

- On Form 565 or 568, select the drill down ![drill down](/content/dam/helpandsupp/en-us/Topics/ONESOURCE-family/images/drill-down.png/_jcr_content/renditions/cq5dam.web.1280.1280.jpeg) on Line 17a and clear any overrides on the yellow workpaper.
- Go to **Organizer** and select **Ordinary Income and Deductions**.
- Select **Depreciation and Amortization** then the entity name.
- In the **4562 Information** folder, select **4562 Overrides**.
- Select the link for **State Overrides** and there is a section you can enter information for 

  California Only

  . Populate here to generate the Form 3885P.
- Finally, the amount on Line 17a must match Form 3885P/3885L Line 6 amount.
