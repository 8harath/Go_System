F565-060 e-file error

Error

You could get one of the following errors.
Form 565 [TaxPeriodBeginDate], [TaxPeriodEndDate], and [SOSNumber], or [FEIN] if [SOSNumber] is not present, from the CA-Return Header cannot match a previously accepted return unless Schedule Q [AmendedReturn] or [SupersededReturn] box is checked.
or
CA F565-060/F568-060: SOS ID or FTB Assigned ID number must be present. If no valid ID number, other reason (Foreign, Appl Applied for or Other reason) must be selected. Navigation: Organizer>States>California>General Information

Cause

The state of California may already has a return on file for this filing period and Federal Employer Identification Number (FEIN).

Solution

  1. Go to
    Organizer
    , then select
    States
    .
  2. Select
    California
    .
  3. elect
    General Information
    , then
    General Information
     again.
  4. In the
    ID Options
     section, make sure this section is filled out correctly.
    1. Don't enter all 0's.
    2. Don't use the FEIN as the SOS/FTB Assigned number.
    3. If they don't have a valid ID#, leave the field empty and select
      Other reason
      .
  5. If the FEIN is incorrect, perform a full re-compute, re-create the e-file, then re-submit.
  6. If the FEIN is correct, contact the California Department of Revenue (DOR) at 800-852-5711.
