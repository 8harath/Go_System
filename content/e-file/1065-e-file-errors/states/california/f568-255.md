# F568-255 e-file error

## Scenario

You may get the following error message when submitting a return.

## Error

```
Schedule B, Line 23 [OrdinaryIncomeLoss] must equal the result of Line 12 [TotalIncomeLoss] minus Line 22 [TotalDeductions]. (F568-255).
```

## Cause

**Ordinary income** (Line 23) on **Schedule B** doesn't equal **Total income** (Line 12) minus **Total deductions** (Line 22).

## Solution

- Go to **Tax Forms**and select **States**.
- Select **California**, then **568**.
- Select **568**, then **568, Side 4**.
- Remove any overrides from **Schedule B**.
- Do a **Full Recompute**, re-create the e-file, and resubmit the return.
