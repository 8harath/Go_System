# E-file error: The field 'DateBusinessStartedInCA' with value '0', data is missing.

```
The field 'DateBusinessStartedInCA' with value '0', data is missing.
```

You'll get this error if the Date Business Began field is blank or contains a 0.

## Solution

- Go to **Organizer**, **States**, **Common State**, **General Information**, **Basic Return Information**, then the **Entity Information** tab.
- Go to the **California** row.
- Enter the date in the **Date Business Began** field in State column (H).
- Go to the **California LLC** row.
- Enter the date in the **Date Business Began** field in State column (H).
- Do a full recompute, re-create the e-file, and resubmit the return.
