# F565-067 e-file error

```
CA Rule F565-067: Form 565, Side 1 Total asset at EOY must have data unless Side 2, Line P is checked "Yes".
```

This happens when you don’t have a total asset value on Form 565 Side 1 or you're missing an entry on Form 565 Side 2 Line P.

**Solution**

Use the following steps to answer Form 565 Side 2 Line P with Yes.

- Go to the **Organizer**, **States**, **California**, and then the **Additional Information** folder.
- Select **Questions**, and go to the **Questions** section.
- Go to **Line P**, **Does the partnership meet all the requirements shown in the instructions for Question P?** and select the radio button**YES**.
- Do a full recompute and recreate the e-file.

**Solution 2**

If your asset information is correct, and you don’t want to select **Yes**, then you need to paper file the return.
