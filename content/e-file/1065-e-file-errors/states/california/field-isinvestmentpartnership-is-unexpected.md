# E-file error: Field 'IsInvestmentPartnership' is unexpected

```
Field 'IsInvestmentPartnership' is unexpected
```

## Solution

- Go to **Tax Forms**, **States**, **California**, **568**, then **568**.
- Information is necessary for **568, Side 2 Question K**. The client needs to update the information at the following location:


  - **Organizer**, **States**, **California**, **Additional Information**, **Questions**, **L/K**. Number of Schedule K-1s (Override).

    note

    At least 2 instances of Schedule K-1 need to be present in a 1065 return.
- Do a full recompute, re-create the e-file, and resubmit the return.
