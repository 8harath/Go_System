# c00ce169 e-file error: Element name failed to parse

```
'XXXX' violates pattern constraint of '(([A-Za-z0-9#\-\(\)] & ') ?)*([A-Za-z0-9#\-\(\)] & ')'.
The element '{http://www.ftb.ca.gov/efile}Name' with value 'XXXX' failed to parse.
```

You may get this error a partner's name or address contains special characters.

## Solution 1

- Go to **Organizer**, **States**, **California**, **E-file**, **K-1 Aggregation**, then **Summary**.
- Remove any special characters from the partner names and addresses.
- Do a full recompute, re-create the e-file, and resubmit the return.

## Solution 2

- Go to **Organizer**, **Partner Information**, **Partner by Partner Data**, **[Partner name]**, **Partner Information**, then the **Partner Information** tab.
- Go to the **Name, Address, Phone Number and SSN \ EIN** section.
- Remove any special characters from the partner's name.
- Do a full recompute, re-create the e-file, and resubmit the return.
