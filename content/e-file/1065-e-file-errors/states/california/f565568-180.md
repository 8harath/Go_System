# F565/568-180 e-file error

```
CA Rule F565/568-180: If Line 8 amount is present, then Schedule D-1 must have data.
```

This happens when California Form 565 Side 1 Line 8 Total gains included on Schedule D-1, Part II Line 17 (gain only) is populated but Schedule D-1 information is missing.

## Solution

- Go to **Tax Forms**, then **States**.
- Select **California**, then go to **Form 565, Side 1, Line 8**.
- If Line 8 is populated, then the Schedule D-1 must be populated. Line 8 should be equal to all the gains in Schedule D-1.


  - To populate Schedule D-1, go to **Organizer** and **Gains and Losses**.
  - Select **Sales of Business Property** and **Property Descriptions**.
  - Enter details for the property. If you need to add a new property, select **Add new Description of Property**.
- Do a full recompute and recreate the e-file.
