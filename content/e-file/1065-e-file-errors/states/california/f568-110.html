F568-110 e-file error

Error

If Form 568, Question M(1) [IsApportioningToCA] is checked Yes then Schedule R, Line 1a [NetIncomeLossAfterAdjustments] must be present.

Cause

A value is missing for Schedule R, Line 1a.

Solution

  • In the Organizer, select
    States
    .
  • Select
    California
    ,
    Return Options
    , then
    Print options
    .
  • In the
    Print suppression
     section, unmark the
    Schedule R and Supporting Schedules
     checkbox.
  • Recompute, then recreate and resubmit.
