F565-260 e-file error

1065 California CA Rule F565-260: If Form 565, Side 2, Line 28 Withholding amount is present, then Form 592- B must have either CA tax withheld amount or backup withholding amount. Navigation: Organizer>States>California>592B from Third Party E-filed only.
This e-file error will show up if the "Withholding (form 592-B and/or 593)" field on Side 2, line 28 of the California Form 565 (found under Tax Forms/States/California/565/565/565) has an amount.
Solution
  1. In Organizer, select
    States
    , then
    California
    .
  2. Locate and select
    592B
     from the
    Third Party and filed only
    .
  3. Select the designated button to add a new 592B form.
  4. Repeat this process to add a separate 592B form for each partner who has a withholding amount.
  5. Recreate and resubmit the e-file.
