# R000-058 e-file error

## Scenario

You may get a 1065 California Reject Code R0000-058 when trying to attach a PDF.

## Error

```
A binary attachment XML document that represents a PDF attachment must have a valid reference to an attached file
```

## Cause

No spaces and no special syntax are allowed, and PDF file name can't exceed 23 characters.

## Solution

- Go to **Organizer** and select **States** then **California**.
- Select **E-file** then **PDF Attachments**.
- Select **Summary**, **Reattach PDF**, **Recompute**, then **Recreate e-file**.

note

No spaces and no special syntax are allowed, and PDF file name can't exceed 23 characters.
