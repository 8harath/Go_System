# E-file error: California LLC Annual Tax: Form 8453-BE Part III cannot be NONE

```
e-File should only be generated and submitted when Form 8453-BE Part III Annual Tax payment have an amount and can't be NONE.
```

If you're filing the California LLC Annual return, Form 8453-BE needs to have payment information. There are 3 solutions.

## Solution 1

Make sure all bank information is correct.

- In **Organizer**, select 

  **States****Common State****General Information****Bank Information****Direct Debit**

   tab.
- Make sure **Authorization to Debit Funds** in column B is marked for the California PTE Tax.
- Make sure columns D-H are complete. Make sure the date in Column G, **Date Amount to be Debited** is the day of or after you submit the return.

## Solution 2

Make sure you're filing the correct form.

Use Form 8453-LLC to make annual tax, estimated fee, and/or PTE elective tax when e-filing Form 568 as one XML. Use Form 8453- BE (PMT) when making stand-alone payment, separate from Form 568.

* If you're using Form 8453-BE to file Estimated Fee Payment, create those separately in 

  **Organizer****States****State E-file****Enable/Create Estimates**

  .
* If you want to submit Annual Tax and estimated fee payment along with the main Form 568, then use Form 8453-LLC instead. Go to 

  **Organizer****States****California****Payment of Taxes****Form 8453-LLC Only**

   section.

## Solution 3

Suppress the California LLC Annual Tax return:

- Go to **Organizer** and select **States**.
- elect **State e-file**, then **Enable/Create returns**.
- Unmark **California Annual LLC** in column C.
