# 514-010 e-file error

```
514-010: Form 514, Part 3, line 15, Column B (NetDistributiveIncome, StateAmount) should equal line 7, Column B (TotalIncome, StateAmount) minus line 14, Column B (TotalDeductions, StateAmount) unless Part 4 is present. If Part 4 is present, Part 3, line 15, Column B should equal Part 4, line 7 (StateNetDistributableIncome).
```

This happens when you have overridden the Net Oklahoma distributive income amount.

## Solution 1

- Go to the **Organizer**, **States**, **Oklahoma** folder.
- Select **State Information**, then go to the**Distributive Share Items** tab.
- In the **Part 3 - Distributive Share Items (Column B)** section, remove the override value.

  note

  If there is an override for Oklahoma, it won’t be calculated correctly. You might need to clear the override to clear the reject.
- Do a full recompute and recreate the e-file.

## Solution 2

- Go to **Organizer**, **States**, **Oklahoma** folder.
- Select **Return Options**, then go to the **Compute Options** section.
- Clear the **All income is from a unitary enterprise** checkbox.

  note

  Marking the **All income is from a unitary enterprise** turns on **Part 4 Unitary Enterprise**. This checkbox should be cleared, or **Part 4** should be completed to clear the diagnostic when **Part 3 Line 15B** and **Part 4 Line 7** are equal.
- Do a full recompute and recreate the e-file.
