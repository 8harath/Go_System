# E-file diagnostic: Partner’s name in state partner information

```
Minnesota Electronic Filing: For partners with an entity type of individual, the partner's name must be entered as first name, middle initial, and last name in state partner information for e-filing purposes.
```

This happens when either the individual name isn’t reformatted or there is an override for the reformatted name.

## Solution

- Go to 

  **Organizer****Partner Information**

  .
- Go to 

  **Partner by Partner Data****[Partners Name]****Partner Information**

  .
- Go to the **Reformat Partner Name for State Purpose** tab.
- Go to the **Override or Imported or Rolled Over 0 Partner Name** section.
- Remove anything in here as long as there is information entered in the **Automatic Reformat – Partner Name** section.
- Run a full recompute and recreate the e-file.
