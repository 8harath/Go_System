# E-file diagnostic: Form KPC, domestic or foreign address

```
On Form KPC, partner domestic or foreign address must be significant.
```

This happens when the Partner Information has missing data such as partner number, 1st name, last name, and address.

## Solution

- In Organizer, select **Partner Information**, then **Partner by Partner Data**.
- Select **Columnar Partner Entry** and verify the information.
- Make sure **Partner Number** has the complete name and address for all the partners.
- Recompute the return and recreate the e-file.
