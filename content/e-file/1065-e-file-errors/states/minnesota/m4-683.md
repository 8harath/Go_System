# M4-683 e-file error

## Error

```
Minnesota Tax ID must be registered under the correct Federal Employer Identification Number and match Department of Revenue Records. To register or verify your ID, call Business Registration at (651) 282-5225. (M4-683)
```

## Cause

According to the state, the Minnesota Tax ID included in the return isn't correct.

## Solution

- In Organizer, go to **States**.
- Select **Minnesota**, then **General Information**.
- Review the Tax ID entered in the **Identification number** field.
- If incorrect, fix it then do a full recompute and recreate the e-file.
- If the Tax ID is correct, you need to contact the state Business Registration office at 651-282-5225.
