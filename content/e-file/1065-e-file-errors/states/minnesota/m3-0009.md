# M3-0009 e-file error

```
A return was previously submitted and accepted for this tax period and MN tax ID
```

## Solution

- Go to **Organizer**, **States**, **Minnesota**, then **General Information**.
- Enter the MN Tax ID for Identification number.
- Do a full re-compute, recreate the e-file, and resubmit.

note

The Minnesota Tax ID must be registered under the correct Federal Employer Identification Number and match Department of Revenue records. To register or verify an ID, call Business Registration at 651.282.5225.
