E-file diagnostic: Form M3, income tax withheld Form M3 line 4

Form M3, Income Tax Withheld: Form M3 line 4 nonresident withholding amount should equal sum of partners’ amount on Form KPI line 52.
This happens when the amount on the M3 line 4 does not match the sum of all KPI’s page 3 line 52.

Solution

  1. In Tax Forms, select
    States
    Minnesota
    M3
    M3 Partnership Return
    .
  2. The value on line 4 must equal the sum of all KPI’s on line 52.
  3. In Tax Forms, select
    States
    Minnesota
    KPI
    Partner's name
    KPI Page 3
    .
  4. Add up the sum of all partners on line 52, This amount must equal the amount from Form M3 line 4.
  5. Once amounts equal, full recompute and recreate e-file.
note
If you use a K-1 aggregation file, make the corrections in the file. Remove the original file and upload corrected one.
  1. In Organizer, select
    States
    Minnesota
    E-file
    Attachments
    K-1 Aggregation
    Summary
    .
  2. Select
    Attach K-1 Aggregation XML File
    , and the locate file.
  3. You can either,
    Edit
    ,
    Delete
     or
    Retrieve
     the file.
