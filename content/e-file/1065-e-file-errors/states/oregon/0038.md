# 0038 e-file error

```
The total number of owners listed on the Oregon Composite return must match the number of owners listed on the Schedule OC 1 or Schedule OC 2. (Automatic GoTo is not available). Navigate - TaxForm\ State\ OR\ Composite Return\ Form OC
```

This happens when the total number of owners listed on the Oregon Composite return didn’t match the number of owners listed on the Schedule OC 1 or Schedule OC 2.

## Solution 1

- Go to 

  **Tax Forms****States****Oregon**

  .
- Go to the **Composite Return** folder, then **Form OC**.
- The form OC Page 1 Line 1 must match the sum of line 5a.
- Go to 

  **Tax Forms****States****Oregon**

  .
- In **Composite Return**, verify the sum of **OC1 or OC2** for the Individuals, Estates and Trusts tab for line 5a.

## Solution 2

If the OR-OC will be submitted without any tax due:

- Go to 

  **Tax Forms****States****Oregon**

  .
- Go to the **Composite Return** folder and select the **OC1 Individuals** tab.
- Select **Individual partner detail**. On this screen, enter **NONE** for column A, Oregon income tax for partners included in the OC.
- Do a full recompute and recreate the e-file.
