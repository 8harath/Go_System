# MTE 21BZT19 Form P e-file error

```
MTE 21BZT19 Form P 'Not allowed if 'IncBeforeOpLossDdctMLT' is a loss.: OperatingLossDeductMLT cannot be more than 75% of IncBeforeOplossDdctMLT.
```

This happens when the Net operating loss is more than 75%.

## Solution

- In Tax Forms, select **Cities and Intangibles**, then **Portland, Multnomah**.
- Select **Metro Supportive Housing Tax Return**, then **METBIT-65**.
- Review the net operating loss on line 12. Loss can't be more than operating loss and can't be more than 75% of line 11.

**To make corrections to the amounts:**

- In Organizer, select **Cities and Intangibles**, then **Portland, Multnomah**.
- Select **City and County Adjustments**.
- In the METBIT-65 Entry section, review if there’s any entry or make a correction in this field.
- Paper file the return.
