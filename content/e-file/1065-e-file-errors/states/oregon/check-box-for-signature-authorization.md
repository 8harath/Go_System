# Checkbox for signature authorization e-file error

```
Check box for signature authorization needs to be complete in Organizer/ States/Oregon/E-file or E-file Composite/Additional Information
```

This happens when the checkbox to authorize the composite e-file isn't marked.

## Solution

- Go to: 

  **Organizer****States****Oregon E-File – Composite****Additional Information**

  .
- Mark the checkbox to agree with **ERO / Preparer certification and signature (OC)**.
- Mark the checkbox to agree with **ACH Transfer Authorization (OC)**.
- Mark the checkboxes for the authorization for **Oregon, E-file, Additional information**.
- Do a full recompute and recreate the e-file.
