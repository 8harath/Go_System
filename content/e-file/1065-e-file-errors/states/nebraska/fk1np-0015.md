# FK1NP-0015 e-file error

```
IncTaxWithheld (line 22) for this partner must equal Nebraska Schedule II ShareholderPartner_Form12NOrWithholding_WithholdingAmt (Col G) for this partner, if Schedule K-1N 1065 is present.
```

This happens when **1065N, Sch K1N**, Part C, Line 22 is not equal to **1065N, Sch II**, Column G total value.

## Solution

- In **Tax Forms**, select the 

  **States****Nebraska****1065N, Sch II**

   folder.
- Select **Sch II**, **Column G** total must be equal to the following path.
- In **Tax Forms**, select the 

  **States****Nebraska****1065N, Sch K1N**

   folder.
- Select the 

  **Partner Name****Sch K1N****Part C****Line 23**

   amount.
- To adjust the percentages, go to 

  **Organizer****Partner Information****Partner by Partner Data**

   folder.
- Select **Columnar Partner Entry**, then go to the **Ratios\Units** tab.
- In the **Partners Ratios or Units** section adjust the percentages.
- Do a full recompute and recreate the e-file.

note

* Make sure all ratios are equal to 100%.
* The partner ratios are calculated based on Nebraska form instructions not the federal partner ratios.
* **1065N, Sch II**, Columns F and Column G should be blank if Column D “Res” is blank. Also, Columns D, E, F, and G should only be populated for nonresident individuals as per form instructions.
