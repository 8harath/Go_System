# SchAPTR-0005 e-file error

```
* SchAPTR-0005: TotOtherDeductionsAmt (line 23) must equal the total of OtherDeductions_Amt (line 23b)
```

## Solution

- Go to **Tax Forms** and select**States**, then **Nebraska**.
- Select **1065N**, then **1065N, Sch A** tab.
- Make sure line 23 isn't overridden. To enter an amount:


  - Go to 

    **Organizer****States****Nebraska****State Adjustments**

    .
  - Go to the **Decreases** tab.
  - In the **Other Deductions on Nebraska Schedule A** section, enter the amount for appropriate lines.
- Go to **Organizer**, **States**, **Nebraska**, then **General Information**.
- Select the **Report other income and other deduction detail for Schedule K-1N** checkbox.
- Do a full re-compute and recreate the e-file.
