# NEGeneral-0001 e-file error

## Error

```
A return has already been filed for this Nebraska State Id for this tax period end date.
```

## Cause

The e-file database shows this ID has already been used on an accepted return.

## Solution

- In the Organizer, go to **States**.
- Select **Nebraska** and then **General Information**.
- Verify that you've entered a valid State ID.
- If the ID was already entered, contact the state to verify/obtain the correct ID number for this return.

note

If you don't have a record of your Nebraska State ID, the taxpayer or representative with a POA on file with the Department may contact our Taxpayer’s Assistance office at 800-742-7474.
