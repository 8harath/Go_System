# F3-755 e-file error

```
Reject code  F3-755
  The Form 3, line 10 Payments made with composite return amount has been calculated incorrectly.
  XPath to Error /ns:ReturnState/ns:ReturnDataState/ns:FormMAForm3/ns:Part1/ns:Payments
  Massachusetts Form 3 Line 10 Totals must equal the sum of MA 3K1 Line 38 for all.
```

Make sure the sum of the 3K1, line 38 amounts for all partners matches the MA Form 3, Line 10.

## Solution

If you are using a K-1 aggregation file, review the totals of all the partners in the 3K-1 aggregation file match what is on Form 3. Otherwise:

- Go to 

  **Tax Forms****States****Massachusetts**

  .
- Select **3**, then the **3, Page 2** tab.
- Select the **Reconciliation: Form 3 lines 9-12 and MA 3K1 lines 37-40** link next to lines 9 and 10.
- Review the **Payments made with composite return** in both the **Form 3, lines 9- 12, Totals** and **MA 3K1, lines 37-40, Totals for all partners** columns. They must match.
- If you need to make changes, use the drill down arrows ![ ](/content/dam/helpandsupp/en-us/Topics/ONESOURCE-family/images/drill-down.png/_jcr_content/renditions/cq5dam.web.1280.1280.jpeg) next to line 10 or go to 

  **Organizer****States****Massachusetts****Partner Information****Other Pass-through Entity Information**

   tab.
- Do a full recompute.
