# MA 63D ELT PYM-004 e-file error

MA 63D ELT reject PYM-004: The M63D extension can only be filed with a payment.

This happens when the payment details are missing for Massachusetts.

## Solution 1

- Go to **Organizer**, **States**, **Common State**, and the **General Information** folder.
- Select **Bank Information**, and go to **Direct Debit** tab.
- Enter all the information in the **Massachusetts Extension** row.
- Do a full recompute, and recreate the e-file.

note

Massachusetts doesn’t accept e-filed extensions without payment.

## Solution 2

- Go to **Organizer**, **States**, **Common State**, and the **General Information** folder.
- Select **Basic Return Information**, and go to the **Other Information** tab.
- Enter the information in the **Massachusetts** row.
- Do a full recompute, and recreate the e-file.

## Solution 3

- Go to **Organizer**, **States**, and the **State E-file** folder.
- Select **Enable/Create Returns**.
- Uncheck Column C in the **Massachusetts** row.
- Do a full recompute, and recreate the e-file for extension.

## Solution 4

- Go to **Organizer**, **States Common State**, **General Information** folder.
- Select **Basic Return Information**, go to **Signature Information** tab.
- Enter all the necessary information in a **Massachusetts** row.
- Do a full recompute and recreate the e-file.
