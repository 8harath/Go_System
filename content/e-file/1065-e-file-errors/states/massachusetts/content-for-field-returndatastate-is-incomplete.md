# E-file error: Content for field 'ReturnDataState' is incomplete

```
Content for field 'ReturnDataState' is incomplete
```

## Solution

- Select **Organizer**, **States**, **Massachusetts**, then **Return Options**.
- Go to the Print Suppression section and clear the **Form 3K-1** checkbox.
- Do a full re-compute and recreate the e-file.
- Select **States**, **Massachusetts**, **E-file**, **Attachments**, **K-1 Aggregation**, then **Summary**.
- Only mark the checkbox if an aggregation file is attached for MA.
