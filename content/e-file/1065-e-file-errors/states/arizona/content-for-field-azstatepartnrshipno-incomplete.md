# E-file error: Content for field 'AZStatePartnrshipNo' is incomplete

```
Content for field 'AZStatePartnrshipNo' is incomplete
```

## Solution

- Go to **Organizer**, **States**, **Arizona**, then **General Information**.
- Make sure the **Check if this Partnership is an Arizona-ONLY partnership** checkbox is clear.
- Go to **Organizer**, **States**, **Arizona**, then **Allocation and Apportionment**.
- Select a multi-state apportionment option other than Not Applicable.

  note

  If you select **Standard (Default)**, then you need to have amounts entered on Form 165, Page 3, Schedule C, lines C4 and C5. Blank, NONE, and 0 are not allowed.
- Do a full re-compute, recreate the e-file, and resubmit.
