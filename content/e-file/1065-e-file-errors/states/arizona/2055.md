# 2055 e-file error

```
Inconsistent Data for Standard Apportionment in Apportionment Formula. If Line F equals Standard, then Schedule C, Lines C4 and C5 is required.
```

This happens when the state e-file expects apportionment information.

## Solution

- Go to **Organizer**, **States**, **Arizona**, and then **General Information**
- If the return doesn't have apportionment for any state:


  * Uncheck the **Check if partnership is a multistate partnership** option.
  * If the return should have apportionment, complete apportionment data entry.
- Go to **Tax Forms**, **States**,**Arizona**, **165**, **165, Page 1 Line F** and select **Standard**.
- Go to **Tax Forms**, **States**, **Arizona**, **165**, **165, Page 3**. Ensure **Schedule C Lines C4 and C5** are populated.
- Go to **Organizer**, **States**, **Arizona**,**Allocation and Apportionment**, In the **Multi-state Apportionment** section, change the option to **Not Applicable**.
- Go to **Organizer**, **States**, **Arizona**, **General Information**, and select the **Check if this Partnership is an Arizona-ONLY partnership** option.
- Do a full re-compute and re-create e-file.
