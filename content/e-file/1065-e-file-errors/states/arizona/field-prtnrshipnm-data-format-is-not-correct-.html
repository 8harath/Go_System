E-file error: The field 'PrtnrShipNm' with value 'X', data format is not correct.

The field 'PrtnrShipNm' with value 'X', data format is not correct.
This error happens if the partner name or entity information contain special characters.

Solution

  1. Select
    Organizer
    ,
    Partner Information
    , then
    Partner by Partner Data
    .
  2. Select the partner name.
  3. Select
    Partner Information
    , then
    Partner Information Name
    .
  4. Remove any special characters.
  5. Select
    Organizer
    ,
    General Information
    ,
    Basic Return Information
    , then
    Entity Information
    .
  6. Remove any special characters.
  7. Do a full re-compute, recreate the e-file, and resubmit.
