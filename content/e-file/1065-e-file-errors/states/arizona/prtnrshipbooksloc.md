# E-file error: The field 'PrtnrShipBooksLoc' is incomplete

```
Content for field 'PrtnrShipBooksLoc' is incomplete
```

You get this error when the content for element 'PrtnrShipBooksLoc' is incomplete according to the DTD/Schema.

## Solution

- Go to **Organizer** and select **States**, then **Common State**.
- Select **General Information**, then **Books and Records**.
- On the **Location of Books and Records** tab, enter the full address including state and zip code for Arizona. (Columns B, C, D, E, F, G)
- Perform a full re-compute and recreate the e-file.
