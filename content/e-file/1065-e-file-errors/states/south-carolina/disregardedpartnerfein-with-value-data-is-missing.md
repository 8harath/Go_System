# E-file error: The field 'DisregardedPartnerFEIN' with value '', data is missing

```
The field 'DisregardedPartnerFEIN' with value '', data is missing.
```

You'll get this error if the disregarded partner information contains a Taxpayer Identification Number (TIN).

## Solution

- Go to **Organizer**, **Partner Information**, **Partner by Partner Data**, then select the partner name.
- Select **Partner Information**, **Partner Information**, **Disregarded Entity**, then **Taxpayer identification number (TIN)**.
- Clear the number.
- Do a full recompute, recreate the e-file, and resubmit.
