# E-file diagnostic: Missing required general partner's first name, last name, title and/or signature date

```
Louisiana E-File: General Partner or LLC Member.: Missing required general partner's first name, last name, title and/or signature date. Navigation: Organizer\States\Common States\General Information\Basic Return\Signature information tab \ LOUISIANA.
```

This happens when the general partner’s information is missing in the Signature Information area.

## Solution

- In **Organizer**, select **States**, **Common State**, then the **General Information** folder.
- Select **Basic Return Information**.
- Go to the **Signature Information** tab.
- In the Louisiana row, enter the necessary information in the specified columns.

note

You'll need to enter the information in the respective columns for **First Name**, **Last Name**, **Title**, **Email**, **Phone Number**, and **Signature Date**.
