# F765-0004 e-file error

## Error

```
Form 765 - The Kentucky Corporate/LLET Account Number is missing or doesn’t match the Kentucky Department of Revenues records. Please contact taxpayer registration at (502) 564-3306. (F765-0004)
```

## Cause

Kentucky requires a valid Corporate/LLET number to file the return.

## Solution

- In the Organizer, go to **States**.
- Select **Kentucky**, then **General Information**.
- Review your account number in the Corporation/LLET account number field.
- If incorrect, correct it and do a full recompute.
- Recreate the electronic file and resubmit the return.
- If correct, you'll need to contact Kentucky's Taxpayer Registration at (502) 564-3306.
