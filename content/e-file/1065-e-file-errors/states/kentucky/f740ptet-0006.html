F740PTET-0006 e-file error

F740PTET-0006: Line 1 should agree with the number of Kentucky PTETCR forms attached to the return.
This happens when the PTETCR has been suppressed.

Solution

  1. In
    Organizer
    , select
    States
    Kentucky
    Return Options
    .
  2. Locate the
    Print Suppression
     section.
  3. Clear the
    Form PTET-CR
     checkbox.
  4. Do a full recompute, then recreate the e-file.
