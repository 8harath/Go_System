# E-file error: ScheduleK1- Partner Count

```
Number of Schedule K-1 value entered on Form 58, Line G = x,
Number of ScheduleK1 elements = 0 in the XML.
```

This can happen when the Partner Activity Schedules are suppressed on the federal level.

## Solution

- Go to **Organizer**, then select **General Information**.
- Select **Return and Print Options**.
- Select **Sch K, K-1 and Activity Schedules**.
- Change the Print or Suppress box under**Schedule K-1, partner activity schedules, K-3** from Suppress to Print.
- Do a full recompute and re-create the e-file.
