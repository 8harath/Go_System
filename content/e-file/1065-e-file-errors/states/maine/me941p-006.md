# ME941P-006 e-file error

```
ME941P-006: If the Pass-Through Withholding (941P-ME, Line 1) is greater than $0.00, a Schedule 2P is required and the Pass-Through Withholding (941P-ME, Line 1) must equal the Schedule 2P total. Note: If Schedule 2P is suppressed from print, it will also be suppressed from e-file XML.
```

This happens when there is an amount on Line 1 of the 1099ME but Schedule 2P isn’t populated.

## Solution

- In **Organizer**, select the **States** folder.
- Select **Maine**, then the **Pass-through Withholding** folder.
- Select the **Withholding Information** folder.
- Go to the WITHHOLDING INFORMATION section and enter your information.
- Do a full recompute and recreate the e-file.
