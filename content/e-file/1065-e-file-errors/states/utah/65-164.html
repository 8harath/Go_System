65-164 e-file error

Schedule N Column F : Calculation Error : E times 0.0465 (not less than zero), and no waiver request
This happens when Utah Schedule N, column F calculation is incorrect.

Solutions

If you're using the K-1 aggregation file:
  1. In Organizer, select
    States
    , then
    Utah
    .
  2. Select
    E-file
    , then
    Attachments
    .
  3. Go to
    K-1 Aggregation
    .
  4. Review the Schedule N amounts on the K-1 aggregation file. If there are negative amounts, a withholding waiver request needs to be indicated.
If you're using Organizer Partner data entries:
  1. In Organizer, select
    States
    , then
    Utah
    .
  2. Select
    State Adjustments
     and look for the
    Schedule N
     attributable income (Override) field.
  3. Update the total value for Column E and the special allocation code. This lets Column E update, which will then calculate Column F.

Additional troubleshooting

If the error still exists:
  1. In Organizer, in the
    Utah
     folder.
  2. Select
    E-file
    , then
    Attachments
    , then
    K-1 Aggregation
    .
  3. Select
    Summary
    and verify that Schedule N is not suppressed.
  4. Uncheck
    Suppress Sch N
     if it's currently checked.
  5. Perform a Full recompute and recreate the e-file.
important
If you're unable to change the data entry, paper file the return. Schedule N can't be e-filed with a negative amount without a waiver.
