# 65\_116 e-file error

```
* 65_116: Schedule K Line 1: Utah Amount Ordinary business income (loss): Utah amount must equal total of Utah amount of all K-1s
```

This happens when the sum of all Schedule K-1’s, Line 1, Ordinary income doesn’t equal to the grand total of Ordinary income reported for Utah.

## Solution 1

- In **Tax forms**, select **Federal**, then **Partner review**.
- Select **Partner Ratios Summary**, then select the **Default ratios** tab.
- If the ratios don’t equal 1.0000000, go to 

  **Organizer****Federal****Partner information**

  .
- Select **Partner by Partner Date, Columnar Partner entry**.
- Select the **Ratios\Units** tab and make sure the beginning profit, loss, and ownership of capital ratios add up to 1.000000.
- If the ratios are already adding up to 1. 000000 go to 

  **Tax forms****States****Utah**

  .
- Select **Sch K**, and note down the amount for Federal and Utah.
- Go to 

  **Organizer****Schedule K****Income Summary**

  .
- On the line for Ordinary income, note the allocation code.
- In **Organizer**, select **Partner information**, then **Allocations**.
- Select **Special allocations**, then select the proper allocation code.
- Make sure the amounts in the special allocation add up to the grand total that is available to be allocated to the partners.
- In **Organizer**, select **States**, then **Utah**.
- Select **Federal overrides** and note the amount and **Allocation code**.

  note

  The amounts here will override the **State** column of Schedule K, not the **Federal** column.
- In **Organizer**, select **Partner information**, then **Allocations**.
- Select **Special allocations** and select the allocation code that is used.
- Make sure the amounts add up to the total for Schedule K, Line 1, Ordinary income.

## Solution 2

Check for an aggregated Schedule K-1.

- In **Organizer**, select **States**, then **Utah**.
- Go to **E-file, K-1 Aggregation** and select **Summary**.
- If the **System generated Schedule K-1s are disabled** and an aggregated XML file is present, select **Attach K-1 Aggregation XML File**.
- Select the aggregated XML file, then select **RETRIEVE**.
- Update the aggregated XML file to have the correct amounts so they’ll add up to the grand total.
- Delete the existing aggregated XML file from the electronic filing attachments screen.
- Select **Add**, then select **Attachment jurisdiction** for **Utah K-1 Aggregation**.
- Select **Browse for file** and attach the updated XML Aggregation.
- Select **Upload**, then **Done**.

## Solution 3

Check for Direct K-1 Import.

- In **Organizer**, select the 

  **Partner Information****Common Partner Data****Direct K-1 Import**

   tab.

  note

  If you don’t see the **Direct K-1 import** tab, then it's not enabled.
- Update the import file and reimport the **Direct K-1 Import** file.
- Or go to 

  **Tax forms****States****Utah**

  .
- Select **Sch K-1**, then **Name of partner** and change the amounts directly on the tax form.
