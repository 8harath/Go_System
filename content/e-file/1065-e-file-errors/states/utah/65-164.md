# 65-164 e-file error

```
Schedule N Column F : Calculation Error : E times 0.0465 (not less than zero), and no waiver request
```

This happens when Utah Schedule N, column F calculation is incorrect.

## Solutions

If you're using the K-1 aggregation file:

- In Organizer, select **States**, then **Utah**.
- Select **E-file**, then **Attachments**.
- Go to **K-1 Aggregation**.
- Review the Schedule N amounts on the K-1 aggregation file. If there are negative amounts, a withholding waiver request needs to be indicated.

If you're using Organizer Partner data entries:

- In Organizer, select **States**, then **Utah**.
- Select**State Adjustments** and look for the **Schedule N** attributable income (Override) field.
- Update the total value for Column E and the special allocation code. This lets Column E update, which will then calculate Column F.

## Additional troubleshooting

If the error still exists:

- In Organizer, in the **Utah** folder.
- Select **E-file**, then **Attachments**, then **K-1 Aggregation**.
- Select **Summary** and verify that Schedule N is not suppressed.
- Uncheck **Suppress Sch N** if it's currently checked.
- Perform a Full recompute and recreate the e-file.

important

If you're unable to change the data entry, paper file the return. Schedule N can't be e-filed with a negative amount without a waiver.
