# 559\_007 e-file error

```
* 559_007: Header Preparer Date Prepared: Must be provided. (Automatic GOTO is not available) Navigation: Organizer \General information\ Paid Preparer\ ERO Information\ Review the enters for Paid Preparer Information.
```

This happens when the Utah State is missing the Preparer Signature Date.

## Solution

- In **Organizer**, select 

  **States****Common State****General Information****Paid Preparer Information**

  .
- In the **Paid Preparer Information**, look for the **Preparer Information** tab, then enter the Preparer Signature Date in the **Signature Date** column.
- Do a full recompute and recreate the e-file.
