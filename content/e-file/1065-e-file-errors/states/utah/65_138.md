# 65\_138 e-file error

```
* 65_138: Schedule K Line 19 : Calculation Error : Must equal total of K1s line 19 - Value must be positive or zero
```

This happens when Sch N Partner Detail Column J for all partners is not equal to line 19 on Sch K.

## Solution

- Go to **Tax Forms**, **States**, **Utah**folder.
- Select **Sch K**, then go to **Line 19 Total Utah tax withheld on behalf of all the partners from Schedule N, Column J** and select a blue arrow.
- Select **To Review Partner Details**.
- The **Column J** value for all partners must be equal to line 19 of Sch K. To make the necessary changes, follow these steps:


  - Go to **Organizer**, **States**, **Utah** folder.
  - Select **State Adjustments**, then go to the **Schedule N (Override)** section.
  - Enter the correct value in **Line Total pass-through withholding tax (Override)**.
- Do a full recompute and recreate the e-file.

note

If you are unable to make these corrections, you will need to file the return on paper.
