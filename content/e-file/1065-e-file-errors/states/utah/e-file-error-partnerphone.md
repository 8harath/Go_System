# E-file error: PartnerPhone

```
Field 'PartnerPhone' cannot be empty
```

## Solution 1

- Go to **Organizer**, **Partner Information**, **Partner by Partner Data**, **[Partner name]**, **Partner Information**, then the **Partner Information** tab.
- Go to the **Name, Address, Phone Number and SSN \ EIN** section.
- Enter or update the phone number.
- Do a full recompute, re-create the e-file, and resubmit the return.

## Solution 2

- Go to **Organizer**, **Partner Information**, **Partner by Partner Data**, **[Partner name]**, **Partner Information**, then the **State Partner Information** tab.
- Go to the **Utah** section and enter the **Partner affiliation date**.
- Do a full recompute, re-create the e-file, and resubmit the return.

note

If using you're using Direct K-1 Import, advise your client to update the phone number and affiliated date for missing partners. Then do a full recompute, re-create the e-file, and resubmit the return.
