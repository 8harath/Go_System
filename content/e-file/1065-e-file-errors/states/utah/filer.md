# E-file error: Content for field 'Filer' is incomplete

```
Form: ReturnHeaderState
Requirement: Expecting USAddress, ForeignAddress
Error: Content for field 'Filer' is incomplete
```

This happens when you need to complete the address.

## Solution

- Select **Organizer**, **States**, **Common State** and **General Information**.
- Go to **Basic Return Information**, **Address** tab, **Utah** and then enter the complete address.
- Do a full re-compute and re-create e-file.
