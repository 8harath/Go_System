# E-file error: The field 'DateAffiliated' with value '0', data is missing

```
The field 'DateAffiliated' with value '0', data is missing.
```

## Solution

- Select **Organizer**, **Partner Information**, then **Partner by Partner Data**.
- Select the partner name, then **Partner Information**.
- Go to the **State Partner Information** tab.
- Go to **Utah** and enter the **Affiliate Date**.
- Do a full re-compute, recreate the e-file, and resubmit.
