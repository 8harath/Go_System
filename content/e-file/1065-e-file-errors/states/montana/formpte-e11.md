# FormPTE-E11 e-file error

```
FormPTE-E11: If you are claiming a refund, the Refund return checkbox must be checked, OR if the Refund return checkbox is checked and no Refund amount is being claimed.
```

This happens when there is a refund on the return, but the refund field isn't checked, or there is no refund on the return, but the refund field is checked.

**Solution**

- Go to **Tax forms**, **States**, and **Montana**.
- Select **PTE, tab: PTE, Page 2** and verify if **line 47** shows a refund.
- Go to **Organizer**, **States**, and the **Montana** folder.
- Select **General information**.
- In the **Return options** section, make sure the **Refund return** field is checked if a refund is present. Otherwise, it shouldn't be checked.
