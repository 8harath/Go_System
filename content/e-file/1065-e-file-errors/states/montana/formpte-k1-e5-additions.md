# FormPTE-K1-E5 Additions e-file error

```
FormPTE-K1-E5 Additions: IF Schedule K-1 Part 3 column I line 1 or 2 is greater than zero AND Montana Adjustments Worksheet Part 1 and 2 is zero. You must complete the Montana Adjustments Worksheet in order to attribute adjustments to owners.
```

This happens when there are amounts on Montana Sch K-1 Part III line 1, but missing descriptions and/or a code.

**Solution**

- Go to **Organizer**, **States**, the **Montana** folder.
- Select **State Adjustments**, the **Montana Adjustments** tab, then the **Montana Additions to Everywhere Income** section.
- Complete columns **Montana Additions to Everywhere Income, Code\*** to **Income**, and **Nonapportionable Income**.
- Do a full recompute and recreate the e-file.
