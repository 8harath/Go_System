FormPTE-K1-E8 e-file error

FormPTE-K1-E8: If the owner type is C Corporation Foreign C Corporation S Corporation Partnership Publicly Traded or Tax Exempt then the nonresident checkbox cannot be checked.
This happens when a partner is marked Non-Resident when they are not an individual partner.
Solution
  1. Select the diagnostic.
  2. A hidden organizer screen will appear.
  3. Deselect the
    NR
     field.
