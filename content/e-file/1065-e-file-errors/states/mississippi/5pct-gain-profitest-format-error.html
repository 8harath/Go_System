E-file error: The field 'FivePercNetGainProfitEst' with value '7', data format is not correct

The field 'FivePercNetGainProfitEst' with value '7', data format is not correct.
You'll get this error when column H contains numbers.

Solution

  1. Go to
    Organizer
    ,
    Partner Information
    , then
    Partner by Partner Data
     and select the partner.
  2. Select
    Partner Information
    , then the
    State Partner Information
     tab.
  3. Go to the Mississippi section and clear the
    Election to pay 5% tax
     checkbox.
  4. Do a full recompute.
  5. Re-mark the
    Election to pay 5% tax
     checkbox.
  6. Do a full recompute.
  7. Complete these steps for each partner with a number in column H. There should be an
    X
     instead of a number in column H.
  8. Do a full recompute, recreate the e-file, and resubmit.
