E-file diagnostic: MS84105P-15.1

MS84105P-15.1: Practitioner PIN was not entered and Preparer Name was not marked as Self Prepared.
This happens when Practitioner PIN is missing and Preparer Name was not marked as Self Prepared.

Solution

  1. In
    Organizer
    , select
    States
    , then the
    State E-file
     folder.
  2. Select the
    Enable/Create Returns
     folder, then
    State
    .
  3. Make a selection in Column J.
  4. Do a full recompute.
  5. In
    Organizer
    , select
    States
    , the
    Mississippi
     folder, then the
    E-file
     folder.
  6. Select
    Additional Information
     and enter the
    5 digit number
     the in
    ERO override
     field.
  7. Do a full recompute and recreate the e-file.
