# E-file diagnostic: Business Representative Name, Title, Phone Number and Taxpayer PIN required

```
Mississippi MS E-File: According to MS Business Rules, Form 84-105 and 83-180, Business Representative Name, Title, Phone Number and Taxpayer PIN required. Organizer/States/Common State/General Information/Basic Return Info Signature Information Tab
```

This happens when 1065 Mississippi e-file is missing the Business Representative Name, Title, Phone Number, and Taxpayer PIN.

## Solution

- In **Organizer**, go to **States**.
- Select **Common State** then **General Information**.
- Select **Basic Return Information** then go to the **Signature Information** tab.
- Enter the required data in Columns B, D, E, F, G, K, and L.
- Do a full recompute and recreate the e-file.
