# MS84131-2.2 e-file error

```
Form 4-131 (Sch K) is not included in the state xml file. Please either remove the check from the 'suppress' checkbox on Organizer/States/ Mississippi / E-file / Attachments K-1 Aggregation Summary, OR attach a Form 84-131 Sch K aggregation file AND enter 100% as an override on the Total Owner Percentage line on Tax Forms / Mississippi / Form 84-131.
```

This e-file diagnostic happens Form 84-131 isn't included in the e-file and should be based on data entry.

## Solution

Review data entry and adjust accordingly.

- Go to **Organizer**, **States**, **Mississippi**, **E-file**, **Attachments**, **K-1 Aggregation**, and then **Summary**.
- Either unmark the **Suppress system generated Form 84-131 partner data** or attach a K-1 aggregation file by selecting **Attach K-1 Aggregation XML File**.


  - If you attach an aggregation file, review the partner ratios in the K-1 aggregation files to ensure the ratios total to 1.00.
