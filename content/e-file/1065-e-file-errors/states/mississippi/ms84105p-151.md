# E-file diagnostic: MS84105P-15.1

```
MS84105P-15.1: Practitioner PIN was not entered and Preparer Name was not marked as Self Prepared.
```

This happens when Practitioner PIN is missing and Preparer Name was not marked as Self Prepared.

## Solution

- In **Organizer**, select **States**, then the **State E-file** folder.
- Select the **Enable/Create Returns** folder, then **State**.
- Make a selection in Column J.
- Do a full recompute.
- In **Organizer**, select **States**, the **Mississippi** folder, then the **E-file** folder.
- Select **Additional Information** and enter the **5 digit number** the in **ERO override** field.
- Do a full recompute and recreate the e-file.
