E-file error: Field OwnerPartnerInformation missing

Form: Form84131[1] OwnerPartnerInformation[1]
Requirement: Expecting PassThroughEntityElection, Status
Error: Field 'OwnerPartnerInformation' is unexpected
This happens when line 5 is empty.

Solution

  1. Go to Tax Forms.
  2. Select
    States
    , then
    Mississippi
    .
  3. Select
    84-131 (Sch K)
    , then line 5.
  4. The state does not accept a blank line 5. It triggers a diagnostic.
  5. Enter
    NONE
     or enter the information.
  6. Do a full recompute and recreate the e-file
