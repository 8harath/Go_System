# E-file error: Field 'PreparerContact' is unexpected

```
Field 'PreparerContact' is unexpected
```

## Solution

- Select **Organizer**, **States**, then **Mississippi**.
- Select **Pass-Through Information**.
- Go to the Form 84-105 Part IV Entity Officer Information section.
- Complete **Officer Name**, **Title**, **SSN**, **% Ownership**, and **Address** fields.
- Do a full re-compute, recreate the e-file, and resubmit.
