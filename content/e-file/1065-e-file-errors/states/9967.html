9967 e-file error

BinaryAttachment within the XML File (AttachmentLocation) Physical Attachments. Thomson Reuters Tax & Accounting has detected a discrepancy between the physical attachments and the attachment list within the e-File XML files.
This rejection typically generates when a PDF attachment doesn't meet name requirements. The file name of each PDF can't exceed 23 characters and can only contain letters and numbers.

Solution

To fix this error, you'll need to take the following steps:
  1. Outside of the program, rename the file to shorten the name and remove any symbols or spaces.
  2. Within the locator, go to
    Organizer
    States
    [State]
    E-file
    PDF Attachments
    Summary
    .
  3. Select
    Attach PDF
    .
  4. Delete the attachment.
  5. Re-add the attachment.
  6. Do a full recompute, recreate the electronic file, and resubmit.
