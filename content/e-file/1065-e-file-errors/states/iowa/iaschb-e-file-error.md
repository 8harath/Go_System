# IASchB e-file error

```
Field 'IASchB' is unexpected
```

## Solution

- Select **Organizer**, **States**, then **Iowa**.
- Select **Penalties and Interest**, then **Overrides**.
- Enter **NONE** on **Penalties and interest** or Line item **Overpayment carryforward from prior period**.
- Do a full recompute, recreate the e-file, then resubmit.
