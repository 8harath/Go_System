# E-file error: XML electronic filing process is completed. Validation is not processed.

```
XML electronic filing process is completed. Validation is not processed.
```

The Iowa Composite E-file won’t create if the PTE-C page 1 line 1 is blank. Line 1 is blank for no-tax due filers, but there's no guidance in the software stating this is why the e-file doesn’t generate. Development verified there will be no changes to the software.

## Solution

Go to **Tax Forms**, **States**, **Iowa**, **PTE-C/PTE-C Page 1**, and enter **NONE** on line 1.
