E-file diagnostic: Contact Name and Phone Number are required

IA Diagnostic: Contact Name and Phone Number are required. Please: navigate to Organizer / States / Common State / General Information / Books and Records. Enter the name and phone number of the contact person.
This happens when the name and phone number of the contact person is incomplete.

Solution

  1. Go to
    Organizer
    States
    Common State
    General Information
     folder.
  2. Go to
    Books and Records
    , select
    Contact Person
     tab.
  3. Enter the
    Name
     and
    Phone Number
     in the Iowa row.
  4. Do a full recompute and recreate the e-file.
