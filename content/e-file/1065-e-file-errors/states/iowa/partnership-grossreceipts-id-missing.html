E-file error: PartnershipGrossReceipts - attribute 'referenceDocumentId' is missing

PartnershipGrossReceipts - Required attribute 'referenceDocumentId' is missing.
This happens when the reference Document Id is missing.

Solution

  1. Go to
    Organizer
    ,
    States
     and
    Iowa
    .
  2. Select
    And A/Business Activity Ratio
     and
    Business Activity Ratio
     tab.
  3. Select the
    Partnership Gross Receipts
     section and enter
    Partnership Name
     and
    EIN
    .
  4. Do a full re-compute, recreate the e-file, then resubmit.
