# Other Include schedule LineNumber 11 e-file error

```
Validation failed on: Form: FormIA1065[1][@documentId='FormIA1065] IASchE[1]/Other[1] Description: Other. Include schedule. LineNumber 11
```

This happens when IA 1065 Schedule E Line 11 is incomplete.

## Solution

- Go to 

  **Organizer****States****Iowa**

  .
- In the **Iowa** folder, select **A and A/Business Activity Ratio**, then in **Business Activity Ratio** look for the **Other Types of Income** section.
- Enter both description and amounts.
- Do a full recompute and recreate the e-file.
