# E-file error: PartnershipGrossReceipts - attribute 'referenceDocumentId' is missing

```
PartnershipGrossReceipts - Required attribute 'referenceDocumentId' is missing.
```

This happens when the reference Document Id is missing.

## Solution

- Go to **Organizer**, **States** and **Iowa**.
- Select **And A/Business Activity Ratio** and **Business Activity Ratio** tab.
- Select the **Partnership Gross Receipts** section and enter **Partnership Name** and **EIN**.
- Do a full re-compute, recreate the e-file, then resubmit.
