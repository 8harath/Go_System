# E-file error: Field 'OverpaymentAppliedToNext' is unexpected

```
Field 'OverpaymentAppliedToNext' is unexpected.
```

This happens when the amount of overpayment is applied to next period’s PTE-C return on Line Number 10.

## Solution

- Go to **Organizer**,**States**, then **Iowa**.
- Select **Penalties and Interest**.
- Enter **NONE** on Penalties and Interest.
- Do a full re-compute, recreate the e-file, then resubmit.
