# E-file error: Field 'WVK1' is unexpected

```
Field 'WVK1' is unexpected
```

You need to have at least 1 partner with a partner number.

## Solution

- Select **Organizer**, **Partner Information**, then **Partner by Partner Data**.
- Add a partner with a partner number.
- Do a full recompute, recreate the e-file, then resubmit.

To exclude this partner from the e-file, follow these steps:



- Select **Organizer**, **Partner Information**, **Common Partner Data**, then the **Sch K-1 Print Options** tab.
- Go to the Print Options section and select the **E-file Only: Suppress...** link.
- Mark the partner you want to exclude.
