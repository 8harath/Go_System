# PTE-100-003 e-file error

```
PTE-100-003: If Form PTE/EPT-100, Entity Type "Partnership" is marked, then either IRS Form 1065 or IRS Proforma 1065 must be attached. The name of the attachment is case sensitive and must be named "IRS1065.pdf" or "IRSPro1065.pdf", both filename and description. Navigation: Organizer\States\West Virginia\E-file\Attachments\PDF Attachments\Summary
```

This happens when you are missing the attachment required by the state to e-file or the attachment File Name is incorrectly updated.

## Solution

- Select **Tax Forms**, then **States**, then **West Virginia**.
- Select **Form PTE-100**, then **Page 1**.
- Go to the **Check All Applicable Boxes** section.
- On line 1 **Entity type**, select **Partnership**.
- Select line 4 **Box A**.
- In **Organizer**, select **States**, then **West Virginia**.
- Select **E-File**, then **Attachments**.
- Select **PDF Attachments**, then **Summary**.
- Select **Attach PDF**.
- Make sure your file has the same file name and predefined description as mentioned on the diagnostics.
- Perform a full recompute and recreate the e-file.
