# PTE-100-102 e-file error

```
PTE-100-102: If any value other than zero exists on Line 6, Line 7, Line 8, or Line 9 then Schedule SP must exist within the State schema.
```

If Schedule SP has an amount on Line 6, Line 7, Line 8, or Line 9, then Schedule SP must be included in the e-file.

## Solution

- In Organizer, select **Partner Information**, then **Partner by Partner Data**.
- Select the **Name and Address** tab, then **Columnar Partner Entry**.
- The entity needs to have at least 2 partners. You can add the partners in Organizer by selecting **Partner Information**, **Partner by Partner Data**, then **Add New Partner**.
- Make sure there is a Partner Number, which is a mandatory requirement. Enter the **Name**, **Address**, **Phone Number** and **SSN/EIN**.
- Perform a full recompute, re-create the e-file, and resubmit the return.

  note

  If using an Aggregation File, there must be at least 1 partner in the return for Schedule SP to be included in the WV e-file.
