# OH-PTE-022 e-file error

```
The taxpayer has not verified the current address on the return. VerifiedAddress must be True. Please correct and retransmit.
```

This happens when the **Has address been verified?** field isn't completed.

## Solution

- Go to **Organizer**, **States**, **Ohio**, **E-file**, and then **Additional Information**.
- In the **IT-4708 or IT-1140 section**, enter X in the **Has address been verified?** field.
- Perform a full re-compute, re-create the e-file, then re-submit.
