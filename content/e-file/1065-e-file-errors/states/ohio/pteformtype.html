You get this error when element 'PTEFormType' is unexpected according to content model of the parent element.

Solution

  1. Go to Tax Forms, then
    States
    Ohio
    IT-K1
    (Partner Name)
    Pass-through entity
    .
  2. In the
    Fiduciary filing
     section only one option should be selected.
  3. Do a full recompute and recreate the e-file.
