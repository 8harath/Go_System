# E-file error: Ohio element name PTEFormType

```
Form: FormOHITK1[2][@documentId='FormOHITK1N1] PTEFormType[2]
Requirement: Expecting InvestorBeneficiaryDetail
Error: Field 'PTEFormType' is unexpected
```

You get this error when element 'PTEFormType' is unexpected according to content model of the parent element.

## Solution

- Go to Tax Forms, then 

  **States****Ohio****IT-K1****(Partner Name)****Pass-through entity**

  .
- In the **Fiduciary filing** section only one option should be selected.
- Do a full recompute and recreate the e-file.
