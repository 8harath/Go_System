E-file error: The field 'InvestorsOwnershipPercentage' with value data is missing.

Form: HeaderRequirement: A fraction between 0 and 1 that allows up to 4 decimal places. Error: The field 'InvestorsOwnershipPercentage' with value '', data is missing.
This happens when the Investor Ownership Percentage field in a 1065 Ohio return is blank.

Solution

  1. Go to
    Tax Forms
    ,
    States
    , and select
    Ohio
    .
  2. Select
    IT 1140
    , then
    1120 Page 1
    .
  3. In the section before Schedule I, find
    Ownership percentage of investors in return
    .
  4. Enter a decimal of up to four places.
