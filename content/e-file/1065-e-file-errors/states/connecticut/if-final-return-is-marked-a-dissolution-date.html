E-file diagnostic: If Final Return is marked, a Dissolution Date must be provided

If Final Return is marked, a Dissolution Date must be provided
This happens if the return is marked as a Final Return but a Dissolution Date is missing.

Solution

  1. Go to
    Organizer
    State
    Common State
    .
  2. Go to the
    General Information
     section.
  3. Open
    Basic Return information
    .
  4. Locate
    Column J
     within the 3rd tab after
    Return Information
    .
  5. Enter the required date in
    Column J
    .
  6. Initiate a full recompute and recreate the e-file.
