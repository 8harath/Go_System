# CT020-MEF-PART e-file error

## Scenario

You may get the following error message when submitting a return.

## Error

```
Invalid or missing CT-NR (CT020-MEF-PART).
```

## Cause

This rejection occurs if you chose the **Alternative Basis** method for the return, but didn't include Form CT-AB in the e-file.

## Solution

- Go to **Organizer**, then **States**.
- Select **Connecticut**, then **Member Information**.
- Enter an amount in **Total Connecticut source income included in return (Override)**.

  note

  If there's no **Connecticut source income** on the return, enter 

  NONE

  .
- Do a **Full Recompute**, re-create the e-file, and resubmit the return.
