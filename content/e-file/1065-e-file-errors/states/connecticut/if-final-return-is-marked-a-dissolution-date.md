# E-file diagnostic: If Final Return is marked, a Dissolution Date must be provided

```
If Final Return is marked, a Dissolution Date must be provided
```

This happens if the return is marked as a Final Return but a Dissolution Date is missing.

## Solution

- Go to 

  **Organizer****State****Common State**

  .
- Go to the **General Information** section.
- Open **Basic Return information**.
- Locate **Column J** within the 3rd tab after **Return Information**.
- Enter the required date in **Column J**.
- Initiate a full recompute and recreate the e-file.
