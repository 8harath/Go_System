E-file diagnostic: For any entry in Part IV

CT E-file: For any entry in Part IV, the following entry must be completed for each partner - Member Type or SSN or FEIN

Solution

  1. In
    Tax Forms
     select
    States
     then
    Connecticut
  2. Select
    CT-1065/CT-1120SI
     then
    Page 6
  3. Select
    Member Detail
     link. All members must have an entry for
    SSN/EIN
     and all members must have a
    Type Code
     entered.
  4. To enter codes go to
    Organizer
     and select
    States
  5. In the
    Connecticut
     folder, select
    Member Information
    .
  6. Enter codes in the
    Member Information
     section.
