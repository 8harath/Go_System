3703 e-file error

Since this is a combined report, the 05-165 form is required to be filed.
The reject occurs because the 05-165 is not required with the 2nd extension. As such, we don’t send it with the 2nd extension e-file. If Texas has no record of the 1st extension being e-filed, it reads the 2nd extension as the 1st and expects the 05-165.

Solution 1

  • Contact the state and provide the submission ID of the 1st extension.
  • Once the state corrects the issue of the 1st extension on their side, then you can recreate the TX 2nd extension and re-submit.
  • Contact the Texas Comptroller at 800-442-3453.

Solution 2

If the 1st extension is not e-filed, consider paper-filing the 2nd extension.
