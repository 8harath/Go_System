E-file error: Texas 2nd extension XML file not created

Texas 2nd Extension XML file is not created - Return is 'Not Qualified'
This happens when the XML file is not created for the extension.

Solution

Follow these steps to successfully create the 2nd extension e-file:
  1. In Organizer, select
    States
    Estimates and Extensions
    Extension Detail
    Texas section
    , then select
    Second extension for mandatory EFT payers
    .
  2. In Organizer select,
    States
    Common State
    Estimates and Extensions
     select
    Column B for Texas 2nd extension
    .
  3. In Organizer, select
    States
    Texas
    General Information tab
    Payments of Tax
     section. Select the
    Payment of Tax During Preceding Tax Year (Mandatory)
     of $10,000 or more.
  4. Do a full recompute and recreate e-file.
