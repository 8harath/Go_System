3020 e-file error

Error message

Taxpayer number not found on the taxpayer database, tax return must be submitted by mail. (3020)

Cause

The state doesn't recognize the taxpayer number submitted with the return.

Solution

  1. Contact the state at 1-800-442-3453.
  2. Verify the taxpayer number entered in the Organizer view under State Franchise Tax, Texas Franchise, in the General Information section.
