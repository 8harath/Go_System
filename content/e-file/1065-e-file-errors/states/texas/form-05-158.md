# E-file Diagnostic: Form 05-158-A Cost of Goods Sold should not be the same as federal

```
Form 05-158-A: State instructions indicate the Cost of Goods Sold for Texas should not be the same as that for federal. Review your input and make adjustment in the Texas Organizer. Navigation: Organizer \ States \ Texas \ Margin Computation \ Cost of Goods Sold.
```

This happens when the cost of goods sold is none or blank and isn’t being picked up by the state.

## Solution

- In Organizer, select **States**.
- Select **Texas**, then **Margin Computation**.
- Select**Cost of Goods Sold**.
- Go to the **Direct Costs** section.
- Enter **None**.
- Run a full recompute and recreate the e-file.
