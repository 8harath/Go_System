# E-file diagnostic: There must be at least one partner/trustee entered in Section A

```
Form 05-167: There must be at least one partner/trustee entered in Section A. (Automatic GOTO is not available.) Navigation: Organizer \ States \ Texas \ Information Report \ Ownership Information Report \ 10% or More Owner folder. Add an owner with 10% or more ownership of the entity.
```

## Solution 1

Form 05-167 isn't required if the entity is a legally formed corporation, limited liability company, limited partnership, professional association, or financial institution. To indicate this on the return:

- Go to 

  **Organizer****States****Texas****General Information****General Information**

  .
- Answer **Yes** for **Corporation, limited liability company, professional association, limited partnership or financial ownership**.

## Solution 2

If Form 05-167 is required:

- Go to 

  **Organizer****States****Texas****Information Report****Ownership Information Report****10% or More Owner**

  .
- Add an owner with 10% or more ownership of the entity.
