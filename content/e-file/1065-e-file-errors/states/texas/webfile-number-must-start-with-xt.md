# E-file diagnostic: Webfile number must start with XT

```
Webfile number: The number must start with "XT" and be followed by 6 digits. Navigation: Organizer \ State \ Texas \ E-file \ Additional Information \ Preparer Validation \ Webfile number
```

This happens when the webfile number is missing or is not formatted correctly.

## Solution

- In Organizer, select **State**, **Texas**, **E-file**, then **Additional Information**.
- Go to the **Preparer Validation** section.
- Enter a number in the **Webfile Number** line.
- Run a full recompute and recreate the e-file.

  note

  The webfile number must begin with “XT” followed by 6 digits. Contact the Texas Comptroller (800-442-3453) to get a webfile number with the correct format.
