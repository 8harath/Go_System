SOSNumber data format is not correct efile error

The field 'SOSNumber' with value '###' data format is not correct. (where ### is the Secretary of State file number)
The Secretary of State file number is incorrect.

Solution

Go to Organizer | States | Texas | General Information | General Information | "Secretary of State file number"Make sure the SOS file number is correct and 10 digits.Perform full recompute and re-create the e-file.
note
The SOS file number can be obtained from the California E-Help Desk at (916)845-0353.
