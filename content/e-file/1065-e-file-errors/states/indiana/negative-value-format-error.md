# E-file error: The field 'PtrShrhldrAGIStateAmt' with a negative value data format is not correct

```
The field 'PtrShrhldrAGIStateAmt' with value '-2873', data format is not correct.
```

This happens when you need to type for a U.S. positive integer amount field. Schedule Composite column C amount cannot be negative.

## Solution

- Go to **Tax forms**, **States**, **Indiana**, then select **Schedule Composite**.
- Select the **Composite Partner Detail** hyperlink.
- Column C can't be negative when e-filing. If you can't change the negative amount to a positive, you'll need to paper file the return.
- To change the values, go to **Organizer**, **States**, **Indiana**.
- Select **Composite Return** and the **Composite Member Overrides** section.
