# SIN-K1-002 e-file error

```
* SIN-K1-002: IN Sch K-1 page 2 line 14 Total pro rata distributions must equal the sum of lines 1 through 11 minus 12, 13a and 13b.
```

This happens when the state K-1 page 2 line 14 doesn’t total the preceding lines.

## Solution

- In **Tax Forms**, go to the **States** folder.
- Select **Indiana**, then the **IT-65** folder.
- Go to the **IT-65, Sch K-1**, **(Partner Name)** folder.
- On the **Sch K-1, Page 2** tab, review the line **14** and make sure it totals line **1** through **11**, minus **12**, **13a**, and **13b**.
- Run a full recompute and recreate the e-file.

note

If you are doing a K-1 aggregation, then you'll need to make sure in the file that those amounts total to line 14.
