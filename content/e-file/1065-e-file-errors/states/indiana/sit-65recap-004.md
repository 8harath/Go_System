# SIT-65RECAP-004 e-file error

```
Indiana Federal Recap Other Deductions total does not match the sum of Other Deductions detail. Please check organizer \ Ordinary income and Deductions \ Deduction summary \ Deductions Detail. Make sure there is an amount on the first line item. Maximum detail items allowed for Other Deductions entries is limited to 20
```

This happens when the amount flowing in the Federal deductions did not match the amounts in the state level.

## Solution

- Go to **Organizer**, **States**, then **Indiana**.
- Select **E-file** and find the **Federal Recap** folder.
- Select the **Detail** tab for **Federal Recap Summary**.
- Verify the amount in **Other deductions total amount**.
- Compare the entry in **Organizer**, **Ordinary Income and Deductions** folder.
- Select **Deduction Summary**, then the **Deductions Detail** tab.
- Go to the **Other Deductions** section and ensure that the amounts and descriptions listed match.
- Do a full recompute and recreate the e-file
