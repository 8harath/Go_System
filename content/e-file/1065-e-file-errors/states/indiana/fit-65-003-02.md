# FIT-65-003-02/03 e-file error

```
FIT-65-003-02: If value provided in line 6a, CompositeTotalTax/SchCompINAmt is not null and greater than zero, it must equal total tax on SchINComp SumCompositePtrShrhldrWthAmt
```

This can happen when the IT-65 page 1, line 6a doesn't equal the Schedule Composite Workpaper, line 15 or Schedule of Composites total in column G.

## Solution

- Go to **Tax Forms**, **States,** and select **Indiana**.
- Select **IT-65**, then **IT-65, Page 1**.
- On line 6a, select the down arrow to open the Schedule Composite.

  ![Line 6a data entry field with a down-arrow in the lower right corner](/content/dam/helpandsupp/en-us/Topics/ONESOURCE-family/images/in-65-line-6a.png/_jcr_content/renditions/original)
- Check the amounts in Column D to make sure they're correct. These are calculated by the amount on Column C multiplied by the tax rate of 3.23%.
- If Column D is wrong, you have to change Column C instead. Go to **Organizer**, **States**, and open **Indiana**. Select **Composite Return** and make adjustments in section **Composite Members Overrides**.
- If Column D is correct, you need to paper file the return.
