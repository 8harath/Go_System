# FIT-65-013-01 e-file error

```
* FIT-65-013-01: If value provided in line 6b CompositeTotalTax/SchCompCORAmt is not null and greater than zero, it must equal total tax on SchCompCOR/SumCORTotalTaxAmt.
```

This happens when the total of column G on the Schedule Composite form doesn’t match line 6a on IT-65 page 1.

## Solution 1

- Go to the **Organizer**, **States** folder.
- Go to the **General Information**, **Basic Return Information** folder.
- Select the **Filling Status** tab.
- Mark the checkbox in **Column E Composite Return** for **Indiana**.
- Do a full recompute and recreate the e-file.

## Solution 2

- Go to the **Tax Forms**, **States** folder.
- Go to **Indiana**, **Schedule Composite** folder.
- Note the total of **Column G**.
- Go to the **IT-65** folder.
- Select the **IT-65, Page 1** tab.
- Make sure line **6a** has the same amount as **Column G**.
