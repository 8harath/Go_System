# E-file diagnostic: WI Form 3 page 2 line 19 apportionment indicator is A01

```
WI Form 3 page 2 line 19 apportionment indicator is A01. However Sch A01 has no apportionment data. Tax form / Wisconsin / Apportionment / A-01
```

This happens when you are missing information that is required by the state or updating apportionment information.

## Solution

- In Organizer, select **States**, then the **Allocation and Apportionment** folder.
- Select **Organizer/Overrides**, then the **Wisconsin** folder.
- Select **Payroll and Sales**.
- Go to the Wisconsin Payroll Apportionment section.
- In line **Within State to Within** , enter **NONE** or the apportionment values in the **Within** and **Everywhere** column.
- Then do a full Recompute.
- Recreate the e-file.
