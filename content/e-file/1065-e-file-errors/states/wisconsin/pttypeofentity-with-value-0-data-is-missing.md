# E-file error: The field 'PTTypeOfEntity' with value '0', data is missing

```
The field 'PTTypeOfEntity' with value '0', data is missing.
```

This validation error occurs when the representative of the company doesn't have the entity type selected.

## Solution

- Go to **Organizer**, **States**, **Wisconsin**, then **General Information**.
- Go to the Pass-through Representative section.
- Select an entity type.
- Do a full recompute, re-create the e-file, and resubmit the return.
