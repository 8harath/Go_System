# F3-180 e-file error

```
State WISeverity ErrorState Record F3Record Name NAForm Occurrence No 0Field Seq No 0Page No 1Reject Code F3-180Rule Number F3-180XML Path /ns:ReturnState/ns:ReturnDataState/ns:Form3/ns:Body/ns:WisconsinApportionment/ns:HundredPercentApportionmentError Message Apportionment schedule required but not included
```

This happens when form A-01 line 11 isn’t populated.

## Solution

- In Organizer, go to the **States** folder.
- Select **Wisconsin**, then **Allocation and Apportionment**.
- Select the **Allocation and Apportionment** tab and go to the **Computer Options** section.
- Select **A-01** from the dropdown.
- Go to **Tax Forms** and select the **States** folder.
- Select **Wisconsin**, **Apportionment**, then **A-01, Page1**.
- Make sure there's an amount in line **11**.
- Do a full recompute and recreate the e-file.
