E-file error: The field 'PartnersLossBOY' with value 'NONE', data format is not correct

The field 'PartnersLossBOY' with value 'NONE', data format is not correct.
You'll get this error if you enter NONE for beginning ratios.

Solution

  1. Go to
    Organizer
    ,
    Partner Information
    ,
    Partner by Partner Data
    ,
    Columnar Partner Entry
    , then the
    Ratios/Units
     tab.
  2. Enter
    0.0000
     instead of NONE for beginning ratios.
  3. Do a full recompute, re-create the e-file, and resubmit the return.
