# F1CNP-020 e-file error

```
Duplicate taxpayer identification numbers.
```

This happens when there is more than one Taxpayer Identification Number in the e-file.

## Solution

Each partner can only have one unique EIN or SSN. Make sure there aren't any duplicate values or shared EINs or SSNs.

- Go to **Tax Forms**, then **States**, and open **Wisconsin**.
- Select **1CNP** and go to **Page 2**.
- Check each of the partner EINs or SSNs to make sure each is unique. Also check that each partner only appears once.
- If you have duplicate partners or duplicate identifying numbers, go to **Organizer**, **Partner information**, then **Partner by Partner data**.
- After you correct the issue, do a full recompute, recreate the e-file, then resubmit.
