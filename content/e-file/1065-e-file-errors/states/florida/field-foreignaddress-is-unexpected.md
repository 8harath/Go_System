# E-file error: Field 'ForeignAddress' is unexpected

```
Field 'ForeignAddress' is unexpected
```

## Solution

- Select **Organizer**, **Partner Information**, then **Partner by Partner Data**.
- Select the partner name, then the **Partner Information** tab.
- Go to the SSN/EIN section.
- Go to **Utah** and enter the **Affiliate Date**.
- Select **SSN** and enter a SSN in the correct format (XXX-XX-XXXX).
- Do a full re-compute, recreate the e-file, and resubmit.
