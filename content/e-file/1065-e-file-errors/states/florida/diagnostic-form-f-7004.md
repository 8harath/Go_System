# E-file Diagnostic: Form F-7004 Florida extension e-file

Resolve the diagnostic error that occurs when you incorrectly select “Return on Extension” for both Florida and Florida LLC extension filings.

```
Diagnostic: Form F-7004: You have selected to electronically file F-7004, but have incorrectly selected RETURN ON EXTENSION for both FLORIDA and FLORIDA LLC on the following: Organizer \ States \ Common State \ Estimates and Extensions.
```

## Cause

This diagnostic appears when you select to file Form F-7004 electronically but have incorrectly selected "Return on Extension" for both Florida and Florida LLC in 

**Organizer****States****Common State****Estimates and Extensions**

.

## Solution

To clear the diagnostic for Form F-7004, Florida Tentative Income/Franchise Tax Return and Application for Extension of Time to File Return, follow these steps:

- Go to 

  **Organizer****States****Common State****General Information****Basic Return Information**

  .
- On the **Return Information** worksheet, find **Column O** and remove the selection.
- Perform a full recompute and recreate the e-file.
