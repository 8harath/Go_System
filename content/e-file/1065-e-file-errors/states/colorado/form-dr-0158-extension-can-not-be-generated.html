E-file diagnostic: Form DR 0158 the extension can't be generated unless the form contains an amount due

Form DR 0158-N Automatic Filing Extension for Composite Nonresident Return: The extension can not be generated unless the form contains an amount due. The instructions state that if no payment is due, do not file the return.
This happens when balance due is missing for the state of Colorado.

Solution

  1. Go to
    Organizer
    States
    Common State
    Estimates and Extension
     folder.
  2. Select
    Estimates and Extension
     in the
    Colorado
     row and enter the value in
    Column C
    .
  3. Do a full recompute and recreate the e-file.
