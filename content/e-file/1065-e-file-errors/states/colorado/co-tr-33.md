# CO TR-33 e-file error

```
CO TR-33: The business representative information First Name, Last Name, Title, Phone, and Date Signed are all required to be entered. Please go to Organizer\States\Common State\General Information\Basic Return Information\Signature Information tab.
```

This happens when Business representative information is missing from the e-file.

## Solution

- Go to 

  **Organizer****States****Common State****General Information****Basic Return Information**

  .
- Go to the **Signature information** tab and enter:


  - First Name
  - Last Name
  - Title
  - Phone
  - Signature Date
  - Taxpayer Pin
- Perform a full recompute and recreate the e-file.
