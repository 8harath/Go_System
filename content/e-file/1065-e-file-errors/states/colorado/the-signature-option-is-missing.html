E-file diagnostic: The signature option is missing

Electronic Filing - Signature Option: The signature option is missing. Please check both of the following items in navigation: (1) Organizer/State/Colorado/E-file/Additional Information/ Signature Option. Check box that have read and agree with certification. This is required to print the form 8453P and avoid an alert diagnostic. (2) Organizer/State/State E-file/Enable/Colorado line, on Signature Option column select one of the 2 options regarding the 8453P.
This happens when the signature option for Colorado is not selected.

Solution

  1. In
    Organizer
    , go to
    States
    , then
    Colorado
    .
  2. Select
    E-file
    , then
    Additional Information
  3. Select the
    I have read and agree with the certification per details on Form 8454 (Mandatory to print)
     checkbox.
  4. Then in
    Organizer
    , go to
    States
    State E-file
    Enable/Create Returns
  5. On the
    Colorado
     line, select a
    Signature Option
     in column
    K
    .
  6. Run a full recompute, then recreate the e-file.
