# SL-AL65-019 e-file error

```
AL E-File: AL Reject Code SL-AL65-019: If AL 65, Page 5, Schedule L line 20b is populated, then a pdf document must be attached (File name and Predefined Name: OtherLongTermLiabilities.pdf) itemizing the separate categories and amounts of other current assets included in the total of current assets.
```

This happens when Alabama Form 65, Schedule L Line 20b is populated and the PDF attachment itemizing the separate categories and amounts of other liabilities included in the total of other liabilities is missing.

## Solution

- Select **Organizer**, **States** then **Alabama**.
- In the **Alabama** folder, go to **E-file - Form 65**, **Attachments**, **PDF Attachments**, **Summary**, then select **Attach PDF**.
- Add the PDF document named **OtherLongTermLiabilities.pdf**. The file name and description must be exactly the same.
- Do a full recompute and recreate the e-file.
