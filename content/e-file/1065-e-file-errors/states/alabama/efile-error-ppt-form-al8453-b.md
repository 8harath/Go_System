# AL E-File (PPT): Form AL8453-B e-file error

```
AL E-File (PPT): Form AL8453-B Signature Authorization MUST be completed in order to electronically file the Alabama Return.
```

This happens when you need the signature authorization completed.

## Solution

- In Organizer, go to 

  **States****Alabama****Signature Authorization**

   and select the **AL8453-B** tab.
- Select the box **I have read and agree with the certification per details on form 8453-B**.
- In **PART II - DECLARATION OF PARTNER**, select the two boxes available.
- In Organizer, go to 

  **Common State****General Information****Basic Return Information**
- Select the **Filing Status** tab.
- n the row for Alabama, select the appropriate **Partnership type** in column **B**.
- Perform a full recompute and then recreate the e-file.
