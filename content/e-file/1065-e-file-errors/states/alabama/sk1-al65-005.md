# SK1-AL65-005 e-file error

```
SK1-AL65-005: AL Schedule K-1 Part II Line 6, if Partner is a Nonresident is checked then State of Legal Residence must be populated.
```

This happens when Schedule K-1 Part II Line 6, if Partner is a Nonresident is checked, but State of Legal Residence isn't populated.

## Solution

- Go to **Tax Forms**, **States**, **Alabama**, then the **Sch K-1** folder.
- Select the **Partner Name**. If **Line 6** has an **X**, enter the **State of Legal Residence**.
- To update **State of Legal Residence**, go to **Organizer**, **States**, **Alabama**, and the **Partner Information** folder.
- Select **Partner Name**.
- Enter the state name in the **Nonresident state of legal residence (Override)** line.
- Do a full recompute and recreate the e-file.
