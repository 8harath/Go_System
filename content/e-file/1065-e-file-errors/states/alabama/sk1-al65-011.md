# SK1-AL65-011 e-file error

```
SK1-AL65-011: The total of all K-1s, Line G, Column 1, Ordinary Income (loss) should equal Schedule K, Line 1 Apportioned Amount.
```

This happens when the total of all K-1s, Line G, Column 1, Ordinary Income (loss) isn't equal to Schedule K, Line 1 Apportioned Amount.

**Solution 1**

- Go to the **Tax forms**, **States**, then the **Alabama** folder.
- Select **Form 65** and the **Form 65 Page 4** tab.
- In the **Schedule K** section, verify the amount on **Line 1, Column C**. This amount should equal the following amount.
- Go to **Tax Forms**, **States**, **Alabama**, and the **Schedule K-1** folder
- Select **Partner Name**.
- In **Part III** **Line H**, verify the amount.
- Do a full recompute and recreate the e-file.

**Solution 2**

- Go to the **Organizer**, **States**, and the **Alabama** folder.
- Go to **E-file Form 65**, **Attachments**, and the **K-1 Aggregation** folder.
- Select **Summary**.
- Within the K-1 Aggregation XML, review the **Ordinary Income Loss** item and ensure the sum of all partners equals **Form 65, Page 4, Column C, Line 1**.
- Do a full Recompute and recreate the e-file.

note

If you are using a K-1 aggregation file, use whole numbers for calculating, don’t use decimals. It removes the issue of rounding, which the return may do when adding the values together.
