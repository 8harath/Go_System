SK1-AL65-046 e-file error

The total of all K-1s, Line Y, Column 1, Other Items and Amounts should equal Schedule K, Line 20c, Other Items and Amounts, Apportioned Amount.
This happens when there's a difference between Alabama's Form 65, Page 4, Line 20c and the state's Schedule K-1 partner amounts.

Solution

This difference is typically due to rounding of these amounts. To correct this, manually edit either amount so these values match.
