E-file diagnostic: Alabama Composite K-1 aggregation 

When using Alabama Composite K-1 aggregation, Form PTE-CK1 Page 1 lines 14 and 15 must have amounts populated. To enter amounts, go to Organizer Alabama Composite Return Composite Return folder.
This happens when K-1 Aggregation or Import is used for the Alabama Composite Return and there is no data on Form PTE-CK1 Page 1 lines 14 and 15.

Solution

  1. Select
    Organizer
    ,
    States
    , then
    Alabama
    .
  2. In the
    Alabama
     folder, go to
    Composite Return
     then the
    K-1 Aggregation or Import Use Only
     section.
  3. Populate the appropriate amounts on all the lines E, F, G and H for the Form PTE-CK1 Totals.
  4. You can use
    NONE
     for lines that don't have amounts.
  5. Do a full recompute and recreate the e-file.
