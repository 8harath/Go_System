# AL65-009 e-file error

```
If check box Multistate Company Separate Accounting on Form 65 Page 1 is checked, then an explanation why separate accounting or allocation is being used by attaching a pdf file. Must name the PDF File Name: SeparateAccounting.pdf NOTE: ALL PDF FILES MUST HAVE THE SAME NAME AS THE PREDEFINED DESCRIPTION.
```

You'll get this error if an attached PDF file name doesn't match the IRS predefined description.

## Solution

- Go to **Organizer**, **States**, **Alabama**, **E-file - Form 65**, **Attachments**, **PDF Attachments**, then **Summary**.
- Select **Attach PDF**.
- Name the PDF file **SeparateAccounting.pdf** and select the matching IRS predefined description from the dropdown.
- Do a full recompute, re-create the e-file, and resubmit the return.
