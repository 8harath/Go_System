# SL-AL65-003 e-file error

```
If OtherCurrentAssetsBOYAmt line 6b is populated, then attach a pdf document named OtherCurrentAssets.pdf itemizing the separate categories and amounts of other current assets included in the total of current assets. Please verify the text for the element Desc under BinaryAttachment.
```

This happens when Alabama Tax Form 65, Page 5, Line 6 Other current assets, Column B Beginning of tax year has an amount and there in no attached PDF file related to the line entry, or the attached file has an invalid name.

## Solution

- Select **Organizer**, **States**, **Alabama**, then **E-file-Form 65**.
- Go to **Attachments** and select **PDF Attachments**.
- Select **Summary**.
- Attach the PDF attachment with the exact same file name as the **Description name**, which was indicated on the **E-file Diagnostics, OtherCurrentAssets.pdf**.
- Do a full recompute and recreate the e-file.
