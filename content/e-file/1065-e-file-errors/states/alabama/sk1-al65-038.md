# SK1-AL65-038 e-file error

```
SK1-AL65-038: The total of all K-1s, Line U, Nondeductible Expenses, column 1, should equal Schedule K, Line 18c, Nondeductible Expenses, Apportioned Amount.
```

This happens when Alabama Schedule K-1 Part III Line U, Alabama Column for all partners doesn't equal Schedule K Line 18c Apportioned Amount (C) Column.

## Solution

- Select the **Tax Forms**folder, **States**, then **Alabama**.
- Check the amount in the column for **Part III, Line U Distributive share allocated and apportioned to Alabama**.
- Go to **Tax Forms**, **States**, **Alabama**, **65**, **65, Page 4**, then **Schedule K**.
- Make sure the column for **Line 18c Apportioned amount** matches the amount on Line U in Part II.
- Do a full recompute and recreate the e-file.
