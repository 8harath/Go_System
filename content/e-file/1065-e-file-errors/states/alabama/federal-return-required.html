E-file diagnostic: Federal return required

AL E-FILE: The State of Alabama requires federal return to be e-filed prior to e-filing AL Form 65. If the federal return is not e-filed then the AL return must be paper filed.
This happens when the Alabama e-file has been submitted before the federal return has been submitted.

Solution

  1. Go to the
    Returns
     tab in the GoSystem browser.
  2. Select the return then select the
    Info
     tab.
  3. Select the
    E-File Status
     tab and make sure that the federal return shows as
    Accepted
    .
  4. If the Federal return isn't accepted, submit the Federal return and wait for it to be accepted.
  5. Select the
    Returns
     tab again and then open the return.
  6. Select
    Organizer
    ,
    States
    , then
    State E-File
    .
  7. Select
    Enable/Create Returns
     and then select
    Create
     for Alabama.
  8. Recreate and resubmit the e-file.
