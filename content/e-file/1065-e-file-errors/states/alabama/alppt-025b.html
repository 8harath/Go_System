ALPPT-025b e-file error

If DEParentSubject (PPT Part A3 Line 11) is not checked, ApportionmentFactor (PPT Part B Exclusions Line 7) is zero and TotApportFraction (Sch C, Line 27) is equal to zero then attach a pdf document name zeroapportstmt.pdf that explains the reason for the zero apportionment factor.
This happens when a zeroapportstmt.pdf attachment is missing or not correctly attached to the PPT return.

Solution

  1. Go to
    Organizer
    ,
    States
    ,
    Alabama
    ,
    E-file-Form PPT
    ,
    Attachments
    ,
    PDF Attachments
    , and then
    Summary
    .
  2. Select
    Attach PDF
     and add (or edit if an attachment already exists) a pdf with filename and description of zeroapportstmt.pdf.
  3. Perform a full re-compute, re-create the e-file, then re-submit.
