AL E-File (PPT): Form AL8453-B e-file error

AL E-File (PPT): Form AL8453-B Signature Authorization MUST be completed in order to electronically file the Alabama Return.
This happens when you need the signature authorization completed.

Solution

  1. In Organizer, go to
    States
    Alabama
    Signature Authorization
     and select the
    AL8453-B
     tab.
  2. Select the box
    I have read and agree with the certification per details on form 8453-B
    .
  3. In
    PART II - DECLARATION OF PARTNER
    , select the two boxes available.
  4. In Organizer, go to
    Common State
    General Information
    Basic Return Information
  5. Select the
    Filing Status
     tab.
  6. n the row for Alabama, select the appropriate
    Partnership type
     in column
    B
    .
  7. Perform a full recompute and then recreate the e-file.
