# SL-AL65-004 e-file error

```
If AL 65,Page 5,Schedule L line 6d is populated, then a pdf document must be attached (File name and Predefined Name: OtherCurrentAssets.pdf) itemizing the separate categories and amounts of other current assets included in the total of current assets.
```

This happens when AL 65, Page 5, Schedule L, line 6d, contains information, and a PDF isn't attached.

## Solution

- Go to 

  **Organizer****States****Alabama****E-file Form 65****Attachments****PDF Attachments****Summary**

  .
- Select **Attach PDF**.
- Attach a PDF with the same file name mentioned in the diagnostic.

  note

  Make sure the description is the same as the file name, and include **.pdf** for the file extension.
- Perform a full re-compute, re-create the e-file, then re-submit.
