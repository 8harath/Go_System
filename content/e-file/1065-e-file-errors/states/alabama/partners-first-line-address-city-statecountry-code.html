E-file diagnostic: Partner's First Line Address, City, State/Country Code and ZIP Code must be present

AL E-File: According to AL Business Rules, Partner's First Line Address, City, State/Country Code and ZIP Code must be present. Please go to Organizer > Partner Information > Partner by Partner Data >Columnar Partner Entry to review the Partners' addresses.
This happens when you haven’t updated the partner address.

Solution 1

  1. Select
    Organizer
    ,
    Partner Information
    , then the
    Partner by Partner Data
     folder.
  2. Select
    Columnar Partner Entry
    .
  3. Then go to the
    Name and Address
     tab, in the
    Partner Information
     section.
  4. Enter the data in Columns
    Partner Address
    ,
    City
    ,
    State
    , and
    ZIP Code
     for all the partners.
  5. Do a full recompute.
  6. Recreate the e-file.
note
If you have foreign partners, leave
State
 and
Zip Code
 blank.

Solution 2

  1. Select
    Organizer
    ,
    Partner Information
    , then the
    Partner by Partner Data
     folder.
  2. Go to the
    Partner Name
     folder.
  3. Select
    Partner Information
    , then go to the
    Partner Information
     tab.
  4. Go to the
    Name
    ,
    Address
    ,
    Phone Number and SSN \ EIN
     section.
  5. Enter the
    Partner Address
    ,
    City
    ,
    State
     and
    ZIP Code
    .
  6. Do a full recompute.
  7. Recreate the e-file.
note
If you have foreign partners, leave
State
 and
Zip Code
 blank.
