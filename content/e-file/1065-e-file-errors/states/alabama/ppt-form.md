# E-file diagnostic: AL E-File (PPT): Form PPT, Page 1

```
AL E-File (PPT): Form PPT, Page 1, Type of Entity must be selected. Only 1 entity type can be selected.
```

This happens when for state Alabama Form PPT Page 1 Type of Entity must be selected only 1 time.

**Solution 1:**

- Go to **Organizer**,**States**, then the **Alabama** folder.
- Go to**Signature Authorization**, and then the **AL8453-PTE** tab.
- In the **Signature Authorization - Form AL8453-PTE** section, select the option **I have read and agree with the certification per details on Form 8453-PTE**.
- Do a full recompute.
- Recreate the e-file.

**Solution 2:**

- Go to **Organizer**,**States**, then the **Common state folder**.
- Go to the **Basic Return information** folder, then the **Filing status** tab.
- Select the state **Alabama** and in **Column B**, select a partnership type.
- Do a full recompute.
- Recreate the e-file.
