# E-file diagnostic: Federal return required

```
AL E-FILE: The State of Alabama requires federal return to be e-filed prior to e-filing AL Form 65. If the federal return is not e-filed then the AL return must be paper filed.
```

This happens when the Alabama e-file has been submitted before the federal return has been submitted.

## Solution

- Go to the **Returns** tab in the GoSystem browser.
- Select the return then select the **Info** tab.
- Select the **E-File Status** tab and make sure that the federal return shows as **Accepted**.
- If the Federal return isn't accepted, submit the Federal return and wait for it to be accepted.
- Select the **Returns** tab again and then open the return.
- Select **Organizer**, **States**, then **State E-File**.
- Select **Enable/Create Returns** and then select **Create** for Alabama.
- Recreate and resubmit the e-file.
