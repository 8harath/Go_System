# AL Reject Code SL-AL65-017

```
1065 Alabama AL E-File: AL Reject Code SL-AL65-017: If AL 65,Page 5,Schedule L line 17b is populated, then a pdf document must be attached (File name and Predefined Name: OtherCurrentLiabilities.pdf) itemizing the separate categories and amounts of other
```

You get this error when a pdf document needs to be attached named: OtherCurrentLiabilities.pdf.

## Solution

- In Organizer, go to 

  **States****Alabama****E-file-Form 65****Attachments****PDF Attachments****Summary**

  .
- Select the file OtherCurrentLiabilities.pdf the description will show as OtherCurrentLiabilities.
- Add the .pdf to the description so that it reads OtherCurrentLiabilities.pdf and then the return will be qualified.
