SL-AL65-005 e-file error

AL E-File: AL Reject Code SL-AL65-005: If AL 65,Page 5,Schedule L line 8b is populated, then a pdf document must be attached (File name and Predefined Name: OtherInvestments.pdf) itemizing the separate categories and amounts of other current assets included in the total of current assets.
This happens when AL 65, Page 5, Schedule L, line 8b, contains information, and a PDF isn't attached.

Solution

  1. Go to
    Organizer
    States
    Alabama
    E-file Form 65
    Attachments
    PDF Attachments
    Summary
    .
  2. Select
    Attach PDF
    .
  3. Attach a PDF with the same file name mentioned in the diagnostic.
    note
    Make sure the description is the same as the file name, and include
    .pdf
     for the file extension.
  4. Perform a full re-compute, re-create the e-file, then re-submit.
