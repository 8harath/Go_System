# E-file diagnostic: Partner's First Line Address, City, State/Country Code and ZIP Code must be present

```
AL E-File: According to AL Business Rules, Partner's First Line Address, City, State/Country Code and ZIP Code must be present. Please go to Organizer > Partner Information > Partner by Partner Data >Columnar Partner Entry to review the Partners' addresses.
```

This happens when you haven’t updated the partner address.

## Solution 1

- Select **Organizer**, **Partner Information**, then the**Partner by Partner Data** folder.
- Select **Columnar Partner Entry**.
- Then go to the **Name and Address** tab, in the **Partner Information** section.
- Enter the data in Columns **Partner Address**, **City**, **State**, and **ZIP Code** for all the partners.
- Do a full recompute.
- Recreate the e-file.

note

If you have foreign partners, leave **State** and **Zip Code** blank.

## Solution 2

- Select **Organizer**, **Partner Information**, then the **Partner by Partner Data** folder.
- Go to the **Partner Name** folder.
- Select **Partner Information**, then go to the **Partner Information** tab.
- Go to the **Name**, **Address**, **Phone Number and SSN \ EIN** section.
- Enter the **Partner Address**, **City**, **State** and **ZIP Code**.
- Do a full recompute.
- Recreate the e-file.

note

If you have foreign partners, leave **State** and **Zip Code** blank.
