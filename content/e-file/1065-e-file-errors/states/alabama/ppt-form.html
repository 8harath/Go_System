E-file diagnostic: AL E-File (PPT): Form PPT, Page 1

AL E-File (PPT): Form PPT, Page 1, Type of Entity must be selected. Only 1 entity type can be selected.
This happens when for state Alabama Form PPT Page 1 Type of Entity must be selected only 1 time.
Solution 1:
  1. Go to
    Organizer
    ,
    States
    , then the
    Alabama
    folder.
  2. Go to
    Signature Authorization
    , and then the
    AL8453-PTE
     tab.
  3. In the
    Signature Authorization - Form AL8453-PTE
     section, select the option
    I have read and agree with the certification per details on Form 8453-PTE
    .
  4. Do a full recompute.
  5. Recreate the e-file.
Solution 2:
  1. Go to
    Organizer
    ,
    States
    , then the
    Common state folder
    .
  2. Go to the
    Basic Return information
     folder, then the
    Filing status
     tab.
  3. Select the state
    Alabama
    and in
    Column B
    , select a partnership type.
  4. Do a full recompute.
  5. Recreate the e-file.
