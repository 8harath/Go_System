# SK-AL65-028b e-file error

```
SK-AL65-028b: Form 65, Page 4, Schedule K Line 20c, if Alabama Amount (Apportioned Amount) is populated then the amount should equal to the detail total.
```

This happens when the sum of all shareholder's Part 3 Line Y amount isn't equal to the Alabama Apportioned Amount.

**Solution**

- Go to the **Tax Forms**, **States**, and the **Alabama** folder.
- Select **Form 65**, and go to the **65 Page 4**.
- Go to the **Schedule K** section.
- In the **20C Other Items and Amounts (attach Statement)** line, the amount must match the following line.
- Go to the **Tax Forms**, **States**, **Alabama**, and the **Sch K-1** folder.
- Select **Partner Name**, and the sum of all shareholders **Part III Line Y** amount.
- Verify the values and make necessary changes in the following path.
- Go to the **Organizer**, **States**, and the **Alabama** folder.
- Select **State Adjustments**, and go to **Other** section enter the values.
- Do a full recompute and recreate the e-file.

note

* Ensure that the form **65 Page 4**, **Sch K**, **Line 20C**, **Column C** amount must equal the total of the **Sch K-1**, **Part III**, **Line Y** amount.
* If you are using the **K-1 Aggregation** file, make the necessary changes in the **K-1 Aggregation** file and reattach it.
