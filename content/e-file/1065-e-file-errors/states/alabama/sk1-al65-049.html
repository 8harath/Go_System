SK1-AL65-049 e-file error

SK1-AL65-049: AL Schedule K-1 Part III Line Z, the total number of K-1s marked NRC-Exempt should have the same number of Schedule NRCs generated in the XML file.
This happens when NCR exempt checkbox is marked but NRC forms are being included.

Solution 1

If you’re doing a K-1 Aggregation:
  1. Select
    Organizer
    , then the
    States
     folder.
  2. Select
    Alabama
     then the
    E-file-Form 65
     folder.
  3. Select
    Attachments
    ,
    K-1 Aggregation
    , then the
    Summary
     folder.
  4. Inside the Aggregation file, if the
    NRCExempt
     checkbox is marked, then NRC Forms need to be populated in the aggregation file.
  5. Once you've updated the aggregation file, remove the existing file and upload the fixed aggregation file.
  6. Run a full recompute, then recreate the E-file.

Solution 2

If the K-1 is inside the return:
  1. Select
    Organizer
    ,then the
    Partner Information
     folder.
  2. Select
    Partner by Partner
    ,
    Data
    , select the partner name, then the
    Partner Information
     folder.
  3. Go to the
    State Partner Information
     tab.
  4. Go to the
    Alabama
     section and select
    Include nonresident partner in Schedule NRC
    .
  5. Run a full recompute, then recreate the E-file.
