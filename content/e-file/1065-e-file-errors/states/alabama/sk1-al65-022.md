# SK1-AL65-022 e-file error

```
SK1-AL65-022: The total of all K-1s, Line L, Column 1, Other Income or Loss should equal Schedule K, Line 10, Other Income or Loss Apportioned Amount.
```

This happens when the total of all the K-1s Line L, Column 1 doesn’t add up to the amount on the Schedule K, Line 10.

## Solution

- Select **Tax Forms**, then **States**.
- Go to the **Alabama, 65** folder.
- Open the **65, Page 4** tab.
- In Column C, find **Line 10** and make note of the amount.
- Go to the **Sch K-1, (Name)** folder.
- In **Part III, Line L**, make sure the amounts add up to the amount in Step 4 for all partners.
- Run a full recompute then recreate the e-file.
