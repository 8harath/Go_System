# AL65-008 e-file error

```
AL E-File: According to AL Reject Code AL65-008, if "Multistate Company Apportionment" is populated then Alabama Apportionment Factor (Schedule C Line 27) must be greater than 0 and less than 100%.
```

When Form 65, page 1 has 2 for **Multistate Company - Apportionment (Sch. C)** marked, Schedule C, Line 27 cannot be less than .0001.

## Solution

- Go to 

  **Organizer****States****Alabama**

  .
- Select **Allocation and Apportionment**.
- Change **Apportionment Percentage** from 

  NONE

   to 

  .0001
- Do a full recompute and recreate the e-file.

If the return does not have any apportionment in Alabama, contact the state regarding filing the return on paper.
