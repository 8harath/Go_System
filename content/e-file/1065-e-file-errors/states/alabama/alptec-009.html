ALPTEC-009: Form PTE-C e-file error

ALPTEC-009: Form PTE-C Page 1 Line 5d must equal the sum of Lines 5a through 5c
This happens when PTE-C, Page 1, line 5d must equal the sum of lines 5a through 5c.

Solution

  1. In Organizer select
    Activity Information
    Pass-Through Entity
    Entity Name
    Pass-Through Entity Activity
    K-1 Line, Lines 1-15
    tab.
  2. Select an entity from the
    Type of entity (Alabama, California & Pennsylvania returns only)
     drop-down.
  3. In Organizer select
    States
    Alabama
    Credits
    Comp Payment/EPT - CP-B
    Summary
    .
  4. Select
    Carry Federal Pass-Through Name and ID..
    .
  5. Do a full re-compute and re-create the e-file.
