# NH1065-007 e-file error

```
Error Message Line 9 NH Business Profits before NOL = Line 7 * Line 8, if negative enter zero
```

This happens when the DP-80 is showing None for the NH apportionment, which is causing the BPT tax apportionment to be None. If BPT tax apportionment is None, then the NH-1065 and DP-80 are not required to be filed.

## Solution

- In **Organizer**, go to 

  **State****New Hampshire****General Information**

   folder.
- Select **No** for **Required to file BPT return (Mandatory)**.
- Do a full recompute and recreate the e-file.

note

Business organizations, including Limited Liability Companies (LLC), taxed as a partnership federally must file Form NH-1065 return provided they have conducted business activity in New Hampshire and their gross business income from everywhere is in excess of 50,000.
