# R0000-005 e-file error

```
R0000-005: TaxpayerPIN Not Found
```

## Solution

- Go to **Organizer**, **States**, **Michigan**, **E-file**, then **Additional Information**.
- Go to the **E-file Requirement** section.
- Select **State Stand-Alone Filing**.
- Do a full recompute, re-create the e-file, and resubmit the return.
