# E-file diagnostic: R0000-006

```
R0000-006: Form 4946 and Form 4947 must be present.
```

This happens when you're missing information required by the state. Form 4946 and 4947 is missing from the e-file.

**Solution**

- In Organizer, select the **States** folder.
- Select **Michigan**, then **Return Options**.
- In the **Force Print** section, mark the checkbox for **Form 4946**.
- Select **Tax forms**, **States**, then the **Michigan** folder.
- Select **Form 4947**.
- In **Part 2 Line 28 and Part 3 Line 39**, enter an amount or **NONE**.
- Perform a full recompute.
- Recreate the e-file.
