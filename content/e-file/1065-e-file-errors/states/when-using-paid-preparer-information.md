# E-file diagnostic: When using Paid preparer information, Paid preparer signature date, EIN, and Phone Number are required fields

```
When using Paid preparer information, Paid preparer signature date, EIN and Phone Number are required fields. Fill out paid preparer information completely.
```

This happens when paid preparer information is missing and or incomplete.

## Solution

- In **Organizer**, select 

  **States****Common States****General information****Paid Preparer Information**

  .
- In the **Preparer Information** tab, complete all columns for the state. This includes Columns **C**, **D**, **E**, **G**, and **H**.
- Do a full recompute and recreate the e-file.
