Import a 5500 filing into IFILE

Import filings prepared in EFAST2-approved third-party applications into IFILE and transmit them to the Department of Labor.
Plan Administrators can prepare filings in EFAST2-approved third-party applications and import them into IFILE for transmission. After you import a filing into IFILE, a Filing Author can edit it.
Follow these steps to import a filing:
  1. Sign in to EFAST2.
  2. In the
    Filings
     section, select
    Import a Filing
    .
  3. Complete all the requested information for the EFAST2 system.
  4. Find the XML file that the e-file process created in your system's data directory.
  5. Use this XML file to import your filing information.
  6. Once you import the filing, you can add attachments to IFILE.
    note
    File format requirements for attachments:
    • Accountant's Opinion: Must be a PDF document
    • Other attachments: PDF or plain text documents
    • No other formats are permitted
