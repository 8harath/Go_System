# E-file 5500 series returns

Complete step-by-step instructions for enabling EFAST2 e-file, configuring signatures, and submitting Form 5500 returns to the Department of Labor (DOL).

Follow these steps to e-file a 5500 return:

- **Turn on e-file:**
- Go to 

  **Organizer****E-file****5500 Return**

  .
- Select **Enable E-file**.
- Select **Enable EFAST2 E-file**.
- **Configure signature options:**
- Go to **Signature Options**.
- Complete the signer section.
- Select **Push To Sign Return** to populate the **Signature Time Stamp** field automatically.
- Enter the **E-Signature Requirements**.
- Enter the **SignerID**, **PIN**, and signature name for the service provider.
- **Attach an e-signature document (if necessary):**
- For the **E-signature Attachment**, indicate if you've attached a PDF document named **SignatureAlternative** to the return.
- If yes, go to 

  **Organizer****E-file****Attachments****Summary**

  .
- Select **Attach PDF**, then **ESignatureAlternative**.
- **Validate the return:**
- Perform a full recompute.
- Go to 

  **Organizer****E-file****Status****E-file Status**

  .
- Select **Create Validation File**.
- Select **View**, then **Diagnostics**.
- Correct any errors that appear.
- **Create the e-file:**
- When you've cleared all errors from the return, go to 

  **Organizer****E-file****Create E-file****Create E-file**

  .
- Select **Create DOL E-file**.
- **Submit the return:**
- Go to 

  **E-file****Status****E-file Status**

  .
- To send qualified e-files, go to 

  **RS Browser****Returns Processing****E-file****Select Returns**

  .
- Select an account, tax year, e-file type, and **5500** for the return type.
- Select **Federal ready to send**, then **Continue**.
- Select the return, then **Submit for E-file**.

  The system will process your return and send it to the DOL.
