E-file 5500 series returns

Complete step-by-step instructions for enabling EFAST2 e-file, configuring signatures, and submitting Form 5500 returns to the Department of Labor (DOL).
Follow these steps to e-file a 5500 return:
  1. Turn on e-file:
  2. Go to
    Organizer
    E-file
    5500 Return
    .
  3. Select
    Enable E-file
    .
  4. Select
    Enable EFAST2 E-file
    .
  5. Configure signature options:
  6. Go to
    Signature Options
    .
  7. Complete the signer section.
  8. Select
    Push To Sign Return
     to populate the
    Signature Time Stamp
     field automatically.
  9. Enter the
    E-Signature Requirements
    .
  10. Enter the
    SignerID
    ,
    PIN
    , and signature name for the service provider.
  11. Attach an e-signature document (if necessary):
  12. For the
    E-signature Attachment
    , indicate if you've attached a PDF document named
    SignatureAlternative
     to the return.
  13. If yes, go to
    Organizer
    E-file
    Attachments
    Summary
    .
  14. Select
    Attach PDF
    , then
    ESignatureAlternative
    .
  15. Validate the return:
  16. Perform a full recompute.
  17. Go to
    Organizer
    E-file
    Status
    E-file Status
    .
  18. Select
    Create Validation File
    .
  19. Select
    View
    , then
    Diagnostics
    .
  20. Correct any errors that appear.
  21. Create the e-file:
  22. When you've cleared all errors from the return, go to
    Organizer
    E-file
    Create E-file
    Create E-file
    .
  23. Select
    Create DOL E-file
    .
  24. Submit the return:
  25. Go to
    E-file
    Status
    E-file Status
    .
  26. To send qualified e-files, go to
    RS Browser
    Returns Processing
    E-file
    Select Returns
    .
  27. Select an account, tax year, e-file type, and
    5500
     for the return type.
  28. Select
    Federal ready to send
    , then
    Continue
    .
  29. Select the return, then
    Submit for E-file
    .
    The system will process your return and send it to the DOL.
