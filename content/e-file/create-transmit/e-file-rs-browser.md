# E-file returns using RS Browser

Select and submit federal, state, and city returns for e-filing through RS Browser and check their status.

- In RS Browser, select **Returns Processing**, **E-file**, then **Select Returns**.
- Select an account, year, and tax type.
- For **e-File Type**, select **Return**.
- Select returns ready to be sent, including federal, state, and/or city.
- Select **Continue**.
- Select your returns, then **Submit for e-file**. After completing this procedure, your returns are processed and sent to the IRS.
- To check the status of an e-file in RS Browser, go to 

  **Returns Processing****E-file****Status Report**

  .
