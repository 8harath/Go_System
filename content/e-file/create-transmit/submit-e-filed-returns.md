# Submit returns for e-filing

Submit returns for e-filing after reviewing them in the e-file viewer by selecting your criteria and transmitting the returns.

After reviewing the return in the e-file viewer, you're ready to e-file the return.

- Go to 

  **Returns Processing****E-file****E-file Submission**

  .
- Go to 

  **Account****Year****Tax Type****E-file Type****State Selection**

  . The **State Selection** list includes federal, state, and city returns.

  ![](/content/dam/helpandsupp/en-us/Topics/ONESOURCE-family/e-file/files/efile-selections.png/_jcr_content/renditions/original)
- Filter by **Name**, **Client Code**, and **Locator**.
- Display the full list of returns available for e-file by selecting **All E-File Types** (not limited to any particular form) or **All E-File Extensions** (no particular extension form).
- Select **Advance Filter** to filter by the preparer, manager, reviewer, partner, or group assigned to the return. You can also filter by location or sign in ID/group name.
- Mark the checkboxes next to the returns you want to transmit, then select **Submit for e-file**. ![](/content/dam/helpandsupp/en-us/Topics/ONESOURCE-family/e-file/files/efile-submit.png/_jcr_content/renditions/original)
- Select the **Batch Status** tab to read the status.
