Clear XML errors before e-filing

Review and clear XML file errors before submitting the e-file.
If errors exist in the XML file, you'll need to clear them before you can submit the e-file.
Follow these steps to clear XML errors:
  1. Create your e-file.
  2. Review the XML file.
    If errors exist, the e-file status indicates the XML file was created but can't be e-filed.
  3. Clear the reject diagnostics and XML validation errors.
  4. Create the XML file again and repeat this process until no errors remain.
  5. Select
    Delete Federal E-file
     to delete an existing federal e-file if needed.
Once you clear all errors, you can submit your e-file.
