Submit a 1040 return for e-filing

Submit a completed 1040 return electronically to the IRS for faster processing and confirmation of receipt.
Before you begin, make sure you have:
  • A completed 1040 return ready to file
  • Your Electronic Filing Identification Number (EFIN)
  • ELF administrator permissions to batch returns
  • Taxpayer authorization to e-file
Use this procedure when you're ready to submit a 1040 return electronically to the IRS. E-filing provides faster processing and confirmation of receipt compared to paper filing.
  1. Go to
    Organizer
    E-file
    Enable/Create
    .
  2. Select the
    Return
     worksheet and turn on
    Federal
    .
  3. Enter your
    EFIN
    .
  4. Go to
    Signature Authorization
    .
  5. Select your signature option:
    • Form 8879 - Practitioner PIN
    • Self-select PIN
  6. Select who entered the PIN.
    important
    If you select
    Taxpayer/spouse
     and
    Self-select PIN
    , Form 8879 won't print. Keep the signed Form 8879 for 3 years and don't send it to the IRS.
  7. Enter the PINs and the date you entered them into the system.
  8. Go to
    Organizer
    E-file
    Error Checking
    .
  9. Select
    Generate Validation File
    .
  10. When the process completes, go to
    View
    Diagnostics
    .
  11. Review items related to
    Electronic Filing
     and correct any data entry errors.
  12. Perform a full recompute and review any new e-file diagnostics.
    Repeat this step until no e-file diagnostics appear.
  13. Check the
    E-file Status
     column to make sure your return is ready.
    The status shows one of the following messages:
    • XML file is created - Return is 'Qualified means the e-file created without errors.
    • XML is created but NOT qualified - Diag needs to be cleared means you have errors to fix.
    • XML is created but NOT qualified - Please clear all vali.errors means you have validation errors to resolve.
  14. Go to
    RS Browser
    Returns Processing
    E-file
    Select Returns
    .
    tip
    You need ELF administrator permissions to batch returns. If you don't see these options, contact your firm administrator.
  15. Select your account, tax year, and tax type.
  16. Select
    e-File Type
     as
    Return
    .
  17. Select whether the returns are
    Federal Ready to Send
     and/or
    States/Cities ready to send: All States/Cities
    .
  18. Select
    Continue
    .
  19. Select
    Submit for e-file
    .
    Your returns are processed and sent to the IRS. The status shows
    Awaiting Acknowledgment
     until the IRS accepts or rejects the return.
