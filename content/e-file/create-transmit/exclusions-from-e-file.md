# 5500 filings excluded from e-filing

Find out which employee benefit filings are not eligible for electronic filing.

You can't e-file the following employee benefit filings:

* Filings sent using an application not approved by the DOL for e-file.
* Filings with accounting periods of more than 365 or (or 366 days for leap years).
* Filings that combine e-file and paper submissions.
* Filings with sections filed at different times instead of together.
* Filings submitted on unsupported media.
* Filings with unsupported attachment types.
* Unsigned filings (missing PIN and Signer ID for electronic signature).
* Unencrypted filings submitted via modern-to-modern or transmission.
