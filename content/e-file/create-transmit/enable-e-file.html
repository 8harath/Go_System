Turn on e-filing for returns

Turn on e-filing in the Organizer before you create an e-file for a tax return.
Follow these steps to turn on e-filing:
  1. In the Organizer, go to the federal
    E-file
     folder.
  2. Select
    Enable
     or
    Enable/Create
    .
  3. Mark the checkbox to turn on e-filing.
  4. Make sure the
    EFIN
     is correct.
  5. Select the
    Type of originator
    .
  6. Go to the
    Signature Authorization
     screen and select a signature option.
