E-file returns using RS Browser

Select and submit federal, state, and city returns for e-filing through RS Browser and check their status.
  1. In RS Browser, select
    Returns Processing
    ,
    E-file
    , then
    Select Returns
    .
  2. Select an account, year, and tax type.
  3. For
    e-File Type
    , select
    Return
    .
  4. Select returns ready to be sent, including federal, state, and/or city.
  5. Select
    Continue
    .
  6. Select your returns, then
    Submit for e-file
    . After completing this procedure, your returns are processed and sent to the IRS.
  7. To check the status of an e-file in RS Browser, go to
    Returns Processing
    E-file
    Status Report
    .
