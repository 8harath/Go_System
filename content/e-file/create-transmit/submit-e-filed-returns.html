Submit returns for e-filing

Submit returns for e-filing after reviewing them in the e-file viewer by selecting your criteria and transmitting the returns.
After reviewing the return in the e-file viewer, you're ready to e-file the return.
  1. Go to
    Returns Processing
    E-file
    E-file Submission
    .
  2. Go to
    Account
    Year
    Tax Type
    E-file Type
    State Selection
    . The
    State Selection
     list includes federal, state, and city returns.
  3. Filter by
    Name
    ,
    Client Code
    , and
    Locator
    .
  4. Display the full list of returns available for e-file by selecting
    All E-File Types
     (not limited to any particular form) or
    All E-File Extensions
     (no particular extension form).
  5. Select
    Advance Filter
     to filter by the preparer, manager, reviewer, partner, or group assigned to the return. You can also filter by location or sign in ID/group name.
  6. Mark the checkboxes next to the returns you want to transmit, then select
    Submit for e-file
    .
  7. Select the
    Batch Status
     tab to read the status.
