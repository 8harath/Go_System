Submit an e-file

Select the return criteria and submit the e-file after you create it.
After you create an e-file, follow these steps to submit it:
  1. Select
    E-file
     then go to the
    Submission
     tab.
  2. Select the
    Work area
    ,
    Year
    , and
    Binder Year
     of the return you want to submit.
  3. Select the returns.
  4. Select
    Submit
    .
