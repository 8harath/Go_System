Submit a qualified FBAR e-file

Select the return criteria and submit qualified FBAR e-files using the
Create E-file Batches
 screen.
Complete the following steps to submit a qualified FBAR e-file:
  1. In RS Browser, go to
    Returns Processing
    E-file
    Select Returns
    .
  2. On the
    Create E-file Batches
     screen, enter the
    Account
    ,
    Year
    ,
    Type
    , and
    Sort List By
     information.
  3. Select
    Other Forms
     for the
    e-file Type
    .
  4. Mark the
    Federal ready to send
     checkbox.
  5. Select
    Continue
     to show the qualified FBARs that meet your search criteria.
  6. For 1040 Returns only:
     If you prepared separate FBARs for taxpayer and spouse and both FBARs are qualified, each FBAR will show in the search results. Each FBAR displays with identical locator numbers and taxpayer names.
