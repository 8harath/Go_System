# Create a federal e-file

Create a federal e-file XML file in the Organizer and review the file status and formatting requirements.

Follow these steps to create a federal e-file:

- In **Organizer**, select **Federal E-file**.
- Select **Create E-file**.

  The system creates an XML file that includes a date and time stamp, along with the e-file status.

* You'll need to clear any XML file errors before submitting the e-file.
* You can only create 1 XML file at a time in the Organizer.
* The system presents consolidated returns only in stacked format.
* The IRS requires that cross-tie print options don't apply to electronic filing.
* Supporting statements might not appear in the same order as they would print for a return.
* Non-numerical information may appear at the entity level where you entered it.
* The system doesn't include the PDF attachment in the PDF reader, but the return displays the attachment information in the **Binary Attachment** section.
