Submit a 1040 return for e-filing

Submit a completed 1040 return electronically to the IRS for faster processing and confirmation of receipt.

Before you begin, make sure you have:

  • A completed 1040 return ready to file
  • Your Electronic Filing Identification Number (EFIN)
  • ELF administrator permissions to batch returns
  • Taxpayer authorization to e-file

Use this procedure when you're ready to submit a 1040 return electronically to the IRS. E-filing provides faster processing and confirmation of receipt compared to paper filing.

  • Go to Organizer → E-file → Enable/Create.
  • Select the Return worksheet and turn on Federal.
  • Enter your EFIN.
  • Go to Signature Authorization.

  • Select your signature option:

  • Form 8879 - Practitioner PIN

  • Self-select PIN
  • Select who entered the PIN. important If you select Taxpayer/spouse and Self-select PIN, Form 8879 won't print. Keep the signed Form 8879 for 3 years and don't send it to the IRS.
  • Enter the PINs and the date you entered them into the system.
  • Go to Organizer → E-file → Error Checking.
  • Select Generate Validation File.
  • When the process completes, go to View → Diagnostics.
  • Review items related to Electronic Filing and correct any data entry errors.
  • Perform a full recompute and review any new e-file diagnostics.

Repeat this step until no e-file diagnostics appear. - Check the E-file Status column to make sure your return is ready.

The status shows one of the following messages:

  • XML file is created - Return is 'Qualified means the e-file created without errors.
  • XML is created but NOT qualified - Diag needs to be cleared means you have errors to fix.
  • XML is created but NOT qualified - Please clear all vali.errors means you have validation errors to resolve.
  • Go to RS Browser → Returns Processing → E-file → Select Returns. tip You need ELF administrator permissions to batch returns. If you don't see these options, contact your firm administrator.
  • Select your account, tax year, and tax type.
  • Select e-File Type as Return.
  • Select whether the returns are Federal Ready to Send and/or States/Cities ready to send: All States/Cities.
  • Select Continue.
  • Select Submit for e-file. Your returns are processed and sent to the IRS. The status shows Awaiting Acknowledgment until the IRS accepts or rejects the return. To check your e-file status, go to

RS Browser → Returns Processing → E-file → Status Report
