File Form 8453 to transmit required paper forms

File Form 8453 to transmit paper forms and supporting documentation when your return includes specific IRS forms.

You need to file Form 8453 when the return includes any of these forms:

  • Form 1098-C
  • Form 2848
  • Form 3115
  • Form 3468
  • Form 4136
  • Form 5713
  • Form 8283
  • Form 8332
  • Form 8858
  • Form 8864
  • Form 8885
  • Form 8949

note

Form 8453 is no longer used for signature purposes. Use it only to transmit paper forms and supporting documentation.
