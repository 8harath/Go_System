Attach XIT files to your international e-file

Attach Thomson Reuters XIT files from international returns to your e-file for submission.

You can attach Thomson Reuters XIT files from international returns to your e-file.

  • Go to Organizer → E-file → International → Thomson Reuters International File.
  • Select Attach Thomson Reuters XIT File.
  • Select Add.
  • Select International XML File and go to your XIT file.
  • Select Done.
  • Repeat steps 2 through 5 for each additional XIT file you want to include.
  • After attaching the XIT files, make sure the attachments in the International Aggregation from a Different Thomson Reuters Account section.

note

The attached XIT file names include the locator number of the primary return.

Your international XIT files are now attached to the e-file and ready for submission.
