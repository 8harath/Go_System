200779 e-file error

ERROR: Duplicate CBTU Found

Ensure that the State ID is unique and entered for all members in a Consolidated Return.

Solution

  • Go to Organizer, States, New Jersey, and selectCombined Return Information.
  • In the Combined report Options section, the Unitary ID entered here is all 9's.
  • You will have to enter a valid New Jersey Unitary ID here, full recompute, then select the Transfer to All button.
  • Do a full re-compute and re-create e-file.
  • If you don't have a valid unitary ID, you will have to contact the state to determine what to enter as the unitary ID or you can paper file.

note

To find return information, go toOrganizer > States > Common State >General Information > Basic Return Information > Return Information tab.
