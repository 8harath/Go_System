📍 Utah (UT) Form e-file

E-file diagnostic: 65_166 Schedule N

Error

65_166: Schedule N : Calculation Error : Total of Column I values.

Cause

This happens when you are missing the information that required by the state for e-Filing.

Solution

  • In Tax forms, select States, then Utah.
  • Select Schedule N.
  • On Schedule N line 1B, select To Review Detail for Schedule N.
  • Select To Review Partner Details.
  • Make sure Line I Tax Paid by PTE is populated for all partners.
  • All partners must have column I populated if there is an override entered in Organizer, in States, on the Utah window.
  • Select State Adjustments.
  • In the Schedule N (Override) section, on line Schedule N Tax Paid by PTE (Override) enter the amount and allocation code.
  • On line Schedule N attributable income (Override) enter the amount and allocation code to populate column E.
  • Do a Full recompute and recreate the e-file.
