📍 Nebraska (NE) Form e-file 00357474

NEHeader-0035 e-file error

Error

Filer_StateEIN is required and must be valid. If you do not have a record of your Nebraska State ID, the taxpayer or representative with a POA on file with the Department may contact our Taxpayer’s Assistance office at 800-742-7474 (NE and IA) or 402-471

Cause

The State ID for the return is either missing, invalid, or doesn't match the return details.

Solution

  • In the Organizer, go to States.
  • Select Nebraska, then General Information.
  • Verify that you've entered a valid State ID in Nebraska State ID number.
  • If the ID was already entered, contact the state to verify/obtain the correct ID number for this return.
  • Do a full re-compute, recreate the e-file and resubmit the return.

note

If you don't have a record of your Nebraska State ID, the taxpayer or representative with a POA on file with the Department may contact our Taxpayer’s Assistance office at 800-742-7474.
