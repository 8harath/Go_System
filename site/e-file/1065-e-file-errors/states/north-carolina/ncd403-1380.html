NCD403-1380 e-file error

NCD403-1380: [D-403] If Part 4 Section C Line 18 is populated with a non-zero value, Part 4 Line 20 must be equal to Part 4 Line 18 minus Part 4 Line 19; otherwise Part 4 Section C Line 20 must be zero or blank.

This happens when Part 4 Section C Line 18 is populated with a non-zero value. Part 4 Line 20 needs to be equal to Part 4 Line 18 minus Part 4 Line 19, otherwise Part 4 Section C Line 20 needs to be zero or blank.

Solution 1

  • Go to Tax Forms, then select States, then North Carolina.
  • Select Form D-403, then go to Page 3.
  • Select Partner Information.
  • If you have an amount in line 18, then line 20 should equal line 18 minus the line 19 amount.
  • To populate line 20, in Organizer, select States, then North Carolina.
  • Select Nonresident Partner Affirmation.
  • In the Print Suppression section, uncheck Form NC-NPAs Nonresident Partner Affirmation (does not alter Part 4 tax calculations).
  • Perform a full recompute and recreate the e-file.

Solution 2

  • Go to Organizer, then select States, then North Carolina.
  • Select State Adjustments
  • In the Overrides section, enter an Amount and Allocation Code for Total tax due for nonresident partners.
  • Perform a full recompute and recreate the e-file.
