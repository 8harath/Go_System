NCD403-1180 e-file error

NCD403-1180: [D-403] If Part 1 Line 20 is greater than Part 1 Line 21d, then Part 1 Line 23 must be equal to Part 1 Line 20 minus Part 1 Line 21d; otherwise Part 1 Line 23 must be zero or blank.

You'll get this error if Line 23 contains NONE.

Solution

  • Go to Tax Forms, States, North Carolina, D-403, then the D-403, Page 2 tab.
  • Make sure Line 23 is clear and doesn't include NONE. Remove the source lines causing the NONE calculation, specifically the values prior to Line 20.
  • Go to Organizer, States, North Carolina, then State Adjustments.
  • Go to the Overrides section.
  • Enter an amount in the Total tax due for nonresident partners field.
  • Do a full recompute, re-create the e-file, and resubmit the return.
