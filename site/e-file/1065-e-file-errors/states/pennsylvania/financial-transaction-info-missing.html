E-file diagnostic: Financial transaction information missing

PA20-S/PA efile reject: Financial Transaction information is missing from E-file, but there is an amount available on the following: Tax forms\PA/P\-20S/PA-65, Page2, Line 14b final payment of Nonresident Tax Withholding and/or Tax Forms\PA\ Schedule NW, Line D Reconciliation payment. Payment by check is also allowed. EFT is not available. Navigation: Organizer\States\ Common State\ General information\ Bank information\Direct Debit\(tab)\ PENNSSYLVANIA\TAX PAYMENT METHOD

This happens when there is an amount on Form PA-20S\ PA- 65-page 2 line 14b but no or incomplete banking information.

Solution

  • Select Tax forms, then States, then Pennsylvania.
  • If there is an amount on PA20S\PA-65, Page 2, Section V, line 14b then you need to enter banking information.
  • Select Organizer, then

StatesCommon StateGeneral InformationBank Information

. - Select the Direct Debit tab and enter all the banking information for Pennsylvania. - Do a full recompute then recreate and resubmit the e-file.
