9990-2010 e-file error

Reject Code 9990-2010
    Message: This return has been "Conditionally Accepted".

Both the return and any payment submitted with the return have been accepted, but some attachments may have errors and need to be resubmitted.

Solution

Per Texas, the Packet Processed with Attachment Errors. The return and payment (if any) has been validated and recorded in the Texas CPA system.

You must resubmit attachments that have errors, but you do not need to resubmit the return or payment (if any). If you believe your return and attachments are correct or if you need more information, contact the Texas Comptroller at 1-800-442-3453.

Since Texas already accepted the return, you'll need to resubmit the return as an amended return with the corrected attachments:

  • Make a copy of the locator/binder.

  • In the new return:

  • Go to

    Organizer

    ,

    States

    , then

    Common State

    . - Select General Information then Basic Return Information. - On the

    Return Information

    tab, select Amended return. - Make any necessary corrections to your attachment. - Recreate the e-file and resubmit the return.

If you also received the following reject codes:

Reject Code 3590 - The Public Information Report was not submitted with the tax return. Texas is expecting Form 05-102 to be included with the return. Make sure Form 05-102 is calculating.

Reject Code 3593 - This entity owes the PIR (form 05-102) not the OIR (form 05-167). Texas considers the return an LLC and not a passive entity. See the Franchise Instructions.
