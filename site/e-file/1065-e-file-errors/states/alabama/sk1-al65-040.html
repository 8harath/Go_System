📍 Alabama (AL) Form e-file AL65-040

SK1-AL65-040 e-file error

* SK1-AL65-040: The total of all K-1s, Line W, Column1, Distributions should equal Schedule K, Line 19a, Distributions of cash and marketable securities, Apportioned Amount + Line 19b Distribution of other property, Apportioned Amount.

This happens when Form 65, Page 4, Schedule K, Line 19a and 19b Column c (apportioned amount) doesn’t equal the sum of all Schedules K-1, Line W, Column 1.

Solution

  • Go to Tax forms, States, Alabama, 65, and the 65, Page 4 tab.
  • Verify that the amounts for lines 19a and b are correct.
  • Go to Sch K-1, Name, and make that line W is correct for each partner.
  • To fix this line, go to the folder Organizer, States, Alabama, State Adjustments, and Income and Expenses.
  • In the Other section, enter the correct amount for Distribution of cash and marketable securities and Distribution of other property.
  • If you're using special allocations, enter a special allocation code for each of these items by going to Organizer, Partner information, and Partner by Partner Data.
  • Select Allocations, Special Allocations, and Add new special allocation code.
  • Enter the same allocation code as entered for the item you want to allocate. Then, enter an amount for each partner until 100% of the amount has been allocated.

note

If an aggregation file has been used to attach the form NC K-1 at Organizer, States, Alabama, E-File, Attachments, K-1 Aggregation, Summary. The aggregation file needs to be updated and reattached.
