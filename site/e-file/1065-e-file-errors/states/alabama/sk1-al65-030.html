SK1-AL65-030 e-file error

SK1-AL65-030: The total of all K-1s, Line R, Column 1, Other Deductions should equal Schedule K, Line 14, Other Deductions Apportioned Amount.

This happens when the total of all K-1s, Line R, Column 1, Other Deductions amounts don't equal the Schedule K, Line 14, Other Deductions Apportioned amount.

Solution

  • Go to Tax Forms, States, and the Alabama folder.
  • Select Form 65, go to Page 4, Line 14. It needs to be equal to all K-1s, Line R, Column 1, Other Deductions.
  • Go to Tax Forms, States, and the Alabama folder.
  • Go to Sch K-1, and total of all K-1s Line R, Column 1 amount.
  • To update the amount, go to Organizer, States, and the Alabama folder.
  • Select State Adjustments, and go to the Income and Expenses tab.
  • Go to the Deductions section.
  • In Line Other, select Other Deductions.
  • Enter the amounts in the necessary lines.
  • Do a full recompute and recreate the e-file.
