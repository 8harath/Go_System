SK1-AL65-048b e-file error

SK1-AL65-048b: If Electing Pass-Through Entity check box is not selected on Form65 page 1, Then total of all K-1s, Line Z, Composite/Electing Pass-Through Entity Credit, column 1, should equal Schedule K, Line 22, Composite Payment.

This happens when the Electing Pass-Through Entity checkbox is not selected on Form65 page 1, and the total of all K-1s, Line Z, Composite/Electing Pass-Through Entity Credit, column 1, is not equal to Schedule K, Line 22, Composite Payment.

Solution 1

  • Select Organizer, States, Alabama, then the Electing Pass-Through Entity folder.
  • Select General Information, then mark the Generate Electing Pass-Through Entity checkbox.
  • Do a full recompute and recreate the e-file.

Solution 2

Check the values on Schedule K, Line 22 and Schedule-K-1 Part III Line Z.

  • Select Tax Forms, States, then the Alabama folder.
  • Select Form 65, then go to 65, Page 4.
  • Go to the Schedule K section, Line 22. note The Form 65, Page 4, Schedule K section, Line 22 need to equal the total of all Sch K-1s Line Z.
  • Select Tax Forms, States, Alabama, then the Sch K-1 folder.
  • Select a Partner Name, then go to Part III, Line Z Other items and amount.

To change the value for Line Z, do the following:

  • Select Organizer, States, then the Alabama folder.
  • Select State Adjustments, then go to the Income and Expenses tab.
  • Go to the Other section, then select Other Items.
  • In the Other Items Overrides section, enter the Amount and Allocation Code.
  • Do a full recompute and recreate the e-file.
