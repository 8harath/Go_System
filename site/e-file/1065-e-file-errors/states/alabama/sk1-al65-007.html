📍 Alabama (AL) Form e-file AL65-007

SK1-AL65-007 e-file error

SK1-AL65-007: AL Schedule K-1, if DisregardedEntity is checked then Owner's ID must be entered

This happens when partner information is missing.

Solution

Verify which partners are marked disregarded entity.

  • In Organizer, select Partner Information, then Partner by Partner Data.
  • Select Columnar Partner Entity, then the Designations tab.
  • In the Partners' Disregarded Entity Information section, check which partners have column Enter X if Partner is a Disregarded Entity (DE) marked.

  • Either remove the X or enter the Partner Name and TIN:

  • Select the partner’s name in the Partner by Partner Data folder.

  • On the Partner Information tab, enter the Partner Name and TIN.
  • Do a full recompute and recreate the e-file.
