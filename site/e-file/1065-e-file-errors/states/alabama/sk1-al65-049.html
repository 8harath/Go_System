📍 Alabama (AL) Form e-file AL65-049

SK1-AL65-049 e-file error

SK1-AL65-049: AL Schedule K-1 Part III Line Z, the total number of K-1s marked NRC-Exempt should have the same number of Schedule NRCs generated in the XML file.

This happens when NCR exempt checkbox is marked but NRC forms are being included.

Solution 1

If you’re doing a K-1 Aggregation:

  • Select Organizer, then the States folder.
  • Select Alabama then the E-file-Form 65 folder.
  • Select Attachments, K-1 Aggregation, then the Summary folder.
  • Inside the Aggregation file, if the NRCExempt checkbox is marked, then NRC Forms need to be populated in the aggregation file.
  • Once you've updated the aggregation file, remove the existing file and upload the fixed aggregation file.
  • Run a full recompute, then recreate the E-file.

Solution 2

If the K-1 is inside the return:

  • Select Organizer,then the Partner Information folder.
  • Select Partner by Partner, Data, select the partner name, then the Partner Information folder.
  • Go to the State Partner Information tab.
  • Go to the Alabama section and select Include nonresident partner in Schedule NRC.
  • Run a full recompute, then recreate the E-file.
