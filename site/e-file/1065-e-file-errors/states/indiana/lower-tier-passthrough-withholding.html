E-file diagnostic: Lower tier passthrough withholding

In E-File: Lower Tier Passthrough Withholding: For IT 65 page 2 line 8, Indiana Requires IN K-1 in XML format. Add new paying entity information in Organizer / States / Indiana / Lower Tier Pass-Through / Sch IN K1.

This happens when there is an amount on the IT 65 Page 2 line 8, then detail for Lower Tier Pass-Through are required.

Solution

  • In Organizer, select States.
  • Select Indiana, then Lower Tier Pass-Through.
  • Select Sch IN K1.
  • Select Add new paying entity.
  • Add the name and information for the pass-through.
  • Perform a full recompute and recreate the e-file.
