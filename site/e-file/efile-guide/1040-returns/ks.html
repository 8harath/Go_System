State electronic filing details

|

E-file information | Details |

| --- | --- |

Grace period | 5 business days |

|

E-filing mandate | Tax preparers must e-file at least 90% of returns if you are preparing 50 or more. |

|

Accepts state-only filings | No, attach the federal XML created for Federal with a status of "Qualified" or "Accepted" |

|

Return types accepted | Resident Part-year resident Nonresident Amended Estimate payments |

|

Return types not accepted | Extension Local Intangibles return LLC Annual Report |

|

Accepts returns with these conditions | Refund Zero balance Balance due |

|

Direct deposit of refunds | Yes |

|

Accepted forms of payment | Direct debit (EFW) Credit card Online ePayment |

|

Signature requirements | Kansas considers the act of e-filing a signature. No signature required for Online returns. No signature document should be mailed to Kansas. |

|

Drivers license requirements | Optional |

|

Supports PDF attachments | Yes |

|

Tax year(s) supported for e-filing | Current tax year and two prior tax years |

|

Special considerations | See KS-1345 e-file Handbook. You can fax certain forms and schedules that you cannot e-file to 785-296-8989 Attn: Chad Sullivan. |
