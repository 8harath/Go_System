1041 federal electronic filing information

Contact information

If you have specific questions about what you can e-file or about rejections you received, contact the IRS for more information.

Internal Revenue Service

Website: https://www.irs.gov/e-file-providers/e-file-for-tax-professionals

Phone: 866-255-0654

Electronic filing details

|

E-filing information | Details |

| --- | --- |

Grace period | 10 calendar days |

|

E-filing mandate | You'll need to e-file if you're preparing 11 or more returns. Complete Form 8944 with paper return to opt out. |

|

Return types accepted | 1041, Estates and Trusts 5227, Split Interest Trusts Estimate payments Extension Amended |

|

Return types not accepted | 1041-A, Trust Accumulation of Charitable Amounts 1041-QFT, Qualified Funeral Trusts 1040NR, Nonresident Alien Withholding Additional short or amended for same tax year |

|

Accepts returns with these conditions | Refund/credit Zero balance Balance due |

|

Direct deposit of refunds | No, for 1041 Yes, for 1040NR |

|

Accepted forms of payment | Electronic funds withdrawal (EFW) Online e-payment Credit card via Official Payments Website Check |

|

Signature requirements | ERO retains 8453-FE , 8453-TE, 8879-TE or 8879-F for 3 years |

|

Supports PDF attachments | Yes |

|

Tax year(s) supported for e-filing | Current tax year and two prior tax years |

|

Special considerations | None |
