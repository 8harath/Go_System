State electronic filing details

|

E-filing information | Details |

| --- | --- |

Grace period | 5 calendar days to resubmit e-file; 10 calendar days if paper return is filed or e-file cannot be retransmitted. or 5 days for return and extension |

|

E-filing mandate | Yes |

|

Accepts state-only filings | Yes. Attach the federal XML created for this State (Default). Only Federal e-file validation errors have to be cleared. E-file Reject Diagnostics do not have to be cleared |

|

Return types accepted | C Corporation S Corporation Estimate Payments (separate e-file for each payment) Extension |

|

Return types not accepted | Composite Consolidated Corporations filing Form 1120-PC Withholding Returns with 52/53 week years Returns with POA currently in effect for the refund to go to a third party. |

|

Direct deposit of refunds | Yes, but not for amended returns |

|

Accepted forms of payment | Direct debit (not for amended returns) Electronic funds transfer (EFT) Credit card Mailed in check |

|

Signature requirements | ERO retains signed EL101B for 3 years |

|

Supports PDF attachments | Yes |

|

Tax year(s) supported for e-filing | Current tax year and two prior tax years |

|

Special considerations | You must make payments that are $10,000 or more electronically. |
