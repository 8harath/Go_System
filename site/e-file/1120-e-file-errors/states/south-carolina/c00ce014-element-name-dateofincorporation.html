📍 South Carolina (SC) Form e-file

c00ce014 e-file error Element name: DateOfIncorporation

Error

Element 'DateOfIncorporation' is unexpected according to content model of parent element 'SchSC1120D.' Expecting: OutStandingShares, DirectorAndOfficerInfo.

Cause

Officer's name, title, and full address is missing.

Solution

South Carolina requires at least 1 officer with name, title, and full address be included in the e-file.

For combined returns, at least 1 officer's information be entered in each member of the combined group.

  • Go to Organizer, Income and Deductions, Deductions, Officers' Compensation, Individual Officers.
  • Select Add new Officer.
  • Enter an officer name, then select Save.
  • Enter the officer's title and address.
  • Select Federal and Selected States in the Select option to apply officer information section.
  • Find Select States and select South Carolina.
  • Perform a full re-compute, re-create the e-file, then re-submit.

important

If you receive this error for a divisional consolidation, enter the officer's name, title, and address in a division return, then re-consolidate.
