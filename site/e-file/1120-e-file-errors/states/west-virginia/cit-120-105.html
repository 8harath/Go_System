📍 West Virginia (WV) Form e-file

CIT-120-105 e-file error 

If any box in Section 6, Reportable Entities, is marked, then Schedule D must be included in State XML. (Automatic GOTO is not available). Navigation: Tax Form\ States\ West Virginia- CIT-120 Page 7 \ Update Schedule D.

This happens when any of the checkboxes on West Virginia CIT-120 page 1, section 6, is checked and there are no entries for Schedule D at West Virginia CIT-120 page 7 found.

Solution

  • In Organizer, select States, then West Virginia, General Information, then General Information.
  • Go to the Reportable Entities section.
  • If any of the options are selected, go to Organizer and select States, West Virginia, then General Information.
  • Select Reportable Entities and complete Add new Disregarded Entities Include.
  • Perform a full recompute and recreate e-file.

note

If you don't have disregarded entities to add in Reportable Entities, clear the Reportable Entities section in General Information.
