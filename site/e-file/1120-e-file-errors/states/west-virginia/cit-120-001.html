📍 West Virginia (WV) Form e-file IRS1120

E-file diagnostic: CIT-120-001

CIT-120-001: The name of the attachment is case sensitive and must be named IRS1120.pdf or IRSPro1120.pdf both filename and description. Navigation- Organizer\States\West Virginia\E-file\Attachments\PDF Attachments\Summary.

This happens when the PDF attachments IRS1120.pdf or IRSPro1120.pdf are missing.

Solution

  • Go to Organizer, States, then West Virginia.
  • Select E-File, then Attachments.
  • Select Summary, then Attach PDF. This opens the

Electronic Filing Attachments

window. - Select Add. - Select West Virginia as the Attachment Jurisdiction. - Select Browse for file, then attach the PDF named IRS1120.pdf or IRSPro1120.pdf without spaces or special characters. - Do a full recompute and recreate the e-file.
