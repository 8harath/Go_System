Report year: The valid report year on any of the forms can only be 2008-20YY

Report year: The valid year on any of the forms can only be 2008-20YY, except for the Public Information Report (PIR).

This happens when the report year isn't somewhere between 2008 and the current tax year.

Solution

  • Go to Tax Forms, States, and then Texas.
  • Select the applicable Franchise Tax Report: 05-158-A, 05-163, or 05-169. Review the report year.
  • To correct the report year, go to Organizer, State Franchise Tax, Texas Franchise, and then General Information.
  • Change the date.
  • Perform a full re-compute, re-create the e-file, then re-submit.

note

For fiscal year returns with a year ending date after January 4th of the following year, either use the tax application for the following year (if forms are approved) or wait for the latest approved forms to be updated in the current tax application.
