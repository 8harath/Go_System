Texas return invalid security information

Texas return invalid security information: Webfile number or last reported revenue is blank.

This happens when the webfile number or last reported revenue is blank.

Solution

For 1120 returns:

  • Go to Organizer, States, State Franchise Tax, Texas Franchise, and then General Information.
  • Select Paid Preparer Information tab, then go to

Preparer Validation

section. - Enter the Webfile number. The webfile number is mailed to all franchise taxpayers. For questions, contact the state at 800-442-3453. - On the same screen and section, verify that your Total revenue on latest return is populated with a positive amount or NONE. - Perform a full recompute, recreate the e-file, and resubmit.

For 1065 returns:

  • Go to

OrganizerStatesTexas

, - Select General Information, then go to Paid Preparer Information tab. - Go to Preparer Validation section, enter Webfile number. - On the same screen and section, verify that your Total revenue on latest return is populated with a positive amount or NONE. - Do a full Recompute and Recreate the E-file

note

The Webfile number is mailed to all State of Texas Franchise taxpayers, or you may reach out to the state at 1-800-442-3453 for webfile number.
