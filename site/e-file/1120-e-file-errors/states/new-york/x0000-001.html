📍 New York (NY) Form e-file X0000-001

X0000-001 e-file error

Generating the New York Combined Franchise Tax Return CT-3-A e-file also generates a Member’s Detail Report CT-3-A/BC for each subsidiary. The subsidiary e-file submission is NOT automatic. Each CT-3-A/BC MUST be submitted individually.

This happens when CT-3-A/BC in each member is not submitted individually.

Solution

important

New York consolidations require a CT-3-A combined electronic file and separate Form CT-3-A/C electronic files for each subsidiary that is required to pay the fixed dollar minimum tax. The CT-3-A/BC e-files should be submitted at the same time as the NY combined e-file.

  • To resolve this error, ensure that each member is submitted individually and wait until their status is changed to Accepted state.
  • Once each member status has been changed to Accepted status, then you can qualify for the Topcon locator.

  • To qualify each member, go through the following steps.

  • In the member level go to Organizer, General Information folder.

  • Select Basic Return Information.
  • Go to the Entity Information tab in the Return / Entity Type section.
  • Make sure the Entity Type is Single.
  • Recompute and submit the return.
  • Once the E-file status is changed to Accepted consolidate the Topcon.
  • Do a full recompute and recreate the e-file.
