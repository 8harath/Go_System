📍 Idaho (ID) Form e-file ID1005

ID1005 e-file error

XML Error Checking: Rule Number: ID1005 Description: If Form 41, line 50 has value, then form 41ESR is required, attach a PDF with the filename 'Form_41ESR_01.pdf'. To attach a PDF: Navigation Edit Insert EFile attachments.

This happens when there is an amount on form 41, page 2, line 50 and a PDF attachment with the name is not correct.

Solution 1

  • Go to Organizer, then to the States folder.
  • Go to the Idaho, then E-file folder.
  • Go to the Attachments, then Summary folder.
  • Select the Attach PDF button.
  • The file name must be Form_41ESR_01.pdf.
  • If there isn’t an attachment add one with that name.
  • If there is an attachment, delete it, and add a new one with the correct file name.
  • Run a full recompute, then recreate the e-file.

Solution 2

  • Go to Tax Forms, then the States folder.
  • Go to the Idaho, 41 – Tax Return folder.
  • Go to the 41, Page 2 tab.
  • Go to line 50. If there isn't an amount there, then this attachment isn't required and needs to be removed.
  • Run a full recompute, then recreate the e-file.
