9501 and 9982 e-file errors

Reject Code 9501

Message : Non-Federal return being filed, but missing the federal file

Reject Code 9982

Message : Non-Federal return is missing the Federal Account XML comment, FEDERALACCT or State was being checked in, but we could not find a federal file.

This error is caused when you need to attach the Federal Copy to the state return.

Solution

  • In Organizer, go to States then State E-file.
  • Select Enable/Create Returns.

  • On theFederal Copy tab, select an option in column B for Federal Copy for the state you're getting the error for. Some states limit the Federal Copy options you can choose, so make sure your selection creates a qualified federal file.

  • If the state is being filed as a single company from a member of a consolidation, select Attach a federal XML created in a different locator/binder .

  • Verify that the top consolidated locator's information is entered correctly in column G for Federal EIN, column H for Locator Number, and column I for Account Number.

  • If the return files as a single company for both federal and state, verify that the current locator's information is entered.
