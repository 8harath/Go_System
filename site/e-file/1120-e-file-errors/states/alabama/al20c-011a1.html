AL20C-011a(1) e-file error

* AL20C-011a(1): If Tax Forms / States / Alabama / 20C - Tax Return / 20C, Page 1 / "This company files as part of consolidated federal group" is populated then the following must be attached: (1) Federal Form 851, Affiliations Schedule, please identify all corporations subject to tax in Alabama. PDF must be named Federal851.pdf **This rule does not apply to filing status 5**

This happens when On Page 1 of Alabama Form 20C, the option indicating "This company files as part of consolidated federal group" is selected (for example, a checkbox is ticked or a field is populated to affirm this) and the company's filing status is NOT 5.

Solution

  • Go to Organizer, States, and the Alabama folder.
  • Select E-file, Attachments, and Summary.
  • Select Edit, Insert, and E-file attachments.
  • Alabama requires an attachment with the exact file name and description as Federal851.pdf.
  • After attaching, do a full recompute and recreate the e-file.
