HIN35-001-03 e-file error

XML Error Checking:Rule Number: HIN35-001-03Description: If Form N-35, Page 1, Line 21 or Schedule K Lines 1 or 2, column b are present, then a binary attachment with the file name beginning with 'ScheduleK1' must be present.

This happens when form N-35, page 1, line 21, or Schedule K, lines 1 or 2, column B, are present but no e-file attachment attached with the name starting with ScheduleK1.

Solution

  • Go to

OrganizerStatesHawaiiE-file

. - Select Attachments, then PDF Summary. - Select Attach PDF. - Attach the PDF file. The file name must begin with ScheduleK1.

note

The file name should not exceed 23 characters. Spaces and special characters aren't allowed in the file name. - Do a full recompute and recreate the e-file.
