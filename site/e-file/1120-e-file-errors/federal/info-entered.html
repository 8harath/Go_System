E-file diagnostic: Information has been entered in the footnote area

Footnotes: Information has been entered in the Footnote area. This information will NOT be included in the e-filed return. Use the Other Attachment Details screens in the Electronically Filing folder (Step 4) to include this information in the e-file return.

This happens when you have footnotes, and the program lets you know that these footnotes will not be included in the e-file.

Solution 1

You can attach the footnote to the e-file as a PDF.

This is an alert and doesn’t stop you from e-filling the return.

  • If you want the footnote to be attached to the e-file, go to Organizer, then the Federal E-file folder.
  • Go to the PDF Attachments, then Summary folder.
  • Select the Attach PDF and add the footnote you want to attach.
  • Run a full recompute, recreate the e-file.

Solution 2

You can add the information as a new General Dependency.

  • Go to Organizer, then the Federal E-file folder.
  • Go to Attachments, General Dependencies, then the Add General Dependency folder.
  • Select the Add new Description and type in the description.
  • Fill in the information for the dependency.
  • Run a full recompute, recreate the e-file.
