R0000-504-02 e-file error

Error

Each 'DependentSSN' and the corresponding 'DependentNameControlTxt' that has a value in 'DependentDetail' in the return must match the SSN and Name Control in the e-File database. (value #########, rule R0000-504-02)

note

The value represents the Social Security number (SSN) of the dependent causing the rejection.

Cause

The IRS e-file database includes a name control and SSN for each filer. This rejection means that the information sent in the e-file doesn't match what the IRS has in the database. This can happen if you enter the wrong name and/or SSN into GoSystem RS. Otherwise, there are a few possible causes that need to be worked out with the IRS or Social Security administration.

Solution

If there's more than 1 dependent on the return, note the value at the end of the rejection. It will help you find the dependent causing the issue.

  • In the Organizer, select General information, then Basic Return Information.
  • Select Dependents, then Dependent Input.
  • Find the dependent whose SSN was included in the rejection.
  • Check to make sure that the Last name and SSN are correct.
  • If the wrong information was entered, correct it. Then do a Full Recompute and e-file the return.

  • If the information is correct:

  • If the dependent has multiple last names, refer to the Individual Name Control section of Publication 4164 for help on how to enter their last name.

  • Otherwise, advise the taxpayer (or legal representative) to contact the SSA at 800.772.1213 to verify the dependent's last name. If a correction is required, it may take the SSA up to 10 days to notify the IRS after they’ve updated their files. Afterward, an electronic return can be resubmitted.

  • If you're unable to resolve the rejection, you can elect to bypass this error. You need the taxpayer's consent. If you do make this election, certain credits or exemptions may be disallowed, and return processing (including refund disbursement) may be delayed 4-6 weeks by the IRS. To make the election:

  • In the Organizer, select E-file.

  • Select Additional Information, then Imperfect Return.
  • Mark the Imperfect return election checkbox.
