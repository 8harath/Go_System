IA 1040 Reject Code X0000-005

Error

The reject occurs when the secondary name control for spouse which is the first four letters of the last name appears in lower case.

Cause

The reject is when secondary name control for spouse which is the first four letters of the last name appears in lower case.

Solution

Go to Organizer, General Information, Basic Return Information, then Taxpayer Information.

We corrected this error on the 23-3.2T release 3/29/2024.

Recompute the locator before you create the e-file and make sure that the spouse last name control appears in upper case in the XML file before submitting.
