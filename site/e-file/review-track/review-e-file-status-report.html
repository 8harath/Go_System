Review the e-file status report

Use the jurisdiction hyperlink on the e-file Batch Status list to view the Cumulative History report, which details current and past e-file histories.

The E-file Status Report shows the status of e-filed returns and returns not yet ready for e-filing on a return-by-return basis across various stages.

Follow these steps to search for returns and jurisdictions on the E-file Status Report.

  • Select Reports, then E-file Status Report to enter and select your search criteria and options.

  • Make choices for either or both federal and states jurisdictions. Choices include:

  • Ignore Federal or Ignore State: Use this option to refine your search criteria and limit the time and volume of data the Status Report produces.

  • Requested: The taxing authority has acknowledged these jurisdictions but hasn't yet reviewed them.
  • Awaiting Acknowledgment: This option shows you which returns and jurisdictions the system has successfully transmitted to the taxing authority but the authority hasn't yet processed.
  • Conditional Accepted: The taxing authority has accepted the return with conditions.
  • Accepted: Select this option to list the returns and jurisdictions that the taxing authorities have successfully transmitted and accepted.
  • Rejected: Select this option for a list of jurisdictions that you have submitted to the correct taxing authority and that the authority has rejected.
  • Fed rejected - state not processed: If you submit the federal return and state return together, and the taxing authority rejects the federal return, the system won’t process the state return. The following 1040 states require you to file the federal return with the state return: Alabama (residents only), Arizona, Arkansas, Kansas, Michigan (only if federal 8879 is used), Mississippi, Oklahoma.
  • Error - Not Submitted: This status lists returns that encountered errors during the transmission of submitted jurisdictions. The system hasn’t submitted returns with this status to the jurisdiction and you will need to resubmit them.
  • Ready to Send: The report shows qualified jurisdictions not yet submitted when you select this option.
  • Not Ready to Send: This option shows you which returns and jurisdictions still have e-file diagnostics in the return's Organizer, or other disqualifications that prevent successful e-filing.
  • All Statuses (excluding Ready to Send): This option shows you all returns submitted for e-file and the status for each jurisdiction within those returns.

E-file Status Report results:

  • Error Not Submitted: For federal and state jurisdictions, for returns and extensions (all e-file types). This lists the submitted returns that can't complete the submission process.
  • Accepted: Select the link on a listed jurisdiction abbreviation to display the Cumulative History report for the selected jurisdiction.
  • Ready to Send: You can export this report to a PDF or Excel spreadsheet.
  • Not Ready to Send: States only for All Tax Types.
