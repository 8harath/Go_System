View e-file PDFs

Open the e-file viewer to view XML data with detailed line numbers and schema elements, and use the toolbar and bookmark features to review the PDF.

Open the e-file viewer

Select the PDF folder to open the e-file viewer in a separate window. The PDF has detailed line numbers, describes schema elements, and shows XML data and schema element names.

note

The PDF doesn't show XML header information, such as taxpayer and paid preparer information. However, you can verify this information by reviewing the full XML file. To do this, select the file in the PDF folder.

Use the toolbar

Once you open the e-file viewer, you can save or print the PDF file. You have 2 options for saving or printing:

  • Using the PDF toolbar
  • When the PDF file initializes

The toolbar also lets you:

  • Send the PDF file in an email.
  • Access a specific page directly and enter a number in the page field or use the arrows.
  • Find content by entering a word or phrase in the word field.

Use the e-file viewer

When you use the e-file viewer, the PDF grid opens in a separate window, displaying the PDF grid.

Each page of the PDF file shows:

  • Taxpayer's name
  • Employer Identification Number (EIN) or Social Security number (SSN)
  • Timestamp when the PDF was created
  • Page number

The viewer shows all schema elements, regardless of whether they contain data.

This bar includes the schema name, the document ID, and informational text (like the dormant indicator for Form 1040). It shows blue underlined hyperlinks. These links open supplemental schemas that the form calls but doesn't tie to a specific line number.

When schemas offer multiple elements, you can only select one. The system indents descriptions for each choice. For example, for Method of Accounting like “cash,” “accrual,” and “other” might apply, but you can only select 1.

The system shows items that can appear multiple times in consecutive order, with a header marking the beginning of each occurrence. For instance, you can include 2 separate items in Dependent Information.

Hyperlinks take you to supporting details. For example, if line 21 has details for Other Income, its description will include a hyperlink.

Select the hyperlink to view the supporting details. You can include the 1st item in Other Income.

Use the bookmark view

The Bookmark view lists the form and schedule schemas within the PDF file.

  • Select the icon circled in red to open the view.
  • Select each form or schedule schema to go directly to that specific section in the PDF.

  • Select the plus sign next to the file name. This expands the list and shows each file's unique identifier (such as IRS1040SchCN1, IRS1040SchCN2, IRS1040SchCN3).

  • When a form has multiple instances, a plus sign appears next to its file name.

  • A form like Schedule C might have multiple instances. The total number of forms appears in parentheses.
  • The form's initial instance has parentheses, while subsequent instances have "N1" or "N2" at the end.
  • Select the bookmark to go to that specific instance of the form.
